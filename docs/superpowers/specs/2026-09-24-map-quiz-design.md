## 지도 문제 3종 (문제마다 랜덤)

- **A. 단계식 찾기** — "🇫🇷 프랑스를 찾아라!" → 세계지도에서 대륙 탭(+3) → 해당 대륙 확대 → 나라 탭(+7). 대륙 오답이면 정답 대륙이 깜빡이며 확대되고 나라 단계는 계속 진행.
- **B. 바로 찍기** — 세계지도(핀치/휠 줌 가능)에서 나라를 바로 탭(+10). 해당 대륙이 2단계 이상 열린 경우에만 출제.
- **C. 색칠된 나라 맞히기** — 대륙 확대 지도에 한 나라가 칠해져 있고 5지선다로 이름 선택(+10). 오답 보기는 같은 대륙 나라 우선.

한 문제 = 최대 10점 (기존 점수 체계와 동일).

## 학습 장치

1. **정답 후 지도 복습** — 정답 나라 반짝임 + 이웃 나라 이름 2~3개 표시 + 위치 설명 한 줄(105개 나라 수작성, 예: "유럽 서쪽, 스페인 바로 위"). 오답 탭한 나라도 "여긴 ○○예요"로 이름 표시.
2. **내 세계지도** — 플레이어별 숙련도로 색 농도 표시(0 회색, 1 연함, 2 중간, 3 진함 + ⭐). 시작 화면(플레이어 칩 탭)과 결과 화면에서 열람.
3. **틀린 나라 다시 출제** — 나라별 숙련도 0~3: 정답 +1(최대 3), 오답 −1(최소 0). 출제 가중치 = 4 − 숙련도.
4. **대륙 단계 열기** — 대륙마다 105개 나라를 1·2·3단계로 분류(1단계 = 큰 나라·유명 나라). 현재 최고 단계 나라의 80% 이상이 숙련도 2 이상이면 다음 단계 열림. 출제 풀 = 열린 단계 나라들.

## 지도 데이터

- Natural Earth 50m admin-0 (퍼블릭 도메인)을 로컬에서 전처리해 `data/world.json`(TopoJSON)으로 동봉. 속성은 ISO_A2 · 대륙 · 한국어 이름만 남김.
- 렌더링: d3-geo + topojson-client (cdn.jsdelivr.net/npm), SVG.
- 문제 대상 = 기존 105개 나라. 나머지 나라는 회색, 탭하면 이름만 표시(점수 없음).
- 대륙 판정: 문제 나라는 기존 게임의 대륙 값 우선(러시아·튀르키예 = 유럽), 나머지는 Natural Earth 대륙 값.
- 대륙 확대 뷰는 대륙별 고정 경계 상자 사용(러시아 때문에 유럽이 과하게 넓어지지 않게).
- 작은 나라(싱가포르·바하마·통가·사모아·카타르·쿠웨이트 등, 화면 면적 기준)는 원형 터치 영역 추가, 최소 44px.

## 저장 구조 (db)

- 컬렉션 `progress`, 문서 id = 플레이어 key (`dad`/`mom`/`seoi`/`seoha`)
- 문서: `{ m: { "<iso2>": 0..3 }, updatedAt }`
- 문제 하나 끝날 때마다 해당 플레이어 문서 update 1회. 여러 기기가 같은 플레이어로 동시에 하는 경우는 last-writer-wins 허용.
- 기록 저장 조건: 용팀장 계정으로 claude.ai 로그인된 기기. 그 외 기기는 localStorage.
