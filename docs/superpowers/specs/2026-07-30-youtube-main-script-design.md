# youtube-main-script 스킬 설계

> 2026-07-30 브레인스토밍 확정. 용팀장님 승인 완료.

## 목적

시온 PD가 노션에 올리는 유튜브 회차 페이지(기획·도입부)를 읽고,
용팀장 말투로 메인 스크립트 초안을 작성해 같은 페이지의
`메인 스크립트(용팀장님)` 토글에 자동 삽입한다.

## 배경 사실 (2026-07-30 검증)

- 회차 페이지는 시온 PD의 GIGWORKERS 워크스페이스에 있고, 용팀장 계정은 **게스트**.
- 게스트 워크스페이스라 Notion MCP(개인 워크스페이스 연동)로는 접근 불가 — 404 확인.
- **크롬 브라우저(로그인 세션)로 읽기·쓰기 모두 가능** — 26화·24화 페이지로 검증 완료.
- 페이지 템플릿(매 화 동일): `경쟁사(시온) → 기획(시온) → 도입부(시온) → 메인 스크립트(용팀장님) → 업로드 본문(하늘)` 토글 구조.
- 캘린더 DB: `업로드 캘린더` (https://www.notion.so/3375fb6a7cd1807a8e86ef6e2ca4a3f2)

## 확정된 설계 결정

| 항목 | 결정 |
|------|------|
| 접근 경로 | 크롬 브라우저 자동화 단독 (claude-in-chrome) |
| 본론 재료 | 실행 시 인터뷰 — 도입부가 약속한 것을 추출해 3~5개 질문, 용팀장님이 대략적 방향 설명 |
| 출력 | 확인 절차 없이 바로 노션 삽입 + 로컬 백업 항상 저장 |
| 완성본 예시 | 없음 — 말투 가이드 + 기획 뼈대 + 인터뷰로 작성 |
| 분량 | 본편 15분 이상 = 본론 4,500자 이상 (1분 ≈ 300자, 공백 포함) |
| 말투 기준 | OneDrive 원본(`...\00 불사자\01 유튜브\용팀장_말투_포터블_최소본.md`) 우선, 스킬 내장 사본 폴백 |

## 실행 흐름 (6단계)

1. **읽기** — 노션 링크를 크롬으로 열고 토글을 아래→위 순서로 펼쳐
   `기획(시온)` + `도입부(시온)` + `경쟁사(시온)` 텍스트 확보.
   (토글은 위에서부터 펼치면 아래 좌표가 밀리므로 반드시 아래→위)
2. **인터뷰** — 도입부가 시청자에게 약속한 항목을 목록으로 추출한 뒤
   그 약속 기반으로 질문 3~5개 생성 (시연 순서, 보여줄 화면, 노하우, CTA 자료).
   기획에 본론 뼈대가 이미 충분하면 인터뷰 생략 가능.
3. **초안 작성** — 말투 가이드 기준:
   - 도입부 마지막 문장을 이어받는 전환으로 시작
   - 본론(시연 단계별, `[화면: ...]` 지시 포함) → 사회적 증거 → 2차 CTA(중반) → 주의점 → 다음 행동 마무리
   - 작성 후 가이드의 검수 체크리스트로 자체 점검
     (결론 먼저 · 금지표현 · 숫자에 조건 · AI 과장 금지 · "AI 위탁판매" 용어 통일)
4. **노션 삽입** — `메인 스크립트(용팀장님)` 토글 안에 클립보드 붙여넣기
   (PowerShell `Set-Clipboard` → 토글 내부 클릭 → Ctrl+V).
   토글에 기존 내용이 있으면 덮어쓰지 않고 아래에 덧붙인 뒤 보고.
   삽입 후 get_page_text로 실제 반영 확인.
5. **로컬 백업** — `20-operations/22-youtube-scripts/[화수]_메인스크립트_초안.md` 항상 저장.
6. **완료 보고** — 분량 · 삽입 위치 · 백업 경로.

## 에러 처리

- 크롬 미실행/확장 미연결 → 안내 후 중단.
- 토글 구조가 템플릿과 다름 → 스크린샷 확인 후 사용자에게 질문.
- 삽입 실패 → 로컬 백업만 남기고 보고.
- MCP 시도 금지 (게스트 워크스페이스 404 — 시간 낭비).
