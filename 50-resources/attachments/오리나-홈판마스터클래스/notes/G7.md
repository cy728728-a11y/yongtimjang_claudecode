## [17-5] 홈판에 뜨는 "고 퀄리티 AI 이미지 만드는 방법"  (05:04)
**한 줄 요지**: 이미지는 ChatGPT가 직접 뽑지 말고, ChatGPT로 "상세 프롬프트"만 만든 뒤 ImageFX에서 생성해서 썸네일 퀄리티를 올린다.

### 핵심 내용
- 블로그 글쓰기 화면에서 사진을 넣으면 "AI 활용 설정" 체크 항목이 있다. AI가 조금이라도 들어간 사진이면 무조건 체크. 체크해도 불이익 없음. 강사는 이를 "네이버가 AI 콘텐츠를 공식 인정한 신호"로 해석.
- 썸네일 완성도가 "조회수의 절반"이라고 할 만큼 중요.
- 나쁜 방식: "방 청소하는 사람 그려줘" 같은 짧은 요청 -> 수백~수천 명이 같은 요청을 해서 비슷한 이미지만 나옴. 핵심은 디테일.
- ChatGPT로 만든 이미지는 티가 나서(비교 화면에서 한쪽이 GPT 생성물) 쓰지 않는다. ChatGPT는 "사진 생성"이 아니라 "사진용 프롬프트(명령어) 생성"에만 쓴다.
- 좋은 프롬프트 예: "햇빛이 들어오는 방 안 바닥에 먼지가 쌓여 있고, 창문엔 얇은 거미줄. 후드티를 입은 금발의 한국인이 신발을 신고 청소기를 돌리고 있어. 햇빛은 따뜻하지만 방은 여전히 지저분한 느낌."
- 절차:
  1. 강사가 따로 전달하는 "프롬프트 만드는 스크립트"를 ChatGPT에 복사해 넣는다.
  2. 스크립트 안의 '해당 소제목 내용 스크랩' 칸을 지우고 내가 쓸 소제목 내용을 붙여 넣는다.
  3. GPT가 프롬프트를 만들어 주면 복사.
  4. ImageFX 사이트(검색해서 접속, 링크는 강사가 별도 공유)에 붙여 넣는다.
  5. 비율은 썸네일용 "정사각형" 선택 -> 만들기.
  6. 애니 느낌으로 나오면 GPT에 "애니메이션 느낌이 아니라 실제 현실처럼 그려줘"를 추가해 프롬프트 재요청 -> ImageFX 초기화 후 다시 넣고 정사각형 -> 만들기.

### 실행 체크리스트
- [ ] 강사가 별도 전달하는 프롬프트 스크립트 파일/링크 확보 → 확인됨: 강의노트 칸의 한 문장 명령어("…프롬포트 영어로 적어줘 realistic, 4K ultra detailed 스타일 넣어서 적어줘"), ImageFX 주소 labs.google/fx/ko/tools/image-fx (영상 확인)
- [ ] ImageFX 접속 확인(구글 계정 필요 여부는 자막에 없음)
- [ ] 글마다 소제목 내용을 스크립트에 넣어 프롬프트 생성 -> ImageFX 정사각형 생성
- [ ] AI 이미지를 쓴 글은 발행 시 "AI 활용" 체크

### 하지 말 것 / 주의
- ChatGPT 이미지 생성 기능으로 썸네일을 뽑지 않는다.
- 한 줄짜리 막연한 요청 금지.

### 화면 확인 필요 구간
- [00:10 부근] 블로그 에디터의 "AI 활용 설정" 체크 위치
- [01:12 부근] GPT 생성 vs ImageFX 생성 이미지 비교 화면
- [02:15~03:15] 강사의 프롬프트 스크립트 원문(자막에 내용 없음, "따로 전달"), '해당 소제목 내용 스크랩' 칸 위치
- [03:15~04:15] ImageFX 화면(비율 선택, 만들기 버튼)
→ 확인:
- 강의노트 칸 첨부 링크: "ImageFX 사이트". 강의노트 본문 제목 "프롬프트 명령어", 원문: `"해당 소제목 내용 스크랩" 이 내용에 맞게 ai 이미지 생성해볼건데 내가 적어준 내용바탕으로 프롬포트 영어로 적어줘 realistic, 4K ultra detailed 스타일 넣어서 적어줘` — 즉 "따로 전달"하는 스크립트가 이 한 문장이다. 앞의 "해당 소제목 내용 스크랩" 자리를 지우고 소제목 내용을 큰따옴표 안에 붙여 넣는다. (강의노트 칸)
- "AI 활용 설정"은 스마트에디터에서 사진을 넣으면 **사진 오른쪽 아래 모서리에 붙는 토글 스위치**("AI 활용 설정 ●")다. 따로 메뉴를 찾을 필요 없음. (영상 01:06)
- ChatGPT 입력창 예: 한국어 상황 묘사를 큰따옴표로 감싸고 뒤에 위 명령어를 붙여 보낸다. GPT는 영어 프롬프트 + "Realistic, 4K ultra detailed, high-resolution lighting and textures." 로 끝나는 문장을 주고, "필요하면 네거티브 프롬프트도 만들어줄까?"라고 묻는다. (영상 03:25~04:20)
- ImageFX 주소는 labs.google/fx/ko/tools/image-fx. 왼쪽 프롬프트 칸 아래 설정 상자에 **시드**(숫자), **모델 "고품질"**(Imagen 4 기반), **가로세로 비율 "정사각형"** 드롭다운이 있고, 프롬프트 칸 오른쪽 아래 "만들기" 버튼. 결과는 오른쪽에 4장 격자. (영상 03:55~04:00)
- 재요청 후 결과: "Shot on a full-frame DSLR camera, 50mm lens, natural lighting" 같은 사진 표현이 붙은 프롬프트로 실사 느낌 이미지가 나옴. (영상 04:50)

### 자막 오인식 의심
- 특이사항 없음

## [17-6] 이렇게 제목 만드니까 지금까지 못 올라가셨죠..  (04:17)
**한 줄 요지**: 제목에 "정답(금액·결과·원인)"을 넣으면 클릭도 체류도 떨어져 홈판에서 도로 내려간다. 정답 직전에서 끊어라.

### 핵심 내용
- 논리: 제목에 정답이 있으면 클릭 안 함 -> 네이버가 "올려줬는데 클릭 못 이끌어냄" 판단 -> 다시 뒤로 보내 기회를 잃음. 클릭해도 정답만 찾고 나가서 체류시간도 낮아짐.
- 원칙: 제목 = 후킹 + 미완성 질문 구조. 정답은 본문 중간에 등장시킨다.
- 제목 교정 사례(원제목 -> 고친 제목):
  - "1조 몸값 남편 둔 와이프가 입는 옷은 10만 원도 안 한다고?" -> "1조 몸값 남편 둔 와이프 옷장 열어보니 이렇게 검소하다고?" (금액 제거)
  - "민생회복지원금 이번 주까지 신청하면 20만 원 지급" -> "민생회복지원금 이번 주 안에 놓치면 만 원 손해 봅니다" (금액 노출 삭제 + 놓치면 손해라는 긴박감)
  - "손흥민 LAFC 이적 후 연봉이 무려 160억?" -> "손흥민 LAFC 이적 후 토트넘 시절과 연봉 비교해보니" (결과 수치 제거)
  - "똥배 잡은 박소담의 비밀 루틴, 뱃살 다이어트는 장 건강부터래요" -> "…비밀 루틴, 트레이너들도 놀란 이유가 있었다" ("장 건강"이 정답이라 "유산균 먹으라는 거네" 하고 이탈)
  - "피부 좋아진 비결 결국 매일 물 많이 마신 거였대요" -> 정답(물) 삭제 필요(고친 예는 직접 안 나옴)
  - "요즘 연예인들이 다 빠졌다는 다이어트 사실 단식 다이어트였대요" -> "요즘 연예인들이 푹 빠졌다는 다이어트, 헬스장이 아니라 이것 때문"
  - "대기업보다 만족도 높다는 직장 바로 공무원이래요" -> 정답(공무원) 삭제 필요
- 정리 문장: "제목은 클릭 전에 항상 정답 직전에서 끊어야 합니다."

### 실행 체크리스트
- [ ] 제목 완성 후 "이 제목만 보고 답을 알 수 있나?" 점검 -> 금액·수치·원인·결과·정답 단어 제거
- [ ] 정답은 본문 중간에 배치
- [ ] "이것 때문", "~한 이유가 있었다" 같은 미완성 구조로 마무리

### 하지 말 것 / 주의
- 후킹이 좋아도 정답(물 마셨다/단식/공무원/장 건강)을 넣으면 실패.

### 화면 확인 필요 구간
- 없음(전부 말로 설명)

### 자막 오인식 의심
- "똥배"는 원문 그대로(추정: 맞음). "푹 빠졌다는/다 빠졌다는" 혼용은 자막 차이.

## [18-1] 저품질로 홈판 올라가기  (05:25)
**한 줄 요지**: 홈판은 블로그 지수(검색 노출용 체급)와 무관하다. 저품질·준최 블로그도 홈판에서 일 방문자 수만~10만+ 가능하지만, 멘탈상 정상 지수 블로그로 시작하는 게 낫다.

### 핵심 내용
- 네이버는 "블로그 지수는 없다"고 공식 발표했지만 강사는 존재한다고 봄(신규가 10년 된 블로그를 이길 수 없다는 논리).
- 지수 = 검색 노출용 체급. 홈판은 별개 세계. 지수 높다고 홈판 잘 뜨지 않고, 낮다고 못 뜨지 않음. 저품질 블로그도 홈판에서 일 방문자 10만~20만 사례 많음.
- 저품질 판별법: 내 글 제목을 복사해 네이버에 정확히 검색했는데 내 글이 안 뜨면 저품질(검색 노출 불가). 화면 사례: 검색엔 안 뜨는데 조회수는 1만, 9천 -> 홈판 덕.
- 지수 단계: 시작은 대개 "준최2" 단계, 끝은 "최적" 블로그. 최적 블로그는 글을 뭘 써도 검색 상단 노출되지만 이것도 홈판과 무관. 최적은 10~20년 전부터 키운 사람들만 가능하고 지금 시작해선 20~30년 해도 어려움. => "홈판이 없었다면 블로그로 돈 벌기 사실상 불가능했다."
- 강사 본인도 월 2,400만 원 벌 때 "준최6" 상태.
- 예전에 쓰다 만 저품질 블로그로 홈판 해도 되나? "가능하다. 하지만 멘탈이 버티기 어렵다." 이유: 초반 검색 유입 0, 홈판 유입만 소량(하루 몇십~몇백) -> 검색으로 조회수 쭉쭉 느는 다른 사람과 비교되어 흔들림.
- 저품질 블로그밖에 없을 때: 가족·지인 블로그 운영, 단 애드포스트는 계정 주인 계좌로 받고 이체받음. 또는 "홈판만 노린다"는 각오로.
- 홈판도 자체 지수가 있으나 네이버 내부 전용이라 확인 불가(지수 사이트에도 안 나옴). 올바른 방법으로 꾸준히 올리면 어느 날 "홈판 최적화 단계로 툭" 올라가며 그때 터진다. 검색 노출 지수와 홈판 노출 지수는 각각 개별로 존재.

### 실행 체크리스트
- [ ] 내 블로그 최근 글 제목을 네이버에 그대로 검색해 노출 여부 확인(저품질 판별)
- [ ] 정상 지수 블로그 우선, 저품질뿐이면 가족/지인 명의(애드포스트 계좌 주의) 또는 홈판 전용으로 운영
- [ ] 초기 유입이 적어도 비교하지 말고 지속

### 하지 말 것 / 주의
- 지수 올리기에 매달리지 않는다(홈판엔 영향 없음).
- 타인 명의 계정 운영 시 정산 계좌는 계정 주인 것.

### 화면 확인 필요 구간
- [01:12 부근] 제목 검색 시 노출/미노출 비교 화면, 조회수 1만·9천 사례
- [02:12 부근] 준최2 ~ 최적 블로그 지수 구조 화면(지수 사이트 추정)
→ 확인:
- 저품질 판별 시연: 홈판에 뜬 글("비염 원인 해결, 아기 맑은 콧물 관리 방법")의 제목을 복사해 네이버에 검색 → 검색 결과엔 안 뜸. (영상 01:30~01:50)
- 지수 확인 사이트는 **LOWORD(loword.co.kr)** — 상단 메뉴 "블로그 지수" → 네이버 탭에서 블로그 아이디 입력 → 검색하기. 결과 오른쪽 "블로그 지수" 칸에 등급(일반 / 준최 2 / 최적 3+ 등)과 빨강→노랑→파랑→초록 막대가 나온다. 시연: 저품질 블로그는 "일반"(빨간 칸 맨 앞), 시작 단계 예 "준최 2", 끝 단계 예 "최적 3+"(초록 칸 맨 끝). (영상 02:02~03:10)
- 저품질인데도 총 방문자 수천만(예: TOTAL 58,499,432) 블로그 화면을 예시로 보여 줌. (영상 02:16)
- 강의노트 칸: 강의노트 없음.

### 자막 오인식 의심
- "일방 방문자" -> 일 방문자
- "준최2/준최6" = 준최적화 2/6 단계(추정)

## [18-2] 홈판 독학하는 사람들이 모두 실패하는 이유  (03:35)
**한 줄 요지**: 키워드 없는 의문형 제목만 쓰면 네이버가 주제를 인식 못 해 홈판에 못 올라간다. 키워드형과 의문형을 섞되 최적화 전엔 키워드형 비중을 높여라.

### 핵심 내용
- 홈판에 뜬 글들은 정답을 숨긴 키워드 없는 의문형 제목이 많아 보임. 예: "상생 페이백으로 생활비 줄인다는데 혹시 나도 받을 수 있을까?"(키워드 없는 형) vs "상생 페이백…"(키워드 깔끔히 + 후킹), "병원 가기 전 매일 5분만 따라하면 땡땡 예방돼요"(키워드 없음) vs 원래 제목 "손목 터널 증후군…".

## [18-4] 오리나 GPT 제대로 이용하는 방법  (13:41)
**한 줄 요지**: 제목 GPT로 제목을 뽑고 -> 최신 뉴스/블로그 내용을 직접 붙여 넣어 글 GPT에 요청 -> 키워드 5회 확인 -> 내 경험·사진·말투로 마무리한다.

### 핵심 내용
**시연 흐름 (상생 페이백 사용 방법)**
1. 오리나 제목 GPT에 키워드("상생 페이백 사용 방법")를 넣어 제목 후보를 받아 하나 복사. 예: "상생 페이백 사용 방법, 평소처럼 결제했는데 두 번 반응 온 이유 뭐지? 알림이 두 번 왔다".
2. 오리나 홈피드(글 GPT)에 들어가 비밀번호 입력(보안상 매번).
3. 제목 넣고 "제목 그대로 글 적어줘". 정책성 주제는 수시로 바뀌므로, 네이버에서 해당 주제 최신 뉴스·최근 블로그 글을 복사해 "내가 내용 줄게"와 함께 붙여 넣는다. 네이버 에이전트 N 시대라 정확한 정보 주입이 필수. 결과: 시점이 11월이라 "10월·11월 연속 10만 원씩" 같은 최신 내용이 반영됨.
4. GPT가 다른 내용을 따라가느라 키워드 누락이 잦음 -> "키워드는 상생 페이백 사용 방법 5번 이상 자연스럽게 넣어줘" 추가 요청. 서브 키워드도: "상생 페이백 사용처도 자연스럽게 5번". 메인 1 + 서브 1 = 총 2개 키워드 잡기. 서브용으로 제목도 변형(예: "…사용처에서 두 번 반응 온 이유 뭐지?").
5. 모바일 버전으로 글 작성. 제목은 2~3줄까지, 4줄 넘으면 홈판에서 잘림.
6. 템플릿을 미리 만들어 둔다: 제목, 소제목·인용구, 본문 글자크기 등. 강사는 소제목 13크기, "함께 보면 좋은 글"을 처음 1개 + 마지막 2개 구조. 글쓰기 때마다 내 템플릿 불러온 뒤 제목·도입부 붙여 넣기.
7. 편집 팁: 번호·"첫 번째/두 번째" 소제목 숫자는 빼기, 줄바꿈 어색하면 붙이기, 외부 링크(공식 홈페이지 등 다른 플랫폼 이동 링크)는 넣지 않기, 중요한 부분은 색칠하되 한 소제목 문단에서 1~2번까지만(3번이면 어지러움).
8. 경험: 네이버 에이전트 N 시대엔 경험성 글만 생존. 직접 캡처한 이미지를 넣어라. "내가 귀찮은 걸 하는 사람이 디테일을 챙기는 것." 캡처하고 PC로 옮기는 귀찮음이 경험 = 홈판 선정 이유.

**롱테일 사례 (당뇨 초기 증상)**
- 제목 GPT에 롱테일 키워드를 넣어 후보 추출 -> 궁금증형 4번 선택. 고른 제목 후킹 예: "이상 신호 한 가지라도 해당된다면 시작된 겁니다". 정보성 롱테일은 네이버·논문 정보가 많아 추가 내용 없이도 글이 잘 나옴.
- 하지만 인간만 넣을 수 있는 디테일 추가: 도입부를 "계단만 조금 올라가도 숨이 턱 막히는 순간 있지 않으세요?"에서 -> "요즘 치킨을 많이 먹어 한 순간에 10kg 불었다. 헬스장은 멀어서 계단 오르기를 선택했다. 막히더라고요" 식의 본인 경험으로 교체. 모두가 GPT 딸깍을 하므로 차별은 내 디테일.

**실시간 이슈글 사례 (박찬호 두산 이적)**
- 제목 먼저 빠르게: "박찬호 두산 이적 확정. FA 무려 80억? 연봉은 얼마일까?" -> 뉴스 복사해 넣고 글 요청.
- 키워드 처음부터 지정: "메인 키워드 박찬호 FA, 서브 키워드 박찬호 연봉". 처음 결과에서 연봉이 본문에 2번만 나오고 FA도 부족했음.
- 마무리에 개인 감정 추가(예: 기아 유니폼 마킹이 박찬호였는데 아쉽다, 연봉 28억은 기아가 맞춰줄 수 없다, 응원한다) + 연봉 키워드를 자연스럽게 재삽입.
- 오리나 GPT가 글을 일부러 길게 나오게 설정돼 있다. 정보·키워드·핵심이 다 들어갔으면 중간에 끊고 올려도 된다.

## [20-1] 오리나 수강생들만 2026년에 살아남는 이유  (14:34)
**한 줄 요지**: 네이버가 DAN 25에서 후킹 필수·에이전트 N 도입·이웃 중시를 발표했다. 따라서 후킹 제목 + 경험 섞인 글 + 한 분야 전문 블로그 + 하루 이웃 신청 100명으로 대응하라.

### 핵심 내용
**DAN 25(11월 초) 요약**
- 올해 영업이익 5,700억으로 역대 최대(강사: 홈판 덕). 홈판 이용자 하루 1,000만 명, 2월~9월 수직 상승. 네이버는 2년간 홈판 데이터를 모아 성공한 데이터만 더 밀어주겠다.
- 네이버가 "후킹 요소 필요"를 공식 언급 -> 후킹 필수.
- 에이전트 N 도입: 검색 플랫폼에서 AI 플랫폼으로. 사용자 생활을 관찰·학습·대신 실행(식당이면 취향·위치·리뷰·가격 종합 후 예약까지; 런닝이면 근처 초보 코스 추천, 용품은 쇼핑 에이전트 연결, 블로그 후기 요약).
- 결과: 검색 블로그엔 악몽(사용자가 블로그에 들어올 이유 감소), 홈판 블로그엔 기회. 네이버 최수연 대표: AI는 신뢰할 수 있는 원본 데이터만 참고. AI는 파스타를 먹거나 호텔에서 자지 못하니 진짜 경험이 없다 -> 경험·체험·후기 블로그가 차별점(내돈내산 후기, 장비 사용 실험, 실제 수익 인증, 직접 마트 가서 찍은 사진).
- "잡블(여러 주제 섞는 블로그)은 몰락" 전망: 데이터 일관성이 낮아 에이전트 N이 신뢰 안 함. 한 분야를 1년째 파는 블로그가 지속 데이터 소스. 예: 코스트코를 올릴 때 잡블보다 리빙 전문 블로그를 올림.

**제목 GPT (새로 제작)**
- 키워드를 넣으면 제목 20개를 유형별 5개씩: 이득형(도움이 되게), 위협형(안 보면 불안), 궁금증형(관심 없어도 궁금하게), 비교논쟁형(비교 키워드).
- 시연: "혈당 관리 방법" -> "출근길 간식 먹고 혈당 관리 방법 썼는데 수치 떨어져 안도한 이유는?" 선택 -> 오리나 GPT에 "제목 그대로 글 써줘".
- 그래도 인간 디테일 후킹 추가: "점심 직후 혈당 관리 방법 따라했더니 수치 안정 체감돼 한참 바라봤어요"도 좋지만 "나 이제 배달 음식 먹어도 되겠다"처럼 더 구체적으로 손질. 모두가 제목 GPT를 쓰므로 차별은 사람 손질.

**경험 서술 가이드**
- 정보형도 경험 냄새를 넣으면 AI가 참고형 블로그로 인용한다. 정보만 나열은 AI가 대체.
- 변환 예: "2025 청년지원금 신청 방법 총정리" -> "직접 신청해보니 이 부분에서 다들 실수하더라"; "서울 벚꽃 명소 10곳" -> "서울 벚꽃 명소 세 곳 다녀봤는데 사람 적고 예쁜 곳은 여기"; "갤럭시 S25 기능 정리" -> "아이폰 쓰다 갤럭시로 바꿔보니 놀랐던 점 다섯 가지".
- 안 해봤는데 한 척 써도 되나? "거짓 경험을 꾸미는 건 안 된다." 단 사진이 없거나 시간이 지났다고 거짓은 아님. AI가 보는 거짓 후기 = 가지 않았는데 "어제 다녀왔어요", "방금 먹었는데 맛있더라" 같은 현재형 허구 경험. 결제·예약·위치 등 행동 데이터와 대조 시 비정상 판정 가능성(강사 해석). 시간 흐름이 자연스러운 글("작년에 다녀왔는데 사진은 없지만 기억이 선명")은 문제 없음. AI는 사진이 아니라 글 속 맥락·감정·상세 묘사로 신뢰도 평가.
- 링거 예: "어제 병원에서 링거 맞았는데 최고" 대신 "요즘 링거 맞는 분들이 많더라고요. 그래서 상담을 받아봤어요", "지인 중에 맞은 분 후기를 들어봤는데".
- 경험이 부족하면 GPT 프롬프트: "내가 직접 경험을 말하지 않아도 너가 직접 겪은 것처럼 자연스럽게 두 번 이상 경험을 녹여줘. 감정이랑 상황까지 진짜처럼 생생하게 써줘."
- 글이 잘 됐는지의 최종 판단은 본인.

**이웃 전략(핵심 변경)**
- 과거: 남는 시간에 이웃 추가 -> 이제: 하루 신청 최대한도 100명을 무조건. 이웃에서 조회수 1만이 들어오는 시대, "이웃판" 신설, 모바일 블로그 첫 화면에 "OO 님 반가운 이웃 글 보셨나요?"가 먼저 뜸. 유입경로 1위가 "블로그 모바일"(이웃·다른 블로그 타고 들어오는 경로)이며 글 하단에도 "반가운 이웃 글" 노출.

## [21-2] 유튜브 300만 원 강의 노하우가 왜 여기에 있어?  (22:20)
**한 줄 요지**: 해외 원본 영상 찾기 -> 화면 녹화 -> 미리캔버스로 템플릿 이미지 만들기 -> 캡컷에서 템플릿+자막+효과음으로 5분 만에 클립 1개 제작하는 실전 절차.

### 핵심 내용
**1. 원본 영상 찾기**
- 재창작된(자막 입힌) 인기 영상의 링크를 복사해 ChatGPT에: "이 영상에서 사용한 원본 소스를 찾고 싶어. 원본 소스 내용은 ~(예: 1988 서울올림픽 개막식 스카이다이빙 올림픽 로고)인데 영어로 키워드 알려줄래?"
- 받은 영어 키워드를 구글에 검색. 안 나오면 영상 장면 캡처 -> 구글 "이미지로 검색"에 이미지+키워드 함께. 원본 채널명(예: 다이나믹 코리아)을 출처로 사용.
- 원본이 안 찾아질 때: GenSpark(AI 사이트)에 유튜브 링크를 주고 "이 영상의 원본을 찾아줘". 필요 시 "스카이다이빙만 하는 원본 영상을 찾아줘"로 구체화. 무료는 질문 횟수 제한, 클립 제대로 할 거면 유료 권장.

**2. 영상 확보**
- 다운로드: "유튜브 영상 다운로드"/"틱톡 영상 다운로드(워터마크 없이)" 검색 사이트 이용. 
- 화면 녹화: 맥북 Shift+Command+5, 윈도우 Shift+Win+R(윈도우10은 Win+G). 영역 지정 불가한 환경이면 오캠(네이버에서 검색, 옵션>녹화>품질 "매우 높음"). 오캠이 안 맞으면 반디캠(무료는 워터마크, 유료 결제 권장).

**3. 템플릿**
- 템플릿의 장점: 클립도 홈판이므로 클릭 유발. 한 영상에 후킹 문구를 여러 번(영상 상단 제목, 영상 속 자막 등) 넣을 수 있음. 없어도 자막+효과음만으로 조회수는 충분히 나온다(선택). 강사는 템플릿 추천.
- 미리캔버스에서 템플릿 만들기:
  1. 벤치마킹 템플릿을 캡처해 복사.
  2. 디자인 만들기 > 유튜브 > 쇼츠, 동영상 에디터를 디자인 에디터로 전환.
  3. 배경 검은색 -> 캡처 이미지 넣고 불투명도 낮춤 -> 요소 > 도형 > 네모를 영상 영역 크기로 맞춤(이 도형이 영상이 들어갈 틀).
  4. 텍스트(제목 텍스트)로 클립 닉네임 입력(예: "영화 보는 곰" 따라 하기), 흰색/노란색, 크기 맞춤.
  5. 배경 불투명도를 0으로 -> 다운로드(템플릿 완성).
- 캡컷에서: 미디어 > 가져오기로 템플릿 불러 타임라인에 올림. 편집 전 4개 옵션 중 2번째(자동 스냅)와 4번째(미리보기 축) 켜기. 영상 따온 파일을 템플릿 틀 크기에 맞춰 넣음. 템플릿 길이를 영상 끝까지 당겨 맞춤.
- 상단 제목(매 영상 바뀜): 텍스트 복사/붙여넣기로 수정, 강조 단어만 빨강. 하단엔 "출처 OOO 유튜브 채널".
- 재창작 필수: 네이버는 재창작이 없으면 수익 조건을 안 받아줌. 목소리/TTS는 여유 있을 때만, 기본은 상황 설명 자막만("울면서 앉아있는 황정민", "피까지 흘리고 있는" 등). 자막은 복사-붙여넣기로 바꿔 쓰고 끝까지 길이 맞춤.
- 자르기: 위치에 선 맞추고 Ctrl+B(분할, 단축키는 W나 A로 변경 가능), 지우기, 간격 붙이기. Ctrl+Z로 되돌리기.
- 효과음: 오디오 > 사운드 효과, 하트 없는 것은 무료. 자막이 바뀔 때마다 넣기 추천. 효과음이 영상 길이를 넘어가지 않게 맞춤. "자막+효과음으로 완벽한 재창작 -> 수익 승인 확률 높아짐".
- 새 영상 만들 때 캡컷 기록이 남아 있으니 새로 딴 영상을 기존 영상 클립에 붙여넣고 "영상 교체"를 쓰면 크기가 딱 맞음 -> 영상 1개당 약 5분. 제목만 새로(예: "사람을 매달고 빠르게 달리면 생기는 일"), 출처도 해당 채널명으로.
- 세로(쇼츠) 영상: 템플릿을 그대로 쓰되 하단 후킹 영역은 버리고 세로 영상 크기에 맞춰 편집, 출처는 원하는 곳에 삽입(예: "출처 메이저리그").

## [21-3] 클립, 하기만 하면 최소 100만 원 벌 수밖에 없는 이유  (09:20)
**한 줄 요지**: 클립 수익화는 "팔로우 1천 + 조회수 300만"이고, 그 전에도 "클립 크리에이터" 선정 시 월 최소 100만 원(강사 주장) 가능. 주제는 대중적인 것만, 업로드는 전용 앱으로, #클립챌린저 필수.

### 핵심 내용
- 수익화 조건: 팔로워 1,000명 + 조회수 300만. 충족하면 애드포스트처럼 조회수당 수익. 강사는 하루 30분~1시간 투자로 한 달 만에 조회수 300만 달성. 수강생 톡방에서 해결 가능하다고 언급.
- 초반 패턴: 2주간 영상당 조회수 1, 10 수준. 약 3주 꾸준히 올리면 알고리즘을 타서 올릴 때마다 조회수가 터짐. 네이버 클립 하루 이용자 1,000만+로 크리에이터가 필요한 상황.
- 클립 크리에이터 프로그램: 한 달에 영상 10개만 올려도 "최소 100만 원"(강사 주장). 한 달 꾸준히 올리면 약 90% 확률로 선정. 매월 추가 선정(클립 팀이 지켜봄). 선정되면 올해 12월 31일까지 활동, 매달 최소 10만 원 + 추가 업로드 시 2~4만 원씩 추가(자막 설명 간 수치 불일치, 아래 모순 참고).
- 드라마·영화 클립: 처음부터는 저작권으로 삭제. 이미 올리는 사람들은 클립 크리에이터이며 방송사와 저작권 제휴(예: "틈만 나면", "공양간의 셰프들"). 선정 후에야 방송 예능 제작 가능. 처음엔 스포츠·해외 영상으로.
- 상황 설명 자막은 어렵지 않음. 감이 없으면 인기 클립 크리에이터 영상(스포츠·해외유머·드라마)을 "공부 말고 재미로" 보며 따라 하기. 링크는 강의 첨부(자막엔 없음).
- 주제 선정: 애견·맛집·체험단은 수익화 조건 채우기 몇 년 걸림 -> 대중 관심 주제. 추천 순위: 1) 스포츠 2) 해외 유머 3) 해외 일상 영상 4) 해외 자동차 사고·블랙박스. 클립 크리에이터 선정을 위해 한 주제 집중, 스포츠만 할 사람은 스포츠만, 2~4는 섞어도 됨. 요리 등 직접 제작은 시간 낭비.

**대본·후킹**
- 판매할 상품 캡처(영상도 같이 주면 학습에 좋음)를 ChatGPT에 주고 썸네일·후킹 문구·대본 여러 개 요청.
- 학습 방법: 유튜브·인스타에서 조회수 높은 후킹 문구를 캡처해 "떡상했던 제목인데 학습해서 후킹 문구에 적용해줘". 마케팅 자료도 학습시킴. 예시를 그대로 따라 하지 말고 내 스타일로. 대본 길이는 늘려도 좋고 마지막에 "제품이 궁금하면 아래 제품 링크를 클릭해 보세요"를 넣어달라 요청.
- 대본 예: "싱크대 물자국 때문에 매일 닦고 계셨죠? 아무리 깨끗하게 청소해도 설거지 한 번 하면 다시 물이 튀잖아요. 그런데 이런 나노코팅제도 있더라고요…"

**TTS (타입캐스트)**
- 새 프로젝트 > 대본 붙여넣기 > 예상 시간 확인. 타겟에 맞는 목소리 선택(중년층 -> 중년 여성 보이스, 뷰티엔 남성 목소리가 신뢰도 낮음). 너무 처진 목소리는 몰입 저하.
- 속도 1.3~1.4배(원배속은 처짐). 감정(예: "화남")은 유료 기능이라 목소리가 더 잘 들림. 무음 처리 기능이 있으나 시연에서는 껐음. SRT 파일 다운로드(자막용).

**캡컷 편집**
1. 새 프로젝트, 영상 추가, 레이아웃 세로형(9:16).
2. 자막이 박힌 영상은 효과 > 흐리게 + 마스크(직사각형/스트립)로 자막 영역만 블러(자막 제거 프로그램은 오래 걸림). 위에 새 자막을 덮으면 깔끔.
3. 상단 박스: 텍스트의 배경 기능이나 라이브러리의 흰/검정 박스. 후킹 문구 두 줄, 의문형으로 최대한 궁금하게(예: "이거 하나로 싱크대가 달라진다고?"). 글씨체 두껍고 고딕(강사는 코브라 볼드), 중년 타깃이라 크게, 단 클립 UI에서 잘리지 않게 가이드 안쪽에 맞춤, 빨강·노랑 포인트 색, 획·그림자.
4. 원본 영상 음소거, TTS 삽입. 무음 구간은 분할 + 왼쪽 삭제/오른쪽 삭제(단축키: 키보드 설정에서 변경, 강사 분할 W 등), 우클릭 "모든 간격 채우기"로 붙이기.
5. 자막: SRT 파일 가져와 "캡션" 기능으로 목소리에 맞게 분할·수정. 무음 컷 후 싱크 어긋남 -> 직접 맞춤. "모든 주요 캡션에 적용"으로 서식 일괄 적용(강조 시 이 기능 끄고). 공감 부분·CTA("제품이 궁금하시면 …")는 색·크기로 강조.
6. 영상 길이 맞추기: 속도 조절(Ctrl+R 스피드 패널)로 0.97배 등 미세 조정.
7. 효과음: 오디오 > 사운드 효과(영어·중국어 혼재로 찾기 어려워 강사는 자체 효과음 모음을 제공 예정). 말이 끊기는 구간에 넣으면 자연스러움.
- 쇼핑 클립은 유튜브처럼 "재사용 영상 판정" 제약이 지금은 없다(강사 발언). 그래서 편집 쉬움, "지금 무조건 시작".

**날먹 방법: 한 영상으로 계정 3개**
- 타임라인을 복사·붙여넣기해서 3가지 버전 제작: 썸네일 후킹 문구·색상 변경(ChatGPT가 준 여러 후보 활용, 예: "살림 잘하는 집", "싱크대의 비밀"), 대본도 후보 중 다른 것으로 교체, 영상 미러링·밝기 변경으로 다른 영상처럼 만들기(유튜브에서는 다른 영상으로 판독한다고 하며 클립에도 적용해 봤다고 함). 같은 영상 소스로 클립 계정 3개에 올림.

12. **무음 구간 자르기**: 키보드 아이콘 → "숏컷" 창 타임라인 탭에서 **왼쪽 삭제 Q / 오른쪽 삭제 W** 확인(강사는 "분할"을 W로 바꿔 씀). 분할 → 왼쪽 삭제 반복으로 빈 구간 제거 → 빈 곳 **우클릭 → "모든 간격 채우기"**로 한 번에 붙임. 타임라인 도구줄의 자동 스냅·미리보기 축 버튼은 "오리나 마스터클래스 챕터21의 2강 참고". (영상 15:55~17:08)
13. **SRT 자막**: 텍스트 → **"자막 가져오기"(로컬 자막)** → "파일 가져오기"로 쇼핑클립.srt → 타임라인에 문장별 자막이 깔림. 오른쪽 패널 맨 앞 **"캡션" 탭**에서 문장 목록을 보고 끊고 싶은 위치에서 **Enter(또는 + 아이콘)**로 줄을 나눔(예 "싱크대 물자국 때문에" / "매일 닦고 계셨죠?"). 무음을 잘라서 싱크가 어긋나므로 자막 블록 길이를 음성에 맞춰 다시 조정. (영상 17:28~18:45)
14. **모든 주요 캡션 적용**: 자막 하나를 골라 텍스트 탭에서 글꼴(예 "그로테스크" 계열)·색 바꾼 뒤 **기본 탭 맨 위 "모든 주요 캡션에 적용" 체크** → 전체 동일 적용. 특정 문장만 강조(노랑·빨강, 크기 키움)할 땐 이 체크를 끄고 그 자막만 바꿈. CTA("클릭해 보세요!")는 빨간 글씨로 강조. (영상 19:15~20:00)
15. **속도 맞추기**: 영상 클립 선택 → 오른쪽 **"속도" 탭 → 표준**(배속 1.37x 같은 숫자, 지속 시간 칸, "오디오 톤 변경" 토글). 더 쉽게는 **설정 → "스피드 패널 보기"(단축키 Ctrl+R)** → 타임라인 위에 속도 패널이 떠서 클립 끝을 드래그하면 길이에 맞춰 속도 자동 계산(예 0.97). (영상 19:55~20:50)
16. **효과음 메뉴**: 상단 **오디오 → 사운드 효과** → 분류 목록(인기 / ASMR / 박수갈채 / 바이럴 사운드 / 코미디 / 브이로그 / 게임 / 기계 / **즐찾(즐겨찾기)** / 만화 / 동물 / 도시 …) → 항목 오른쪽 + 로 추가. 영어·중국어 이름이 섞여 찾기 어려워 강사가 효과음 모음집(zip) 별도 제공. 말이 끊기는 지점에 넣는다. (영상 21:40~22:20)
17. **3계정 변형**: 타임라인 왼쪽 위 **타임라인 탭(+로 추가)**을 복사해 이름을 "계정 1 / 계정 2 / 계정 3"으로 바꿈("이름 변경" 창). 계정마다 썸네일 문구·색 변경(계정2 "살림 잘하는 집 / 싱크대의 비밀"(파랑 강조), 계정3 "싱크대에 이걸 / 바르는 진짜 이유"(노랑 박스+검은 바탕)). 영상도 변화: **영상 클립 선택 → 오른쪽 "조정" 탭(기본 / HSL / 곡선 / 컬러 휠 / 마스크) → 기본에서 밝기·LUT** 등 조정, **미러링(좌우반전)**은 클립 선택 후 타임라인 도구줄의 반전 버튼으로 적용(정확한 아이콘 클릭 장면은 화면에 짧게만 보임, 추정). 대본도 GPT가 준 다른 안으로 TTS를 새로 만들어 교체. (영상 22:40~23:55)

## 그룹 종합

### 핵심 원리 (이 묶음)
1. **홈판 노출은 블로그 지수와 별개**: 저품질/준최도 가능. 단 초기 성장 체감 때문에 정상 지수 블로그가 유리. 홈판 자체 지수는 비공개이며 꾸준한 운영 후 어느 날 점프.
2. **제목 = 후킹 + 정답 직전에서 끊기**: 금액·결과·원인 제거. 네이버가 후킹 필수라고 DAN 25에서 공식 언급.
3. **키워드는 놓치지 않는다**: 홈판 제목이라도 메인·서브(상품명, +가격 등) 키워드를 본문에 5회 이상 -> 검색·구글·타 블로그 하단 추천 유입. 신규는 키워드형 3 : 의문형 2.
4. **숏테일+롱테일 혼합**: 하루 5포 기준 롱테일 2~3 + 숏테일 3~2. 롱테일은 쉬는 동안 수익을 만드는 자산.
5. **지식판 공략**: 모든 주제에 마음·심리 각도 글(TOP3/특징 4가지)을 하루 5포 중 1개 섞기 -> 홈판+주제판+지식판. 오리나 GPT로 30개씩 주제 생성.
6. **스마트블록 선점**: 글 쓰기 전 스블 확인 -> 스블 키워드를 제목+인용구 1~2개에.
7. **경험이 AI 시대의 생존 조건**: 에이전트 N/AI 브리핑은 직접 체험 블로그 글을 원본 데이터로 사용. 직접 캡처·사진, 경험 문장, 한 분야 전문성, 공지사항에 경험 글 3~4개 고정. 현재형 허구 경험은 금지.
8. **GPT 사용 원칙**: 최신 정보 주입, 키워드 횟수 명시, 도입·마무리에 내 경험, 이미지는 GPT 프롬프트 + ImageFX. 단 개설 초기 대량 발행(1일 10~20포)은 누락 위험. 2개월 차까지 1일 5포·1시간 간격.
9. **이웃이 유입원이 됨**: 하루 100명 서로이웃 신청, 5,000명 한도까지. 뒷삭 정리.
10. **클립 + 다음 홈판 확장**: 출처 필수·재창작·#클립챌린저·전용 앱 업로드. 다음 스튜디오 입점은 신청형(승인 확률 낮음, 반복 신청). 쇼핑 클립은 별도 수익 경로(쇼핑 커넥트 수수료).

### 다른 단원과 이어질 개념/용어
- **홈판**: 네이버 앱 홈 피드(개인 맞춤 추천). **판**: 홈판 내 주제별 영역(경제판, 야구판, 지식판, 이웃판 등).
- **리트리버 로직**: 홈판에서 글을 찾아 사용자에게 물어다 주는 추천 방식(강사 표현). 최적화(주제 인식) 후 모든 글이 올라간다는 맥락.
- **홈판 최적화**: 5~6개월 한 주제 운영 후 네이버가 주제를 인식해 글이 홈판에 올라가는 상태.
- **숏테일/롱테일**: 이슈성·단기 인기 키워드 / 꾸준히 검색되는 키워드.
- **스마트블록(스블)**: 검색 결과 내 키워드별 블록.
- **지식판**: 마음·심리 글 중심 영역(8월 이후 다른 주제도 진입 가능).
- **에이전트 N / AI 브리핑**: 네이버가 내년 도입하는 AI 비서 / 검색 상단 AI 요약. 경험형·전문 블로그 인용.
- **오리나 GPT(올인원 GPT), 제목 GPT**: 강사 제공 글·제목 생성 도구(비밀번호 입력 방식).
- **클립 크리에이터 / #클립챌린저**: 네이버 클립 지원 프로그램과 활동 해시태그.
- **다음 스튜디오 / 루프**: 다음 홈판 입점 채널 / 숏폼 영상.
- **쇼핑 클립 / 쇼핑 커넥트**: 상품 링크를 붙여 판매 수수료를 받는 클립 / 링크 발급 서비스.

### 강의 간 모순점·불일치
- **발행량**: 19-1은 2개월 차까지 1일 5포 이내를 권장하나, 22-2 제안서 예시는 "날마다 최소 6개 글" 언급. 22-1은 월 150~200개(하루 5~6개). 초기 한정 권장인지 일반 기준인지 불명확.
- **키워드 vs 의문형**: 17-6(정답 숨기기), 18-2(최적화 전엔 키워드형 우선, 이후 의문형 비중 확대)와 18-3(항상 키워드 잡기)는 서로 보완되지만 "의문형 키워드 없는 제목"에 대한 입장은 상황별(최적화 전/후)로 달라 헷갈릴 수 있음.
- **경험 문제**: 20-1에서 "거짓 경험 금지"라 하면서 곧바로 GPT에게 "직접 겪은 것처럼 경험 두 번 이상 녹여줘" 프롬프트를 제공 -> 허구 현재형 경험과 이 프롬프트의 경계가 모호. (강사 설명: 시점이 자연스러우면 OK.)
- **클립 크리에이터 수익**: 21-3에서 "한 달 10개 올리면 최소 100만 원"과 "매달 최소 10만 원 + 2~4만 원 추가"가 동시에 나옴. 자막상 수치 일관성 없음(포인트와 활동비 혼재 가능) -> 공식 안내로 재확인 필요.
- **한국 영상**: 21-1의 오리나는 KBO 등 한국 야구 영상을 쓰는 반면, 23-2 서아빠는 쇼핑 클립에서 한국인 영상은 절대 금지. 대상 장르가 달라서 생긴 차이(저작권 vs 쇼핑).
- **저작권**: 21-1은 출처 필수, 야구 40초 이내 프리라 하고, 23-1은 "저작권 무서우면 시작 못 한다"로 상대적 저위험 태도. 서로 다른 수준의 위험 감수.
- **시점**: 20-1의 DAN 25 "11월 초"와 22-1 "입점 승인이 11월이었고 불과 두 달 전, 올해 1월 수익 미정산"은 촬영·편집 시점이 다름(후자는 이듬해 1월 전후로 추정).
- **18-1 vs 19-1**: 홈판은 블로그 지수와 무관하다 했지만 19-1에서 세부 카테고리(코인/주식/부동산)별로 최적화가 다르다고 설명. 지수와 별개의 "홈판 최적화" 개념으로 해석(추정).
- **다음 홈판 수익**: 22-0은 "50만 원이라도", 22-1은 "한 달 70만 원"·"최소 50~100만 원"으로 확신적이나, 22-2는 "승인 확률 높지 않다"로 기대 하향. 수익 주장은 승인 이후 한정.
