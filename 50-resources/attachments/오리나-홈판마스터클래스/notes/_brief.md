# 분석 지시서 (각 워커 공통)

## 배경
- 강의: 프레스런 "네이버 홈판 애드포스트 마스터 클래스" (강사: 오리나). 네이버 블로그 글을 네이버 앱 홈피드(=홈판)에 올려 애드포스트 수익을 내는 법.
- 수강생: 용팀장(구매대행 셀러 겸 강사). 이 강의를 "최대한 잘 파악"하는 게 목표. 요약이 아니라 **실행 가능한 수준의 정밀 학습노트**.
- 원문: `transcripts/NNN_X-Y.md` — Vimeo 한국어 **자동 자막**(오인식 있음). `[mm:ss]`는 1분 단위 위치 표시.

## 할 일
배정된 파일을 **전부 처음부터 끝까지** 읽고, 강의 하나당 아래 형식으로 `notes/<그룹명>.md` 하나에 써라.

```
## [코드] 강의 제목  (길이)
**한 줄 요지**: …
### 핵심 내용
- 강사가 말한 주장·원리·규칙을 빠짐없이. 숫자(조회수·수익·시간·개수·비율·기간)는 그대로 살린다.
- 절차는 번호 목록으로 단계별.
- 강사가 든 사례·예시(어떤 글이 어떻게 떴는지 등)도 남긴다.
### 실행 체크리스트
- [ ] 내가 그대로 따라 할 행동 (구체적으로)
### 하지 말 것 / 주의
### 화면 확인 필요 구간
- [mm:ss 부근] 무엇을 화면으로 보여 주는지("여기 보시면", "이렇게 누르시면", 사이트·GPT·도구·썸네일 예시 등) — 자막만으론 알 수 없는 정보가 무엇인지 적는다. 없으면 "없음".
### 자막 오인식 의심
- 원문 표기 → 추정 (예: "홈 판" → 홈판). 없으면 생략.
```

## 규칙
- 지어내지 마라. 자막에 없는 내용은 쓰지 않는다. 추정은 "(추정)"으로 표시.
- 짧은 직접 인용은 핵심 표현에만(따옴표).
- 홍보·자랑성 말(수익 자랑, 수강 권유)은 한 줄로 줄이고, **방법·기준·수치**에 지면을 쓴다.
- 그룹 파일 맨 끝에 `## 그룹 종합`: 이 묶음의 핵심 원리 5~10개, 다른 단원과 이어질 개념(용어 정의 포함), 강의 간 모순점.
- 다 쓰면 최종 답변으로 "파일 경로 + 강의 수 + 화면확인 필요 구간 목록(파일·시각·무엇)"만 짧게 돌려줘라.
