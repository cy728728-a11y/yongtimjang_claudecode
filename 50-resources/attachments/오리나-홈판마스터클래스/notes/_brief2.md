# 2차 보강 지시서 (전자책 대조)

## 배경
1차에서 강의 자막만 보고 `notes/<그룹>.md` 를 썼다. 이제 강사가 직접 만든 **전자책**(강의 대본 + 영상 화면 캡처 그림)으로 보강한다.
- 전자책 글자: `전자책-원문.md` (쪽 구분 `=== p.N ===`). 자막보다 정확하다(오인식 없음).
- 전자책 쪽 그림: `ebook_pages/pNNN.jpg` (NNN=3자리 쪽 번호). 강의 화면 캡처(도구 화면·메뉴 위치·예시 썸네일·GPT 출력·도식)가 들어 있다.

## 할 일
1. 배정된 쪽 범위의 전자책 글자를 전부 읽는다.
2. 배정된 쪽 그림을 **전부 하나씩 Read 로 직접 본다**(건너뛰지 마라. 장식 그림이면 넘어가되, 화면 캡처·도식·예시는 내용을 글로 옮긴다).
3. 내 그룹 노트(`notes/<그룹>.md`)를 직접 고쳐 쓴다:
   - 자막 오인식을 전자책 표기로 바로잡는다(인명·도구명·숫자).
   - 전자책에만 있는 내용(추가 설명·목록·수치·예시 문장·프롬프트·체크리스트)을 해당 강의 항목에 넣는다. 끝에 "(전자책 p.N)" 표시.
   - "화면 확인 필요 구간" 항목마다 그림에서 확인한 내용을 적는다: 메뉴 경로, 버튼 위치, 설정값, 예시 제목·썸네일 문구, 도식 구조, GPT 출력 형식 등. 그림에서도 확인 못 한 건 "전자책에도 없음"으로 남긴다.
   - 도식·표는 마크다운 표나 목록으로 옮긴다.
4. 그룹 종합도 보강된 내용으로 갱신한다.

## 규칙
- 지어내지 마라. 그림에서 안 보이면 안 보인다고 쓴다.
- 수익 인증 캡처는 금액·기간만 한 줄로.
- 다 쓰면 최종 답변으로 "고친 파일 + 본 그림 수 + 전자책에서 새로 얻은 핵심 5~10개 + 그래도 남은 미확인 항목"만 짧게.
