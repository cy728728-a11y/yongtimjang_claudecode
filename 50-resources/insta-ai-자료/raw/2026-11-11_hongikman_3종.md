## 1. Claude Founder 스킬 설치하고 써보기 (g-f8c76efd8c05, 11/09 릴스 댓글 자료)
- 저장소: https://github.com/Jakeschincariol/founder-skill
- 설치(클로드 코드): `/plugin marketplace add Jakeschincariol/founder-skill` → `/plugin install founder-skill@founder-skill`
- 스킬 11개, 순서: Board → Competitors → Consumer → Pricing → Offer → CFO → Marketing → Brand → Ops → Launch → Plan
  - Board: 3가지 관점 검토(매력·망하는 이유·시작 전 확인할 것)
  - Competitors: 경쟁사·대안 가격·차이·고객 불만
  - Consumer: 가상 구매자 에이전트 여럿으로 누가 사고/망설이고/안 사는지 시뮬레이션
  - Pricing: 수용 가격대·경쟁가·테스트할 가격
  - Offer: 망설이는 이유 기반 구성·혜택 개선 후 재점검
  - CFO: 건당 이익·손익분기·초기자금
  - Marketing: 채널·메시지·광고 아이디어·30일 캠페인
  - Brand / Ops / Launch / Plan
- 입력 양식: 사업 아이디어·상품·예상 고객·고객 문제·지역·가격·비용·궁금한 점. "알려주지 않은 정보는 지어내지 말고 질문 먼저"
- 주의: Consumer 결과는 시뮬레이션. 실제 고객에게 물어볼 질문을 찾는 용도.
