# 설치 — 코덱스 / 헤르메스 (Codex)

소요 시간 5분.

> **코덱스는 클로드 코드의 "스킬 자동 실행" 구조를 그대로 쓰지 않습니다.**
> 그래서 코덱스용은 **작업 폴더에 규칙을 두고, 필요할 때 지목해서 부르는** 방식입니다.
> 하는 일과 규칙은 클로드 코드 버전과 **완전히 동일**합니다.

---

## 1단계. 작업 폴더를 정합니다

상품 작업을 할 폴더를 하나 정합니다. 새로 만들어도 됩니다.

```
예: C:\작업\불사자
```

앞으로 코덱스를 **이 폴더에서** 실행합니다.

## 2단계. 파일을 복사합니다

이 팩의 `codex\` 안에 있는 것들을 **작업 폴더에 그대로** 붙여넣습니다.

```
C:\작업\불사자\
├── AGENTS.md          ← 코덱스가 매번 자동으로 읽는 파일
├── 규칙\
│   ├── 01-실물판별-대표검색어.md
│   ├── 02-상품명-규칙.md
│   └── 03-옵션명-규칙.md
└── prompts\
    ├── 카테고리교정.md
    ├── 상품명.md
    └── 옵션정리.md
```

> **`AGENTS.md` 가 핵심입니다.** 코덱스는 작업 폴더의 `AGENTS.md` 를 자동으로 읽습니다.
> 여기에 "어떤 요청이 오면 어떤 프롬프트를 실행하라"가 적혀 있습니다.
>
> ⚠️ **이미 `AGENTS.md` 가 있는 폴더라면 덮어쓰지 말고**, 기존 파일 맨 아래에
> 이 팩의 `AGENTS.md` 내용을 **이어 붙이세요.**

## 3단계. 슬래시 커맨드로도 쓰고 싶다면 (선택)

매번 파일 이름을 말하기 번거로우면, 프롬프트를 코덱스 프롬프트 폴더에도 복사합니다.

```
%USERPROFILE%\.codex\prompts\
```

여기에 `prompts\` 안의 3개 파일을 복사하면 코덱스에서 `/카테고리교정` 처럼
슬래시로 부를 수 있습니다.

> 폴더가 없으면 만드세요. 이 단계는 **안 해도 됩니다** — 2단계까지만 해도 동작합니다.
> 사용하는 코덱스 버전에 따라 슬래시 커맨드가 지원 안 될 수도 있는데,
> 그때는 4단계의 "직접 지목" 방식을 쓰면 됩니다.

## 4단계. 잘 되는지 확인합니다

작업 폴더에서 코덱스를 실행하고:

```
AGENTS.md 읽고, 네가 할 수 있는 상품 작업 3개가 뭔지 알려줘
```

카테고리 교정 / 상품명 생성 / 옵션 정리 셋을 말하면 완료입니다.

## 5단계. 불사자 MCP 연결 확인 (이게 없으면 아무것도 못 합니다)

```
불사자 MCP 연결됐는지 확인해줘. 내 마켓그룹 목록 보여줘
```

마켓그룹 목록이 나오면 준비 끝입니다.
안 나오면 **코덱스 설정에 불사자 MCP를 먼저 등록**하세요. 이 팩에는 포함돼 있지 않습니다.

---

## 부르는 법

| 방법 | 예 |
|---|---|
| **그냥 말하기** (AGENTS.md가 알아서 연결) | `카테고리 교정해줘` |
| **파일 직접 지목** (가장 확실함) | `prompts/카테고리교정.md 읽고 그대로 실행해줘` |
| **슬래시 커맨드** (3단계를 했다면) | `/카테고리교정` |

**잘 안 붙는 것 같으면 "파일 직접 지목"을 쓰세요.** 이게 제일 확실합니다.

## 잘 안 될 때

| 증상 | 해결 |
|---|---|
| 규칙을 무시하고 대충 함 | `prompts/OOO.md 읽고 그대로 실행해줘` 로 파일을 직접 지목하세요 |
| AGENTS.md를 안 읽는 것 같음 | 코덱스를 **작업 폴더 안에서** 실행했는지 확인 |
| `/카테고리교정` 이 안 먹음 | 3단계를 건너뛰었거나 버전이 지원 안 함. "파일 직접 지목"으로 쓰세요 |
| 한글이 깨져 보임 | 메모장 대신 VS Code 등으로 열어보세요. 파일 자체는 정상입니다 |
