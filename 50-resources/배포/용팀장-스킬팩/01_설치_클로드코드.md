# 설치 — 클로드 코드 (Claude Code)

소요 시간 5분. 명령어를 몰라도 됩니다. **폴더를 복사하는 게 전부입니다.**

---

## 1단계. 스킬 폴더를 찾습니다

파일 탐색기 주소창에 아래를 그대로 붙여넣고 엔터:

```
%USERPROFILE%\.claude\skills
```

> **폴더가 없다는 메시지가 뜨면** — 아직 스킬을 한 번도 안 쓰신 겁니다.
> `%USERPROFILE%\.claude` 로 들어가서 그 안에 **`skills`** 라는 이름의 새 폴더를 만드세요.
>
> 맥(Mac) 사용자는 `~/.claude/skills` 입니다.

## 2단계. 스킬 3개를 복사합니다

이 팩의 `claude-code\skills\` 안에 있는 **폴더 3개**를 통째로 복사해서 붙여넣습니다.

```
category-fix
product-name
option-cleanup
```

붙여넣은 뒤 이런 모양이 되면 성공입니다:

```
%USERPROFILE%\.claude\skills\
├── category-fix\
│   ├── SKILL.md
│   └── references\
│       ├── 실물판별-대표검색어.md
├── product-name\
│   ├── SKILL.md
│   └── references\
│       ├── 상품명-규칙.md
│       └── 실물판별-대표검색어.md
└── option-cleanup\
    ├── SKILL.md
    └── references\
        └── 옵션명-규칙.md
```

> ⚠️ **`SKILL.md` 파일만 복사하면 안 됩니다.** `references` 폴더가 진짜 규칙이 든 곳입니다.
> 폴더 3개를 **통째로** 옮기세요.

## 3단계. 클로드 코드를 껐다 켭니다

이미 클로드 코드가 켜져 있었다면 **완전히 종료 후 다시 실행**합니다.
새로 넣은 스킬은 실행할 때 한 번 읽어들입니다.

## 4단계. 잘 들어갔는지 확인합니다

클로드 코드에서 이렇게 물어보세요:

```
설치된 스킬 목록 보여줘
```

`category-fix`, `product-name`, `option-cleanup` 세 개가 보이면 완료입니다.

---

## 5단계. 불사자 MCP 연결 확인 (이게 없으면 아무것도 못 합니다)

```
불사자 MCP 연결됐는지 확인해줘. 내 마켓그룹 목록 보여줘
```

마켓그룹 목록이 나오면 준비 끝입니다.
안 나오면 **불사자 MCP부터 연결**하세요. 이 팩에는 포함돼 있지 않습니다.

## 잘 안 될 때

| 증상 | 해결 |
|---|---|
| 스킬 목록에 안 뜸 | 클로드 코드를 완전히 종료 후 재실행. 그래도 안 되면 폴더 위치 재확인 |
| "SKILL.md를 찾을 수 없다" | 폴더 안에 폴더가 하나 더 있는지 확인 (`category-fix\category-fix\SKILL.md` 형태면 잘못됨) |
| 한글이 깨져 보임 | 메모장 대신 VS Code 등으로 열어보세요. 파일 자체는 정상입니다 |
| 스킬이 자동 실행 안 됨 | `"카테고리 교정 스킬 써줘"` 처럼 스킬 이름을 직접 말하면 됩니다 |
