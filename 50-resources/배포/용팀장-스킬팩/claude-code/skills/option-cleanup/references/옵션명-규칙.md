# 옵션 정리 규칙 (정본)

## 메인상품 선별

**제외 대상 8분류**:
구매금지·선택금지 안내행 / 사이즈표만 있는 행 / 보증금·배송비·잔금·추가금 /
홍보·이벤트 배너·문의 카드 / 부속품 단독 판매 / 메인상품과 다른 모델·디자인 /
메인상품이 빠진 불완전 구성 / 실제 수령품 확인 불가한 가격 유인.

> **체크돼 있어도, 싸도, 재고 있어도 유지·대표 선택 금지.**
> 반대로 메인상품이 맞으면 **이름이 어색하다는 이유만으로 빼지 않는다.**

**부속품을 미리 손으로 빼지 마라** — 왜 빠졌는지 사유가 남는 경로가 사라진다.
제외는 사유와 함께 기록한다.

## 옵션명의 기준

**중국어 원문이 기준이다.** 저장된 한국어 표시명은 기계번역이라 틀려 있는 경우가 많다 —
그걸 다듬으면 **틀린 채로 다듬게 된다.**

## 옵션명 규칙 17가지

1. **중국어 원문 기준 교정** — 한국어 표시명은 보조 증거
2. **소스 순서 보존** — 원본 옵션 순서를 임의로 바꾸지 않는다(업로드 순서는 별도로 정한다)
3. **공백 포함 25자 이내** — 눈대중 말고 실제로 센다
4. **고객 선택 기준을 앞에** — 색·용량·크기·길이·수량·구성·방식
5. **모든 이름 고유화** — 같은 차원 안에서 서로 달라야 한다
   (`2000mAh 화이트` vs `4500mAh 화이트`)
6. **고유성을 지키는 최단 이름** — 전 옵션이 공유하는 정보는 뺀다
   (6색이 전부 30x45x55cm면 치수는 이름에서 뺀다. 그건 상품명·상세의 몫)
7. **군더더기 제거** — `형` `타입` `제품` `옵션` `상품` `加厚`(전 옵션 공통이면)
   **예외: 규칙 17의 `기본형` 은 군더더기가 아니라 대표옵션 마커다. 지우지 않는다**
8. **치수 압축** — `120×70×90` 형태로
9. **확인된 차별점만** — 원문에 없는 소재·성능을 지어내지 않는다
10. **모델코드 전파 금지** — 소스 내부 코드를 옵션명에 옮기지 않는다
11. **정렬용 접두사 제거** — `H. 블랙 수트` → `블랙 상하세트`.
    단 **실제 사이즈 `S`/`M`/`L`/`XL` 은 보존**한다(접두사가 아니라 값이다)
12. **복합 라벨은 차원별로 각각** — 조합 표시명이 아니라 각 차원의 값 이름을 고친다
13. **깔끔한 한국어** — 번역투(`~용의`, `~적인`) 제거
14. **명명 형식 통일** — 한 상품 안에서 `3층`/`3 레이어`/`3단` 섞지 않는다
15. **최종 판매가 오름차순으로 제시** — 검토표에서 사람이 가격 흐름을 보게
16. **★수식어와 수치어 사이는 띄운다 — 한 상품 안에서 예외 없이**
    `대형 2층` · `넓은바닥 3층` · `3다리 대형 2층`.
    수식어(`대형`·`넓은바닥`·`3다리`)를 수치어(`N층`·`XXXcm`)에 붙여쓰지 않는다.
    **글자를 아끼려고 붙이지 마라** — 25자에 걸릴 때만 줄이고,
    그때도 붙여쓰기가 아니라 **규칙 6(공통 정보 제거)** 으로 줄인다
17. **★대표옵션 이름 끝에 ` 기본형`** — 아래 별도 절

## 규칙 17 — 대표옵션 마커 `기본형`

**네이버는 '대표상품'(추가금 0원인 대표옵션)을 상품명으로 작성하라고 요구한다.**
그래서 **썸네일 = 대표옵션 = 상품명**이 같은 옵션 하나를 지칭해야 한다.

상품명 끝과 대표옵션명 끝에 **같은 단어 `기본형`** 을 붙여 짝을 지목한다.

```
옵션 (선택 1개)              상품명
  블랙 기본형   ← 대표         "…무선청소기 기본형"
  화이트                      ↑ 같은 단어로 짝이 맞는다
  베이지
```

- **대표옵션 = 판매 가능한 메인상품 후보 중 최저가**
- **대표가 아닌 옵션엔 절대 붙이지 않는다.** 마커가 짝을 지목하는 유일한 수단이라,
  둘 이상에 붙으면 상품명이 어느 옵션을 가리키는지 흐려진다.
  판매에서 제외되는 행의 이름에도 붙이지 않는다
- **25자 상한은 그대로다**(규칙 3). 상한을 늘리지 않고 **본문을 줄여 흡수한다** —
  ` 기본형` 이 5자(공백 포함)라 본문은 20자 이내가 된다.
  자리는 **규칙 6(전 옵션이 공유하는 정보 제거)** 으로 만든다.
  **붙여쓰기로 줄이는 것은 규칙 16이 금지한다** (`블랙기본형` ✕ / `블랙 기본형` ○)
- 25자 안에 못 넣겠으면 줄이지 말고 **위반으로 남긴다** — 사람이 판단한다

### 복합옵션 — 마지막 선택 항목에 붙인다

선택 항목이 2개 이상이면 옵션명은 **항목별로** 존재하고 고객이 보는 이름은 그 조합이다.
한 항목 값이 여러 판매 조합에 공유되므로 **어디에 붙여도 대표가 아닌 조합까지 마커가 보인다.**

```
선택1 색상 : 블랙 / 화이트          대표 = 블랙 + 2000mAh (최저가)
선택2 용량 : 2000mAh / 4500mAh

'블랙'에 붙이면 →  블랙 기본형 + 2000mAh  ○
                  블랙 기본형 + 4500mAh  ✕ 대표가 아닌데 마커가 붙는다
```

구조적으로 우회할 수 없다.
**대표 조합의 마지막 선택 항목 값에 붙이고, 오염은 감수한다.**
위 예에서는 `용량 > 2000mAh 기본형`.

**예외 — 마지막 차원 값이 1개뿐이면 자동 저장하지 않는다.**
마지막 선택 항목의 값이 1개면 전 조합이 그 값을 공유한다 → 규칙대로 붙이면 전면 오염.
이 모양은 `보류(기본형 수동판단)` 으로 멈추고 사람이 판단한다.

## 대표·판매범위·순서 (계산 규칙)

1. 메인상품이면서 **팔 수 있는**(가격 있고 재고 있는) 행만 후보
2. **최저가가 대표.** 동률이면 대표 썸네일과 가장 닮은 것 → 그래도 동률이면 원본 순서
3. **대표가 × 1.5 = 판매 상한**(같은 값 포함). 상한 초과는 판매 제외
4. **판매가 오름차순 = 업로드 순서.** 대표는 동가 그룹 안에서 맨 앞
5. **1.5배 상한은 메인상품 후보를 확정한 뒤에만 적용한다** —
   부속품이 섞인 채 계산하면 기준가가 500원이 되어 **본품이 전멸한다**

## 띄어쓰기는 "한 상품 안에서 같은가"로 본다

파일럿에서 실제로 어긋났다. 화분대 23개 중 **`3다리` 가 붙은 것만** 수식어를 붙여썼다.

| | `3다리` 없음 | `3다리` 있음 |
|---|---|---|
| 대형 | `대형 2층 120cm` ✅ 띄움 | `3다리 대형2층 120cm` ❌ 붙임 |
| 넓은바닥 | `넓은바닥 3층 100cm` ✅ 띄움 | `3다리 넓은바닥3층 120cm` ❌ 붙임 |

**25자 제한 때문이 아니었다** — 가장 긴 `3다리 넓은바닥 3층 150cm` 가 18자다.
이름이 길어 보이면 무의식적으로 공백부터 줄인다. 그래서 규칙 16이 필요하다.

교정 후 형식은 하나다: `[3다리 ][대형|넓은바닥 ]N층 XXXcm`

**자기 점검**: 같은 차원의 이름들을 세로로 늘어놓고 **같은 자리에 같은 종류의 토큰이
오는지** 본다. 한 줄만 토큰 경계가 다르면 그 줄이 틀린 것이다.

## 차원이 다르면 같은 이름이 정상이다

복합 옵션에서 `색상 > 블랙` 과 `테두리색 > 블랙` 은 충돌이 아니다.
**중복 검사는 같은 차원 안에서만** 한다.

## 제외되는 옵션의 이름도 고친다

판매에서 빠지는 행도 옵션값으로는 남는다. 이름을 안 고치면 접두사·중국어가 섞인 채
목록에 남는다. 비용이 0이므로 전부 고친다.

## 예시

| 원문 | 기존 한국어 | 정리 후 | 근거 |
|---|---|---|---|
| `橙色 3层 30*45*54CM` | `A. 주황색 3층 30x45x54` | `주황색` | 6색 전부 동일 치수 → 치수 제거(규칙 6) |
| `8寸拉杆锯+不带锯片` | `A. 8인치 레버 톱` | `8인치 톱날 미포함` | 원문의 `不带锯片` 가 진짜 차별점(규칙 1·9) |
| `三腿两层【150厘米长】加厚` | `D. 3다리 두겹 길이 150cm` | `3다리 2층 150cm` | `加厚` 는 전 옵션 공통(규칙 7·14) |
| `三腿大两层【150厘米长】加厚` | `P. 3다리 2층 길이 150cm` | `3다리 대형 2층 150cm` | 위와 이름이 겹쳤다 → `大` 를 살려 고유화(규칙 5). **`대형 2층` 은 띄운다**(규칙 16) |
| `原木色+坐高60+软包坐垫米色布艺` | `E. 로그색 60cm 소프트 백 쿠션` | `원목색 60cm 베이지쿠션` | `原木色`=원목색으로 통일, 번역투 제거(규칙 13·14) |
| `黑色 30*45*54CM`(최저가) | `A. 검정색 30x45x54` | `검정색 기본형` | 치수 제거(규칙 6)로 만든 자리에 대표옵션 마커(규칙 17) |

## 알려진 함정

| 함정 | 왜 |
|---|---|
| 대표 썸네일에 없는 색이 옵션에 있음(또는 반대) | 썸네일이 재고 이미지일 수 있다. 구조로 매칭하고 **썸네일 교체 필요로 기록** |
| 치수가 전 옵션 동일 | 이름에서 뺀다. 고유성은 색·구성이 만든다 |
| 기존 한국어 이름끼리 거의 같음 | **원문을 봐야 다름이 보인다** (`三腿两层` vs `三腿大两层` → '대형'을 넣어 고유화) |
| 상품명이 원문과 다름(8인치인데 '10인치') | 옵션 범위 밖이다. **상품명 재작업 필요로 기록해 넘긴다** |
| 최저가 동률인데 어느 쪽이 대표인지 모름 | 원본 순서로 정하고 **경고한다.** 썸네일과 다른 색이 대표가 될 수 있다 |
