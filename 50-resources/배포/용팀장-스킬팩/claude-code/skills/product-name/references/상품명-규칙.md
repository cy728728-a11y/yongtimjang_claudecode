# 상품명 판단 규칙 (정본)

> 상품 1건씩 순차 처리한다. 여러 상품을 한꺼번에 판단하면 뒤 상품이 앞 상품 결론에 끌려간다.

## 1. 실물 정체를 확정한다

상품명은 실물을 오해시킨다 (`낚시텐트 매트` → 실제는 유아 놀이매트). 정체부터 확정한다.

- **카테고리 교정에서 나온 `실물판정` 이 있으면 그게 실물이다.** 재판정하지 않는다
- 없으면 증거 4종으로 직접 판정한다:
  한국어 상품명(**용의자** — 키워드 나열로 왜곡됨) + **중국어 원문명** + **옵션명**(실제 판매단위) + 썸네일
  → 판정 결과를 `실물판정` 에 반드시 적는다
- **한국어 상품명과 썸네일은 둘 다 가공 후라 같이 틀린다.** 가공 전 원문명·옵션명이 실물을 드러낸다
- **넷 다 봐도 모르겠으면** `보류(실물불명)`. 억지로 찍지 마라

## 2. 카테고리 키워드 목록에서 관련어를 전부 뽑는다 — 여기가 가장 흔한 실패 지점

키워드 도구(아이템스카우트·셀러라이프 등)에서 받은 **그 카테고리의 키워드 목록**을 본다.
컬럼: `키워드 / 상품수 / 월검색량 / 쇼핑성`

- **이 상품과 관련될 만한 항목을 전부 펼친다.** 눈에 띄는 몇 개만 보고 자르지 마라
- 제외: 브랜드·모델명 / 다른 상품 / 원본에서 확인 안 되는 소재·효능·인증
- **쇼핑성이 `-` 인 것은 배제 사유가 아니다** — 실측에서 정답 키워드의 절반이 `-` 였다
- **관련어는 채택 여부와 무관하게 전부 기록한다.** 채택 안 한 것엔 `사유` 를 적는다

## 3. 키워드를 고른다 — 내용어 term 6을 무조건 채운다

**우선순위: ① 상품 적합성(관계없는 키워드 절대 금지) → ② 상품수 낮은 직결어 먼저 → ③ 내용어 6 무조건.**

내용어 6을 이 순서로 채운다 (맨 끝 `기본형` 은 term 수에 세지 않는다):

1. **저상품수 직결어** — 1페이지 노출용 (예 `9칸서랍장` 상품수 3,867)
2. **적합한 대형 키워드** — 저상품수로 모자라면 상품수 높아도 쓴다. 롱테일 검색 조합에 걸린다
3. **실물과 맞는 원본 단어 + 옵션명·원문에서 확인된 단어**
   - 원본 상품명 단어는 대개 관련이 보장된다.
     단 **실물이 정정된 상품은 실물과 어긋나는 원본 단어 금지**
     (자키세트로 판정된 상품의 원본 `받침대` 는 실물에 없다 → 제외)
   - 옵션명·원문에서 확인된 구성·형태·규격은 term 재료로 인정 (`에어펌프`·`전동렌치` 등)
   - **원본에서 가져오는 순서**: `사용목적 > 사용장소 > 구조·구성 > 색상 > 전원·작동방식 > 부가활용`

사용 키워드는 **2~5개**. 원본까지 다 뒤져도 6이 안 되면 4~5로 내보낸다(경고, 실패 아님).

### 쓰면 안 되는 표현

증거(썸네일·원문명·옵션명)에 **명시가 없으면 추측이다. 넣지 마라.**

| | 항목 |
|---|---|
| **써도 되는 것** (증거에서 확인됨) | 상품 종류 · 형태 · 설치방식 · 사용장소 · 색상 · 보이는 구조 · 명시된 전원방식 · 실제 구성품 |
| **쓰면 안 되는 것** (증거에 없으면 = 추측) | 소재 · 규격 · 용량 · 하중 · 성능 · 무선/충전식 · 조립방식 · 인증 · 원산지 · 내구성 · 브랜드 · 과장어 |

> **금지 단어 목록이 아니다.** 원문에 `无线` 가 있으면 `무선` 을 쓰고,
> 옵션명에 `3톤` 이 있으면 규격도 쓴다. **근거가 있으면 쓰고 없으면 안 쓴다**가 규칙이다.

### 단일상품 지칭

상품명은 물건 **한 개**를 가리켜야 한다.
`색상 선택`·`다양한 색상`·`옵션 선택`·`모음` 같이 여러 변형을 묶는 표현은 넣지 마라.
썸네일에 여러 색이 보여도 옵션 근거가 없으면 색상을 생략한다.

### 색상 예외

판매 옵션이 **전부 같은 가격**(= 추가금 0원)이고 색상만 다른 상품이면,
색상을 term으로 채우지 않아도 된다. 대표옵션의 색은 **썸네일이 보여준다.**
색상 **금지**가 아니라 "색상 자리를 다른 내용어에 양보해도 된다"는 허가다.

## 4. 상품명을 조립한다 — 키워드는 원문 그대로, 쪼개지 않는다

> **term** = 네이버 검색의 최소 의미 단위(어절). 같은 term이 2번 들어가도 **term count는 1**.
> `시럽통` 처럼 한 덩어리로 자연스러운 단어는 1 term.
> 예: `소스디스펜서업소용` → 소스/디스펜서/업소용 = term 3

**네이버는 검색어가 상품명에 연속 문자열 그대로 있을 때 적합도 만점을 준다. 쪼개 재배열하면 0이 된다.**

### 배치 순서는 `a 1 b 2 c` — 원본 단어와 키워드를 번갈아 놓는다

원본 상품명 단어를 `a·b·c`, 채택 키워드를 `1·2` 라 하면 자리는 이렇게 정해져 있다:

```
a  1  b  2  c        예) 탕면기 스파게티냄비 우동 면삶는냄비 업소용
↑     ↑     ↑           a=탕면기  b=우동  c=업소용
원본 단어가 키워드 사이를 메운다
```

- **`a·b·c` 는 실물 직결어 우선 순서.** 실물을 정확히 지칭하는 단어가 `a`,
  약한 활용·수식 표현일수록 뒤(`c`)로 간다
- **자리가 모자라면 `c → b → a` 순으로 지운다. 키워드는 절대 자르지 않는다**
- 키워드가 3개 이상이면 계속 번갈아: `a 1 b 2 c 3`
- 쓸 만한 원본 단어가 하나도 없으면 키워드만 이어 붙인다

```
✗ 스파게티냄비 면삶는냄비 업소용 뜰채 깊은   ← 키워드를 앞에 몰고 원본을 뒤에 붙였다
✓ 탕면기 스파게티냄비 우동 면삶는냄비        ← 실물 직결어(탕면기·우동)가 앞자리를 지킨다
```

> **왜**: 키워드를 앞에 몰면 실물을 지칭하는 원본 직결어가 꼬리로 밀리고, 그 자리부터 잘려 나간다.
> 실측 사례에서 `탕면기·우동·스테인레스` 가 전부 사라지고
> 실물과 가장 먼 `스파게티냄비` 가 1번 자리를 먹었다.
> 번갈아 놓으면 두 종류가 같은 속도로 잘려 실물 지칭이 끝까지 남는다.

### 조립 절차

1. **상품수 낮은 키워드부터 원문 그대로** 위 자리에 끼워 넣는다.
   공유 term 1종인 쌍을 고른다 → `업소용 이발의자 높이조절 전동미용의자` ('의자' 2회 = 1종 2회 ✓)

2. **term 2종 이상을 공유하는 키워드 쌍은 둘 다 통으로 못 넣는다 → 부분 반영한다.**
   (예 `조립식캐노피천막` + `자바라캐노피천막` = '캐노피'·'천막' 2종 공유)
   - **상품수 낮은 쪽만 통 키워드(연속 문자열 = 적합도 만점)로 쓴다**
   - **높은 쪽에서는 공유하지 않는 '구별 term' 1개만** 뽑아 붙인다
   - 결과적으로 같은 term이 2회 나오지 않게 만든다. 두 키워드는 키워드 칸에는 다 남긴다
   ```
   조립식캐노피천막(21,172) < 자바라캐노피천막(29,665)
     → "자바라 조립식캐노피천막"  (자바라=구별 term, 캐노피·천막 각 1회)
     → 남는 자리는 실물 확인 단어로 내용어 6 → "자바라 조립식캐노피천막 원터치 접이식"
     → 맨 끝에 마커 → "자바라 조립식캐노피천막 원터치 접이식 기본형"
   ```
   같은 원리: 자동비누방울머신 + 자동버블머신 → 앞쪽 통 + '버블'만

3. 원본 상품명 단어를 `a`(첫 자리)부터 끼워 **내용어 6까지** 채운다
4. **맨 끝에 `기본형` 을 붙인다**
5. `term분해` 는 등장 순서대로 전부 나열(중복 포함) + **마지막이 `기본형`**
   → `[업소용,이발,의자,높이조절,전동,미용,의자,기본형]`

- **중복 term은 1종·2회까지만.** 3회 이상 또는 2종 이상이면 순위 하락
- **내용어 7 이상은 패널티 구간. 넘지 마라.** 옵션명은 상품명 term에 넣지 않는다
- 6을 넘겨 빼야 하면 **뒤 자리(`c` → `b` → `a`)부터** 지운다.
  **고른 키워드는 마지막까지 보존**(쪼개거나 순서를 바꾸면 적합도 0)

## 5. `기본형` 은 왜 붙이나 — 대표옵션 마커

**네이버는 '대표상품'(추가금 0원인 대표옵션)을 상품명으로 작성하라고 요구한다.**
그래서 **썸네일 = 대표옵션 = 상품명**이 같은 옵션 하나를 지칭해야 한다.

```
옵션 (선택 1개)              상품명
  블랙 기본형   ← 대표         "…전동미용의자 업소용 높이조절 기본형"
  화이트                      ↑ 같은 단어로 짝이 맞는다
```

옵션 정리 작업이 대표옵션명 끝에도 같은 `기본형` 을 붙인다.
**상품명 쪽은 대표옵션이 무엇인지 몰라도 된다 — 무조건 맨 끝에 붙이면 된다.**

- `기본형` 은 모든 상품명에 붙는 고정 접미어라 **변별력이 0 → term 수에 세지 않는다.**
  내용어 예산은 그대로 6개 다 쓴다
- 그래도 `term분해` 에는 **마지막 원소로 반드시 넣는다**
- **딱 1번만.** 2번 나오면 어느 쪽이 마커인지 알 수 없어 짝이 흐려진다
- 상품명 본문에 `기본형` 을 쓰지 마라(같은 이유)

## 6. 반증 — 생략 불가

상품명을 다 만든 뒤, 각 상품마다 스스로 되묻는다:

> **채택한 키워드보다 상품수가 낮으면서 같은 범주어를 쓰는 후보가 목록에 있었나?**

- 있고 그게 더 적합하면 → **지목하고 상품명을 다시 만든다**
- 없으면 → `반증: 없음` + 한 줄 이유

> 파일럿의 실패는 규칙 위반이 아니었다(형식 검증은 다 통과했다).
> **후보를 다 안 보고 스스로 잘라 찍은 것**이었다.
> "자릿수 2개 낮은 키워드를 놔두고 비싼 걸 골랐다"를 잡는 게 이 단계다.

## 7. 밀린 키워드는 버리지 말고 속성·태그로

내용어 6 상한에 밀려 상품명에 못 넣은 것은 버리지 마라.
**속성은 경쟁을 자릿수로 깎는다** (실증: `접이식 책상` 131만 → 가로사이즈 속성 2,900 → 소재까지 495).

- `속성제안` = 규격·사이즈·소재 등 **증거에서 확인된 것만**
- `태그제안` = 검증됐지만 상한에 밀린 키워드 **원문 그대로**
- 자동 반영 경로는 없다. **스마트스토어 센터에서 직접 입력한다**

## 8. 보류는 사유에 따라 세 가지로 나눈다

| 상태 | 조건 | 다음 |
|---|---|---|
| `보류(실물불명)` | 증거 4종으로도 실물 불명 | 이미지 더 보고 재판정 |
| `보류(카테고리의심)` | 실물은 아는데 목록에 직결어가 **하나도** 없음 | **카테고리부터 재교정** |
| `보류(키워드부족)` | 직결어는 있으나 2개를 못 채움 | 상품수 계단 확장 / 상위 카테고리 |

> **직결어가 하나도 없는 상품은 대부분 "상품명 문제"가 아니라 "카테고리 문제"다.**
> 억지로 원본 단어로만 상품명을 만들지 마라.

## 검증 체크리스트 (반영 전 자가 점검)

| | 규칙 | 실패 조건 |
|---|---|---|
| R1 | term 분해가 상품명을 정확히 분할 | 이어붙인 게 상품명(공백제거)과 다름 |
| R2 | 고유 **내용어** term 수 4~6 (목표 6) | 3 이하 또는 7 이상. 4~5는 통과+경고 |
| R3 | 중복 term 1종·2회 (마커 제외) | 2종 이상 중복 / 같은 term 3회 이상 |
| R4 | 사용 키워드 2~5개 | 1개 이하 / 6개 이상 / 키워드 중복 |
| R5 | **적합도** — 키워드가 상품명에 **연속 문자열 그대로** | 어느 키워드도 그대로 없으면 실패 |
| R6 | 관련어 목록·반증 답변이 존재 | 둘 중 하나라도 비면 실패 |
| R7 | 채택보다 싼 관련어에 사유가 존재 | 채택 최저 상품수보다 낮은 관련어에 사유가 빔 |
| R8 | 끝이 `기본형`, 딱 1번, term분해 마지막 원소 | 안 끝남 / 2번 이상 / 마지막이 아님 |
| R9 | 원본 단어와 키워드가 `a 1 b 2 c` 로 번갈아 | 키워드끼리 붙은 뒤에 원본 단어가 남아 있음 |

**R6·R7은 산술이 아니라 절차 검증이다.** 형식만 맞고 판단이 게으른 경우를 잡는다.
