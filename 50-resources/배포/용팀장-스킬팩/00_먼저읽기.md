# 용팀장 스킬팩 — 먼저 읽기

구매대행 상품 작업 3종을 AI에게 시키는 **규칙 묶음**입니다.

| 스킬 | 하는 일 |
|---|---|
| **카테고리 교정** | 상품의 실물 정체를 증거로 판별 → 맞는 네이버 카테고리 찾기 |
| **상품명 생성** | 그 카테고리의 키워드로 상위노출용 네이버 상품명 짓기 |
| **옵션 정리** | 안 파는 옵션 빼고, 옵션명 다듬고, 대표옵션·판매범위 정하기 |

**순서가 있습니다: 카테고리 → 상품명 → 옵션.**
카테고리가 틀리면 키워드도 상품명도 전부 틀린 모집단에서 나옵니다.

---

## 어느 폴더를 쓰나

본인이 쓰는 도구에 맞는 폴더 **하나만** 쓰면 됩니다.

| 쓰는 도구 | 폴더 | 설치법 |
|---|---|---|
| **클로드 코드** (Claude Code) | `claude-code/` | [01_설치_클로드코드.md](01_설치_클로드코드.md) |
| **코덱스 / 헤르메스** (Codex) | `codex/` | [02_설치_코덱스.md](02_설치_코덱스.md) |

설치가 끝나면 **[03_사용법.md](03_사용법.md)** 로 갑니다. 사용법은 두 도구 공통입니다.

---

## 필요한 것

| | 필수 여부 | 설명 |
|---|---|---|
| 클로드 코드 **또는** 코덱스 | 필수 | 둘 중 하나 |
| **불사자 MCP 연결** | 필수 | 상품 정보를 읽고 저장하는 통로. 없으면 아무것도 못 함 |
| 셀하(sellha.kr) 계정 | 카테고리 교정에 권장 | 없으면 네이버 검색으로 대체 (정확도 떨어짐) |
| 키워드 도구 export 파일 | 상품명에 필요 | 아이템스카우트·셀러라이프 등에서 받은 카테고리 키워드 목록 |

불사자 MCP 연결법은 불사자 쪽 안내를 따르세요. 이 팩에 포함돼 있지 않습니다.

---

## 이 팩이 하지 않는 것 (미리 알고 시작하세요)

- **자동 대량처리를 하지 않습니다.** 한 번에 5~30건 정도를 대화로 처리하는 구조입니다.
  수백 건을 자동으로 도는 버전은 별도 스크립트·서버 세팅이 필요해서 이 팩에 넣지 않았습니다.
- **구글 스프레드시트에 기록하지 않습니다.** 작업 기록은 여러분 PC의 CSV 파일로 남습니다.
- **저장 전에 항상 표로 보여주고 여러분 승인을 받습니다.** AI가 마음대로 상품을 바꾸지 않습니다.

## 안전 수칙 3가지

1. **처음엔 무조건 3~5건으로 테스트하세요.** 결과가 납득되면 늘립니다.
2. **저장(반영) 전 표를 반드시 눈으로 보세요.** "네 해줘"를 습관적으로 누르지 마세요.
3. **옵션 정리는 매출에 직결됩니다.** 무엇을 팔고 안 팔지, 대표가격이 얼마인지를 바꿉니다.
   가장 마지막에, 가장 천천히 하세요.
