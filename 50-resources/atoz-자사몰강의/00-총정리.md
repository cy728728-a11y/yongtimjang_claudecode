## 1. 한 줄 요약

**"마진 2만 원 남는 상품을 노출(눈) 기준으로 골라, 재고 없이 AI 영상 소재로 메타 광고를 일주일 돌려 보고, 지표가 좋으면 발주·브랜딩한다."**
세팅은 단순하게(캠페인 1개·세트 1개·소재 여러 개), 승부는 소재와 7일 단위 성과분석.

## 2. 강사가 말하는 매출 구조

- **기획(소싱·판매기획·브랜드) 60% / 광고 소재 20% / 성과분석 20%** (4-1에선 기획·마진 60 / 상세·리뷰 전환 20 / 메타 20)
- 앞단(팔리는 구조)이 안 돼 있으면 메타 광고를 아무리 잘해도 안 나온다.
- 대행사는 7곳 써서 다 실패 → **대표가 직접 메타 광고를 운용할 줄 알아야 한다.**
- 답안지는 **메타 광고 라이브러리**에 있다. 경쟁사 소재·세팅을 계속 보고 "빈틈"을 찾는다(따라 하기 X).

## 3. 단계별 흐름 (멘토 워크플로우 6단계와 맞춤)

### ① 온보딩 — 카페24 + 메타 계정 (01-온보딩.md)
- **카페24 순서**: 결제(PG) 심사부터 먼저 넣고(영업일 3~5일, 영상은 "일주일 안") → 기다리는 동안 도메인·약관·검색엔진 등록·스킨·주문/배송/결제 설정 → 네이버 로그인·네이버페이·카카오싱크·톡체크아웃·알림톡. **이틀이면 끝.**
- 함정: **카드결제 월 정산 한도 1천만 원**(넘으면 보증보험, 2주 이상), **.shop/.store 550원은 첫해만**.
- 비용: 유료 스킨 1회 약 25만 원(강사는 '웹퍼블릭'), 도메인 연 2만 원대, 리뷰 앱 월 19,900원~(자료엔 약 3만 원), 무통장 자동입금 월 약 1만 원, 1초 회원가입 월 5~6만 원, 알림톡 2,000건 4만 원.
- **메타 계정 안전수칙**: 오래된 개인 페이스북 아이디 사용 / 전체 권한 가족 1명 미리 초대(계정 막힘 대비) / 메타 전용 크롬 프로필 / 2차 인증, 하루 1회 이내 / 피싱 DM 무시 / 광고비는 비자·마스터 카드만(간편결제 X) / 사업자번호 넣어 부가세 안 내게.
- 비즈니스 포트폴리오에 자산 5개: **페이지 → 광고계정 → 인스타 → 픽셀 → 도메인**. 신규 아이디면 2~3일 간격으로 천천히.
- 포트폴리오 명의(부모님 등)와 자사몰·카드·인스타·사업자(내 것)는 달라도 된다 → 그래서 광고 계정 구매(약 30~50만 원)도 가능하다(1-3).

### ② 상품 고르기 (02-제품선정-소싱.md)
- **키워드(검색량) 소싱 습관을 버리고 "노출 기반"**: 릴스 넘기다 손가락이 멈추고 누를 만한, 설명 필요 없는 직관적인 상품 + 비교 없이 충동구매하게 만드는 마케팅 소구(1+1, 타임세일, 무배 29,800원 등).
- 발견 채널: 쿠팡(1순위, 시크릿 모드), 인스타(관심 카테고리 전용 계정 일주일 키우기), 도매꾹, 테무, 알리, 1688, 오늘의집·지그재그.
- 수요 추정: **쿠팡 리뷰 1개 ≈ 구매 20건**(네이버 ×10), 최신순으로 최근 며칠 리뷰 세기. 예) 지압 슬리퍼 3일 리뷰 60개 → 하루 약 400개.
- 공급: 메타 광고 라이브러리에서 같은 상품 소재 수·업체 수 확인 → 경쟁이 사실상 1곳이면 기회.
- **자사몰 = 같은 관심사의 전문몰** (자사몰 1개당 픽셀 1개). 모자 다음 가방 OK, 모자 다음 인덕션 X.
- 5~6만 원 넘는 고관여 상품은 충동구매가 어려워 따로 차별화가 필요하다.

### 마진계산표 (자료6종/ATOZ-마진계산표.xlsx)
| 칸 | 계산 | 예시 |
|---|---|---|
| 원가(원) | 1688 위안 × **300** (배송·통관 다 포함한 대략 배수, 본발주 후 실제 총비용÷수량으로 다시 잡음) | 27위안 → 8,100원 |
| 1차 마진 | 판매가(택배비 포함) × 0.97(결제수수료 3%) − 원가 − 물류비 3,200 | 34,900 → 22,553 |
| 최종 마진 | 1차 마진 − 부가세(1차 마진 ÷ 11) | 20,503 (마진율 58.7%) |
| 손익분기 ROAS | 판매가 ÷ 최종 마진 | 170% |
| ROAS별 마진율 | 마진율 − 1.04 ÷ ROAS (1.04는 영상에 설명 없음, 광고비에 붙는 약 4% 추가비용으로 추정) | ROAS 250% → 17%, 300% → 24% |

- 59,700원 칸은 원가율 계산에만 쓰임(정가로 추정, 영상에 설명 없음).
- **월 목표 역산**: 순수익 500만 ÷ 마진율 20% = 월매출 2,500만 → ÷ ROAS 2.5 = 월 광고비 1,000만 → **일 예산 약 30만 원.**

### 발주 (1688)
- 배대지(강사는 가장 싼 '정직닷컴'), 구매대행(수수료 약 3%)보다 배송대행이 쌈. 소량은 LCL 해운.
- **원산지(Made in China) 표기**가 핵심 리스크 → 생산 전에 알리왕왕으로 공장에 요청(보통 무료). 중국어 문장은 자료6종/알리왕왕 대화 스킬.
- 리드타임 약 2주, 넉넉히 3주. 원산지증명서(33,000원)로 FTA 관세 감면. 테스트 통과 후 본발주 약 50개부터.
- 강사는 **샘플·재고 없이 광고부터 7일** 돌려 본다(도매꾹 상품으로 바로 테스트 → 되면 사입).

### ③ 자사몰 완성 · 상품등록 (03-자사몰완성-상품등록.md)
- **브랜드명 먼저**(로고가 디자인에 들어가니까). ChatGPT에 제품·소구를 자세히 쓰고 "브랜드명 10개 + 이유" → **키프리스 상표 검색 + 네이버·구글 검색**으로 아무것도 안 나오는 이름. 일반명사형 이름은 상표 등록 불가.
- 이미지(로고·배너·소재·상세)는 지금 ChatGPT 이미지가 최강.
- 디자인: 유료 스킨 매뉴얼 보며 **필요 없는 것 끄기**가 전부. **페이지 속도가 생명**(무거운 이미지·팝업 빼기, PageSpeed Insights로 확인).
- 상품 페이지: 위쪽은 마케팅 소구(할인·타임세일·사은품·추가구성·리뷰 수), **리뷰를 상세보다 먼저**, 상세는 사진 위주로 간단히, 맨 끝 교환·반품 안내.
- 강사 말: "제 자사몰은 거지같이 만들었는데도 엄청 팔린다" — 자사몰은 비교 구조가 아니라서 예쁠 필요 없다.
- 상품등록은 기존 상품 **복사 → 수정**. "진열 안 함 + 판매함" = 링크로만 들어오는 **비밀 링크**.
- **리뷰(3-3)**: 리뷰에이드 앱(19,900원 요금제) > 리뷰 업로드 탭에서 엑셀 양식으로 한 번에 업로드("한 번에 1만 개도 박을 수 있다" — OT). 엑셀 내용(작성일·앞 두 글자만 보이는 이름·별점 평균 4.8·본문)은 GPT로 만들고, 타사 리뷰를 가져와 실제 리뷰처럼 바꿔 쓰게 한다. 리뷰 사진은 이미지 호스팅 링크 필요(ESM PLUS 무료 호스팅). 올라온 리뷰는 "게시 안 함" 상태라 좋은 포토리뷰를 골라 "게시함"으로.
- **매일 관리 3가지**: 무통장 입금 확인 / 문의 답변·리뷰 게시 관리 / 문자·알림톡 충전.

### ④ 메타 광고 소재 (04-메타광고.md 4-1~4-3, 05-보충강의.md 5-6)
- 안드로메다(2025년 말) 이후 **사람이 타겟을 고르는 시대는 끝, 소재를 다양하게 만드는 게 핵심.**
- 소재 설계: 아무 생각 없이 릴스 넘기는 사람이 **① 멈추게(첫 3초 후킹·직관적 화면) ② 누르게(감정·혜택)**.
- 다양화 축: **형태(UGC·독백·ASMR·브이로그) × 상황 × 제품 소구 × 마무리 문구(CTA)**.
- 도구: 자료6종/Flow 프롬프트로 10초 영상 시나리오 10개 → 구글 Flow로 생성(월 29,000원 = 1,000크레딧, 영상 1개 15크레딧) → Vrew 자동 자막 → 미리캔버스로 **1:1(1080×1080)과 9:16(1080×1920) 두 버전**. 글자는 세이프존 안에.
- 막히는 유형: 소재에 너무 공들여 테스트를 못 하는 사람 / 빨리 만들지만 첫 3초가 약한 사람.
- 라이브러리에서 빈틈 찾기: 남들이 롱폼이면 5~8초 숏폼, 큰 업체가 안 하는 "대놓고 가격·혜택" 광고, 요즘 드문 감성형.
- 보충(5-6): 제품이 일그러지면 이미지 먼저 만들고 → 영상. Higgsfield(비쌈), Claude Code·GPT를 Higgsfield와 연결해 기획까지 자동화하는 방향도 언급.

### ⑤ 광고 세팅 (04-메타광고.md 4-8, 05-보충강의.md 5-3~5-5)
- **"판매" 캠페인 하나, 픽셀 구매 이벤트, 캠페인 1개·세트 1개·소재 여러 개.** 캠페인·세트를 늘리면 학습이 흩어지고 서로 경매에서 부딪힌다.
- 세트: 대한민국, 언어 한국어, 타겟 넓게(브로드), 전환수 극대화, 클릭 7일·조회 1일, 게재 위치 전체.
- 시작 일 예산 **3만 원, 소재 2~3개**(소재 1개당 1.5~2만 원), 시작·증액은 **밤 12시**.
- 광고: 1:1 먼저 넣고 세로 칸만 9:16 교체, 링크는 **상세페이지**(메인 X), 카탈로그·여러 광고주 광고 끄기, 처음엔 영상만.
- **신규 계정 첫 달 = 워밍업**(5-4): 일 3만 원 길게, 이때만 타겟을 조금 건다 — 25~55세, 성별, 관심사 2~3개 + "최근 구매·온라인 쇼핑 관심" 교집합.
- 제품 여러 개(5-5): 같은 종류면 세트 1개 안에 제품별 소재 / 다른 종류면 제품별 세트(각 3만 원).

### ⑥ 성과분석 (04-메타광고.md 4-10, 05-보충강의.md 5-7)
- **7일을 못 기다리고 만지는 게 실패 1순위.** 가설 → 하나만 바꾸기 → 7일 두기 → 7일 단위 분석.
- 보는 순서: 일자별 → 연령·성별 → 노출 위치 → 시간대 → 타겟 → **변경 내역**(옛 캠페인 복기가 최고 교재).
- 소재 하나 성과만 보고 끄지 말 것 — 다른 소재가 데려온 손님을 마지막에 가져간 것일 수 있다. **판단은 세트 단위.**
- 벤치마크: CTR 3%+, 전환율 3%+. 퍼널(5-2): 상세 조회→장바구니 약 10%, 장바구니→결제 시작 40~50%, 결제 시작→구매 40~50%.

## 5. 본강의 vs 보충강의 — 바뀐 것 (보충이 최신)

| 항목 | 본강의(4부) | 보충(5부) |
|---|---|---|
| 잘 된 ABO 처리 | CBO로 **복제**해 키움 | **복제 금지** — 복제하면 학습이 0부터. ABO 그대로 키움 |
| 증액 폭 | 하루 20% | **10~15%**, 초반 5천~1만 원 단위 |
| 학습 완료 기준 | 주 30~40건 | **주 40~50건** |
| 감액 조건 | 3일 연속 CPA 18,000원+ | **4일 연속 미달** 또는 7일 누적 |
| 피로도 빈도 | 2.5~3 | 3.5+ |
| 신규 계정 타겟 | 브로드(타겟 없음) | **첫 달은 타겟 조금 걸기** |

## 8. 용팀장 사업 기준으로 본 포인트

- **구매대행(스마트스토어)과 정반대 구조다.** 구매대행은 키워드 검색 유입·상품 수·위탁. 이건 노출(인스타 피드) 유입·상품 소수·사입·마진 2만 원.
- 이미 가진 것: 1688·타오바오 소싱 경험, 불사자로 쌓은 판매 데이터, 상세·썸네일 AI 자동화. 특히 **"판매가 이미 나온 상품"을 후보로 쓸 수 있다**는 게 강점 — 쿠팡 리뷰 세기 대신 내 판매 기록으로 수요를 확인할 수 있다.
- 새로 필요한 것: 사입(발주·배대지·원산지 표기·재고), 메타 광고 운영 감각, 영상 소재 제작 루틴.
- 강사 본인도 소싱·인스타 발행을 AI 에이전트로 자동화하고 있다고 말했다(5-2, 4-9). 소재 제작(Flow 프롬프트)과 소싱 후보 리스트업은 지금 쓰는 자동화 방식과 잘 맞는다.
