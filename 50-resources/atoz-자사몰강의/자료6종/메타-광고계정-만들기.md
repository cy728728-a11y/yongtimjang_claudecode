(3) 메타광고 셋팅
* 구글검색 '비즈니스관리자'
https://www.facebook.com/business/tools/business-manager
 -> 시작하기 -> facebook로그인(또는 개인 새계정만들기) -> 로그인후
 -> 좌측메뉴 '홈' 바로위의 네모칸 클릭[1] -> 맨아래 '비즈니스 포트폴리오 만들기'[2]
 -> 이름넣고 만들기(비즈니스계정이름에 브랜드넣고, '이름'에는 [성 띄우고 이름])
 -> 만들어진 비즈니스 포트폴리오 클릭 -> 톱니바퀴[3]비즈니스설정
 -> 5가지 자산을 셋팅 (페이지, 광고계정, 인스타그램, 픽셀, 도메인)




  1.페이지 : (왼쪽메뉴)계정 -> 페이지 -> 우측상단 +추가 -> 새 facebook페이지 만들기
   -> 만든페이지 선택후 -> 우측상단 facebook에서 보기 클릭 ->(만든 페이지로 이동됨)
   -> '지금전환' 클릭 -> 페이지 활성화 위해서 (프로필사진, 배경사진, 게시글1~2개, 정보->주소(시),한국어)
   -> 좌측메뉴의 '설정' -> 아랫쪽 '연결된 계정' -> 인스타그램 계정 연결하기 (없으면 인스타그램 가입~)


  2.광고계정 : (왼쪽메뉴)계정 -> 광고계정 -> 우측상단 +추가 -> 새 광고계정 만들기
        (시간대는 서울 / 통화는 '원화와 달러 중에서 보기쉽게 원화 추천함. 2중환율수수료 약간 더 청구됨)
   -> 내용입력 후 결제정보 추가 -> '비즈니스 및 세금정보' 우측의 '수정'클릭 -> 사업자등록번호(숫자만)
     (부가세 안낸다!! 꼭꼭!)


  3.인스타그램 : (왼쪽메뉴)계정 -> instagram계정 -> 우측상단 +추가 -> 인스타그램 계정 소유권 요청, 로그인
   -> 인스타계정 선택 후 -> 자산연결 -> 광고계정 선택하여 연결하기


  4.픽셀 : (왼쪽메뉴)데이터 소스 -> 데이터세트 및 픽셀 -> 우측상단 +추가 -> 새 데이터세트 만들기
   -> (왼쪽메뉴)모든도구 -> [이벤트관리자]로 이동!! -> 전환API설정하기 -> 파트너통합으로설정
   -> cafe24선택 -> café연결승인on
   -> [cafe24자사몰]로 이동!! -> 판매채널 -> 페이스북 -> 페이스북채널
      -> 채널설정 -> 전부다 연결~ -> '내웹사이트에서 결제' -> '자동고급매칭'만 on


  5.도메인 : (왼쪽메뉴)브랜드가치보호 및 적합성 -> 도메인 -> 우측상단 +추가 -> 도메인만들기
   -> 도메인주소 넣을때 https://는 빼고 넣기~
   -> [cafe24자사몰]로 이동!! -> 판매채널 -> 페이스북 -> 페이스북채널
      -> 채널설정 -> 도메인인증설정 -> '인증' 클릭




* 픽셀이란?
 메타광고 - 자사몰 간의 data를 서로 연결
   -소비자가 광고를 보고 클릭을 할때까지의 data는 메타에 있음
   -클릭후 랜딩페이지인 자사몰에 유입된후 소비자의 data는 자사몰에 있음
     => 이 둘을 연결
