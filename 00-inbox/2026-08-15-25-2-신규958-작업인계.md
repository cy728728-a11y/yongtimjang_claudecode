## 6. 상품명 팬아웃 pending 계산 (스크립트에 서브커맨드가 없다)

`run_names.py` 에는 `pending` 이 없어서 직접 센다. **`draft_*` 와 `named_*` 를 둘 다** 세야 한다(§2⑤).

```bash
PYTHONPATH=.claude/lib .venv/bin/python -c "
import os, json, glob, re
R='<run-dir 절대경로>'
done_={int(re.search(r'_(\d+)', os.path.basename(p)).group(1)) for p in glob.glob(R+'/named/*.json')}
nums, kbs = [], []
for p in sorted(glob.glob(R+'/batches/batch_*.json')):
    n=int(re.search(r'batch_(\d+)', p).group(1))
    if n in done_: continue
    vs=json.load(open(p, encoding='utf-8')).get('뷰크기') or {}
    nums.append(n); kbs.append(int(re.sub(r'[^0-9]','', str(vs.get('leaf','0'))) or 0))
print('pending', len(nums)); print(json.dumps(nums, separators=(',',':'))); print(json.dumps(kbs, separators=(',',':')))
"
```
배치가 200개를 넘으면 압축형 args(`batchNums` + `viewKB`)를 쓴다 — 인라인 경로 40KB가 메인을 먹는다.
**`batchNums` 를 생략하면 워크플로가 `0..N-1` 로 가정해 파일을 못 찾는다.** 항상 같이 넘겨라.
