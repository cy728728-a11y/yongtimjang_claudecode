## 수강생에게 그대로 보내면 되는 공지

> **불사자 키트 설치 안내**
>
> **1단계.** 클로드코드에서 이 한 줄. (평생 한 번만)
> ```
> /plugin marketplace add cy728728-a11y/bulsaja-kit
> ```
>
> **2단계.** 둘 중 **하나만** 고르세요.
>
> 전부 다 받기:
> ```
> /plugin install bulsaja-kit@bulsaja-kit
> ```
>
> 필요한 것만 골라 받기:
> ```
> /plugin install bulsaja-thumbnail@bulsaja-kit
> /plugin install bulsaja-shipping-fee@bulsaja-kit
> /plugin install bulsaja-option-cleanup@bulsaja-kit
> /plugin install bulsaja-product-name@bulsaja-kit
> ```
> ⚠️ 두 방식을 같이 쓰지 마세요.
>
> **3단계.** 자동 업데이트를 켭니다. **꼭 하세요.**
> `/plugin` → **Marketplaces** 탭 → `bulsaja-kit` → **Enable auto-update**
> 이걸 켜두면 앞으로 스킬이 개선돼도 **아무것도 안 해도 최신**이 됩니다.
>
> **4단계.** `설치 점검해줘` 라고 말해서 전부 ✅ 인지 확인.
>
> **쓰는 법**
> ```
> 1-1그룹 썸네일 만들어줘
> 1-1그룹 배송비 계산해줘
> 1-1그룹 옵션 정리해줘
> 1-1그룹 상품명 만들어줘
> ```
> 실습은 한 번에 20~30건으로 시작하세요.

## 형이 앞으로 하게 될 일

새 스킬을 내거나 기존 스킬을 고쳤을 때:

```
"옵션정리 스킬 고친 거 수강생용으로 다시 배포해줘"
```

**단, 이걸 자동으로 해주는 `skill-publish` 스킬은 아직 안 만들었다.**
계획서에 설계까지 다 있고(Task 5), 강의 당일엔 필요 없는 도구라 뒤로 미뤘다.
지금은 내가 수동으로 같은 절차를 밟으면 된다.

**수강생 쪽은 형이 푸시만 하면 끝난다** — 자동 업데이트를 켰으면 알아서 받는다.

지난번과 달리 **`claude plugin` 셸 명령을 찾아서 설치까지 내가 직접 검증했다.**
"아침에 형이 쳐봐야 한다"던 미검증 항목이 없어졌다.

## 구조 (지난번에서 바뀐 것)

플러그인을 **묶음 1개 + 개별 5개**로 나눴다. 저장소는 하나다.

```
bulsaja-kit/
├─ .claude-plugin/marketplace.json   플러그인 6개 선언
├─ plugins/                          ← 빌더가 만든다. 손대지 않는다
│   ├─ bulsaja-kit/                  묶음(스킬 5개)
│   ├─ bulsaja-thumbnail/
│   ├─ bulsaja-shipping-fee/
│   ├─ bulsaja-option-cleanup/
│   ├─ bulsaja-product-name/
│   └─ bulsaja-kit-doctor/
├─ shared/                           ← ★ 여기가 정본. 고칠 땐 여기를 고친다
│   ├─ eroomlib/  skills/  config/  scripts/
├─ scripts/build_plugins.py          정본 → 플러그인 복사
└─ tests/
```

**플러그인은 자기 폴더 밖을 못 읽는다**(공식 규격). 그래서 라이브러리를 6벌 복사해야
하는데, 사람이 맞추면 반드시 어긋난다. 그래서 **빌더가 복사하고 테스트가 검사한다.**

## 작업 중 잡은 실제 결함

1. **`marketplace.json` 의 `source` 형식** — 공식 문서가 소개한 짧은 표기
   (`pluginRoot` + 이름)를 실제 클로드코드가 `Invalid input` 으로 거부했다.
   명시적 상대경로(`./plugins/이름`)로 고쳤다. **실제 설치를 안 해봤으면 못 잡았다.**

2. **옵션정리 원본 테스트의 잠복 오염** — `test_option_prep` 이 `option_rules.verify` 를
   스텁으로 갈아끼우고 복원하지 않아, 같이 돌면 검증 테스트 8개가 조용히 깨진다.
   형 워크스페이스에서는 그 파일이 **import 자체가 안 돼서**(requests 부재) 안 보였다.
   → **원본에도 있는 결함이다.** 배포판은 고쳤고, 원본은 형 판단에 맡긴다.

3. **라이브러리 탐색 코드가 파일마다 갈라져 있었다** — 구조를 바꾸자 한 파일만
   옛 형태로 남아 import 에서 죽었다. 전 파일을 같은 형태로 통일하고
   **테스트로 못 박았다**(`test_lib_lookup.py`).

## 형이 알아야 할 것 두 가지

**① 상품명 스킬만 준비물이 있다.**
- 수강생이 **셀러라이프 키워드 엑셀**을 `~/bulsaja-kit/keywords/` 에 넣어야 한다
  (원래 형 구글드라이브에서 받던 것)
- **`openpyxl` 설치가 필요하다** (`pip3 install openpyxl`)

  "추가 설치 없이 돌아간다"는 원칙을 상품명 스킬에서만 못 지켰다. 엑셀을 읽어야 해서
  피할 방법이 없었다. 진단이 콕 집어 안내하고, 나머지 세 스킬은 영향 없다.

**② 자동 업데이트는 수강생이 직접 켜야 한다.**
서드파티 마켓플레이스는 기본이 꺼짐이다. 안 켜면 형이 아무리 개선해도 옛날 것을 쓴다.
**강의에서 이 단계를 꼭 같이 눌러보게 하는 게 좋다.**

---

## 카테고리 스킬을 뺀 이유

카테고리 교정의 핵심인 "키워드 → 네이버 카테고리 경로" 조회 엔진이 수강생 환경에 없다.

- `aside-category` → Aside 브라우저의 형 상시 로그인 세션에 의존. 공유 불가
- `sellha-category` → 셀레니움 + 크롬 프로필 수작업 + 셀하 로그인. 게다가 보안프로그램이
  크롬을 30초에 죽여서 형도 안 쓰고 Aside 로 갈아탄 경로

조회 엔진 없이는 스킬이 껍데기가 된다. **수강생이 쓸 수 있는 조회 경로를 먼저 정한 뒤**
붙이면 된다. 나머지 4개는 카테고리 없이도 그대로 돈다.
