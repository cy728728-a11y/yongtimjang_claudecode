## 강의 전 형이 딱 하나 해봐야 하는 것

**`/plugin marketplace add` 와 `/plugin install` 을 직접 쳐보기.**

이 두 줄은 클로드코드 슬래시 명령이라 내가 대신 못 돌렸다. 그래서 이것만 미검증이다.
나머지(파일 구조·경로 해석·실제 작업 완주)는 전부 확인했다.

혹시 `bulsaja-kit@bulsaja-kit` 부분에서 안 되면, 설치 화면에 뜨는 이름으로 바꿔서
치면 된다. README 도 같이 고쳐야 하면 말해줘.

## 배포판이 형 버전과 다른 점

**판정 기준·프롬프트·요금 계산은 하나도 안 건드렸다.** 저장 위치만 바뀌었다.

| | 형 버전 | 배포판 |
|---|---|---|
| 진행 상황 | 구글시트 현황판 | 로컬 `board.json` |
| 결과 기록 | 그룹 시트 탭 | 로컬 `ledger.json` + `review.html` |
| 동시 처리 | 팬아웃(Workflow) | 배치를 순서대로 |
| 오픈차이나 | ID/PW 로그인 | **코드 통째로 삭제** |
| 배송비 요율 | 코드에 박힘 | `config/shipfee.ini` (수강생이 수정 가능) |
| 파이썬 패키지 | requests 필요 | **없음** (pip 설치 불필요) |

## 작업 중 잡은 실제 버그 3개

1. **`chunk_by_size` 반환 형태 불일치** — 원본은 `(시작인덱스, 행들)` 튜플을 yield 하는데
   내가 리스트로 만들어서, 상품 행이 글자 단위로 쪼개져 저장될 뻔했다. 테스트가 잡았다.
2. **방화벽이 Python 기본 User-Agent를 403으로 차단** — 이걸 안 고쳤으면 수강생 전원이
   "불사자 연결 안 됨"에서 막혔다. UA 한 줄로 해결.
3. **행 전체 범위(`'탭'!1:1`) 파싱 실패** — 진행판 헤더 검증이 조용히 건너뛰어졌다.
   실제 마켓그룹 리허설에서 드러났다.

셋 다 회귀 테스트를 붙여놨다.

## 안 한 것 / 남은 판단

- **`bulsaja-shipping-fee` 를 main 에 병합하지 않았다.** 아직 worktree
  `shipfee-skill-install` 브랜치에만 있다. 형 워크스페이스를 건드리는 별개 결정이라
  손대지 않았다. 병합할지는 형이 정해라.
- **원본 스킬은 전혀 수정하지 않았다.** 읽어서 복사만 했다.
- 자동 반영(승인 게이트 없음)은 형 지시대로 유지했다. 수강생이 그룹 이름을 잘못
  말하면 그 그룹이 작업되니, **강의에서 이 점을 한 번 짚어주는 게 좋다.**
