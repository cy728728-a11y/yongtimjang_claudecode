# 클로드가 유튜브로 알아서 공부한다 (게으른빌더 쇼츠 + 가이드)

> 출처: 유튜브 쇼츠 https://youtube.com/shorts/kYnNTl1BWOk (게으른빌더, 2026-09-10 업로드, 44초)
> 고정댓글 링크: https://lazyowen.com/guides/claude-youtube-skill · https://lazyowen.com/challenge
> 정리일: 2026-11-05 · 유형: 영상(홍보성 쇼츠) + 가이드 페이지

## 핵심 3줄
1. 클로드에게 유튜브 주소만 주면 **영상을 안 보고 제목으로 짐작해 답하는 경우가 많다** → 실제로 "보게" 만드는 도구를 붙이자는 내용.
2. 구성은 3개: ① 영상 화면+자막을 가져오는 **watch 스킬** ② 같은 영상을 **제미나이(무료 API 키)** 로 한 번 더 읽힘 ③ 두 결과를 합친 설계도를 **skill-creator** 로 스킬화.
3. 가장 배울 만한 건 도구보다 **"두 AI가 따로 읽고 → 일치/한쪽만/충돌 딱지 → 실제 실행으로 검증"** 하는 방법론.

## 영상 대본 (자동자막, 교정 반영)
> "세상에서 가장 똑똑한 클로드를 직접 만드는 방법 바로 알려 줄게요."

> "클로드가 직접 유튜브로 보고 공부하는 걸 자동화하면 클로드를 각 분야의 전문가로 만들 수 있어요."

> "첫째, 클로드가 유튜브를 직접 보게 하려면 영상에서 정보를 자동으로 가져오는 스킬들을 설치해요."

> "두 번째, 구글 AI 스튜디오에서 제미나이 API 키를 무료로 받아요. 제미나이는 기본적으로 유튜브를 이해하고 연동되거든요."

> "세 번째, 앞의 두 방법으로 정보를 받은 다음 이 에이전트 설계 도구를 써서 여러분의 클로드가 모든 업무를 처리할 수 있는 에이전트로 만드는 거예요."

> "댓글에 유튜브라고 남겨 주세요. 바로 보내 줄게요." (← 댓글 유도형 홍보)

## 가이드 페이지 내용 (lazyowen.com/guides/claude-youtube-skill)

### 쓰는 도구
| 도구 | 역할 | 설치 |
|---|---|---|
| watch 스킬 | 영상 프레임(화면 캡처)+자막 가져옴 | `/plugin marketplace add bradautomates/claude-video` → `/plugin install watch@claude-video` |
| 제미나이 API | 유튜브 주소를 직접 읽어 설명서 작성 | aistudio.google.com/apikey 에서 무료 키 · `pip install google-genai` |
| skill-creator | 설계도(SPEC.md)를 스킬로 만듦 | `/plugin install skill-creator@claude-plugins-official` |
| yt-dlp, ffmpeg | 영상 받기·화면 자르기 | `brew install ffmpeg yt-dlp` |

### 9단계 절차 (약 54분)
1. 준비물 확인 (ffmpeg·yt-dlp·파이썬 3.10+)
2. watch 설치 후 짧은 영상으로 `/watch` 시험
3. 화면 캡처 양 고르기: transcript(0장) / efficient(50) / balanced(100, 기본) / token-burner(116). 터미널 화면 영상은 `--resolution 1024`, 구간은 `--start --end`
4. 제미나이 키 저장 → 제미나이 결과를 `notes/gemini-pass.md`
5. skill-creator 설치
6. **클로드가 먼저** 영상을 보고 6항목 설명서 → `notes/claude-pass.md` (제미나이 결과는 이거 저장한 뒤에 본다)
7. 두 기록을 합쳐 `SPEC.md` — 줄마다 **확인됨 / 한쪽만 / 충돌** 딱지
8. skill-creator 로 스킬 생성 → 실제 입력으로 한 번 돌려서 고침
9. (선택) 전 과정을 `/youtube-to-agent <주소>` 한 줄로 묶기

### 6항목 설명서 (이게 핵심 프롬프트)
① 결과물이 뭔지 ② 필요한 도구·계정 ③ 화면에 나온 명령·설정 **글자 그대로** ④ 실제 작업 순서 ⑤ 함정·경고 ⑥ 영상이 안 보여준 준비 과정. 못 읽은 건 `UNREADABLE`, 영상에 없는 건 지어내지 않음.

### 주의사항 (가이드가 직접 적은 것)
- 제미나이 결과를 먼저 보면 클로드 판단이 끌려간다 → 순서 지킴
- AI가 말하는 **시간·개수는 신뢰도 낮음**. 명령어·패키지명·오류 메시지를 증거로
- 설계도가 맞아 보여도 **실제 실행으로 한 번 검증**
- 캡처 장수 많을수록 비용↑. 긴 영상은 구간을 나눠서
- 충돌은 평균 내지 말고 둘 다 적은 뒤 그 장면을 다시 확인

### 상업 요소
- 가이드 일부(약 12개 섹션)·PDF는 **이메일 등록 후 열림** (광고 메일 수신 동의 포함)

## 내 상황에 비춰본 분석

### 이미 갖고 있는 것
| 가이드 요소 | 내 환경 |
|---|---|
| 자막 가져오기 | `transcript-organizer` 스킬이 이미 함 (자막 → 없으면 맥북 로컬 받아쓰기) |
| yt-dlp, ffmpeg | 설치돼 있음 |
| skill-creator | 이미 있음 (`anthropic-skills:skill-creator`) |

### 새로 얻을 만한 것
1. **화면을 보는 능력** — 지금 스킬은 "말"만 읽는다. 클로드 코드·불사자 화면 시연처럼 **말 없이 화면에서 클릭하는 강의 영상**은 지금 방식으론 절반을 놓친다. watch 스킬이 이 구멍을 메움.
2. **두 번 읽기 교차검증** — 기존에 배운 "확신도 100%가 정답은 아니다"와 같은 맥락. 한 AI 결과를 그대로 믿지 않고 다른 AI와 대조해 일치한 것만 쓰는 방식은 소싱 검수·상세페이지 검수에도 그대로 옮길 수 있는 사고방식.
3. **영상 → 실행 가능한 스킬** 흐름 — 남의 튜토리얼을 보고 "좋네"로 끝내지 않고 바로 내 스킬로 굳히는 루틴. 실전반 강의 자료로도 쓸 만한 이야기.

### 조심할 점
- 영상 자체는 44초 홍보물이라 정보 거의 없음. 실제 내용은 가이드 페이지에 있다.
- 제미나이 무료 키 = 구글 계정 하나 더 엮임. 공개 영상만 가능, 하루 약 8시간 분량 한도.
- 가이드 속 모델명(`gemini-3.8-flash` 등)은 실행 전 실제 존재하는지 확인 필요.
- 30일 챌린지는 아직 실체가 없으니 등록할 이유 없음.
