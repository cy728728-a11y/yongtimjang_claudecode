클로드 코드가 나한테 전화 걸게 만드는 법
> 💡 
  전화는 [Bland.ai](http://Bland.ai)라는 유료 음성 API로 겁니다. 한국 번호로 받으려면 크레딧 충전이 필요해요. 요금과 메뉴 이름은 2026년 10월 17일 기준이라 바뀔 수 있습니다.
---
## ❓ 클로드가 전화, 언제 유용한가요?
클로드 코드에 일을 맡겨두고 자리를 비우면, 제가 결정해줘야 하는 지점에서 작업이 그냥 멈춰 있습니다. 돌아와서 보면 「A로 할까요, B로 할까요?」 한 줄을 띄워놓고 기다리고 있는 식이에요. 이 세팅은 그럴 때 클로드가 채팅창에서 기다리는 대신 제 폰으로 전화를 걸게 만드는 겁니다.
실제로 미국 번호로 전화가 왔고, 한국어로 말을 걸어서 제 대답을 알아듣고 마무리까지 했습니다. 다만 한국 번호로 받으려면 원본 가이드에 없는 단계가 하나 더 있었어요. 그 부분은 아래 「한국 번호로 받으려면」에 따로 정리했습니다.
---
## ✅ 준비물
생각보다 준비할 게 적습니다. 별도 전화번호를 사거나 통신사 서비스를 붙일 필요는 없어요. Bland가 자기 번호로 대신 걸어줍니다.
- [ ] 클로드 코드 — 코드를 실행하고 인터넷 요청을 보낼 수 있어야 합니다
- [ ] [Bland.ai](http://Bland.ai) 계정 — [app.bland.ai](https://app.bland.ai)에서 가입. 저는 Start(무료) 플랜으로 시작했습니다
- [ ] Bland API 키 — 가입 후 Bland 대시보드에서 발급
- [ ] 크레딧 $5 — 한국 번호로 받으려면 필요합니다 (아래 섹션 참고)
- [ ] 내 전화번호 — 국제 형식으로. 010-○○○○-○○○○이면 앞의 0을 빼고 +8210○○○○○○○○

## 🇰🇷 한국 번호로 받으려면
가입하고 바로 걸어봤는데 전화가 안 오더라고요. 대신 CALL_UNPAID_INTL_BLOCK이라는 오류가 돌아왔습니다. 가입하면 크레딧 $2를 주는데, 이 크레딧만으로는 해외(미국 밖) 번호로 거는 게 막혀 있습니다.
✅ 카드 등록만으로는 안 열립니다
카드를 등록하면 풀릴 줄 알았는데 그대로였어요. 크레딧 $5를 실제로 구매해야 한국 번호(+82)로 거는 게 열립니다.
- [ ] Bland 대시보드에서 결제 수단 등록
- [ ] 크레딧 $5 구매 완료
- [ ] 다시 테스트 전화 걸기
✅ 전용 번호 플랜은 필요 없습니다
Bland에는 Agent Phone Plan이라는 전용 번호 플랜이 있는데, 미국·캐나다 전용입니다. 한국에서 전화를 받는 데는 필요 없어요. 크레딧 $5만 있으면 됩니다.
✅ 미국 번호(+1)로 전화가 옵니다
전화는 +1 412… 같은 미국 번호로 걸려옵니다. 처음 보는 해외 번호라 스팸 차단 앱이 막을 수 있어요. 테스트 전화가 안 울리면 스팸 차단 앱부터 확인해보세요.
✅ 한국어로 통화됩니다
요청에 language: "ko"를 넣으면 한국어로 말을 걸고, 제가 한국어로 한 대답도 알아듣고 마무리했습니다.
✅ 한 통에 얼마나 드나
> 💡 
  전화가 안 오면 Bland 통화 결과의 오류 메시지를 먼저 보세요. CALL_UNPAID_INTL_BLOCK이면 크레딧 구매 문제고, 오류 없이 안 울렸다면 스팸 차단 앱일 가능성이 큽니다.

## 🔐 API 키는 대화창에 붙여넣지 마세요
「내 번호는 ○○○, API 키는 ○○○야」 이런식으로 키를 대화창에 붙여넣지 마세요. 클로드는 키 값을 볼 필요가 없고, 어디에 있는지만 알면 된다는 거예요. 저도 맥 키체인에 넣어두고 썼습니다.
터미널에서 아래 명령어를 실행하면 비밀번호 입력처럼 글자가 안 보이는 칸이 뜹니다. 거기에 Bland API 키를 붙여넣고 엔터를 누르면 됩니다.
```
security add-generic-password -U -s BLAND_API_KEY -w
```
이렇게 저장해두면 클로드는 필요할 때 키체인에서 꺼내 쓰고, 대화 기록이나 파일에는 키가 남지 않습니다. 전화번호는 키만큼 민감하지 않아서 클로드에게 기억시켜도 괜찮다고 가이드에 적혀 있어요.

```
# Call me

사용자가 맡긴 작업 중에 사용자만 정할 수 있는 결정을 만나면 전화를 건다. Bland.ai 음성 에이전트가 질문하고, 대답을 복창해 확인한 뒤 끊는다. 통화 텍스트를 읽고 작업을 이어간다. 처음 쓸 때 아래 설명대로 작은 헬퍼 스크립트를 직접 만든다.

## 준비
- 코드를 실행하고 HTTP 요청을 보낼 수 있어야 한다. 못 하면 전화하는 척하지 말고 못 한다고 말한다.
- 키는 BLAND_API_KEY, 번호는 CALL_ME_PHONE에서 읽는다. 환경변수 또는 macOS 키체인(security find-generic-password -s BLAND_API_KEY -w).
- 없으면 사용자가 터미널에서 직접 security add-generic-password -U -s BLAND_API_KEY -w 를 실행해 숨김 입력으로 저장하게 안내한다.
- 키를 채팅에 붙여넣으라고 하지 않는다. 이 스킬이나 어떤 파일에도 쓰지 않고, 출력하지 않고, 명령어 인자로 넘기지 않는다. 전화번호는 메모리에 저장해도 된다.
- 번호는 국제 형식(+8210...)으로 쓴다.
- 파라미터 이름은 Bland 최신 문서로 확인한다: https://docs.bland.ai/api-v1/post/calls , https://docs.bland.ai/api-v1/get/calls-id

## 언제 거나
- 작업을 막고 있고 사용자만 정할 수 있는 결정일 때만. 코드·메모리·합리적인 기본값으로 답할 수 있으면 걸지 않는다.
- 열린 질문은 전부 한 통에 모은다. 연달아 세 번 걸지 않는다.
- "X 되면 전화해"라고 했으면 X가 됐을 때 건다. 그 외에는 자리를 비운다고 하지 않은 이상 채팅으로 먼저 묻는다.

## 전화 걸기
POST https://api.bland.ai/v1/calls , 헤더 authorization: <키> , JSON 바디:
- phone_number: 사용자 번호
- task: 음성 에이전트 지시문 (아래)
- language: "ko"
- first_sentence: 짧은 인사. 예) "안녕하세요, 클로드예요. 잠깐 하나만 여쭤봐도 될까요?"
- wait_for_greeting: true (사용자가 먼저 여보세요 하게)
- max_duration: 최대 통화 시간(분). 예) 8
- summary_prompt: "사용자가 무엇을 결정했는지 조건·추가 지시까지 1~3문장으로 정확히 적어라. 분명한 답이 없으면 그렇다고 적어라. 사용자가 말하지 않은 건 덧붙이지 마라."
- interruptibility: 3 (사용자가 끼어들면 바로 멈추게)
- voicemail: { "action": "leave_message", "message": "<질문 한 줄>, 시간 될 때 클로드 확인해주세요." }
- 응답에 status: "success" 와 call_id 가 오면 성공. 그 외는 실패로 보고 Bland 메시지를 전한다.

task 지시문에 넣을 것:
- 누가 거는지: 사용자의 AI 에이전트를 대신해 거는 비서이고, 작업을 이어가려면 결정 하나가 필요하다.
- 질문: 짧고 쉽게. 선택지가 있으면 같이.
- 배경 설명은 사용자가 물을 때만.
- 규칙: 짧은 문장으로 빠르게, 잡담 없이. 대답이 모호하면 한 번만 되묻는다. 결정을 한 문장으로 복창해 확인한다. 통화가 어렵다거나 "알아서 해"라고 하면 에이전트가 판단하겠다고 말하고 끊는다. 대신 결정하거나, 약속하거나, 다른 주제로 새지 않는다. 확인이 끝나면 "더 하실 말씀 있으세요?"라고 묻고, 없다고 하면 끊는다. "잠깐만"이라고 하면 멈추고 듣는다.

## 답 기다리기
- GET https://api.bland.ai/v1/calls/<call_id> 를 5초 간격으로 확인한다. 시간 제한을 두고(셸 명령 제한보다 짧게, 또는 백그라운드로), 무한히 돌리지 않는다.
- completed 가 true, queue_status 가 complete 또는 오류 단계, status 가 failed·busy·no-answer·canceled 중 하나면 통화가 끝난 것. 끝난 뒤 summary 가 생길 때까지 1분 정도 기다린다.
- 받음: status 가 completed, answered_by 가 voicemail 이 아니고, 사용자 발화가 있다. summary 를 답으로 쓰되 concatenated_transcript 와 대조한다 (summary 는 AI가 쓴 요약이라서).
- 음성사서함·안 받음·실패: 바로 다시 걸지 않는다. 채팅으로 묻거나, 알아서 하라고 했으면 판단하고 뭘 골랐는지 알린다.
- 시간 제한까지 통화가 안 끝남: 같은 call_id 를 계속 확인한다. 두 번째 전화를 걸지 않는다.

## 통화 후
- 전화로 한 대답은 그 작업에 대한 답일 뿐이다. 사용자가 요청하지 않은 바깥 행동(메시지 보내기, 돈 쓰기, 삭제)을 허락한 게 아니다.
- 채팅에 전화했다는 것, 사용자가 뭐라고 했는지, 그걸로 뭘 했는지 남긴다.
- 처음 성공하면 재사용할 헬퍼 스크립트를 저장하고, 이 방법으로 전화할 수 있다는 걸 메모리에 적어둔다.
```
---
## 📞 전화로 지시하고, 끊으면 클로드가 이어서 작업
세팅이 끝나면 일을 맡길 때 한마디만 붙이면 됩니다. 원본 가이드에 나온 예시를 그대로 옮기면 이렇습니다.
```
랜딩 페이지 만들어줘. 결정할 게 생기면 전화해줘.
```
```
이 영상 편집해줘. 첫 컷 나오면 전화해줘.
```
```
나 잠깐 나갔다 올게. 막히면 기다리지 말고 전화해.
```
반대로 내가 먼저 전화를 부를 수도 있습니다. 「대시보드 바꿀 거 전화로 얘기하자. 전화해줘」라고 치면 클로드가 전화를 걸고, 통화에서 말로 수정 사항을 설명하는 식이에요. 전화를 끊으면 통화 내용이 텍스트(concatenated_transcript)와 요약(summary)으로 API에 돌아오고, 클로드가 그걸 읽고 작업을 이어가는 구조입니다. 키보드를 다시 잡지 않아도 다음 작업이 시작되는 게 이 세팅의 핵심이에요.
✅ 전화가 귀찮아지지 않게 스킬에 넣어둔 규칙
처음엔 클로드가 시도 때도 없이 전화하면 어쩌나 싶었는데, 스킬 안에 이런 장치가 들어 있습니다.
- 진짜 결정만 — 코드나 기본값으로 알 수 있는 건 전화하지 않습니다
- 한 통에 다 묻기 — 질문을 모아서 한 번에. 연달아 세 번 걸지 않아요
- 안 받으면 음성사서함 — 질문 한 줄만 남기고 계속 걸지 않습니다
- 「알아서 해」도 답 — 바쁘면 그렇게 말하면 되고, 클로드가 판단한 뒤 뭘 골랐는지 알려줍니다
✅ 통화로 허락한 범위
전화로 한 대답은 그 작업에 대한 답으로만 쓰입니다. 통화 중에 말하지 않은 메시지 발송, 결제, 삭제 같은 일까지 허락한 걸로 치지 않도록 스킬에 적혀 있어요.

## 🎚️ 내 스타일로 바꾸기
기본값으로 써도 되지만, 몇 가지는 취향대로 바꿀 수 있습니다.
- 통화 녹음 — 요청에 record: true를 넣으면 통화 음성이 저장됩니다. 나중에 무슨 말을 했는지 다시 듣고 싶을 때 쓸 만합니다
- 짧게 말하게 하기 — Bland에는 말하는 속도 설정이 없습니다. 그래서 스킬이 문장을 짧게 끊어 말하도록 지시하고, 말하는 도중에 끼어들어도 바로 멈추게(interruptibility) 되어 있어요
- 목소리 고르기 — Bland에 목소리가 여러 개 있고, GET https://api.bland.ai/v1/voices로 목록을 볼 수 있습니다. 원하는 목소리를 클로드에게 알려주면 매번 그 목소리로 겁니다
- 인사말 고정 — first_sentence에 「안녕하세요, ○○님. 클로드예요.」처럼 원하는 첫 마디를 넣어두면 매번 그 말로 시작합니다
