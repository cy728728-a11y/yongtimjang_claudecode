옛 2건 기준이라 **새로 들어온 6건이 판정 없이 통과한다.** 이어붙일 때마다 끝수 배치 named 를 지운다.

### ④ 상품명 pending 계산은 `.chal.json` 을 빼야 한다

`named/` 에는 `draft_NNN.json` · `named_NNN.json` 말고 **`draft_NNN.chal.json`**(반증 파일)도 있다.
`_(\d+)` 정규식으로 세면 이게 잡혀 **재작업할 배치를 done 으로 오판한다**(실제로 pending 0 이 나왔다).

```python
if b.endswith('.chal.json'): continue   # ← 이 줄이 없으면 재팬아웃이 안 돈다
```

### ⑤ `캡챠감지` 는 대개 **간헐적 rate limit** 이다 — 화면엔 캡챠가 없다

이번에 캡챠를 2번 만났고 **둘 다 `captcha-relay` 가 `needs_human`** 을 돌려줬다.
Aside 가 못 푼 게 아니라 **스크린샷에 캡챠 화면이 실제로 없었다**(정직한 답).
직접 그 URL 을 다시 열어 보니 `PAGESTATE = 정상` 이었다.


**대응은 휴식 총량이다** — 간격(`--sleep`)만 늘리면 또 만난다:
