1단계. 원본 컷 분석
==================================================
- 원본 이미지를 사진 칸 단위로 잘라 목록을 만든다.
  컷마다: 번호 / 종류(제품단독·사용장면·디테일·구성품·사이즈·옵션) / 보이는 것 / 확인되는 사실 / 쓸 수 있나(이유)
- 사진 위 중국어 문구 띠는 잘라낸다. 못 자르면 "사용 불가"로 표시.
- 해상도: 가로 750px 이상 그대로, 600~749px 은 보정 1회(최대 2배), 600px 미만은 작게만 쓴다. 흐린 제품컷은 안 쓴다. AI 업스케일 금지.

2단계. 구성(장 계획)
==================================================
- 맨 위에 "이 상품을 쓰는 사람 1명 + 쓰는 장면 1개"를 원본 근거로 적고, 모든 카피를 그 사람에게 말하듯 쓴다. "누구나·모든 분" 금지.
- 장수는 "확인된 메시지 수"와 "쓸 수 있는 서로 다른 컷 수" 중 작은 쪽. 같은 컷 재사용·비슷한 문구 반복으로 장수를 늘리지 않는다.
- 쓸 수 있는 컷의 70% 이상을 쓴다. 한 컷은 한 번만(대표 제품컷만 최대 2번).
- 흐름(해당 없으면 빼기):
  1장: 가장 강한 사용 장면 + 고객이 얻는 결과 중심 제목
  2장: 리뷰형 후킹컷 — 넓은 여백에 큰 따옴표 문장 1개 + 보조 1줄
        (별점·후기 수·닉네임·날짜·"내돈내산"·"실구매 후기" 금지)
  3장~: 핵심 장점 → 특징 → 구조·조작부 → 사용 장면 → 활용 예시 → 사용 준비/연결 → 구성품(원본에 있을 때만)
  옵션 장: 판매 옵션을 한 장에 세로로(진갈색 번호 라벨 + 사진 + 설명 2줄). 옵션 차이가 불분명하면 만들지 말고 나에게 알린다.
  마지막 장: 확인된 스펙만 진갈색 띠 위 큰 숫자로 + "구매 전 확인" 2~3개(사이즈·호환·전원·조립 여부 중 원본에서 확인된 것)
- 장 계획표에 장 번호·제목·레이아웃·쓴 컷·근거, 그리고 "안 쓴 컷과 이유"를 적는다.

3단계. 디자인 (C 세일즈형: 아이보리 + 진갈색)
==================================================
- 860px 폭 낱장 PNG(01.png, 02.png …), 장마다 높이 1000~1500px.
- 배경 아이보리 #F8F6F2, 보조 베이지 #EDE8E0~#E8E4DC.
  순백 전면 배경 금지 / 초록·검정·보라·파랑 배경 금지 / 그라데이션 금지.
- 강조색은 진갈색 #514733 하나(큰 제목, 요약 띠 배경+흰 글씨). 알약 라벨 #8A7F70, 본문 #4F4838, 보조 #8A8378.
- 폰트는 Pretendard 하나(실제 폰트 파일 사용, 시스템 폰트 대체 금지).
  큰 제목 Bold 56~60px 가운데 정렬 / 본문 30~34px, 행간 1.6 / 각주 19~22px.
- 여백: 섹션 위아래 60px, 사진–글 32px, 좌우 48px. 빈 공간이 40% 넘는 장 금지.
- 같은 레이아웃 연속 2장 금지. 톤 배경 장 ↔ 사진 꽉 채운 장을 번갈아.
  레이아웃 종류: 사진 꽉 채움 / 사진↔글 지그재그 2열 / 사진 2~4장 그리드 / 번호 단계 / 스펙 띠
- 사진 위에 글자를 얹지 않는다. 사진 색을 바꾸지 않는다(리사이즈만).
- 대표 제품컷 1~2장은 배경만 아이보리 스튜디오 톤으로 바꿀 수 있다. 제품 픽셀은 그대로, 그림자는 제품 윤곽 따라 옅은 타원형(사각 받침 금지). 제품을 새로 그리거나 색을 바꾸는 것 금지.
- AI 티 금지: 이모지, 체크(✓)·아이콘 목록, 그림자 둥근 카드 반복, 아이콘+3열 카드, 밑줄·형광펜·제목 밑 장식선, 모든 장 같은 가운데 정렬.

==================================================
4단계. 카피 규칙
==================================================
- 한 장에 메시지 하나. 고객이 얻는 변화를 먼저. 장마다 "불편 → 해결 → 기대효과" 흐름.
- 제목 10~18자·최대 2줄 / 부제 15~28자 / 본문 섹션당 2~3줄. 자리가 모자라면 글씨를 줄이지 말고 문장을 줄인다.
- 제목은 4가지 공식 중 하나, 연속 2장 같은 공식 금지:
  ① 숫자+구체성("3초면 접혀요") ② 질문형 공감("매번 엉키는 줄, 지겹지 않으셨어요?")
  ③ 타깃 지정("좁은 원룸에 사는 분께") ④ 결과 제시("바닥이 한 번에 깨끗해져요")
  "안 사면 후회" 같은 겁주기 금지.
- 스펙을 쓰면 같은 장에 "그래서 고객이 할 수 있는 것" 한 줄을 붙인다.
  예: 방수 원단 → 비가 와도 안이 젖지 않아요 → 젖은 짐 걱정 없이 바로 출발
- 숫자에는 일상 비유 1개까지 가능(예: 200g → 스마트폰 한 대보다 가벼워요). 확인 안 된 숫자엔 비유도 금지. 다른 브랜드 비교 금지.
- 불편은 추상어(불편함·스트레스) 말고 구체적 장면으로("퇴근길 비에 젖은 노트북 가방").
- 해요체 구어. "~를 제공합니다·~가 가능합니다·~에 적합합니다" 같은 번역투 금지 → "~할 수 있어요·~돼요".
- "살펴보세요/확인해 주세요" 반복 금지.
- 금지어: 무조건·완벽·최고·100%·특가·선착순·혁신적인·프리미엄·고품질·고급스러운·최고급·국내산·국내생산·1위·베스트셀러·재구매율·판매량 N개
- 이미지 안 금지어: 공급처, 판매자에게 확인, 원본, 합성, 연출, 타오바오, 업로드, 파일, 해상도, 추출, 편집, 생성, AI, GPT, 코드
- 원본에 없는 기능·수치·인증 금지. 한 곳에만 나오거나 교차 확인 안 되는 수치는 뺀다.
- 실제 판매 구성과 다르게 읽힐 수치는 뺀다(예: 파는 호스는 5m·20m인데 "100m까지 연결" 금지).
- 상위 옵션에만 있는 부속을 기본형에 포함된 것처럼 쓰지 않는다.
- 제품 본체에 인쇄된 브랜드·모델명·라벨은 그대로 두고, 그 외 중국어는 잘라내거나 여백으로 처리한다.

5단계. 보호 표시 (마지막에 얹기)
==================================================
- 먼저 보호 표시 없는 본판(clean 버전)을 만들어 검수하고, 그 위에 아래 3가지를 얹어 최종본을 만든다. 다시 고칠 땐 항상 본판에서 다시 얹는다(겹쳐 얹기 금지).

① 작은 상표등록번호
  - 문구: 상표등록 제40-2501444호
  - 상품당 1번, 자연스러운 여백에. 24px, 얇은 테두리, 차분한 색(#8A8378 계열). 인증마크처럼 보이게 하지 않는다.
  - 사진·글과 겹치면 그 장 높이를 늘려서 넣는다.

② 무단복제 경고 박스 (전체 장수의 가운데쯤, 톤 배경 장에 1번)
  - 좌우 60px 여백, 폭 약 740px, 짙은 차콜 배경 + 밝은 글씨 + 낮은 채도 금갈색 포인트. 제목 32~34px, 본문 24~26px, Pretendard.
  - 제목: 상세페이지 무단복제·재사용 금지
  - 번호: 상표등록 제40-2501444호
  - 본문: 무단 사용 확인 시 증거 확보 후, 권리 침해 여부에 따라 신고 및 법적 대응을 진행할 수 있습니다.

③ 마켓명 대각선 워터마크
  - 폰트: 나눔손글씨 펜체(Nanum Pen Script)
    https://github.com/google/fonts/raw/refs/heads/main/ofl/nanumpenscript/NanumPenScript-Regular.ttf
  - 왼쪽 아래 → 오른쪽 위 18도, 불투명도 18%(배경이 복잡한 사진은 23%). 밝은 사진엔 짙은 회색, 어두운 사진엔 밝은 회색.
  - 글자 전체 길이 = 사진 폭의 80~85%, 자간 약 5px. 회전 후에도 사진 안에 들어와야 한다.
  - 주요 사진당 1번만(타일 반복 금지). 제품 로고·설명은 가리지 않는다. 글자만 있는 장·스펙 띠·경고 박스엔 넣지 않는다.
  - 마켓명은 내가 준 이름만 쓴다. 모르면 지어내지 말고 물어본다.

6단계. 장별 검수 (전부 통과해야 완료)
==================================================
1. 자연스러운 판매 문구인가 / 스펙마다 혜택 줄이 있나 / 제목이 4공식 중 하나이고 앞 장과 안 겹치나
2. 내부 용어·금지어가 없나
3. 중국어가 남지 않았나(제품 본체 인쇄 제외)
4. 밑줄·장식선·이모지·그라데이션이 없나
5. 글자가 박스 안에 있고 서로·제품과 겹치지 않나
6. 글자가 잘리거나 넘치지 않나
7. 마지막 요소가 이미지 끝에 붙지 않았나
8. 실제 리뷰처럼 속이는 표현이 없나
9. 글자 크기·색·여백이 위 값 그대로인가
10. 바로 앞 장과 레이아웃이 다른가
11. 아이보리+진갈색 톤이 전체적으로 맞나
12. (최종본) 워터마크가 로고·설명을 안 가리고, 상표번호 숫자가 정확하고, 경고 박스가 읽히나
