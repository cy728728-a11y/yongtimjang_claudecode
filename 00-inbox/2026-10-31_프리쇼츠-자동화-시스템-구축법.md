## 1부. 수익 인증과 사업 구조 (00:00 ~ 03:52)

### 1-1. 주장하는 실적

- 쇼츠 1개로 383만 원 번 사례 제시
- 채널별 누적: 3,147만 / 2,547만 / 963만 원. 반면 월 8,000원·1,600원짜리 채널도 있음

> "지금부터 저는 영상 직접 편집 없이 월 5,900만 원을 벌어보겠습니다." (00:00)

> "저희가 모든 채널이 수익이 잘 나는 건 아니고요. 이렇게 한 달 수익 8,000원. 여긴 더 심합니다. 한 달 수익이 1,600원입니다." (02:11)

### 1-2. 운영 구조
| 요소 | 내용 |
|------|------|
| 채널 수 | 30~40개 (테스트 채널 포함 약 40개) |
| 장비 | 휴대폰 30대 + 공유기 여러 대, 채널마다 인터넷 주소(IP)까지 분리 |
| 사람 | 프리랜서 18명 (대본 담당 / 편집 담당 분리) |
| 본인 역할 | 기획과 디렉팅만 |
| 분리 이유 | 채널 하나가 정지되거나 정책이 바뀌어도 전체가 안 흔들리게 |

> "제가 직접 고생을 하면서 편집을 하고 있는 게 아니라 프리랜서나 AI를 통해서 공장처럼 쇼츠가 계속 찍혀 나오게 하는 시스템입니다." (01:05)

> "3, 40개의 채널을 물리적으로 IP까지 싹 다 분리를 해서 채널 하나가 정지당하거나 정책이 바뀌거나 해도 크게 흔들림 없는 시스템을 만들었습니다." (02:11)

- 은행 외화 입금 증명서(신한·우리) — 월 485만 ~ 2,670만 원, 27,148달러 등

## 2부. 직접 만들어 보기 — 초보용 실습 (03:52 ~ 24:23)

### 2-1. 채널 만들기 (03:52 ~ 05:31)
1. 구글 계정 → 크롬 → 유튜브
2. 오른쪽 위 사람 모양 → 채널 만들기
3. 채널명은 자유(중복 가능), 핸들은 고유값이라 되는 것으로

### 2-2. "알고리즘 작업" (05:31 ~ 08:14)
- 쇼츠 탭에서 **내가 만들고 싶은 종류의 영상만** 끝까지 보고 좋아요·댓글
- 관심 없는 영상은 바로 넘김 → 추천이 그 종류로 채워짐
- 목적: 따라 만들 영상과 벤치마킹 채널을 쉽게 찾기 위함
- 초보 추천 유형: 음성(TTS) 없이 배경음 + 상황 설명 자막만 있는 동물 영상

> "끝까지 안 봤으니 알고리즘의 입장에서는 이분은 이 영상을 싫어하는구나, 보지 않는구나라고 판단을 하는 거죠." (06:04)

### 2-3. 벤치마킹 채널 분석 (08:14 ~ 11:04)
- 채널 영상을 최신순으로 보고 **조회수 터진 영상의 키워드**를 확인 (예: 인절미, 아기냥이, 리트리버)
- 구독자 9만 수준의 "채널 힘이 있는" 곳을 하나 정해 템플릿·자막·구성을 그대로 따라 함
- 이유: 그 채널 시청자 피드에 내 채널이 노출될 가능성이 올라감

> "저는 항상 채널을 새로 시작할 때 잘되는 벤치마킹 채널을 하나 찾으라고 해요." (10:30)

> "요런 채널들은 보통 이렇게 조회수 잘 나오는 이유가 있습니다. 영상의 구조가 완성도가 높다는 뜻이거든요." (11:04)

### 2-4. 소재 영상 구하기 (08:47 ~ 10:30)
1. 키워드를 영어로 번역(영어 검색이 영상이 더 많이 나옴) — 예: cute cat
2. 틱톡 + 유튜브 두 곳에서 검색, 조회수 수천만짜리 중 고름
3. 링크 복사 → "틱톡 다운로드" 사이트에서 HD로 내려받기

### 2-5. 준비물
| 준비물 | 방법 | 비용 |
|--------|------|------|
| 프로필 사진 | 챗GPT에 "귀여운 고양이 캐릭터 하나 그려줘" | 무료 |
| 편집 프로그램 | 캡컷(CapCut) | 연습은 무료, 업로드용은 월 19,800원 |
| 폰트 | 벤치마킹 채널 화면을 캡처 → 산돌구름 "이미지로 폰트 검색" → 무료 폰트 내려받기 | 무료 |

### 2-6. 캡컷 편집 순서 (12:43 ~ 22:43)
1. 프로젝트 만들기 → 영상·프로필 사진 끌어오기
2. 화면 비율 9:16
3. 위아래 흰 띠(미디어 라이브러리의 흰 이미지) 배치
4. 프로필 사진 + 채널명 + 영어 아이디를 위쪽에 배치 (인스타 화면처럼)
5. 제목 자막: 영상을 보고 떠오른 공감 포인트 — 예: "모든 집사들이 공감되는 행동"
6. 아래 자막: 상황 설명만, **약 2초마다 바뀌게**
7. 영상 길이 줄이기: 20초 → 8초
8. 자막 바뀌는 타이밍에 화면도 같이 전환되게 컷 맞춤
9. 영상 안에 말풍선식 자막(물음표, "쪽쪽", 일부러 낸 오타) 추가
10. 내보내기: 해상도 1080, H.264, 30프레임

> "20초는 너무 길어요. 별 내용이 없는데 내가 이걸 이렇게 끝까지 다 보고 있을 이유가 없거든요." (19:00)

> "쇼츠는 우리가 도파민을 얻기 위해서 보는 건데 조금이라도 지루하거나 요런 장면이 있는 거는 이탈율이 많아질 확률이 높습니다." (19:26)

> "처음 연습할 때는 100% 카피를 해 보는 게 좋은데… 일단 만드는 거에 의의를 두고 그냥 해 보는 겁니다." (17:09)

### 2-7. 업로드 (22:43 ~ 24:23)
- 만들기 → 동영상 업로드 → 제목은 영상 위 제목 자막 그대로
- **시청자층은 반드시 "아니요, 아동용이 아닙니다"** — 아동용이면 광고·알림 기능이 막힘
- 바로 공개 또는 예약(예: 밤 9시)
- 본인은 평소 휴대폰으로 올림

## 3부. 프리랜서와 분업하기 (24:23 ~ 30:31)

### 3-1. 구하는 법
- 알바몬에 "유튜브 쇼츠 편집자" 구인글 (남들 글을 참고해 작성)
- 지원자에게 오픈채팅 링크를 보내고 **면접은 100% 카톡**

### 3-2. 일의 흐름
| 단계 | 담당 | 내용 |
|------|------|------|
| 1 | 대본 프리랜서 | 원본 영상 링크 + 대본 작성 |
| 2 | 운영자 | 대본 검토·수정 요청 → 통과 |
| 3 | 편집 프리랜서 | 통과된 대본으로 편집, 완성본을 카톡으로 전달 |
| 4 | 운영자 | 자막 오류·컷 튐·오타 검수 |
| 5 | 프리랜서 | 정산서 제출 |

### 3-3. 관리 요령
- **"포기하시면 됩니다"** — 사람은 내 뜻대로 안 움직인다는 전제. 정해진 수량을 규칙적으로 받지 않고, 영상을 미리 쌓아 둬 공백을 메움
- 구글 시트로 매출·인건비·남는 돈을 날짜별 기록
- 면접 때 볼 것은 편집 실력이 아니라 **피드백 수용 능력**
- 초보도 최소한 "좋은 영상과 나쁜 영상을 구분하는 눈"은 있어야 프리랜서를 쓸 수 있음

> "가장 크게 중요하게 생각하는 게 편집 실력도 아니고 테스트 영상의 완성도 아니에요. 피드백 수용 능력을 보세요." (28:49)

> "이게 똥인지 된장인지 구분을 할 수 있는 최소한의 능력은 있어야 돼요." (29:23)

## 4부. AI(GPT 아스트라)로 자동 제작 (30:31 ~ 46:38)

### 4-1. 다루는 유형: "해자" (해외 짜깁기)
해외 영상을 가져와 한국어 해설·재미 요소를 넣어 재구성한 쇼츠.

### 4-2. 소재 고르는 기준
- 크롬 확장 프로그램 **vidIQ**로 영상의 조회수 추이 그래프 확인
- **더 이상 노출이 안 되는(그래프가 평평해진) 과거 대박 영상**을 고름 — 예: 1년 전, 705만 회

> "레전드 영상은 시간이 지나도 그대로 레전드로 남아 있는 거거든요… 사람들 기억에서 잊혀졌을 때쯤 다시 꺼내는 거죠." (31:37~32:11)

### 4-3. 대본: 젬스(맞춤형 AI)
- 영상 링크를 넣으면 대본을 A·B·C 세 가지 안으로 재구성
- 편집자 단톡방 대화 **카톡 45,000개**를 학습시켜 만들었다고 설명
- 이 젬스가 댓글 고정글의 "신청하면 주는 선물"

### 4-4. 편집: 아스트라가 컴퓨터를 직접 조작
| 순서 | 아스트라가 하는 일 |
|------|-------------------|
| 1 | 고른 대본 + 영상 링크를 받음 |
| 2 | 타입캐스트(음성 합성 사이트)에서 목소리·배속 지정해 음성 생성 |
| 3 | 원본에서 대사 구간을 찾아 자막 맞춤, 내레이션 1.2배속·쉬는 구간 제거 |
| 4 | 캡컷을 열어 프로젝트를 만들고 영상·자막·음성·효과음 배치 |
| 5 | 스스로 재생해 검수, 품질 보정 |

- 소요: **19분 11초**에 61초짜리 영상 1개
- 사람이 한 수정: 제목이 세 줄이라 두 줄로 줄임 ("9만 원 VS 890만 원")
- 결과물을 완성 영상이 아니라 **캡컷 프로젝트로 남기게 함** — 다른 언어판을 만들 때 자막·음성만 바꾸면 되기 때문

> "아스트라가 제 컴퓨터를 직접 제어를 하면서 영상을 제작해 줄 거예요." (33:51)

> "초반에 조금만 요런 지침들을 잘 구성을 해 놓으면 나중에 진짜 저처럼 영상 링크 하나 대본 하나만 넣었을 때 영상이 만들어지게끔 구성을 할 수 있는 거죠." (37:10)

> "저 아스트라 GPT 처음 하는데 저도 이렇게 할 수 있나요에 대한 대답을 드리자면은 아니요 안 됩니다… 요런 디테일한 프롬프트가 필요한 거죠." (42:09)

### 4-5. 다국어 확장
- 한국어 프로젝트 이름만 넣으면 일본어판 생성 (음성은 무료 프로그램 VOICEVOX)
- 일본 채널을 따로 만들어 업로드 → 콘텐츠 1개로 영상 2개
- 독일·스페인 등 광고 단가 높은 나라도 시도 중
- 한계: 캡컷은 한 번에 하나만 쓸 수 있어 캡컷 작업은 동시에 여러 개 못 돌림

### 4-6. 프리랜서 vs AI
| 구분 | 프리랜서 | 아스트라 |
|------|----------|----------|
| 시간 | 본인 일정에 맞춤 | 새벽에도 바로 |
| 부담 | 사람에게 시키는 부담 | 편하게 지시 |
| 품질 | 손발 맞춘 사람의 감성·센스는 대체 불가 | 잘하는 편집자는 아직 대체 못 함 |

> "잘하는 편집자들 기준에서는 아직 대체가 되지 않는다고 생각을 하거든요." (37:43)

## 5부. 자체 프로그램과 자동 업로드 (46:38 ~ 53:19)

### 5-1. "뚝딱이" (초보용 영상 제작기)
- 챗GPT 계정을 연결 → 프리셋(미리 넣어 둔 지침) 선택 → 유튜브 링크 붙여넣기 → 쇼츠 완성
- 시연: 스케치 코미디 영상 링크 → 56초 쇼츠
- 내 지침을 프리셋으로 추가 가능
- 3기 수강생용

### 5-2. 자동 업로드 (텔레그램 중계)
1. 제작 컴퓨터: 영상이 완성되면 영상·제목·설명문·예약시간을 텔레그램 방으로 전송
2. 업로드 컴퓨터: 메시지를 받아 영상을 내려받고 아스트라가 유튜브에 예약 업로드
- 컴퓨터를 나누는 이유: 한 기기에서 너무 많이 올리면 위험하다고 봄 + 자리 비웠을 때도 돌아가게

> "한 기기에서 너무 많은 업로드가 진행되는 거는 저는 조금 리스크가 있다고 생각을 하는 편이에요." (49:57)

### 5-3. 수강생 사이트 "프쇼의 숲"
- 챌린지·숙제 제출·순위표, 프로그램 내려받기, 질의응답

- 3기: 초보는 진입 장벽 낮추기, 중급은 카테고리 발굴·확장

> "완벽한 영상은 아니더라도 제작해서 업로드는 해 보셨으면 좋겠어요." (53:52)

## 핵심 요약

1. **구조**: 소재 찾기 → 대본 → 음성 → 편집 → 검수 → 업로드. 사람은 "소재 고르기·대본 고르기·최종 검수"만 남김.
2. **돈 버는 원리**: 한 채널에 기대지 않고 수십 개로 분산. 안 되는 채널이 많다는 걸 전제로 수량으로 덮음.
3. **AI 활용의 실체**: 편집 프로그램(캡컷)을 AI가 대신 클릭하게 하는 방식. 핵심 재료(세부 지침)는 비공개.
4. **확장**: 같은 영상을 언어만 바꿔 다른 나라 채널에 재사용.

## 분석: 용팀장이 자동화할 수 있나

### 결론
**기술적으로는 거의 전부 가능하다.** 영상이 비공개로 둔 "세부 지침"은 특별한 비법이 아니라 목소리·폰트·자막 규칙을 적어 둔 문서라서 직접 만들 수 있다. 다만 **영상 방식(남의 영상을 내려받아 재가공) 그대로는 비추천**이고, 내 소재로 바꿔 쓰는 게 맞다.

### 단계별 자동화 가능 여부
| 단계 | 자동화 | 방법 |
|------|--------|------|
| 소재 후보 수집 | 가능 | 유튜브 공식 조회 기능으로 조회수·업로드일 기준 추림 |
| 대본 3안 작성 | 가능 | 클로드가 바로 씀. 젬스 불필요 |
| 음성 생성 | 가능 | 음성 합성 서비스 연결 (유료 계정 필요) |
| 편집 | 가능 | 캡컷을 클릭시키지 않고 코드로 바로 영상 생성 (이미 있는 모션그래픽 도구 방식) — 더 빠르고 동시에 여러 개 가능 |
| 자막·효과음 | 가능 | 편집 단계에 포함 |
| 다국어판 | 가능 | 자막·음성만 교체 |
| 예약 업로드 | 가능 | 유튜브 공식 업로드 기능 (하루 업로드 수 제한 있음) |
| 채널 30~40개·기기·IP 분리 | 비추천 | 휴대폰 30대급 물리 장비가 필요하고, 걸리면 전 채널이 같이 정지될 수 있음 |

### 그대로 따라 하면 안 되는 이유 (사업 판단)
- 유튜브는 "재사용 콘텐츠"에 수익 창출을 안 내주거나 회수한다. 영상 속 운영자도 채널 정지를 전제로 40개로 분산해 놓은 것 — 즉 **정지가 일상인 사업**이다.
- 수익 인증은 상위 채널 기준이고, 본인도 월 1,600원 채널이 있다고 밝혔다.
- 용팀장은 얼굴·이름을 걸고 강의하는 사람이라 채널 정지·저작권 신고가 본업 신뢰에 직접 타격이 된다.

### 추천 방향
같은 "공장" 구조를 **내 소재**에 적용한다.
- 구매대행 상품 영상 (판매자 제공 영상·내 상세페이지 이미지)
- 내 유튜브 긴 영상·강의 녹화를 쇼츠로 자르기
- 하입덕 스레드 글을 쇼츠 대본으로 재활용
