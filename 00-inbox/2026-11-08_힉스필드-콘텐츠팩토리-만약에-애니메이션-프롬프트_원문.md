### 📖 **콘텐츠 팩토리 쓰는 순서**
콘텐츠 팩토리는 질문 하나를 넣으면 이야기, 장면, 자막까지 들어간 애니메이션 한 편을 만들어 주는 기능입니다. 장면을 그림으로 그리는 게 아니라 클로드가 코드로 짜서 움직이는 방식이라, 화면에 숫자를 띄우는 영상도 숫자가 흐트러지지 않고 나옵니다. 저는 한국어 화면에서 했고, 생성 버튼을 누르고 결과가 나오기까지 20분 정도 걸렸습니다.

✅ **순서**
- [ ] 위 링크로 힉스필드에 들어가 콘텐츠 팩토리를 엽니다 (한국어 화면: `higgsfield.ai/ko/content-factory`)

- [ ] 완성되면 내 생성 목록에서 영상을 열어 확인하고 내려받습니다

### 🫡 **영상에서 돌린 프롬프트**
릴스에 나온 "1원 vs 10억" 애니메이션을 만든 프롬프트 원문입니다. 요즘 조회수가 크게 나오는 "만약에" 영상들을 보니 첫 장면에 질문이 뜨고, 화면 위에 숫자가 실시간으로 오르고, 장면이 점점 커지는 흐름이 공통이더라고요. 그 흐름을 그대로 옮겨 적었습니다.

✅ **콘텐츠 팩토리 입력창에 그대로 붙여 넣기**
```Plain Text
만약 오늘 1원을 받고 매일 2배가 된다면? 아니면 지금 당장 10억? 3D 로우폴리 스타일, 1인칭 시점(내 손에 동전 하나), 밝고 선명한 조명. 화면 상단에 큰 숫자 HUD로 'DAY'와 '내 돈', '10억까지' 진행바를 실시간 표시. 숫자가 오르는 걸 충분히 볼 수 있게 각 단계에 여유를 둔다. 1일차 1원 → 5일차 16원("이게 뭐야") → 10일차 512원 → 15일차 1만6천 원 → 20일차 52만 원("역시 10억이 낫네") → 25일차 1,677만 원(금고가 차기 시작) → 27일차 6,710만 원 → 29일차 2.7억("아직 한참 멀었는데…") → 30일차 5.4억("겨우 절반") → 31일차 10.7억으로 10억을 추월하는 순간을 슬로모션과 큰 글자로 강조 → 35일차 172억 → 40일차 5,498억. 돈의 크기에 맞춰 장면이 커진다: 손바닥 동전 → 지갑 → 금고 → 은행 금고 → 한강 위로 쌓이는 지폐 탑 → 서울 도심 전체를 덮는 지폐(밝은 낮 하늘, 남산 위에서 내려다보는 시점). 숫자가 커질수록 카메라가 뒤로 빠지며 스케일이 폭발한다. 내레이션 없이 한국어 자막과 경쾌한 효과음만. 마지막 화면: "29일까지 참을 수 있는 사람만 이긴다" → 첫 질문 "1원 vs 10억, 당신은?"을 다시 띄워 끝낸다.
```

✅ **내 주제로 바꿀 자리**
- 첫 질문 → 내가 궁금한 "만약에" 질문 (예: `만약 지구가 하루 동안 멈춘다면?`)
- 날짜별 숫자 → 내 주제에서 변하는 값 (높이, 인구, 온도처럼 화면에 띄울 숫자)
- `손바닥 동전 → 지갑 → 금고 …` → 숫자가 커질 때 같이 커질 장면 순서
- 마지막 화면 → 다시 첫 질문으로 돌아가는 한 줄
