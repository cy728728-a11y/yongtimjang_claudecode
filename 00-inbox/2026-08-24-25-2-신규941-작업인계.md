## 3. gws 인증 — 403은 계정 문제가 아니었다

작업 도중 시트가 전건 막혔다. 진단이 **두 번 틀렸다**:

1. 로그 첫 줄이 `invalid_grant: Token has been expired or revoked` → 늘 있는 7일 만료로 봤다
2. `gws auth status` 의 `user` 가 `chloe91727@gmail.com` → 계정 착오로 단정하고 재로그인
3. **`cy728728@gmail.com` 으로 제대로 붙었는데도 403 그대로였다**

실제 원인은 **GCP 프로젝트 `gws-cli-cy728728-01` 자체를 못 쓰는 상태**였다. 표식은
**sheets·drive·gmail 이 전부 같은 403** 이라는 것 — 특정 API 문제였다면
"API가 사용 설정되지 않았습니다"로 다르게 나온다. 콘솔에서 정리된 뒤 저절로 풀렸다
(에러 메시지가 예고한 "Propagation ... may take a few minutes").

**다음에 403이 뜨면 재로그인부터 하지 마라.** 순서는
① 전 서비스 공통인지 확인 → ② 공통이면 Cloud Console 에서 프로젝트 상태 → ③ 그다음 계정.
메모리 `gws-quota-project-403` 에 남겼다.

> **재로그인을 브라우저로 대신할 때 함정**: Claude in Chrome 확장은 **머신이 아니라
> 계정에 붙는다.** 이 계정엔 macOS 1 + Windows 2 = **3개**가 연결돼 있어서, 브라우저를
> 지정하지 않으면 엉뚱한 기계의 크롬에 탭이 열린다. `gws auth login` 콜백은
> **맥북의 `localhost:<포트>`** 로 와야 하므로 윈도우 크롬에서 열면 절대 안 끝난다.
> `open -a "Google Chrome" "<URL>"` 로 **맥북에서 직접 여는 게** 가장 확실하다.
> 그리고 **로그인 창을 두 개 띄우면** 구글이 "문제가 발생했습니다"를 낸다 — 하나만 띄운다.
