## 0. 한 줄 요약

카톡방 수십 개를 AI(클로드 코드)가 직접 열어 읽고, 메시지마다 **요청·질문·일정·결정·잡담**을 초고속 판정 AI(Jev)로 분류한 뒤, 업무 누락·불일치를 잡아 보고하고, 필요하면 ERP 확인·세금계산서 발행 요청·카톡 발송까지 이어서 처리하는 "카톡 업무 비서" 시연.

## 1. 영상에서 쓴 도구 (고정 댓글 기준)

| 도구 | 역할 | 비고 |
|------|------|------|
| 클로드 코드 | 카톡을 읽고 판단하고 일을 처리하는 본체 | 용팀장 이미 사용 중 |
| Orca | 클로드 코드·코덱스 등을 한 화면에서 다루는 작업 환경 | 용팀장 이미 설치됨 (`/Applications/Orca.app`) |

## 2. 내용 정리 (흐름 순)

### Part 1. 문제 제기 — "카톡 지옥" (00:00~01:30)

- 화자는 아버지 회사에서 4년간 일하며 가장 힘들었던 게 카톡 업무였다고 함.

> "하루에도 이렇게 수십개의 카톡창 띄어 놓고 정신없이 일하다 보면은 이게 업무 누락이 꼭 발생을 하더라고요. 그러다가 수백만 원 손실을 더 본 적도 있고요."

> "제가 아버지 회사에서 4년 동안 구르면서 제일 힘들었던 게 바로 이 카톡 지옥이었어요."

- 영상 구성 예고: ① AI가 카톡을 어떻게 읽나 ② 메시지를 어떻게 분석해 업무로 파악하나 ③ 에이전트와 엮어 끝까지 처리하나.

### Part 2. 시연 1 — 한 사람과의 대화 분석 (01:30~03:00)

- 명령: "김수현 님과 카톡 내용 분석해봐"
- AI가 스스로 카톡방을 열고 스크롤하며 읽음. 이미지도 눌러서 확인. 사진 6장을 22초 만에 확인.
- 결과: 가장 급한 일(코드 수정 미반영) → 다음 할 일 → 우선순위 → **보낼 메시지 초안**까지.

> "우선 순위로까지 알려 주고 심지어 이렇게 보낼 메시지 초안까지 작성을 해 줘요. 이거 보내라고 하면 당연히 메시지 발송도 됩니다."

### Part 3. Jev의 역할 — 메시지별 의도 판정 (03:00~04:30)

- 뒤에서 Jev가 메시지 하나하나를 판정: 잡담 / 정보 요청 / 요청 / 문제.
- 속도: 몇 초. 비용: 1~2원 수준(화자 주장).

> "필요한 메시지가 있고 필요 없는 메시지가 있잖아요. 이 제브라는 AI는 판단을 엄청나게 빠르게 할 수 있는 그런 툴이거든요."

> "지금 모든 메시지마다 어떤 의도인지 판단을 지금 다 한 거예요."

> "수백개의 카톡방이나 수백건 뭐 수천 건의 메시지도 엄청나게 빠르게 분석을 할 수가 있어요."

### Part 4. 원리 — 접근성 기능으로 화면 읽기 (04:30~05:30)

- 컴퓨터에는 시각장애인용으로 "화면에 이런 글자·버튼이 있다"를 알려 주는 기능이 있음 (맥: 손쉬운 사용 / 윈도우: 접근성).
- 이걸 AI의 눈으로 씀. 일반 "컴퓨터 사용"(화면 캡처해서 보는 방식)보다 훨씬 빠름.

> "컴퓨터 유즈로 할 때는 이제 화면을 캡처하거나 구조를 파악하는 방식이라 속도가 되게 느린데 이렇게 하니깐 되게 빠르게 할 수 있더라고요."

### Part 5. 시연 2 — 한 달치 여러 방 읽기 + 고객 데이터 대조 (05:30~07:00)

- "최근 한 달치 읽어"라고 지시 → 방 3개를 차례로 열고, 날짜를 찾아 위로 올라가며 읽음.
- 224건을 Jev가 6초 만에 판정.
- 미리 넣어 둔 고객 데이터와 대조해 "업무를 제대로 했는지" 확인 → "해야 할 일 3개" 정리.
- 제품 코드까지 넣어 두어서 "저장 오류 수정은 제가 바로 시작할 수 있습니다" → 그 자리에서 개발까지.

> "판단도 우리의 기준을 계속 먹여 주면 훨씬 더 계속 정확해지더라고요."

> "따로 개발자한테 가서 뭐 요청하고 대화하고 할 필요가 없이 그러니까 이 터미널 창에서 모든 일을 다 하는 거죠."

- 운영 방식: 일정 시간마다 자동으로 돌려 두고, 필요할 때 바로 물어봄.

### Part 6. 시연 3 — 프로젝트 관리 툴(ERP) 연결 (07:00~08:30)

- 카톡에서 관련 인물들 찾기 → 메시지 판정 → 브라우저로 ERP 들어가 스크롤·캡처.
- 결과: "다음 주 설치 3건 중, 김수현 님 방에서 프로그램 저장 오류 발견 → 빨리 고쳐야 일정 차질 없음" + 오늘 할 일 정리 + 해당 직원에게 카톡 발송.

> "결국 AI한테 도구를 하나씩 하나씩 붙여 주면은 얘 능력이 이렇게 많아지는구나, 커지는구나라고 깨달았고"

### Part 7. 읽기 → 쓰기(행동) (08:30~10:00)

- 지금까지는 "읽기(업무 파악)", 여기에 "쓰기(행동)"를 붙임.
- 우리만의 기준을 주면: 이런 경우 카톡 보내기 / 이메일 보내기 / 견적서 작성 / 대표 호출.

> "이런 우리만의 기준을 주면 얘가 진짜 슈퍼 직원이 되더라고요."

- 옛날 ERP·자체 어드민은 연동 통로(API)가 없는 경우가 많음 → 그래서 화면 조작으로 처리.
- 시연 4: 세금계산서. 카톡 확인 → 분류 → 브라우저 열어 발행 요청 작성 → "발행 요청이 등록되었습니다" → 담당자가 "발행 완료" 누르면 볼타 API로 실제 발행.

### Part 8. 실수 사례 — 120칸/140칸 사건 (10:00~11:00)

실제 일을 각색한 사례. 구매대행 주문 실수와 구조가 똑같다.

| 순서 | 일어난 일 |
|------|----------|
| 1 | 고객: "120칸, 금요일까지 되나요?" → "가능합니다" 답변 |
| 2 | 공장: "월요일 가능" → 월요일로 잡음. 고객에게 전화 안 함 (까먹음) |
| 3 | 고객: 150칸으로 변경 → 다시 140칸으로 변경, "금요일 오전 맞죠?" |
| 4 | 공장엔 전달 안 됨 → 공장: "내일 조립 들어갑니다, 120칸 맞죠?" → 따봉 |

> "진짜 제 온몸에 식은땀이 흘렀어요."

- AI 판정 결과: **"중지. 조립 전에 멈춰라. ① 수량이 다르고 ② 날짜가 다르다. 틀린 수량을 공장에 확정해 버렸다. 고객에겐 금요일 가능한지 다시 묻고, 공장엔 140칸으로 정정해라."**

> "이걸 원래였으면 목요일 날 알았겠지만 이 AI 시스템을 도입하고 나서는 월요일 날 알 수가 있는 거죠. 그날 바로."

### Part 9. 화자의 결론 (11:00~12:30)

- 카톡(여러 방) + AI(읽기·보내기) + 여러 도구(ERP·구글드라이브·슬랙) 연결.
- 중요한 건 "우리 회사를 어떻게 세팅하느냐" — 어떤 정보를 받았을 때 어떻게 처리하는지의 규칙. 발전하면 온톨로지(회사 업무 지식 지도).

> "마음만 먹으면 컴퓨터에서 내가 하고 있는 일들을 대부분의 일들을 다 얘가 할 수 있는 거예요."

> "한 6개월 혹은 진짜 길게 12개월 정도만 지나면 이 방법이 이제 보편화될 거고"

> "이걸 도입하지 않은 기업들 혹은 AI를 이렇게 다룰지 모르는 사람들은 아, 좀 힘들지 않을까"

### Part 10. 입문 방법 (12:30~13:23)

- ChatGPT 앱 → 왼쪽 아래 설정 → 통합 → "컴퓨터 사용" 켜기 → 크롬·엑셀 등 허용할 앱 선택.
- 느리고 답답할 때가 많은데, "왜 안 되는지" AI와 차분히 대화하며 풀어 가라.

> "차분히 왜 그러는지 어떻게 해야 지금 이 이슈를 해결할 수 있는지 한번 대화를 잘 해 보시면 이제 신세계가 열릴 겁니다."

## 3. 핵심 요약

1. **읽기**: 카톡을 AI가 직접 읽는다 (영상은 접근성 기능으로 화면을 읽음).
2. **판정**: 메시지마다 의도 분류는 싸고 빠른 판정 전용 AI(Jev)에 맡긴다. 긴 글 쓰는 AI(클로드)는 정리·판단에만.
3. **대조**: 고객 데이터·ERP와 비교해 "말한 것과 처리한 것이 다른 곳"을 잡는다 ← 진짜 가치는 여기.
4. **행동**: 규칙을 주면 카톡 발송·계산서 요청·견적서까지 이어서 한다.
5. **규칙이 자산**: "이런 메시지엔 이렇게"라는 회사 기준을 쌓을수록 정확해진다.

## 4. 용팀장 관점 분석

### 4-1. 이미 갖고 있는 것 vs 새로 필요한 것

| 영상 구성요소 | 용팀장 현황 | 판단 |
|--------------|------------|------|
| 클로드 코드 | 사용 중 | — |
| Orca | 설치·사용 중 | — |
| 카톡 읽기 | **`kakao-read` 스킬 있음** (맥 카톡 저장 파일을 직접 읽음, 설정 완료) | 영상 방식(화면 스크롤)보다 빠르고 안정적. 한 달치도 몇 초 |
| 카톡 체크 루틴 | `kakao-read` 의 "카톡 체크" → inbox-triage 연결 있음 | 이미 "새 대화만 훑기"가 됨 |
| 메시지 의도 분류 | 클로드가 직접 함 | 양이 적으면 클로드로 충분. Jev는 선택 |
| 카톡 보내기 | `auto-watch` 의 "나에게 보내기"만 | 남에게 보내기는 의도적으로 막아 둠 (계정 위험) |
| ERP | 불사자·스스·업무판(구글시트) 연동 있음 | 이미 영상보다 앞서 있음 |
| 세금계산서(볼타) | 없음 | 구매대행 B2B 계산서 요청이 많을 때만 검토 |

**결론: 새로 깔 건 사실상 없다.** 영상의 핵심(카톡 읽기)은 이미 더 좋은 방식으로 갖고 있다. 빠진 건 "판정 규칙"과 "대조"뿐.

### 4-2. 내 업무에 바로 쓸 포인트

1. **"말과 처리가 다른 곳" 잡기 (120칸 사건의 구매대행 버전)**
   - 고객이 카톡/톡톡으로 옵션·색상·수량을 바꿨는데 구매처·배대지 주문엔 반영 안 된 경우.
   - 방법: `카톡 체크` 할 때 "요청·변경·결정"으로 판정된 메시지만 모아, 주문시트와 대조하게 한다.
2. **판정 규칙 문서 만들기** — 영상의 핵심 메시지("우리만의 기준을 먹여라").
   - 예: "교환·반품 문의 → cs-response로 답변 초안", "배송 지연 → 송장 확인", "세금계산서 요청 → 메모 후 todo", "잡담 → 무시".
3. **카톡 체크 정기 실행** — 화자는 "일정 시간마다 돌려 둔다". 아침 auto-watch 처럼 하루 1~2회 카톡 체크 요약을 '나에게 보내기'로 받는 구성이 가능.
4. **보내기는 초안까지만** — 영상은 화면 조작으로 카톡을 직접 보내지만, 카카오 계정 제재 위험이 있다. 초안을 만들어 주면 내가 복사해서 보낸다.

### 4-3. Jev 판단

**정체**: TypeSafe AI가 만든 "판단 전용" AI. 글을 안 쓰고 "환불 82% / 결제 15% / 배송 3%" 같은 짧은 판정만 낸다. 2026-09 기준 입력 100만 토큰당 $0.042, 출력은 무료 (1만 건 ≈ 600원 수준).

**필요한가?**
- 카톡 분류용: **아직 불필요.** 1인 셀러의 카톡 양은 클로드가 직접 읽어도 몇 초~몇십 초. 비용 차이도 미미.
- 오히려 쓸모 있는 곳: **대량 텍스트 판정**. 예) 소싱 검수 1차의 상품명·카테고리 기반 걸러내기, 고객 문의 대량 분류, 리뷰 대량 분류. 수만~수십만 건일 때 클로드 대비 비용이 크게 준다.
- 주의: 속도·비용 수치는 회사 자체 측정, 외부 검증 없음. 한국어 성능은 공식 안내에 없음 → 써 보기 전 표본 테스트 필수. 이미지 판정은 확인 안 됨.

**설치·사용 순서 (원하면)**
1. https://console.typesafe.ai 가입
2. https://console.typesafe.ai/keys 에서 키 발급 → 맥북 비밀 파일에 저장 (채팅에 붙이지 않음)
3. 클로드 코드에 공식 스킬 설치:
   ```
   claude plugin marketplace add typesafe-ai/skills
   claude plugin install typesafe@typesafe-ai
   ```
4. 클로드에게 "카톡 체크 결과를 Jev로 요청/질문/일정/결정/잡담 분류해줘"라고 시킴
5. 플레이그라운드(https://console.typesafe.ai/playground)에서 먼저 손으로 몇 건 시험해 보는 게 안전

### 4-4. 수강생·스터디원에게

| 대상 | 추천 방법 | 이유 |
|------|----------|------|
| 일반 수강생 (비개발자) | **카톡 "대화 내보내기" → 텍스트 파일을 ChatGPT/클로드에 올려 분석** | 설치 0, 무료, 윈도우·맥 공통, 계정 위험 없음 |
| 조금 하는 수강생 | ChatGPT 앱 "컴퓨터 사용" (영상 말미 방법) | 영상이 추천한 입문 경로 |
| 스터디원 (클로드 코드 쓰는 사람) | `kakao-read` 방식 (맥 전용) | 강력하지만 맥 전용·설치 단계가 있음 |

**수강생용 프롬프트 예시**
```
첨부한 카톡 대화에서 메시지마다 [요청/변경/결정/일정/질문/잡담]으로 분류해줘.
그다음 고객이 처음 말한 것과 나중에 바꾼 것이 다른 곳(옵션·수량·날짜·주소)을 표로 찾아줘.
마지막으로 내가 오늘 해야 할 일과, 고객·구매처에 보낼 메시지 초안을 써줘.
```

**주의(수강생에게 꼭 말할 것)**: 고객 이름·전화·주소가 든 대화를 AI에 올릴 땐 개인정보 주의. 남의 카톡을 몰래 읽는 용도 금지. 카톡 자동 발송은 계정 제재 위험.

### 4-5. 무료강의 소개 가치

**소개할 만하다 — 단, "도구 소개"가 아니라 "사례" 중심으로.**

- **훅**: "카톡 지옥" + "120칸 사건" → 구매대행 버전으로 각색: "고객이 색상 바꿨는데 타오바오 주문은 원래 색으로 들어가서 반품비 날린 경험 있으시죠?"
- **데모 (3분)**: 카톡 대화 내보내기 → 위 프롬프트 → 바뀐 부분 표 + 할 일 + 답장 초안. 설치 없이 무료라 수강생이 바로 따라 함.
- **메시지**: "AI는 글쓰기 도구가 아니라 실수 잡는 직원이다. 기준을 먹이면 직원이 된다." → 실전반에서 "기준 만드는 법"을 배우는 동기로 연결.
- **빼는 것**: Jev·볼타 API·접근성 원리는 무료강의에선 과함 (개발자 영역). 실전반/스터디에서 "이런 것도 있다" 수준으로만.
