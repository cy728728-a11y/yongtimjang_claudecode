프롬프트와 자료집

      프롬프트 3개는 설치 없이 바로
      REA, replica 설치 순서 수록

    잘 만든 앱 화면을 캡처 한 장과 요청문 하나로 내 것으로 다시 만드는 프롬프트 3개를 모았어요. 앱 속을 직접 뜯어보고 싶을 때 쓰는 REA, replica 설치 순서와 이용 방법, 주의할 점 체크리스트도 담았어요.

    프롬프트는 설치 없이 바로 써 볼 수 있어요. 위에서 아래로 읽어도 되고, 필요한 절만 골라 보셔도 돼요.

    에트매거진 에디터가 클로드(Max 요금제, Opus 5.5)로 직접 해 본 요청문 그대로 정리했어요. 요금제와 모델에 따라 결과는 달라질 수 있어요.

    먼저, 리버스 엔지니어링, REA, replica가 뭔가요?

    완성된 요리를 맛보고 레시피를 알아내듯, 완성된 앱을 보고 어떻게 만들었는지 거꾸로 알아내는 일이 리버스 엔지니어링이에요.

      REA: 소스 코드 없이 완성된 앱을 뜯어 작동 원리를 알아내는 무료 오픈소스 도구예요. 클로드 코드, 코덱스 같은 AI에 붙여 써요.

      replica: 앱을 분석해 다시 짓는 클로드용 무료 스킬 11개 묶음이에요. 화면과 흐름을 분석하고, 다시 만들고, 원본과 비교하고, 리뷰 속 불만을 고치는 순서로 돌아가요.

      두 도구는 따로 설치해 따로 써요. replica는 첫 단계 recon에서 스스로 앱을 뜯어요.

    이렇게 사용하세요

      1절 프롬프트 3개 중 하나를 골라 클로드 채팅창에서 먼저 해 봐요. 설치는 필요 없어요.

      앱이 실제로 어떻게 움직이는지까지 보고 싶어지면 2절대로 REA, replica를 설치해요.

      만든 걸 쓰거나 올리기 전에 3절 체크리스트를 봐요.

    1절
    설치 없이 붙여 쓰는 프롬프트 3개

    이럴 때 써요: 잘 만든 화면을 보고 "이거 내 가게, 내 모임 버전으로 있으면 좋겠다" 싶을 때. 클로드(claude.ai) 채팅창에 원본 캡처를 올리고 아래 문장을 붙이면 돼요.

    💡 잘 시키는 공식: 구성(무엇이 어디에 있는지) + 내 주제 + 실제로 움직일 것 + 원본에서 쓰지 말 것을 한 문장에 넣어요.

      🎮 게임을 우리 집 강아지 버전으로

      원본: 달리기 게임 화면 캡처

      복붙용 👇🏻

      이 게임 화면의 구성(왼쪽에서 달리는 캐릭터, 오른쪽에서 다가오는 장애물, 오른쪽 위 거리 점수, Play·Jump·Restart 버튼, 속도 막대)을 그대로 빌려서, 우리 집 강아지(하얀 말티즈)가 동네 골목을 달리며 화분을 뛰어넘는 게임을 HTML 한 장으로 만들어 줘. 스페이스바나 화면을 누르면 점프하고 실제로 플레이할 수 있게 해 줘. 게임 중인 장면이 보이는 미리보기 이미지도 보여 줘. 원본의 공룡 그림과 글자는 쓰지 말고 새로 그려 줘.복사

      ✅ 받는 결과: 말티즈가 골목을 달리고, 누르면 점프하는 게임 한 장.

        클로드가 만든 게임 화면이에요.

      🧮 계산기를 우리 모임 N빵 계산기로

      원본: 계산기 앱 화면 캡처

      복붙용 👇🏻

      이 계산기 화면의 구성(위쪽 계산 탭 2개, 오른쪽 큰 숫자 결과창, 아래 버튼, 맨 아래 한 줄 설명)을 그대로 빌려서, 모임 회비 N빵 계산기를 HTML 한 장으로 만들어 줘. 총액과 사람 수를 넣으면 1인당 금액이 바로 나오고, 술 안 마신 사람 빼기와 10원 단위 올림도 되고, 카톡에 붙일 정산 문구를 복사하는 버튼까지 실제로 작동하게 해 줘. 숫자를 넣은 상태의 미리보기 이미지도 보여 줘. 원본 글자는 쓰지 말고 한국어로 새로 만들어 줘.복사

      ✅ 받는 결과: 총액과 인원을 넣으면 1인당 금액이 바로 나오고, 정산 문구를 복사할 수 있는 계산기.

        클로드가 만든 계산기 화면이에요.

      ☕ 메뉴 화면을 담기 되는 주문 페이지로

      원본: 카페 메뉴 페이지 캡처

      복붙용 👇🏻

      이 메뉴 페이지의 구성(왼쪽 위 큰 제목, 분류를 고르는 상자와 체크 칸, 분류 이름 띠, 아래 사진 4칸 격자)을 그대로 빌려서, 동네 카페 "골목 끝 커피"의 주문 페이지를 HTML 한 장으로 만들어 줘. 분류 체크 칸을 누르면 메뉴가 실제로 걸러지고, 메뉴를 누르면 장바구니에 담겨 오른쪽에 수량과 합계 금액이 바로 바뀌게 해 줘. 장바구니에 2~3개 담긴 상태의 미리보기 이미지도 보여 줘. 원본의 로고와 사진은 쓰지 말고, 음료는 연한 배경 위 컵 그림으로 그려 줘.복사

      ✅ 받는 결과: 메뉴를 누르면 장바구니에 담기고 합계가 바뀌는 주문 페이지.

        클로드가 만든 주문 페이지 화면이에요.

    💡 "골목 끝 커피", "하얀 말티즈" 자리에 내 가게 이름, 내 강아지를 넣으면 돼요.

    2절
    REA, replica 설치 순서 및 이용 방법

    💡 이 절은 클로드 코드를 쓰는 분용이에요. REA는 코덱스, 커서 같은 다른 AI에도 붙일 수 있어요. 아직 없다면 1절 프롬프트만으로도 해 볼 수 있어요.

    이럴 때 써요: 화면 캡처만으로는 모자라서, 앱이 실제로 어떻게 움직이는지까지 뜯어보고 다시 짓고 싶을 때.

    ⚠️ REA는 클로드 코드처럼 컴퓨터에서 도는 AI에 붙여 써요. replica는 클로드에 스킬로 넣어요. 클로드 코드는 유료 요금제(Pro 이상)에서 쓸 수 있어요.

      🔵 REA (앱 속을 뜯는 도구)

      준비물: Node.js(22.23.4 이상의 22 버전, 24.22.1 이상의 24 버전, 26.12.1 이상 중 하나)가 설치된 컴퓨터. nodejs.org에서 받아요.

        터미널은 명령어를 글자로 입력하는 프로그램이에요. 맥은 Spotlight(⌘ + 스페이스), 윈도는 시작 메뉴에서 "터미널"을 검색해 열어요.

        뜯어볼 앱 폴더 밖, 믿을 수 있는 폴더에서 터미널에 아래 명령을 넣고 Enter를 눌러요.
          🍎 🪟 터미널 👇🏻

          npx rea-agents setup복사

        쓰는 AI(클로드 코드, 코덱스, 커서, 제미나이 CLI 등)를 고르고, 바뀌는 설정을 확인한 뒤 승인해요.

        AI를 껐다 켜요.

      💡 설치된 앱을 깊게 뜯으려면 호퍼, 기드라, 아이다 같은 분석 프로그램이 필요할 수 있어요. 설치 중에 호퍼를 깔지 물어봐요. 호퍼와 아이다는 유료 프로그램이에요. 자바스크립트 앱을 정적으로 볼 땐 없어도 돼요.

      ⚠️ 받는 곳은 공식 깃허브 morluto/rea, rea.tools, npm rea-agents만 써요. 비슷한 이름의 저장소는 공식이 아닐 수 있어요.

      이용 방법: AI에게 아래처럼 부탁해요. 메모 앱 자리에 뜯어볼 앱과 궁금한 기능을 넣으면 돼요.

      복붙용 👇🏻

      메모 앱의 검색이 어떻게 작동하는지 알아내고, 근거를 보여 준 다음, 내 프로젝트에 비슷한 기능을 만들어 줘.복사

      ✅ 됐을 때: AI가 REA 도구를 불러 근거와 함께 설명해요.

      💡 새 버전이 자주 나와요. 다시 설치할 땐 아래 명령을 넣어요.

      npx rea-agents@latest setup복사

      🟠 replica (클로드 스킬 11개)

      설치: 클로드 코드에서 플러그인으로

      아래 두 줄을 차례로 하나씩 넣어요.

      🟠 클로드 코드 👇🏻

      /plugin marketplace add Jakeschincariol/replica-skill복사

      /plugin install replica-skill@replica-skill복사

      ✅ 됐을 때: 클로드 코드에서 /replica-skill:replica-recon 같은 명령이 보여요.

      이용 방법: 프로젝트 폴더에서 다시 만들 앱의 주소와 함께 첫 명령을 넣어요. 스킬마다 앞 단계가 replica 폴더에 쓴 결과를 읽어서 이어 가요.

      🟠 클로드 코드 👇🏻

      /replica-skill:replica-recon https://다시-만들-앱-주소복사

      💡 순서: recon(뜯기) → architect → design → build(다시 짓기) → backend → test → diff(원본과 비교) → entrepreneur(리뷰 불만 고치기) → brand → launch → deploy. 도구 일부는 파이썬 3.8 이상이 필요해요.

      💡 앱을 만들까 고민 중이면 entrepreneur 하나만 먼저 돌려 봐요. 그 앱 리뷰에서 사람들이 무엇을 싫어하는지 순위로 나와요.

    3절
    주의할 점 체크리스트

    이럴 때 봐요: 만든 결과물을 실제로 쓰거나 올리기 전에.

      ✅ 구조, 배치, 흐름은 참고해도 돼요.

      ✅ 글, 사진, 로고는 내 것으로 채워요.

      ❌ 남의 코드 복사, 유료 기능 우회는 안 돼요.

      ❌ 로그인 뒤의 화면을 긁거나 남의 계정에 들어가지 않아요.

      ❌ 원래 앱 이름과 같은 이름, 비슷한 로고로 내놓지 않아요.

      ❌ 복제 방지, 라이선스 검사, 안티치트를 우회하거나 게임 치트를 만들거나 AI 사용 정책을 피하는 데 쓰지 않아요.

      ⚠️ 리버스 엔지니어링은 나라 법이나 그 프로그램의 라이선스로 제한될 수 있어요. 필요한 허락과 약관은 직접 확인해요.

      ⚠️ 프로그램을 실행하며 뜯으면 앱, 파일, 계정에 영향이 갈 수 있어요. 믿기 어려운 프로그램은 따로 분리한 환경에서 돌려요.

      ⚠️ 쓰는 서비스 약관이 경쟁 제품 제작을 막으면 공개 자료만 참고해요.

      💡 돈을 받고 팔 생각이면 상표를 확인하고, 쓴 서비스의 약관을 읽어 보세요. 돈이 걸린 출시라면 변호사와 상의해요.

    REA 공식 안내: 합법적인 연구, 교육, 호환, 보존과 내 소프트웨어나 분석 권한을 받은 소프트웨어를 살피는 데 쓰는 도구예요. 아이다 프로 같은 유료 분석 도구를 함께 쓸 땐 정식 라이선스가 있어야 해요.

    replica 공식 안내: 앱이 하는 일은 다시 만들되, 앱이 가진 것(코드, 로고, 글, 콘텐츠)은 가져오지 않아요.

    자주 묻는 질문

    똑같은 앱이 한 번에 나오나요?replica 안내문도 완벽한 복제를 보장하지 않아요. 앱이 복잡할수록 오래 걸리고, 예약 도구 정도도 몇 주를 잡아요. recon이 먼저 크기를 재고, diff가 원본 대비 점수를 알려 줘요.

    결과가 미리보기 이미지로만 나와요.요청문 끝의 "미리보기 이미지도 보여 줘"는 확인용이에요. 실제로 눌러 보려면 채팅창에 나온 HTML 파일을 받아 브라우저로 열어요.

    설치 명령을 넣었는데 "command not found"가 떠요.REA는 Node.js가 있어야 돌아가요. nodejs.org에서 Node.js를 먼저 설치하고 터미널을 새로 열어 다시 넣어요.

    클로드가 분석하다가 중간에 멈춰요.10월 말부터 클로드가 기존 게임을 그대로 따라 만드는 요청을 막는다는 보도가 나왔어요(Kotaku 10월 30일 기사, 10월 27일 무렵 새 규칙). 리버스 작업이 중간에 멈춘다는 사용자 보고도 있어요. 뜯어볼 대상이 내 앱이나 오픈소스처럼 분석해도 되는 것인지 요청문 첫 줄에 밝히고, 특정 게임을 똑같이 만들어 달라는 대신 내 아이디어로 새로 만들어 달라고 부탁해 보세요.

    클로드 코드가 없어요.1절 프롬프트는 클로드 채팅창에서 바로 돼요. replica는 채팅창 맨 위에 SKILL.md 한 개를 붙여 넣어 방식만 빌려 쓸 수도 있어요(파이썬 도구는 못 써요).
