## 0. 판단: 용팀장이 이걸로 릴스 자동발행 할 수 있나?

### 결론
**만드는 건 자동으로 할 수 있다. 올리는 것(발행)은 이 강의에 없다.**
세비야도 영선도 **자동으로 만들고, 사람이 읽어 보고 직접 올린다.** 6시간 내내 인스타 공식 자동게시·예약·외부 예약툴 얘기는 한 번도 안 나온다.

> "제가 하는 일은 최종적으로 내용 읽어 보고 업로드만 하는 거예요." (1:59:47)

### 강의가 보여 준 자동화 범위

| 단계 | 세비야 방식 | 자동? | 용팀장이 이미 가진 것 |
|---|---|---|---|
| 소재 수집 | 매일 07시, Aside가 해외 AI 계정·레딧·X·유튜브를 브라우저로 긁어 옴 | ✅ 자동 | Aside, 매일 자동작업 돌리는 구조 |
| 소재 선별 | 조회수가 아니라 **그 계정 평균 대비 몇 배 터졌나**로 거름 (3배 이상) | ✅ 자동 | 없음 — 새로 넣을 규칙 |
| 분해 분석 | 릴스 링크 → 장면별·시간별·문장별 분해 | ✅ 자동 | watch(영상 보기)·받아쓰기 도구 |
| 대본·캡션 | `/릴스` 스킬: 제목6·후킹6·대본3·캡션3·DM문구 | ✅ 자동 | threads-writer 같은 글쓰기 스킬 구조 그대로 |
| 카드뉴스 | `/캐러셀` → 이제는 아침마다 자동 생성, 노션 저장(출처·팩트체크 포함) | ✅ 자동 | 상세페이지 이미지 만드는 파이썬·HTML 도구 |
| 영상 편집 | 촬영본 8분 28초 → 1분 14초, 자막·오버레이·모션 자동 | ✅ 자동(촬영은 사람) | motion-graphic 스킬(Remotion), ffmpeg |
| 고르기·검수 | 사람이 읽고 "올릴 만한 것" 선택 | ❌ 사람 | — |
| **발행** | **사람이 직접 업로드** | ❌ 사람 | — |

→ 강의에서 말하는 "자동화"는 **만드는 공장**이고, 그 공장 부품(클로드 코드 + 스킬 + Aside + 매일 정해진 시간 실행 + 대시보드)은 용팀장이 **이미 다 쓰고 있는 것**과 같다. 250만·490만 원 과정에서 새로 얻을 도구는 없다.

### 발행까지 자동으로 하려면 (강의 밖, 별도 확인한 내용)
- **길은 하나: 인스타 공식 자동게시 통로**(메타가 공식으로 허락한 방식). 조건은 ① 인스타를 프로페셔널(비즈니스) 계정으로 ② 메타 개발자 앱 하나 등록 ③ 영상을 인터넷 주소로 올려 두고 넘겨주기.
- 하루 게시 한도는 출처마다 25~100개로 엇갈림. 실제 값은 계정에서 직접 조회하면 됨. 하루 1~3개면 전혀 문제 없음.
- 릴스는 공식 통로로 올릴 때 길이 제한(90초라는 말 있음, 확인 필요)·형식(MP4) 조건이 있음.
- **Aside로 인스타 화면을 눌러서 올리는 방식은 하지 말 것.** 프로그램 조작으로 걸리면 계정이 날아간다. 세비야도 "인스타가 요즘 칼질을 너무 많이 한다"(4:58:13)고 경고.

### 추천 순서
1. **먼저 "자동 제작 + 사람 한 번 보고 올리기"로 2~4주 돌린다** (세비야와 똑같은 형태). 아침에 후보가 쌓여 있고, 용팀장은 고르고 올리기만.
2. 조회수가 나오는 형식이 잡히면, 그때 **공식 통로로 "예약 발행"**을 붙인다. 붙이는 작업은 하루 정도.
3. 완전 무검수 발행은 비추천. 세비야·영선 둘 다 "AI 슬롭(아무도 안 보는 찍어낸 글)은 안 된다", "팩트 체크하고 내 걸로 소화해서 내보낸다"고 함.

### 먼저 정해야 할 것 (용팀장 몫)
- **어떤 계정, 무슨 주제로 할지.** 세비야 공식은 "내 배경 + AI로 하는 일 + 누구에게". 구매대행·살림(하입덕)·AI 셀링 중 무엇인지에 따라 소재 수집처가 완전히 달라진다.
- 얼굴·목소리를 낼지. 안 내면 카드뉴스(캐러셀) 위주가 제일 쉽게 완전 자동에 가깝다 — 세비야는 "캐러셀로 팔로우가 생각보다 많이 늘어난다"(1:58:43)고 함.

### 강의에서 가져다 쓸 만한 것 (돈 안 내고)
1. **평균 대비 배수 필터**: 1.1만 평균 계정의 16만(15배)이 26만 평균 계정의 122만(5배)보다 좋은 소재.
2. **릴스 7가지 구조**: 결과 먼저 / 흔한 실수 지적 / 말 없는 결과물 쇼케이스 / 새 도구 공개 / 목록 연타 / 지금 터진 소식 / 직접 실험.
3. **장면·시간·문장 3축 분해** → 구조는 빌리고 내용은 내 것.
4. **디자인은 하나 정해서 절대 안 바꾼다** — 그래야 자동화가 된다.
5. **스킬은 손으로 3~5번 해 본 뒤에 만든다.**

# 부록 2/4 — 구간 상세


> 원본: 유튜브 자동자막(오인식 많음). 화자는 크게 둘이다. 세비아(셀링링 채널, 1:26~2:12) → 게스트 영선(신형선생 AI 탐구 채널 운영자, 2:12~끝). 수강생 채팅에서 "부트캠프 19기"가 언급되는데 이 부분은 영선 쪽 강의 수강생이다.

## 1. 구간별 정리

### (1:26:08) 어사이드로 크롤링·릴스 분해 분석 시연 시작
- 세비아가 "어사이드(Aside)"를 클로드에 연결해 두었다고 설명한다. 어사이드를 쓰면 별도 API 없이 브라우저로 직접 들어가 긁어(크롤링) 올 수 있다. API 비용을 따로 내지 않는다.
- 시연 중 생성이 "조금 걸린다"고 계속 언급(분석 생성에 시간이 걸림).
- 수강생에게 "어사이드 클로드한테 물어서 설치하셔도 된다"고 안내. "어사이드가 진짜 너무 좋다"를 반복.
### (1:27:12) 대시보드 + 클로드 요금제
- 어사이드를 대시보드에 연결했느냐는 질문 → 클로드의 어사이드를 연결해 두었고, 대시보드는 클로드로 만들었다고 답한다.
- 클로드 요금제는 "울트라"를 쓰고 있다고 밝힌다(Max 계열을 뜻하는 것으로 추정, 정확한 요금제명은 불명).
- 모아둔 소재(호재 → "소재"의 오인식)를 이제 뜯어보는 단계로 넘어간다.
### (1:28:15) 분해 분석의 3가지 축
- "이런 내용의 릴스구나"로 끝내지 말고 장면별로 뜯는다: 이 장면엔 무엇이 나오는지, 시각적 후킹은 어떤지, 중간 카드 오버레이는 어떻게 되는지, 사람이 나오는지 아닌지.
- 두 번째: 시간별. 몇 분 몇 초에 어떤 이야기를 하는지, 마지막에 무슨 얘기를 하는지. 30/40/60초 대본이 어떻게 분포·구성되어 있는지 파악.
- 세 번째: 대본 문장별. 20~30초 안에 많은 정보를 줘야 하므로 문장별로 어떤 내용이 있는지를 본다.
### (1:29:22) 분석 결과를 "내 대본"으로 바꾸는 구조
- 앞의 세 가지(장면별/시간별/문장별)로 뜯고, 그 구조에 내 키워드·내용을 씌워 "나의 대본"을 만든다. 큰 틀은 레퍼런스 구조를 쓰고, 내용·키워드는 내 것으로 가공.
- 예시: 평소 1.1만 정도 나오던 계정에서 16.1만 회가 나온 "쫄라맨" 영상(추정)을 분해해 보면 29초 안에 예고 → 4단계 시연 → "당신이 하고 싶으면 이렇게 하면 된다"까지 압축적으로 들어 있다.
### (1:30:25) 링크 하나만 넣으면 분석되는 도구
- 미리 크롤링해 둔 "레디메이드" 소재 외에, AI 소식을 보다가 갑자기 "이거 괜찮다" 싶은 것도 분석하고 싶을 때가 있다 → 링크만 넣으면 자동 분석.
### (1:31:31) 아이디어 출처 = 영선
- 이 "링크 넣으면 분해" 방식은 영선과 팟캐스트(유튜브)를 찍을 때 영선의 아이디어를 보고 차용한 것이라고 밝힌다. "영선님의 꿀팁".
- 링크를 넣으면 알아서 해당 링크로 들어가 장면·대본을 쪼개 분석한다.
### (1:32:36) 릴스 분석 화면 시연
- 분석 결과 구성: 개요, 후킹, 기능 증명, CTA, "왜 터졌는지", 길이(초).
- 짧은 릴스는 장면이 1개뿐이고 대사가 없다고 나오는 경우도 있음.
### (1:33:42) 복잡한 구조 릴스 분석
- 시간별·문장별로 뜯고, 몇 초에 어떤 장면(얼굴 등장, 화면 녹화가 상단에 나오는 구성 등)이 나오는지, 편집은 어떻게 되어 있는지까지 나온다.
### (1:34:45) 분석 항목 확장
- 화면 움직임, 전환 방식, 소리, "내가 어떻게 따라 할 수 있는지"까지 분석에 포함. 세비아가 화면에서 마우스 위치까지 짚으며 설명(분석이 마우스 커서 위치까지 잡아낸다는 취지로 보임, 추정).
- "이렇게 해 두라, 이렇게 해야 진짜 AI 자동화로 시간을 줄일 수 있다."
### (1:35:50) 시간 절감 + 성장 순서 예고
- 하루 1일 1콘텐츠를 해야 하는데 하루 4시간씩 콘텐츠 기획에 쓰는 일이 없어진다.
- 정리: 클로드에 어사이드 연결 → 클로드로 대시보드 제작 → 어사이드로 API 비용 없이 크롤링 → 장면별·시간별·문장별 자동 분석.
### (1:36:52) 성장의 3단계
- ① 잘된 구조(흐름)를 빌려와 내 것으로 바꿔 쓴다.
- ② 익숙해지면 내 경험(직접 써 본 것, 겪은 일, 배경, 직무)을 얹는다.
- ③ 그것도 익숙해지면 나만의 노하우·스킬이 생긴다. "교과서 배우기 → 응용 → 창의".
### (1:38:01) 대본·카드뉴스 파트 진입
- "인스타 콘텐츠 AI로 어떻게 만드나? 4시간 걸리던 게 어떻게 줄었나" 질문으로 클로드 활용 파트 시작. 제작 자동화(제작도 배우고 싶다는 채팅 반응).
- 4시간 → 2~30분~1시간으로 1/2 이상 줄었다고 말함(자막이 뒤섞여 정확한 수치는 불명확, 추정).
### (1:39:05) 클로드 코드 세팅 = CLAUDE.md + 스킬
- 계정 세팅(프로필·바이오 3초 테스트)처럼 클로드 코드도 세팅이 중요.
- 첫째 "클로드 MD(CLAUDE.md)" = 계정 설명서(가장 기본). 둘째 "스킬" = 작업 순서(워크플로우)를 저장해 두는 것.
### (1:40:10) 스킬 비유
- 게임 스킬(단축키 눌러 연속 동작)처럼 반복되고 순서가 큰 변화 없는 작업을 하나의 명령으로 묶는다.
- CLAUDE.md에 배경(직업·직무)을 잘 써 두고, 스킬로 작업 순서를 넣어 두면 → 그다음부터 "릴스 기획하자" 한마디로 돌아간다.
### (1:41:14) 세비아의 CLAUDE.md 예시
- "나는 AI 콘텐츠 크리에이터 세비아다" 같은 자기소개를 넣는다.
- 공통 규칙 예: "대본·캡션은 항상 세 개 옵션으로 내놔라".
- 공통 사항(말투, 끝맺음, 알아야 할 정보)은 CLAUDE.md, 릴스 전용/캐러셀 전용 절차는 각각 스킬에.
### (1:42:18) CLAUDE.md는 직접 안 써도 된다
- 형식(마크다운 #, 번호 등)은 클로드가 만들어 준다. 기본 정보만 주고 "CLAUDE.md 만들어 줘"라고 하면 된다. 직접 쓰고 있지 말 것.
### (1:43:25) /릴스 스킬
- 슬래시(/)는 명령어 호출. "/릴스"라는 스킬명은 세비아가 직접 지정(다른 이름도 가능).
- /릴스 한 번이면 제목 6개, 후킹 6개, 대본 3개, 캡션 3개, DM 문구까지 나오게 설정해 둠. 실제 화면 녹화로 시연(시간이 오래 걸려서 녹화본 사용).
### (1:44:29) /릴스 기획하자 시연 + 재료 제한
- "/릴스 기획하자" → 제목·후킹 6개, 대본 3개, 캡션 3개를 정리해서 출력.

- 서울대 교수팀의 "AI 시대 계급도"(추정)를 인용. 1계급은 플랫폼 등 기술 보유 기업인(0.001%). 사람들로 먹고사는 계급(정치인·연예인·인플루언서·크리에이터·유튜버 = 트래픽 만드는 사람).
- 이 자리 430여 명 중 0.001%면 한 명도 안 나올 수 있다고 설명.
### (2:30:35) 결론: 비즈니스를 하거나 트래픽을 만들어라
- 평범한 사람은 "비즈니스를 하거나 트래픽을 만든다". 맛집·브이로그·AI·뷰티·주식·부동산 어떤 계정이든 AI로 사람을 모아야 경쟁력이 생긴다.
- 하루 1~2시간만 투자해도 대부분은 안 하기 때문에 큰 아웃풋 가능성이 높다.
### (2:32:40) 시도할 때 중요한 6가지 조건
- ① 리스크가 없을 것(자본) ② 자본이 적게 들 것(100원짜리 오락실 비유) ③ 시간을 자유롭게 투자할 수 있을 것 ④ 시공간 제한이 없을 것 ⑤ 얼굴 공개 여부를 내가 선택할 수 있을 것 ⑥ 혼자 결정할 수 있을 것.

### (2:35:50) "처음부터 시작한다면?" - 콘텐츠 베끼기 영상
- 어떤 크리에이터가 내 콘텐츠를 따라 한 비교 영상 시청(포맷은 같고 사람만 다름). "베꼈지만 신경 안 쓴다, 이 사람은 콘텐츠의 맥락과 본질을 알고 있다"는 취지의 코멘트.
### (2:36:55) 콘텐츠 리버스 엔지니어링의 시대
- 클로드 + 오픈소스로 레퍼런스 영상을 분해(대본·이미지 요소 추출)해 구조를 역설계하고 패턴을 뽑아 내 주제에 적용 가능. 1년 전엔 완전 노가다였다.
### (2:37:59) 영상 자동화 기본 개념 + 4가지 도구
- "컨텐츠 리버스 엔지니어링은 요즘 크리에이터들이 무조건 하고 있는 액션".
- 영상 자동화에는 "클로드 코드, 오픈소스, 대시보드, 어사이드" 4개를 쓴다(세비아와 동일하다고 강조).
### (2:39:05) 부트캠프 19기용 자료 일부 공개 ①
- 채팅에서 "보고 싶다 1번" 폭주(렉). 부트캠프 19기에게만 강의한 내용 일부를 공개.
- 영상 제작 자동화에서 오픈소스를 어디에 어떻게 쓰는지 아키텍처로 분해한 정리.
### (2:40:12) 오픈소스 아키텍처 설명
- 세비아가 후기 남기면 주는 오픈소스가 각 영역에서 어떻게 쓰이는지 분해한 구조도. 예: "와치 비디오" = 화면 연출 노트, "하이프레임즈(HyperFrames, 추정)" = 모션 자막.
### (2:41:16) 영상 제작 흐름
- 순서: 레퍼런스 분석 → 대본 → 음성 → 편집 → 그래픽·모션 → 업로드. 이 순서대로 오픈소스를 적용·세팅하는 구조도를 클로드에 입히면 클로드가 그 구성에 맞게 영상을 만들어 준다.

### (2:44:27) 영선의 대시보드 버전 공개

### (2:45:34) 어사이드 + 대시보드 = 캐러셀 무한 양산
- 대시보드를 만들어 두고 어사이드가 매일 정해진 시간에 특정 워크플로우를 대시보드 기능으로 실행하면 작업 결과물이 자동으로 만들어진다 → "캐러셀이 그냥 무한 양산된다".
- 본질적으로 "AI 티 나지 않는 캐러셀"을 선호하며, 그를 위해 모션 그래픽 영상까지 만든 것(화면은 영상).
### (2:46:39) 오픈소스 → 대시보드 로직
- 앞에서 보여 준 오픈소스를 순서대로 정리한 것을 대시보드의 작동 로직에 입혀 만들었다.
- "AI 정보성 콘텐츠를 10개 20개 만들 수 있다고 한 게 될까요?" → 만들어 놓으면 된다는 취지.
- 어사이드는 유료 결제, "리모트 컨트롤 기능"과 "컴퓨터 유지(잠들지 않게) 기능"을 쓰려고 예전부터 결제했다. 맥 스튜디오 구입 이유와 연결.
### (2:47:42) 정규 강의 안내 + 영감 목적
- 이 시연은 "영감"을 주려는 것. 정식으로 배우려면 정규 강의가 준비되어 있다.
### (2:48:45) 영선의 자동화 철학
- 대시보드는 세비아에게서 영감을 받아 만든 게 아니라 본인이 쓰려고 만든 것(벤치마킹 아님). 콘텐츠를 매주 금·토에 몰아서 만드는데 그것도 귀찮아서 자동화.
- AI 슬롭(의미 없고 조회수·댓글 없는 콘텐츠)은 좋지 않다. 자동화했다면 조회수든 댓글이든 결과로 증명해야 한다.
- 레퍼런스 링크를 넣으면 화면별·대본 구조별로 분석하는 기능도 있음(세비아와 팟캐스트 때 공유).
### (2:49:49) 리버스 엔지니어링 인사이트
- 몇 분 몇 초에 어떤 이야기를 왜 했고 왜 잘됐는지 인사이트를 뽑는다. 이러한 도구가 "막히는 부분을 뚫어 준다". 만드는 방법을 다 알려 주려면 3~4시간 강의가 필요하다.
### (2:50:53) 마무리 예고
- 강의 끝나고 지난 강의에서 대시보드 제작에 쓴 프롬프트를 준비해 둔 게 있다. "드린다고 한 적은 없다"며 말을 흐림. 비밀 자료 1번 = 오픈소스 피그마 정리, 2번 = 대시보드. 연말이라 따뜻하게 하겠다며 선물을 암시하는 데서 이 조각이 끝남.

## 4. 자동화 관련 상세 (들은 그대로)

### 4-1. 소재 수집(크롤링) 자동화
- 도구: 어사이드(클로드에 연결) + 자체 대시보드. API 없이 브라우저로 들어가 긁어 온다. 비용은 어사이드 구독 외 API 사용료 없음.
- 수집 기준: 단순 조회수가 아니라 그 계정 평소 대비 많이 터진 릴스(상대 수치). 해외 AI 계정이 주 대상.
- 완전 자동 단계(1:59:47): 매일 아침 7시에 해외 AI 계정을 훑고 → 평소보다 잘된 것을 필터링 → 카드뉴스·캡션을 한글로 제작 → 팩트 체크 → 가공. 즉 "수집·선별·한글화·제작"까지 자동이다.

### 4-2. 릴스 분해 분석(자동)
- 릴스 링크를 넣으면 어사이드가 들어가 분석: 개요, 후킹, 기능 증명, CTA, 왜 터졌는지, 길이. 장면별·시간별·문장별 대본, 화면 움직임·전환·소리·편집 방식까지.
- 아이디어는 영선에게서 차용. 영선도 같은 방식("컨텐츠 리버스 엔지니어링")을 쓴다고 2:36:55에 설명.

### 4-3. 릴스 대본·기획 "자동 제작"

## 1. 구간별 정리

## 4. 자동화 관련 상세 (이 구간 한정, 들은 그대로)

### 4-1. 카드뉴스(캐러셀)
- 영선이 보여 준 방식: 대시보드에서 카드뉴스가 **아침에 자동 제작**되어 기다리고 있고, 사람이 **만들어진 것 중 골라서 올린다**(4:59:17~5:00:24). 즉 제작은 자동, 선택·업로드는 사람 손(자동 발행이라고 말하지 않음). 정확한 업로드 방식(API/수동)은 언급 없음.
- 강의에서는 **4주차에** 캐러셀 자동화를 다룬다고 안내(4:59:17). 만드는 방법(어떤 도구·프롬프트)은 이 구간에서 설명하지 않고 "강의 때 알려 드린다"고만 말함.
- 4:38:49에서도 "케로셀 100% 완전 자동화 ... 아침마다 되어 있는 거 보셨죠?"라고 언급 -> 이 시연은 라이브 앞 구간(이 파일 밖)에서 있었다.
- 수강생 상민님: 시사·이슈 매거진 형식 캐러셀을 **하루 15개 수작업**, 월 7,000달러(추정 약 900만 원대, 자막 불명확). 자동화 문의에 강사진은 이 강의가 자동화에만 포커스한 강의는 아니라 맞춤 추천은 어렵다는 입장.

### 4-2. 릴스(영상)
- "릴스 영상 자동화도 다루나?" -> "그럼요", 단 **오프라인 강의(기획 중)**에서 각자에게 맞는 영상 자동화를 만들어 가는 형태로 다룬다(4:39:53).
- 영선은 부트캠프 수강생에게 **영상 제작 자동화 시스템 패키지**(한 번에 짜인 자료)를 전날 제공했다고 말함(5:35:33). 내부 구조 설명은 없음.
- 영선: 컨텐츠 크리에이팅 워크플로우를 복사해 가는 수준이라고 표현.
- 릴스 대본 자동 생성·자동 업로드·예약에 대한 구체 설명은 이 구간에 **없음**.

### 4-3. 사람이 손대는 단계
- 카드뉴스는 아침에 자동 생성된 것 중 **사람이 골라서 업로드**.
- 5주 강의 첫 주차에 "나에게 맞는 컨셉 정하기"(사람 판단).
- 얼굴 노출은 권고. 영상 촬영은 강의에서 가르침.
- 세비아의 철학: AI 슬롭(디테일·감도 없는 자동화 결과물)을 싫어하며 "AI를 써서 내 것으로 만드는" 디테일이 핵심 -> 완전 방치 자동화에 부정적 뉘앙스.

### 4-4. 인스타 공식 API·예약기능·메타 비즈니스 스위트·외부 툴
- 이 구간에서 언급 없음.

### 4-5. 계정 제재·저품질·도달 경고
- 인스타가 요즘 "칼질"(제재)을 많이 한다, 계정·콘텐츠가 날아가면 아찔하다(4:58:13). 구체 사유(자동화 감지 등)는 언급 없음.
- 저품질 콘텐츠: AI 슬롭은 조회수가 안 나오고 오래 못 간다(4:47:24). 대중의 AI 판별 능력이 시간이 갈수록 올라간다(4:48:29).

### 4-7. 운영 인프라
- 자동화하려면 컴퓨터를 24시간 켜 놔야 하나? -> 세비아와 영선 모두 24시간 켜 둠(5:01:27). 영선은 맥스튜디오를 24시간 서버로, 노트북·폰으로 원격 조작(5:13:08, 5:32:22).
- 병렬 에이전트·MCP·크롬 세션을 많이 돌리면 램이 중요(16GB도 간당간당).

### 4-8. 수익화 방식
- 1순위 광고 수익(릴스/계정 수익), 이후 협찬·강의·오프라인 강연·행사·전자책/도서 제안이 들어옴(4:40:58).
- 제휴·공구는 이 구간에서 언급 없음(상품 판매 수익화는 안 나옴).
- 목표 지표: 3개월 챌린지 내 팔로워 5,000명 + 수익화.
- 디자이너 등은 AI 디자인 콘텐츠로 브랜딩 후 프리랜서 이상 수익(4:50:40).

### 4-9. 자동 발행 가능 판단 근거로서의 한계
- 이 구간만 보면 "릴스 자동 발행" 구체 방법은 근거가 없다. 확인되는 것은 (a) 카드뉴스는 자동 제작 후 사람이 골라 올림, (b) 릴스 자동화는 오프라인 강의에서 다룬다는 예고, (c) 세비아는 디테일 없는 자동화 콘텐츠에 비판적, (d) 인스타 제재 위험 언급. 판단은 앞 3개 조각 노트와 합쳐 해야 한다.
