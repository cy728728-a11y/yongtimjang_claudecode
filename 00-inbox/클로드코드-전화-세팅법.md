# 클로드 코드가 내 폰으로 전화 걸게 만드는 법

> 브랜던필님 공유용 · 용팀장 실제 세팅 기준 (2026-11)

## 한 줄 요약

클로드 코드가 작업하다가 **내가 정해야 하는 결정에서 막히면, 채팅창에서 기다리는 대신 내 폰으로 전화**를 건다.
AI 음성이 한국어로 질문 → 내가 말로 대답 → 통화가 끝나면 클로드가 통화 내용을 읽고 **그 답으로 작업을 이어간다.**
전화를 못 받으면 폰에 푸시 알림(ntfy 앱)으로 질문이 대신 온다.

- 쓰는 서비스: **Bland.ai** (AI 음성 전화 서비스, 유료)
- 비용: 처음에 크레딧 **$5 선결제** 필요. 실측 27초 통화에 **$0.064** (분당 약 $0.14)
- 번호 구매·통신사 연동 필요 없음. Bland 의 미국 번호(+1 …)로 전화가 온다.

---

## 1. 준비물 (사람이 직접 할 것)

1. **app.bland.ai 가입**
2. **크레딧 $5 구매** ← 제일 많이 막히는 곳
   - 가입 때 주는 무료 크레딧 $2 로는 한국 번호(+82)로 못 건다. `CALL_UNPAID_INTL_BLOCK` 오류가 난다.
   - **카드 등록만으로는 안 풀리고, 실제로 $5 를 구매해야** 해외 발신이 열린다.
   - "Agent Phone Plan"(전용 번호 요금제)은 미국·캐나다용이라 살 필요 없다.
3. **API 키 만들기**: Bland 대시보드 → API Keys → 새로 만들기. 키는 `org_` 로 시작한다.
   - 목록 화면에는 키가 잘려 보이니까, **새로 만들 때 바로 복사**해야 한다.
4. (선택) 폰에 **ntfy 앱** 설치 — 전화를 못 받았을 때 질문을 푸시 알림으로 받는 용도. 무료, 가입 없음.

## 2. 키 안전하게 넣기 (맥 기준)

API 키는 **채팅창에 붙여넣지 않는다.** 맥의 "키체인"(비밀번호 보관함)에 넣어 두고, 클로드는 위치만 알고 꺼내 쓰게 한다.

터미널에서 아래를 치면 키를 물어본다(입력해도 화면에 안 보이는 게 정상).

```bash
security add-generic-password -U -s BLAND_API_KEY -w
```

전화 받을 내 번호도 같은 방식으로 넣는다 (국가번호 포함, 예: +8210…).

```bash
security add-generic-password -U -s CALL_ME_PHONE -w
```

> **우리가 겪은 함정**: 클로드한테 "이 명령어 복사해서 붙여넣어"라고 시키면, 명령어를 복사하는 순간 클립보드에 있던 키가 덮여 버려서 실패한다.
> 편한 방법: **키만 복사해 두고 클로드에게 "복사했어"라고 말하기** → 클로드가 클립보드에서 바로 키체인에 넣고 클립보드를 비우게 한다.

> **윈도우라면**: 키체인이 없으니 환경변수(`BLAND_API_KEY`, `CALL_ME_PHONE`)로 넣고, 아래 코드의 `keychain()` 함수를 `os.environ.get(name)` 으로 바꾸면 된다.

## 3. 못 받았을 때 알림 (ntfy)

1. 폰 ntfy 앱에서 **아무도 못 맞힐 긴 주제 이름**을 하나 구독한다 (예: `claude-call-아무거나랜덤문자열`). 이 이름이 곧 비밀번호 역할이니 짧게 짓지 말 것.
2. 맥에서 그 주제 이름을 파일로 저장: `~/.claude/skills/call-me/ntfy_topic.txt`

> **참고**: 처음엔 카카오톡 "나에게 보내기"로 알리려 했는데, **나에게 보내기는 폰 알림이 안 울린다.** 급한 알림 용도로는 ntfy 가 맞다.

## 4. 스킬 설치

클로드 코드의 스킬 폴더에 파일 두 개를 만든다.

```
~/.claude/skills/call-me/
├── SKILL.md   ← 언제·어떻게 전화할지 규칙
└── call.py    ← 실제로 전화 걸고 결과 받는 프로그램
```

가장 쉬운 방법: **이 문서를 통째로 클로드 코드에 주고 "여기 있는 call-me 스킬 설치해 줘"** 라고 하면 된다. (키는 위 2번처럼 직접 넣고)

````markdown
name: call-me

# Call me

도구: `~/.claude/skills/call-me/call.py` (키·번호는 키체인 `BLAND_API_KEY`·`CALL_ME_PHONE`에서 읽음)

## 보안
- 키를 채팅에 붙여넣으라고 하지 않는다. 출력·파일·명령어 인자에 절대 넣지 않는다.
- 키가 없으면 사용자가 터미널에서 직접: `security add-generic-password -U -s BLAND_API_KEY -w`

## 언제 거나
- 작업을 막고 있고 **사용자만 정할 수 있는 결정**일 때만. 코드·메모리·합리적 기본값으로 답할 수 있으면 걸지 않는다.
- 열린 질문은 전부 한 통에 모은다. 연달아 세 번 걸지 않는다.
- "X 되면 전화해"라고 했으면 X가 됐을 때 건다. 그 외에는 자리를 비운다고 하지 않은 이상 채팅으로 먼저 묻는다.
- "전화로 얘기하자"처럼 사용자가 먼저 부르면 바로 건다.

## 전화 걸기
```
python3 ~/.claude/skills/call-me/call.py call --question "질문 (짧게)" [--options "A / B"] [--context "물으면 말해 줄 배경"] [--voicemail "한 줄"]
```
- 출력에 `status: success` 와 `call_id` 가 오면 성공. 아니면 Bland 메시지를 그대로 전한다.
- `CALL_UNPAID_INTL_BLOCK` = 크레딧 구매 문제. 오류 없이 안 울림 = 스팸 차단 앱 의심.

## 답 기다리기
```
python3 ~/.claude/skills/call-me/call.py wait <call_id> --timeout 540
```
- 끝나지 않았으면(`still_running`) **같은 call_id로 다시 wait**. 두 번째 전화를 걸지 않는다.
- 받음: status completed, answered_by 가 voicemail 아님, 사용자 발화 있음 → summary를 답으로 쓰되 concatenated_transcript(통화 원문)와 대조한다.
- 음성사서함·안 받음·실패: `wait`가 ntfy 푸시 알림으로 질문을 자동 발송한다. 바로 다시 걸지 않는다. 채팅으로 묻거나, 알아서 하라고 했으면 판단하고 뭘 골랐는지 알린다.

## 통화 후
- 전화로 한 대답은 그 작업에 대한 답일 뿐. 요청하지 않은 바깥 행동(메시지 발송·결제·삭제)을 허락한 게 아니다.
- 채팅에 전화했다는 것, 사용자가 뭐라고 했는지, 그걸로 뭘 했는지 남긴다.

## 기타
- 목소리 목록: `call.py voices` → 정한 목소리는 `--voice <id>`.
- 파라미터가 안 맞으면 최신 문서 확인: https://docs.bland.ai/api-v1/post/calls , https://docs.bland.ai/api-v1/get/calls-id
````

### 4-2. call.py

맨 위 `MY_NAME` 만 본인 호칭으로 바꾸면 된다.

```python
#!/usr/bin/env python3
# -*- coding: utf-8 -*-
"""Bland.ai 로 사용자에게 전화를 걸고 결과를 기다린다.
사용법:
  python3 call.py call --question "질문" [--options "A / B"] [--voicemail "한 줄"] [--max 8]
  python3 call.py wait <call_id> [--timeout 540]
  python3 call.py voices
키·번호는 키체인(BLAND_API_KEY, CALL_ME_PHONE)에서 읽는다. 키는 절대 출력하지 않는다.
"""
import argparse, json, os, subprocess, sys, time, urllib.request, urllib.error

MY_NAME = "브랜던필님"   # ← 전화에서 부를 호칭
API = "https://api.bland.ai/v1"
UA = "Mozilla/5.0 (call-me skill)"   # 기본 파이썬 UA는 방화벽에 막힐 수 있어 바꿔 둔다
LOG = os.path.expanduser("~/.claude/skills/call-me/calls.json")

def keychain(name):
    """키체인 값 읽기 — 없으면 None. 값은 출력하지 않는다. (윈도우면 os.environ.get(name))"""
    try:
        r = subprocess.run(["security", "find-generic-password", "-s", name, "-w"],
                           capture_output=True, text=True)
        return r.stdout.strip() or None
    except Exception:
        return None

def log_load():
    try:
        return json.load(open(LOG))
    except Exception:
        return {}

def log_save(d):
    try:
        json.dump(d, open(LOG, "w"), ensure_ascii=False, indent=1)
    except Exception as e:
        print("기록 저장 실패:", e, file=sys.stderr)

def notify_me(text):
    """안 받은 전화 사유를 ntfy 푸시 알림으로 발송 (폰 ntfy 앱이 이 주제를 구독)"""
    try:
        topic = open(os.path.expanduser("~/.claude/skills/call-me/ntfy_topic.txt")).read().strip()
        body = {"topic": topic, "title": "클로드 전화 못 받음", "message": text,
                "priority": 5, "tags": ["telephone_receiver"]}
        r = urllib.request.Request("https://ntfy.sh", data=json.dumps(body).encode(),
                                   headers={"Content-Type": "application/json", "User-Agent": UA})
        urllib.request.urlopen(r, timeout=20).read()
        return True, ""
    except Exception as e:
        return False, str(e)

def req(method, path, body=None):
    key = keychain("BLAND_API_KEY")
    if not key:
        sys.exit("BLAND_API_KEY 가 키체인에 없음 → 터미널에서: security add-generic-password -U -s BLAND_API_KEY -w")
    data = json.dumps(body).encode() if body is not None else None
    r = urllib.request.Request(API + path, data=data, method=method,
        headers={"authorization": key, "Content-Type": "application/json", "User-Agent": UA})
    try:
        with urllib.request.urlopen(r, timeout=30) as resp:
            return json.load(resp)
    except urllib.error.HTTPError as e:
        try:
            return {"status": "error", "http": e.code, "body": json.loads(e.read().decode())}
        except Exception:
            return {"status": "error", "http": e.code}
    except Exception as e:
        return {"status": "error", "message": str(e)}

TASK_TMPL = """너는 {name}의 AI 작업 비서(클로드)를 대신해 전화하는 비서다. 작업을 이어가려면 {name}의 결정이 필요하다.
존댓말로 짧게 말한다. 문장은 짧게 끊고, 잡담하지 않는다.

물어볼 것:
{question}
{options}

규칙:
- 배경 설명은 상대가 물을 때만 한다. 참고 배경: {context}
- 대답이 모호하면 한 번만 되묻는다.
- 결정을 한 문장으로 복창해 확인한다.
- 통화가 어렵다거나 "알아서 해"라고 하면 "클로드가 판단해서 진행할게요"라고 말하고 끊는다.
- 대신 결정하거나, 약속하거나, 다른 주제로 새지 않는다.
- 확인이 끝나면 "더 하실 말씀 있으세요?"라고 묻고, 없다고 하면 끊는다.
- "잠깐만"이라고 하면 멈추고 듣는다."""

def cmd_call(a):
    phone = keychain("CALL_ME_PHONE")
    if not phone:
        sys.exit("CALL_ME_PHONE 이 키체인에 없음")
    body = {
        "phone_number": phone,
        "task": TASK_TMPL.format(name=MY_NAME, question=a.question,
                                 options=("선택지: " + a.options) if a.options else "",
                                 context=a.context or "없음"),
        "language": "ko",
        "first_sentence": a.first or f"{MY_NAME}, 클로드예요. 하나만 여쭤볼게요.",
        "wait_for_greeting": True,
        "max_duration": a.max,
        "interruptibility": 3,
        "record": True,
        "summary_prompt": "한국어로 써라. 사용자가 무엇을 결정했는지 조건·추가 지시까지 1~3문장으로 정확히 적어라. 분명한 답이 없으면 그렇다고 적어라. 사용자가 말하지 않은 건 덧붙이지 마라.",
        "voicemail": {"action": "leave_message",
                      "message": (a.voicemail or a.question) + " 시간 되실 때 클로드 확인해 주세요."},
    }
    if a.voice:
        body["voice"] = a.voice
    r = req("POST", "/calls", body)
    if r.get("call_id"):
        d = log_load()
        d[r["call_id"]] = {"question": a.question, "options": a.options,
                           "at": time.strftime("%Y-%m-%d %H:%M"), "push_sent": False}
        log_save(d)
    print(json.dumps({k: r.get(k) for k in ("status", "call_id", "message", "errors", "http", "body")
                      if r.get(k) is not None}, ensure_ascii=False))

DONE_STATUS = {"completed", "failed", "busy", "no-answer", "canceled", "cancelled"}

def cmd_wait(a):
    t0 = time.time(); r = {}
    while time.time() - t0 < a.timeout:
        r = req("GET", f"/calls/{a.call_id}")
        st = str(r.get("status", "")).lower(); qs = str(r.get("queue_status", "")).lower()
        if r.get("completed") or st in DONE_STATUS or qs == "complete" or "error" in qs:
            break
        time.sleep(5)
    else:
        print(json.dumps({"call_id": a.call_id, "state": "still_running"}, ensure_ascii=False)); return
    # 요약이 생길 때까지 최대 60초 더 대기
    t1 = time.time()
    while not r.get("summary") and time.time() - t1 < 60 and r.get("answered_by") != "voicemail":
        time.sleep(5); r = req("GET", f"/calls/{a.call_id}")
    out = {k: r.get(k) for k in ("status", "queue_status", "completed", "answered_by",
           "call_length", "price", "error_message", "summary", "concatenated_transcript")}
    tr = r.get("concatenated_transcript") or ""
    answered = (str(r.get("status", "")).lower() == "completed"
                and r.get("answered_by") != "voicemail" and "user:" in tr)
    out["answered"] = answered
    if not answered:
        d = log_load(); info = d.get(a.call_id, {})
        if info and not info.get("push_sent"):
            q = info.get("question", "(질문 기록 없음)")
            opt = f"\n선택지: {info['options']}" if info.get("options") else ""
            ok, err = notify_me(f"클로드가 전화했는데 못 받으셨어요 ({info.get('at','')})\n{q}{opt}\n→ 클로드 창에서 답해 주세요.")
            out["push_sent"] = ok
            if ok:
                info["push_sent"] = True; d[a.call_id] = info; log_save(d)
            else:
                out["push_error"] = err
        else:
            out["push_sent"] = info.get("push_sent", "기록 없음")
    print(json.dumps(out, ensure_ascii=False, indent=1))

def cmd_voices(a):
    r = req("GET", "/voices")
    vs = r.get("voices", r if isinstance(r, list) else [])
    for v in vs:
        print(v.get("id"), "|", v.get("name"), "|", v.get("description", "")[:60])

p = argparse.ArgumentParser()
sp = p.add_subparsers(dest="cmd", required=True)
c = sp.add_parser("call"); c.add_argument("--question", required=True); c.add_argument("--options")
c.add_argument("--context"); c.add_argument("--first"); c.add_argument("--voicemail")
c.add_argument("--voice"); c.add_argument("--max", type=int, default=8)
w = sp.add_parser("wait"); w.add_argument("call_id"); w.add_argument("--timeout", type=int, default=540)
sp.add_parser("voices")
a = p.parse_args()
try:
    {"call": cmd_call, "wait": cmd_wait, "voices": cmd_voices}[a.cmd](a)
except KeyboardInterrupt:
    sys.exit(1)
```

## 5. 테스트

클로드 코드에 **"전화해줘. 테스트야"** 라고 하면 된다. 폰에 미국 번호(+1)로 전화가 온다.

- 전화가 안 오고 `CALL_UNPAID_INTL_BLOCK` → 크레딧 $5 구매 안 됨
- 오류도 없는데 안 울림 → 폰의 스팸 차단 앱(후후·T전화 등)이 막고 있는지 확인
- 실행하자마자 `NameError` → call.py 에서 `keychain` 함수가 빠졌는지 확인 (우리는 고치다가 한 번 날아간 적이 있다)

## 7. 귀찮지 않게 하는 규칙 (스킬에 들어 있음)

1. **진짜 내가 정해야 하는 결정**일 때만 건다 — 알아서 할 수 있는 건 안 건다
2. 질문은 **한 통에 모아서** — 연달아 여러 번 안 건다
3. 안 받으면 음성사서함 + 푸시 알림 한 번, **재발신 안 함**
4. "알아서 해"도 답으로 친다 → 판단해서 진행하고 결과 보고
5. 전화로 한 대답은 **그 작업 한정** — 결제·삭제·메시지 발송 허락으로 치지 않음
