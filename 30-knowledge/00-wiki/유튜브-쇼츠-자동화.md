# 유튜브 쇼츠 자동화

> **관련**: [[힉스필드-콘텐츠-팩토리]] · [[AI-영상-제작]] · [[숏폼-만약에-포맷]] · [[하입덕-스레드]]
> **Facets**: 쇼츠 · 숏폼 · 자동 제작 · 벤치마킹 · 대본 · 음성합성 · 업로드 · 다채널

> **이 페이지의 역할**: 쇼츠·숏폼 제작과 자동화에 관한 자료가 들어올 때마다 여기에 쌓는 허브. 용팀장이 "이거 학습해"라고 주는 쇼츠 자료는 전부 이 페이지에 통합한다.

## 핵심 (현재 아는 것의 요약)

쇼츠 자동화는 **소재 찾기 → 대본 → 음성 → 편집 → 검수 → 업로드** 여섯 단계를 사람 손에서 떼어 내는 일이다. 사람에게 남는 건 "소재 고르기·대본 고르기·최종 검수" 세 가지다.

지금까지 본 방식은 한 가지(은곤쥬 "프리쇼츠")다.
1. **소재**: 남의 영상(틱톡·해외 유튜브)을 내려받아 재가공. 과거에 크게 터졌다가 노출이 끊긴 영상을 다시 꺼낸다.
2. **형식**: 잘되는 채널 하나를 정해 틀·폰트·자막 박자까지 그대로 따라 한다.
3. **제작**: 직접 편집 → 프리랜서 분업 → AI가 편집 프로그램을 대신 조작, 세 길을 섞어 쓴다.
4. **분산**: 채널 30~40개로 쪼개 정지·정책 변경을 수량으로 버틴다.
5. **확장**: 같은 영상을 자막·음성만 바꿔 다른 나라 채널에 올린다.

**용팀장 기준 판단**: 제작 6단계는 거의 전부 자동화할 수 있다(편집 프로그램을 클릭시키지 않고 영상을 바로 만들어 내는 편이 더 빠르고 여러 개 동시 제작도 된다). 다만 남의 영상 재가공 + 다채널 분산은 채널 정지가 일상인 구조라 그대로 따르지 않고, **같은 공장 구조를 내 소재(구매대행 상품 영상·내 강의 녹화·하입덕 글)에 적용**하는 쪽이 맞다.

## 근거 (소스별 증거)

### 만드는 요령
- 쇼츠 탭에서 만들고 싶은 종류만 끝까지 보고 좋아요·댓글을 달면 추천이 그 종류로 채워져 벤치마킹 대상을 찾기 쉬워진다. [source: 은곤쥬 프리쇼츠 자동화 영상, 2026-10-31]
- 벤치마킹 채널은 최신순으로 훑어 **조회수가 터진 영상의 키워드**부터 본다(예: 인절미·아기냥이·리트리버). [source: 같은 영상, 2026-10-31]
- 소재 검색은 한국어보다 영어 키워드가 영상이 더 많이 나온다. [source: 같은 영상, 2026-10-31]
- 초보에게 쉬운 형식: 음성 없이 배경음 + 상황 설명 자막. 화면은 위아래 흰 띠 + 프로필 + 제목 자막 + 아래 자막. [source: 같은 영상, 2026-10-31]
- 자막은 **약 2초마다** 바뀌고, 자막이 바뀔 때 화면도 같이 전환한다. [source: 같은 영상, 2026-10-31]
- 내용이 얇으면 20초도 길다 — 시연에서는 20초 원본을 8초로 줄였다. 지루한 장면은 이탈로 이어진다. [source: 같은 영상, 2026-10-31]
- 제목은 두 줄까지. 세 줄은 줄인다(예: "9만 원 VS 890만 원"). [source: 같은 영상, 2026-10-31]
- 업로드 때 시청자층은 "아동용 아님"으로. 아동용이면 광고·알림이 막힌다. [source: 같은 영상, 2026-10-31]
- 내보내기 기준: 9:16, 해상도 1080, 30프레임. [source: 같은 영상, 2026-10-31]

### 소재 고르는 기준
- vidIQ(크롬 확장)로 조회수 추이를 보고, **그래프가 평평해진 과거 대박 영상**(예: 1년 전 705만 회)을 고른다. "잊혀졌을 때 다시 꺼낸다." [source: 같은 영상, 2026-10-31]

### 프리랜서 분업
- 대본 담당과 편집 담당을 나누고, 단계마다 운영자가 검수한다. 구인은 알바몬, 면접은 카톡으로만. [source: 같은 영상, 2026-10-31]
- 뽑을 때 볼 것은 편집 실력이 아니라 **피드백 수용 능력**. [source: 같은 영상, 2026-10-31]
- 정해진 수량을 요구하지 않고 영상을 미리 쌓아 공백을 메운다("포기하시면 됩니다"). [source: 같은 영상, 2026-10-31]
- 초보도 좋은 영상과 나쁜 영상을 구분하는 눈은 있어야 남에게 맡길 수 있다. [source: 같은 영상, 2026-10-31]

### AI 자동 제작
- 대본용 맞춤 AI(젬스)에 영상 링크를 넣으면 A·B·C 세 안이 나온다. 편집자 단톡방 카톡 45,000개를 학습시켰다고 한다. [source: 같은 영상, 2026-10-31]
- GPT 아스트라가 음성 사이트(타입캐스트)와 캡컷을 직접 조작해 61초 영상 1개를 **19분 11초**에 만들었다. 내레이션 1.2배속, 쉬는 구간 제거, 효과음 자동 삽입. [source: 같은 영상, 2026-10-31]
- 완성 영상이 아니라 **편집 프로젝트로 남기게** 해서 다국어판을 만들 때 자막·음성만 바꾼다. 일본어 음성은 무료 VOICEVOX. [source: 같은 영상, 2026-10-31]
- 캡컷은 한 번에 하나만 쓸 수 있어 동시에 여러 편을 못 만든다. [source: 같은 영상, 2026-10-31]
- 잘하는 편집자는 아직 AI로 대체되지 않는다는 게 운영자 본인 평가. [source: 같은 영상, 2026-10-31]
- 세부 지침(목소리·폰트·틀 지정)이 없으면 같은 결과가 안 나온다 — 이 지침이 비공개 판매 재료다. [source: 같은 영상, 2026-10-31]

### 업로드·운영
- 제작 컴퓨터가 텔레그램 방에 영상·제목·설명·예약시간을 보내면 다른 컴퓨터가 받아 예약 업로드한다. 한 기기에서 너무 많이 올리는 걸 위험으로 본다. [source: 같은 영상, 2026-10-31]
- 휴대폰 30대 + 공유기 여러 대로 채널별 인터넷 주소까지 분리. [source: 같은 영상, 2026-10-31]

### 수익 (운영자 주장)
- 월 최고 5,900만 원, 평균 2,500만 원, 누적 4억 6,400만 원. 쇼츠 1개 383만 원 사례. 반면 월 8,000원·1,600원 채널도 있다. [source: 같은 영상, 2026-10-31]

## 적용 (내 맥락에서 실제 사용)

- **방향**: 내 소재로 공장 구조를 돌린다 — 구매대행 상품 영상, 내 유튜브·강의 녹화 자르기, 하입덕 스레드 글의 대본 재활용. [2026-11-11 판단]
- **용팀장이 개입할 지점**: (처음 1회) 올릴 채널 정하고 업로드 권한 연결 / 음성 서비스 가입·목소리 선택 / 영상 틀 시안 선택 / 소재 범위 결정. (매번) 대본 3안 중 선택, 완성본 승인.
- **가져다 쓸 규칙**: 자막 2초 박자, 자막-화면 동시 전환, 제목 두 줄, 내용 얇으면 10초 안쪽, 대본은 3안 중 고르기, 다국어판은 자막·음성만 교체.
- 상태: 정리만 해 둠. 아직 제작 시작 안 함. [2026-11-11]
