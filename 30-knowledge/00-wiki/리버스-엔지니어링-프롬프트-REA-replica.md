# 리버스 엔지니어링 프롬프트와 REA·replica (캡처 한 장 → 내 버전 도구)

> **관련**: [[힉스필드-콘텐츠-팩토리]] · [[상세페이지-제작]] · [[실전반-강의-커리큘럼]] · [[리뷰-분석]]
> **Facets**: 프롬프트공식 · 리버스엔지니어링 · 클로드코드 스킬 · 벤치마킹 · 저작권 체크리스트 · 강의 시연

## 핵심 (현재 아는 것의 요약)

**리버스 엔지니어링** = 완성된 앱을 보고 거꾸로 어떻게 만들었는지 알아내는 일. 자료집은 세 층으로 나뉜다.

1. **설치 없이 쓰는 프롬프트 3개 (claude.ai 채팅)** — 잘 만든 화면 캡처 한 장을 올리고 한 문장으로 "내 버전"을 HTML 한 장으로 받는다.
   **잘 시키는 공식**: `구성(무엇이 어디에 있는지) + 내 주제 + 실제로 움직일 것 + 원본에서 쓰지 말 것` 을 한 문장에 넣는다. 끝에 "미리보기 이미지도 보여 줘"는 확인용이고, 실제로 눌러 보려면 HTML 파일을 받아 브라우저로 연다.
   예시 셋: 달리기 게임 → 우리 집 강아지 게임 / 계산기 → 모임 N빵 계산기(카톡 정산 문구 복사 버튼) / 카페 메뉴 → 장바구니 담기는 주문 페이지.
2. **REA** (무료 오픈소스) — 소스 코드 없이 완성된 앱을 뜯어 작동 원리를 알아내는 도구. 클로드 코드·코덱스·커서에 붙인다. `npx rea-agents setup`. 공식 출처는 github morluto/rea · rea.tools · npm rea-agents 만.
3. **replica** (클로드 스킬 11개 묶음) — 앱 주소를 주면 recon(뜯기) → architect → design → build → backend → test → diff(원본 대비 점수) → **entrepreneur(그 앱 리뷰에서 사람들이 싫어하는 것 순위)** → brand → launch → deploy 순으로 다시 짓는다. 설치: `/plugin marketplace add Jakeschincariol/replica-skill` → `/plugin install replica-skill@replica-skill`.

**주의점 체크리스트(원문 그대로의 뼈대)**: 구조·배치·흐름은 참고 가능 / 글·사진·로고는 내 것으로 / 남의 코드 복사·유료 기능 우회 금지 / 로그인 뒤 화면 긁기·남의 계정 금지 / 같은 이름·비슷한 로고 금지 / 복제방지·라이선스 검사 우회 금지 / 쓰는 서비스 약관이 경쟁 제품 제작을 막으면 공개 자료만.

**2026-10 말 변화**: 클로드가 "기존 게임을 그대로 따라 만들기" 요청을 막기 시작(Kotaku 10/30 보도). 리버스 작업이 중간에 멈추면 요청문 첫 줄에 "내 앱/공개 화면이고 구조만 참고한다"를 밝히고, 똑같이 말고 내 아이디어로 새로 만들어 달라고 바꾼다.

## 근거 (소스별 증거)

- REA 준비물: Node.js 22.23.4+/24.22.1+/26.12.1+ 중 하나. 설치된 앱을 깊게 뜯으려면 호퍼·기드라·아이다 같은 분석 프로그램이 더 필요(호퍼·아이다 유료). 자바스크립트 앱 정적 분석엔 불필요.
- replica FAQ: 완벽한 복제는 보장 안 함. 예약 도구 정도도 몇 주. recon 이 먼저 크기를 재고 diff 가 원본 대비 점수를 준다. 클로드 코드 없으면 SKILL.md 한 개를 채팅창에 붙여 방식만 빌릴 수 있다(파이썬 도구 제외).
- "앱을 만들까 고민 중이면 entrepreneur 하나만 먼저" — 리뷰 불만 순위가 곧 요구사항 목록이라는 발상.

## 적용 (내 맥락에서 실제 사용)

REA·replica 자체(앱 해부·재구축)는 구매대행 사업과 거리가 멀다. 건질 것은 **① 프롬프트 공식 ② "리뷰 불만 순위 → 고칠 목록" 발상 ③ 저작권 체크리스트** 세 가지.

- **강의 시연 소재(가장 큼)**: 비개발자 수강생에게 "캡처 한 장 + 한 문장 → 눌러지는 도구"는 그 자체로 와우 장면. 구매대행 버전 예시: 계산기 캡처 → **마진 계산기**(판매가·환율·국제배송비·수수료 → 순이익·마진율, 카톡 공유 문구 복사), 메뉴 페이지 캡처 → **소싱 후보 비교표**(체크로 걸러지고 담으면 합계), 게임 캡처는 재미용. 공식 네 칸을 그대로 가르치면 수강생이 스스로 변형한다. 11/28 하입덕 정식 강의·실전반 "AI 도구" 꼭지 후보. 스레드·유튜브 "이거 캡처 한 장으로 만들었어요" 소재.
- **상세페이지 구조 벤치마킹**: 카테고리 1위 상세페이지 캡처 → "구성만 빌리고, 글·사진·로고는 내 상품 것으로, 원본 문구 금지" 한 문장. detail-page-opus 끝판왕 템플릿의 **변형 생성 통로**로 쓴다(새 템플릿을 매번 손으로 짜지 않음). 단, 네이버 상세는 공개 화면만, 판매자 관리 화면(로그인 뒤)은 대상 아님.
- **리뷰 불만 순위 → 소싱·상세 선제 답변**: replica entrepreneur 발상은 이미 있는 review-analyzer 스킬과 같다. 쓸 자리는 소싱 검수 통과 상품에 대해 "경쟁 상품 리뷰 불만 Top3 → 상세페이지 첫 화면에서 먼저 답하기(사이즈 표기·배송 기간·조립 난이도)". 네이버 접속은 Aside 조회 경로만(직접 접속 금지 규칙 유지).
- **하지 않을 것**: 불사자·셀러라이프 등 쓰는 서비스를 REA/replica 로 뜯기(약관·법 위험, 체크리스트 자체가 금지). 스마트스토어·쿠팡 판매자 화면 분석(로그인 뒤 화면). 경쟁사 상세의 문구·사진 그대로 가져오기.
- **수강생에게 같이 가르칠 함정**: 10월 말부터 "그대로 만들어 줘"는 클로드가 멈춘다 → 첫 줄에 "공개 화면 참고, 구조만, 내 가게 이름으로". 결과가 그림으로만 나오면 HTML 파일 받아 브라우저로 열기.
