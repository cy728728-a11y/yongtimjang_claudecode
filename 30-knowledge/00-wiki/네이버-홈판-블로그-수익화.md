# 네이버 홈판 블로그 수익화

> **관련**: [[유튜브-쇼츠-자동화]] · [[무료강의-공지방-시퀀스]]
> **Facets**: 네이버 홈판(홈피드) · 애드포스트 · 쇼핑커넥트 · 네이버 클립 · 다음 홈판 · 오리나

## 핵심 (현재 아는 것의 요약)

- **홈판** = 네이버 앱 검색창 바로 아래 뜨는 추천 글 피드(공식 명칭 홈피드). 검색 순위(C랭크·다이아)와 별개로 돌아가서 새 블로그도 같은 출발선이라는 것이 오리나 강의의 핵심 주장.
- **돈의 흐름**: 광고주 → 네이버 → 블로거 글 속 광고(애드포스트) → 클릭·구매 → 블로거 수익. 그래서 네이버는 체류시간 길고 광고 클릭 많은 블로그를 반복 노출한다는 논리.
- **글이 걸러지는 순서**: 후보 수집(리트리버 5종: 구독·키워드·인기도·소비 이력·검색 이력) → 클릭 확률 심사 → 체류·만족 심사 → 주제 쏠림 조정 → 첫 칸 배치. 네이버 공식 체크리스트는 제목·이미지·본문 각 2문항.
- **글 한 편 기준값**: 700~3,000자 / 메인 키워드 1개를 제목에 + 본문 5~7회 / 해시태그 2개 / 썸네일 960×960 / 인용구 소제목 + 사진 1장씩 / 내 글 링크 3개(도입 1 + 마무리 2) / 끝에 의견 묻는 문장 2~3개 / 페이지당 글 1개 설정.
- **제목 공식**: 키워드 1개 + 후킹 한 스푼. 하루 5개면 키워드형 3 : 의문형 2. 강사 GPT는 제목 10개를 이득형 3·위협형 3·궁금증 4로 냄.
- **주제**: 조회수 나는 10개(방송연예·스포츠·경제·자동차·패션뷰티·푸드·리빙·건강·IT테크·여행). 주제별 글쓰기 스타일이 다름(13장 비교표).
- **애드포스트**: 경험칙 만 19세·개설 90일·글 20개·일 방문 50명. 가입 + 미디어 등록 둘 다. 정산 계좌 25일(5만 원 이상)/네이버페이 12일. 연 12.5만 원 초과 8.8% 원천징수 → 다음 해 5월 종합소득세.
- **부가 수익**: 쇼핑커넥트(글 맨 위 필수 문구, 링크 글당 2개, 정산은 구매확정 두 달 뒤 21일), 체험단, 네이버 클립(팔로워 1,000 + 조회 300만), 다음 스튜디오 입점.
- **현실 목표**: 하루 3만 원 → 월 100만 원. 시간 단위는 1년.
- **2026-11-16 무료 라이브 갱신**: 글자수 800~1,400자 · 사진 최소 5장 · 신규 하루 3개(최대 5) · 결론은 중간·끝에 숨김 · 제목 7유형(이득·위협·궁금·비교·반전·실행·베스트) · 인기 키워드+서브 키워드 3개 · 시즌 키워드 한 달 앞서. **자동 발행(자동 로그인·발행)은 아이디 정지 위험**이라고 강하게 경고(AI 글 복붙 자체는 괜찮다고 함). 저품질 확인 = 내 글 제목을 네이버에 그대로 검색.
