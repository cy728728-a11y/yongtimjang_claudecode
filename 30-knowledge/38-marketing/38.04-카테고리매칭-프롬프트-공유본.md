# 🎯 카테고리 매칭 프롬프트 (용팀장 실전 테스트 버전)

> 설치할 거 없어요. **ChatGPT나 Claude 채팅창**이랑 **네이버쇼핑**만 있으면 됩니다.
> 상품 1개에 2~3분 걸려요. 익숙해지면 1분이면 돼요.

---

## 카테고리가 왜 자꾸 틀릴까?

**이유 1. 상품명이 엉터리인 경우가 많아요.**
구매대행 상품명은 검색 잘 되라고 키워드를 줄줄이 붙여 놓잖아요. 그러다 보니 상품명만 봐서는 진짜 뭘 파는 건지 헷갈려요.
- 예: 상품명은 `자동차 전동 자키 받침대`인데, 중국 원본을 보면 실제로는 **자키 + 에어펌프 + 전동렌치 세트**였어요. '받침대' 카테고리에 넣으면 틀린 거죠.

**이유 2. 단어 하나로 검색하면 엉뚱한 데로 가요.**
같은 단어라도 쓰는 곳이 여러 군데면, 네이버는 더 많이 팔리는 쪽 카테고리를 보여줘요.
- 예: `폴리셔`만 검색하면 → 금속 갈아내는 공구인데 **세차용품**이 나와요
- 예: `그라인더`만 검색하면 → 공구인데 **커피 그라인더**가 나와요

**이유 3. 검색 결과가 전부 같은 카테고리여도 틀릴 수 있어요.**
검색어를 처음부터 잘못 넣으면, 결과가 한 카테고리로 쫙 몰려도 그게 엉뚱한 카테고리예요.

### 그래서 이 순서로 해요

1. **이게 진짜 뭔지부터 확인** (상품명 말고 중국 원본·옵션·사진으로)
2. **어디에 쓰는 물건인지까지 붙여서 검색어 만들기** (`폴리셔` ❌ → `금속 연마 폴리셔` ⭕)
3. **네이버쇼핑에서 검색해서, 상품들이 어느 카테고리에 제일 많이 있는지 보기**
4. **검색어 3개로 해 봐서 2개 이상 같은 카테고리가 나오면 그걸로 결정**

---

## 준비물 (상품 1개당)

| 준비물 | 어디서 가져오나 | 왜 필요하나 |
|---|---|---|
| 내 상품명 | 지금 등록된 상품명 | 참고만 해요 (틀렸을 수 있음) |
| 중국어 원본 상품명 | 타오바오/1688 상품 페이지 제목 복사 | 가장 믿을 만한 정보 |
| 옵션 이름들 | 원본 페이지 옵션 5~8개 복사 | 실제로 뭘 파는지 보여요 |
| 대표 사진 1장 | 사진 저장해서 채팅창에 올리기 | 눈으로 확인용 |

> 중국어 원본이랑 옵션이 없으면 상품명 + 사진만 넣어도 돼요. 대신 정확도는 좀 떨어져요.

## 1단계. AI한테 "이거 뭐야?" 물어보고 검색어 받기

아래 박스를 **통째로 복사**해서 채팅창에 붙여넣으세요.
맨 아래 `[입력]` 부분만 내 상품 정보로 채우고, 대표 사진을 같이 올려서 보내면 돼요.

> AI가 **"C"**라고 답하면 → AI도 뭔지 모르겠다는 뜻이에요. 원본 상세페이지를 더 보고 정보를 추가해서 다시 물어보세요.

```
당신은 오픈마켓 상품의 실제 정체를 판정하고, 카테고리 검색용 대표 검색어를 만드는 전문가입니다.

[1단계: 실물 판정]
아래 4가지 증거를 종합해서 "이 상품이 결국 무슨 물건인지" 판정하세요.
- 한국어 상품명: 키워드 나열로 왜곡됐을 수 있는 '용의자'. 그대로 믿지 마세요.
- 중국어 원문명: 가공 전 원본. 실물 판단의 1순위 근거. 번역해서 읽으세요.
- 옵션명: 실제 판매 단위. 구성품·형태가 드러납니다.
- 썸네일: 눈으로 확인.

판정 결과를 셋 중 하나로 내세요.
- A 일치: 넷이 같은 물건을 가리킴
- B 정정: 상품명은 틀렸지만 원문·옵션·썸네일로 실물이 명확함 → 실물 기준으로 진행
- C 정체불명: 증거끼리 모순이거나 뭔지 모르겠음 → 검색어를 만들지 말고 "추가로 필요한 정보"를 알려주세요.
조금이라도 애매하면 C로 판정하세요. 억지로 찍지 마세요.

[2단계: 대표 검색어 추출]
판정한 '실물'을 기준으로(상품명 기준 아님) 대표 검색어를 만드세요.
이 검색어로 네이버쇼핑을 검색했을 때 이 상품이 실제로 속한 카테고리가 나와야 합니다.

가장 중요한 원칙: 검색 결과가 한 카테고리로 몰려도 그 카테고리가 '틀린 분야'일 수 있습니다.
핵심 명칭이 여러 분야에 걸치는 넓은 단어이면 검색은 더 대중적인 분야(자동차용품·주방·미용 등)로 쏠려,
엉뚱하지만 확신에 찬 결과가 나옵니다. 그래서 분야를 못 박는 한정어가 반드시 필요합니다.

규칙
1. 핵심 제품(정체성)과 '어느 분야에서 쓰이는지'를 먼저 파악한다. 판매자가 제목 맨 앞에 쓸 대표 명칭을 핵심으로 삼아 반드시 포함한다.
2. 브랜드·색상·크기·수량·호환기종은 제거한다. 단, 카테고리를 가르는 형태·구동 방식(장/단, 좌식/입식, 벽걸이/스탠드형, 전동/수동, 접이식, 대형/미니 등)은 남긴다.
3. 한 낱말만으로 뽑지 않는다 — 반드시 최소 2단어 이상. 분야/용도/재질/동력 한정어를 붙여 특정한다.
4. 구체적 분야를 가리키는 용도·사용처(주방용·차량용·산업용·욕실용·캠핑용·의료용 등)가 있으면 그 분야를 대표하는 말 하나를 반드시 포함한다. '다용도·만능'처럼 막연한 말은 넣지 않는다. '인테리어·프리미엄·고급' 같은 꾸밈말보다 카테고리를 실제로 가르는 말(대용량·벽걸이·전동 등)을 우선한다.
5. 핵심 명칭이 여러 분야에 걸치는 애매한 단어이면 올바른 분야로 좁혀 주는 한정어를 반드시 남긴다. 특히 '공구·산업용 vs 소비자용(자동차·주방·미용)'처럼 갈리는 단어는 한정어 없이 쓰면 대중 분야로 오검색된다.
   - 분야·용도: 농약·농업·원예·공업·산업용·금속·세공·미술·의료·실험실·음식점 등
   - 동력·구동: 전기·전동·충전·무선·유압·에어 (수동형과 카테고리가 갈릴 때)
   - 대상·재질: 원단·시편·금속·플라스틱·리빙(가구가 아닌 정리함) 등
6. 아래 단어들은 반드시 분야 한정어로 못 박는다:
   - 폴리셔·광택기 → 금속/연마(공업) vs 세차(자동차)
   - 그라인더·연마기 → 연삭/절삭(공구) vs 커피·양념(주방)
   - 저울 → 산업 계량 vs 주방저울 vs 실험 정밀
   - 브러쉬·브러시 → 청소·자동차 vs 미용 vs 공업
   - 펌프·호스·매트·카트·트레이 등도 분야가 갈리면 한정어 필수
7. 검색에 더 적합한 '동급' 명칭으로 바꿔도 되지만(예: 바의자→바스툴), 분야 한정어는 유지한다.
8. 이미 구체적으로 특정된 핵심어를 더 넓은 말로 바꾸지 않는다. (예: '무드등'을 '인테리어 조명'으로 바꾸지 말 것)
9. 보통 2~4단어. '장비·기기·기구·도구·용품·제품' 같은 막연한 상위어를 채우기용으로 붙이지 않는다. 뜻이 겹치는 말을 중복하지 않는다(예: 석션+흡입, 스툴+의자).
10. 증거에 없는 속성(성별·연령·재질·용도 등)을 추측해서 넣지 않는다. 단, 원문·옵션에서 확인된 구성은 추측이 아니다.
11. 서로 다른 품목명을 하나로 합치지 않는다. 가장 핵심 품목 하나만 고른다.

예시
- 풋스위치 커버 전기 자재 발판 스위치 덮개 보호 커버 → 풋스위치 보호커버
- 전기분무기 5L 농업 휴대용 원예 스프레이 정원 농약살포기 → 농약 분무기
- 정밀 시편 저울 중량 미세 무게 측정기 전자저울 섬유 원단 → 원단 저울
- 투명 서랍 수납장 의류 리빙박스 다용도 보관함 장난감 → 플라스틱 서랍 정리함
- 연마 폴리셔 세공 용접 작업 공구 금속 광택 → 금속 연마 폴리셔
- 엔진오일 흡입기 폐유 제거 교환용 석션 장비 → 엔진오일 석션기
- 가죽 뮬 운동화 반슬리퍼 플랫 캐주얼 신발 → 가죽 뮬 슬리퍼

[3단계: 검색어 변형]
같은 실물에 대해 검색어를 총 3개 만드세요. 분야 한정어는 셋 다 유지합니다.
- 검색어1: 가장 구체적인 대표 명칭
- 검색어2: 띄어쓰기·동의어 변형
- 검색어3: 한 단계 위 대표 명칭

[출력 형식] 설명은 짧게, 아래 형식 그대로.
판정: A/B/C
실물: (한 줄)
근거: (원문·옵션·썸네일에서 무엇을 보고 판단했는지 한 줄)
검색어1:
검색어2:
검색어3:

[입력]
한국어 상품명:
중국어 원문명:
옵션명:
(썸네일 이미지 첨부)
```

## 2단계. 네이버쇼핑에서 검색해서 AI한테 세어 달라고 하기

AI가 준 검색어 3개를 **하나씩** 네이버쇼핑에 검색해요. 검색어마다 이렇게 하면 돼요.

1. 네이버쇼핑에서 검색어1을 검색해요
2. 검색 결과 화면에서 `Ctrl+A`(맥은 `Cmd+A`)로 **전체 선택 → 복사**해요
3. **아까 쓰던 채팅창**에 아래 문장이랑 같이 붙여넣어요
4. 검색어2, 검색어3도 똑같이 반복해요

```
아래는 네이버쇼핑에서 "검색어N: (여기에 검색어)" 로 검색한 1페이지 내용이다.
광고 상품은 빼고, 각 상품에 표시된 카테고리 경로(예: 생활/건강 > 공구 > 전동공구 > 그라인더)를 모두 세라.

출력:
- 1순위 경로: (전체 경로) / 몇 개 중 몇 개 (%)
- 2순위 경로: (전체 경로) / 몇 개 중 몇 개 (%)
- 3순위 경로: (전체 경로) / 몇 개 중 몇 개 (%)
- 이 경로가 1단계에서 판정한 '실물'과 맞는 분야인지 한 줄 의견

(여기에 붙여넣기)
```

> 1순위 카테고리가 **70% 넘게** 나오면 꽤 믿을 만해요.
> 그래도 100%라고 무조건 정답은 아니에요. 그래서 검색어를 3개나 돌려 보는 거예요.

## 3단계. 최종 카테고리 정하기

검색어 3개를 다 돌렸으면, 같은 채팅창에 이걸 보내요.

```
지금까지 검색어 3개의 결과를 종합해서 최종 카테고리를 정해라.

판정 규칙:
1. 검색어 3개 중 2개 이상에서 1순위 '전체 경로'가 같으면 그 경로로 확정.
2. 확정한 경로가 1단계 '실물'과 분야가 어긋나면 확정하지 말고 이유를 말해라.
3. 2개 이상 일치가 없으면 "보류"로 하고, 어떤 검색어를 더 넣어 보면 좋을지 2개 제안해라.

출력:
최종 판정: 확정 / 보류
카테고리 경로:
최종 차수(경로의 마지막 단계):
일치: (예: 3개 중 2개)
확신도: (일치한 검색어 중 가장 높은 %)
```

> **"확정"** 이 나오면 → 4단계로 가요.
> **"보류"** 가 나오면 → AI가 추천해 준 검색어로 2단계를 한 번 더 해 보세요.

---

## 4단계. 내 상품에 카테고리 넣기

AI가 준 카테고리가 이렇게 생겼다고 해 볼게요.
`생활/건강 > 공구 > 전동공구 > 그라인더`

1. **맨 끝 단어**(`그라인더`)만 스마트스토어나 불사자 같은 솔루션의 카테고리 검색창에 넣어요
2. 후보가 여러 개 뜨면, **앞부분까지 전부 똑같은 것**을 골라요
   - `주방용품 > ... > 그라인더` ❌ (끝 단어만 같고 앞이 다름)
   - `생활/건강 > 공구 > 전동공구 > 그라인더` ⭕
3. 저장하면 끝!

## 자주 하는 실수

| ❌ 이렇게 하면 틀려요 | ⭕ 이렇게 하세요 |
|---|---|
| 상품명을 통째로 검색 | AI가 뽑아 준 짧은 검색어(2~4단어)로 검색 |
| `폴리셔`처럼 한 단어만 검색 | `금속 연마 폴리셔`처럼 어디에 쓰는지 붙이기 |
| 한 번 검색해서 바로 결정 | 검색어 3개 중 2개가 같은지 확인 |
| 뭔지 모르겠는데 대충 넣기 | 원본 상세페이지를 더 보고 다시 물어보기 |

## 솔직하게 말씀드리면

- 이건 **상품 하나씩 손으로 하는 버전**이에요. 저는 같은 방식을 프로그램으로 자동으로 돌려서 1,000개를 2시간 안에 끝내요. 손으로 하면 그 속도는 안 나와요.
- 그래도 **판단하는 방법은 똑같아요.** 지금 팔리고 있는 상품, 광고 돌리는 상품처럼 중요한 것부터 하나씩 바로잡아 보세요.
