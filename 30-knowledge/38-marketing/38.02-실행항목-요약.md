## 실행 항목 5

**1. 반박 목록 두 벌 작성** (30분, 최우선)
- 스토어 고객용 → 아바닛 CS 로그에서 실제 문의 추출
- 실전반 예비 수강생용 → 1·2기 인테이크 콜 질문 정리
- 이유: 이후 모든 콘텐츠(상세페이지·유튜브·모집페이지)의 설계도가 됨

**2. 실전반 모집 페이지 6단계 퍼널 감사**
- 취약 추정 지점 ④의심: "용감한 용팀장 후기" 네이버 검색 결과 확인 → 1기 수료생 후기가 카페 안에만 있으면 외부 검색에 안 잡힘
- ⑤결제 직전: 완충 장치 유무 (조건부 재수강 보장 등)
- ⑥간편성: 모바일 결제 탭 수, 계좌이체 전용 여부

**3. 판매 상위 10개 상품 상세페이지에 반박 제거 블록 삽입**
- 고정 4블록: 배송 / 품질 / 반품 / 검수(상표권 필터링)
- 효과 확인되면 템플릿화 → 불사자 상세페이지 생성 파이프라인에 반영

**4. 1기 성과 사례 콘텐츠화**
- 수료생 1~2명 인터뷰 영상 또는 외부 게시 후기
- 유형 배분: "왕초보였는데" 1명 + "직장인인데" 1명
- 3기 모집의 핵심 탄약

**5. 수강생 사례 코퍼스를 AI 프로젝트에 구축**
- 1기 24명 최종 PPT·인테이크 콜·스터디 기록 익명화 → 정제 문서
- 2기 데이터 쌓이는 지금 시작해야 3기 때 코칭 보조 AI로 작동

## 판단 재료 2

- **V스코어 채점**: 구매대행 단독 1.2~1.4점(경쟁강도 극대, 본질강화 어려움) / 강의+커뮤니티 2점대. → 스토어는 "현역 실증 장치"로 유지, 순익 성장 주력은 강의·커뮤니티 쪽.
- **톤 경고**: 자청 라이브 후반의 가격 인상 카운트다운·자료 배포 지연은 구조만 가져오고 강도는 절반. 자산이 "은행원 출신 신뢰 + 현역 실증"이라 톤이 어긋나면 오히려 깎임.
