# 쿠팡 광고 운영 정리 (구리삽 강의 + 시크릿노트 통합)

> **출처**: ① 구리삽 강의 노트 — 250321 4강(광고1), 250326 6강(광고2), 250407 광고 마지막 강의 합침 (이미지 9장, 2026-11-10 수령) ② 「구리삽의 시크릿노트(Full)」 전자책 8장 쿠팡 광고 (2024-12, 원문 md: `~/Downloads/구리삽의 시크릿노트(Full).md`)
> **우선순위**: 두 자료가 다르면 **강의(2025-03~04)가 최신**이라 강의 기준. 전자책 값은 [책]으로 표시.
> 작성 2026-11-10

## 0. 한 장 요약 (운영 순서)

```
[세팅] 수동성과형 · 일예산 1.2만 · 스마트타겟팅 OFF · 키워드 15~50개 · 입찰 200원 일괄 → 제안가로 정리
   ↓ 매일 17시
[CPC 영점] 17시 소진액 6천±1천 → 5천↓ CPC 올림 / 7천↑ CPC 내림 (100원 단위)
   ↓ 8일째
[판정] ROAS·ROI 각각 END ROAS(=1/마진율)와 비교 → 유지 / 트래픽만 / 둘 다 / 끔
   ↓
[소진 안 됨] 입찰 600원 → 스마트타겟팅 ON / 매출최적화 추가 / 썸네일 교체 → 5일
[소진은 되는데 ROAS < END] 마진 20%로 가격 인하 2일 → 매출최적화로 변경 2일 → 끔(상품은 유지)
[잘 됨] CPC 최저(100원)·목표수익률 5000%↑ 인데도 예산 다 씀 → 일예산 증액
[정리] 소진 빠르면 키워드 반씩 삭제 / 광고 옵션 반씩 OFF
```

## 1. 광고를 보는 관점

- **노출**: 광고·키워드·트래픽 — 누구나 하는 것. **유입**: 썸네일·가격. **전환**: 상세페이지·가격·리뷰.
- 쿠팡 광고 본질 [책]
  - **롤링**: 광고 자리를 쿠팡 로직이 돌려가며 보여 준다(쿠팡 매출이 최대가 되게).
  - **리타겟팅**: 한 번 클릭한 상품·비슷한 상품을 계속 다시 보여 준다 → 한 번이라도 상위 노출되면 판매로 이어지기 쉽다.
  - 네이버는 입찰가+품질지수 순위제라 돈 싸움. 쿠팡은 적은 광고비로 효율이 잘 나온다.
- **쿠팡엔 광고점수가 있다.** 유입 = 쿠팡이 버는 광고비가 많아짐, 전환 = 쿠팡이 버는 수수료가 많아짐. 유입·전환이 잘 되는 상품이어야 광고가 잘 돈다.
- **최종 목표**: 처음엔 CPC를 높여 광고비를 많이 써서 광고점수를 올리고 → 결국 CPC를 낮게 써도 잘 팔리게 만든다.
  - 검색량이 적은 키워드(월 5천 이하)는 수요가 적어 광고가 잘 안 돌아서 CPC가 계속 높게 책정될 수 있다.
- 계정 전체 **광고비 ≤ 매출의 5%** 목표 [책]. 관리 못 하면 10~20%까지 간다.
- **광고매출 : 자연매출 = 1:1이 이상적** [책]. 광고매출이 훨씬 작으면 광고를 소극적으로 쓰는 것 → 광고비를 더 넣는다(자연매출도 같이 오른다).

## 2. 지표

| 지표 | 공식 | 메모 |
|---|---|---|
| ROAS | 광고전환매출 ÷ 광고비 | 광고 클릭 후 **14일 내** 구매가 광고전환매출 |
| ROI(트래픽) | 자연발생매출 ÷ 트래픽비용 | 트래픽비용 = 그 기간 트래픽에 쓴 돈. 예: 한 달 5만 → 8일 = 5만/30×8 |
| 전체매출 | 광고전환매출 + 자연매출 | |
| **END ROAS** | **1 ÷ 마진율** (= 판매가 ÷ 마진) | 마진 30% → **333%**, 40% → 250%, 20% → 500% |
| Total ROAS [책] | (광고매출+자연매출) ÷ 광고비 | |

- **판정 기간은 무조건 8일.** ROAS와 ROI를 합치지 말고 **각각** END ROAS와 비교 → 광고 유지 / 트래픽 유지 / 둘 다 / 둘 다 끔.
  - [책]은 2주. 강의(최신)는 8일.
- 트래픽 감 잡기: 한 달 5만 원 · 1슬롯 · 1키워드로 8일 성과를 본다.

## 3. 수동성과형 광고 세팅

| 항목 | 값 |
|---|---|
| 캠페인 이름 | **대표키워드 + END ROAS** (예: `소파베드 333%`) |
| 광고상품 설정 | 수동상품설정 → 상품명 검색 → **모든 옵션 선택** (광고그룹 이름은 안 써도 됨) |
| 광고운영방식 | **직접입력** |
| 일예산 | **12,000원** ([책]은 3만) |
| 스마트타겟팅 | **OFF** |
| 키워드 | **15~50개** (보통 15개 미만인 경우가 많다) |

### 키워드 고르는 법
- 기준: "그 키워드로 누가 검색했고 우리 상품이 떴다. 그 사람이 **사겠나?**"
  - 상품에 맞는 키워드만. 1인용 상품에 4인용 키워드 금지.
  - 시크릿모드로 검색했을 때 **우리 상품과 비슷한 것들이 나오는 키워드**를 쓴다.
- 쿠팡 **연관검색어**를 메인키워드 앞뒤에 붙여 변형(띄어쓰기 없이):
  - 소파베드 → `★1인용`, `1인용★`, `★1인`, `1인★`, `★일인용`, `일인용★`, `★접이식`, `접이식★`, `★1인용접이식`, `1인용접이식★`
  - 연관검색어의 서브키워드도 변형해서 넣는다.
- ★★★ **대표키워드 변형은 반드시**: 소파베드·쇼파베드·소파침대 등을 ★자리에 넣어 조합.
- 브랜드 넣어도 상관없다.

### 입찰가
1. 제안입찰가는 웬만하면 안 쓴다고 생각하되, 정말 맞으면 수용.
2. **200원 일괄** 입력.
3. 키워드별 제안입찰가와 비교:
   - 제안가 > 200원 → 그대로(200원)
   - 제안가 없음 → **100원**
   - 제안가 < 200원 → 제안가로 변경
4. 17시 전 5천 원보다 적게 소진 → **전날 CPC +100원**(예: 200원 시작 → 300원 일괄) 후 같은 규칙(300 기준)으로 재정리.
5. **비검색 영역**: 당일 CPC와 동일 규칙(예: 300 기준 — 위면 그대로, 없으면 100원, 아래면 제안가).
- [책] 대안: 스마트타겟팅·비검색 입찰가를 **제안가보다 50% 높게** 시작.

## 4. 매일 관리 — 레귤러 (17시 기준)

### CPC 영점 (수동성과형)
- 기준 = **예산/2 ± 1,000** → 일예산 1.2만이면 **17시 6,000원 ± 1,000**
  - 17시 **5,000원↓** → CPC **올림**
  - 5,000~7,000원 → 유지
  - 17시 **7,000원↑** → CPC **내림**
- 조정 단위 **100원** (범위 100~600원). 익숙해지면 10원 단위.
- 최소 8일은 돌려 보고, 광고가 돌 수 있는 상태가 되면 CPC 조절은 매일.

### 효율 영점 (매출최적화)
- 효율(목표광고수익률)은 CPC와 반대: CPC를 올리려면 효율을 **낮추고**, 내리려면 **높인다**.
- 시작 1000% → 17시 5천↓면 500%로 / 5~7천 유지 / 7천↑면 1500%로.
- 조정 = **절반씩** 낮추거나 높임. 예: 1500%에서 미충족·과충족 → 750% 또는 2250%.
- [책] 쿠팡 권장은 350%. 초기엔 CPC를 높여야 하므로 350%보다 낮게 시작.

### 키워드 삭제 (수동광고) — 마지막 강의
- 1)CPC 2)일예산 관리를 했고 100원까지 내렸는데도 **17시 기준 소진이 빠르면** 진행. (ROAS와 무관)
- 삭제 기준: 제안입찰가 **없는 것 → 낮은 것 → 높은 것** 순으로 줄 세워 **반으로 나누고**, 제안가가 **낮은 쪽 절반**을 지운다.
  - 이유: 광고점수 = 제안입찰가와 적용입찰가의 갭. 제안가 200·5000(비쌀수록 좋은 키워드), 적용가 100이면 갭이 큰 것이 좋은 키워드.
- 25개 → 13 → 7 → 4개. 4개 정도는 남긴다.
- 지운 뒤 소진이 너무 안 되면(5천 미만) 다시 넣되 중간값으로(25개가 아니라 20개 등).
- 5일째 전에 일예산을 다 쓰면: ① 제안가가 있어도 우리 상품과 관련 없는 키워드 삭제 ② 제안가 없는 것 삭제.

### 광고 옵션 OFF — 마지막 강의
- 옵션을 **절반씩** 끈다. 기준: **전환판매 1순위**, 전환 없는 것 중엔 **클릭률 높은 것**을 살린다.
  - 예: A(클릭 0.1, 판매O) B(0.2, X) C(0.3, X) D(0.4, X) → **B·C 끄고 A·D 남김** (D는 노출이 잘 되는 옵션 = 광고가 잘 돌게 하는 키워드 역할).
- 옵션 수량 기준 10개: 처음 10개 이상이면 10개로, 10개 미만이면 한 번만 줄이고 끝. 예: 24 → 12 → 6(소진 속도가 빨라도 더 안 줄임) / 4 → 2.

## 5. 일예산 증액 (잘 될 때)

조건: CPC 최저(100원) / 목표수익률 5000%↑ 로 올렸는데도 일예산을 다 씀 → 증액 단계.

| 8일 ROAS | 일예산 |
|---|---|
| END ROAS ~ 1.2배 | 1.2만 → **3만** |
| 700%+ | 3 → **6만** |
| 1100%+ | 6 → **12만** |
| 1500%+ | 12 → **24만** |

→ 광고비를 많이 소진하면서 리스크를 최소화하며 매출을 키우는 가이드라인.

[책] 다른 방식: 리뷰 1개 ≈ 판매 12~15개로 추정 월매출(최솟값) → 월 광고예산 = 추정 광고전환매출 ÷ END ROAS.

## 6. 이벤트 관리 (광고 외 조치: 썸네일·마진 등) — 가끔

### 광고 ON인데 소진이 안 된다
1. 입찰가 **600원**까지 올림.
2. 그래도 안 되면 1~3을 한꺼번에 하고 **5일** 지켜봄:
   1. **스마트타겟팅 ON** — 600원(제안가가 더 작으면 제안가). 우리가 넣은 키워드 외에 AI가 맞는 키워드로 광고를 돌림. 일단 소진이 되게 만드는 것.
   2. **매출최적화(제외) 추가** — 수동성과형은 그대로 두고 매최를 더해 총 2개 광고가 돈다.
   3. **썸네일 개선** — 클릭률을 높이려고. 노출상품 ID가 바뀔 수 있으니 선택.
3. 그래도 안 되면 아래로.

### 소진은 되는데 5일째(광고는 켜면 자정 이후 돈다) ROAS < END ROAS
1. **판매가 인하**: 마진 20%로 맞춰 낮춤. (처음부터 20%로 하면 안 된다. 30%로 했다가 20%로 낮춰 매출이 늘면 유입·전환점수가 높아져 오가닉으로도 많이 팔림 → 그 뒤 마진율을 30%까지 점차 올리는 작업을 추후에.) **2일** 지켜봄.
2. **매출최적화(제외)로 변경**(추가가 아니라 변경). **2일** 지켜봄.

### 그래도 안 되면
- 광고를 끈다. **상품은 지우지 않는다**(시즌이 어떻게 될지 모름).
- 광고 끈 상태에서 2개 정도 팔리면 광고를 다시 켠다.
- 입질이 오면 광고를 켜 본다.

## 7. 수동성과형 → 매출최적화로 넘기기 (대량수동 방식)

- 목적: **어떤 상품은 수동성과형이, 어떤 상품은 매출최적화가 잘 돈다** — 그걸 확인하려고. 수동에서 효율이 나오면 매최로 넘어간다.
- 검색영역/비검색영역 중 어디서 잘 팔리는지는 같은 카테고리 안에서도 **상품별**로 다르다. 비검색에서 잘 팔리게 하려면 매최에서 **제외키워드를 왕창** 넣는다.
- 수동성과형 CPC 200원 시작 ↔ 매최 **1000%** 시작.
- 제외키워드: 셀러라이프에서 메인키워드 검색 → "가운데 키워드추천" → 전체 복사 → 붙여넣기. 연관 있는 다른 키워드로도 반복. **최소 3번, 제외키워드 최소 200개.**
  - 예: 소파베드 / 접이식 소파베드 / 1인용접이식소파베드 등

## 8. 광고 종류 비교 [책]

| | 수동 키워드 | 스마트 타겟팅 | 매출최적화 기본 | AI 스마트 |
|---|---|---|---|---|
| 상품 선택 | O | O | O | X(쿠팡이 고름, 계정당 1캠페인) |
| 검색/비검색 따로 관리 | O | O | X | X |
| 키워드 선택 | O | X | X | X |
| 조절 수단 | 입찰가 100원~10만 | 입찰가 100원~10만 | 목표수익률 100~10,000% | 목표수익률 100~10,000% |
| 언제 | 맞는 키워드를 알 때 | 키워드는 모르지만 자신 있는 단일 상품 | 여러 상품을 로직에 맡겨 볼 때 | 로직이 고른 상품만 돌릴 때 |

- 입찰가를 경쟁자보다 월등히 높게 하면 실제 CPC는 **차상위 경쟁자 수준**으로 정해진다.
- 목표수익률을 높이면 CPC가 내려가고, 낮추면 CPC가 올라간다.

## 9. 두 자료가 다른 곳

| 항목 | 강의 (2025-03~04, 채택) | 전자책 (2024-12) |
|---|---|---|
| 일예산 시작 | 1.2만 | 3만 |
| 판정 기간 | 8일 | 2주 |
| 첫 입찰가 | 200원 일괄 → 제안가로 정리 | 제안가 +50% |
| 매최 시작 효율 | 1000% | 350%보다 낮게 |
| 운영 단위 | 17시 소진액 매일 영점 | 하루 안에 다 안 타게 영점 |

## 적용 메모 (용팀장 맥락)
- 강의가 말한 "캠페인별 광고 업무 플로우 표를 만들어 관리하자" → 자동화 설계의 출발점. (2026-11-10 브레인스토밍 시작)
- 판정 규칙 대부분이 숫자 기준(17시 소진액, 8일 ROAS vs END ROAS, 제안가 비교)이라 **판정은 자동화하기 좋다.** 실제 쿠팡 광고센터 조작이 자동으로 가능한지는 확인이 필요하다.
