## DAY 1 — 사전 세팅

1. 크롬 웹스토어에서 **하입덕 확장프로그램** 설치 → hypeduck.ai 로그인
2. 설정 → 계정 연결 → **임시 사용자명**으로 추가 (아무 영어 ID, 스레드 계정 없어도 됨)
3. **AI 계정 세팅 → "제휴마케팅 계정 세팅"** 선택 (일반 아님)
4. ⚠️ 4단계쯤 저장 버튼이 떠도 **누르지 말 것**. 성향 → 페르소나 → 키워드 → 프로필 → **일상글 10개**까지 생성되고 "추출 완료" 뜨면 그때 저장
5. 결과 확인: 카테고리·말투·성격·타깃 / **TOP 8 키워드** / 프로필 이름·소개글 / 이미지 프롬프트 / 일상글 10개
6. 추천 ID 뒤에 숫자 붙여 **최종 ID** 확정 (예: hyori_log92) — 인스타·스레드 공용
7. 프로필 이미지: 프롬프트 복사해 ChatGPT로 생성, 또는 하입덕 생성(15크레딧)
8. 새 구글 계정 생성 → 그 이메일로 **인스타 신규 가입** (이름·ID는 하입덕 결과)
9. 프로필 편집: 이름·ID·소개글·사진 그대로 적용. 소개글은 판매 문구 X, 생활 계정 느낌
10. **인지작업**: 돋보기에서 TOP 8 키워드 검색(PC는 `#` 붙여서), 릴스·피드 자연스럽게 보기

**가입 기기 원칙**: 폰으로 가입했으면 DAY 1은 폰으로 끝까지. DAY 2부터는 강의용 노트북 하나로.

**하지 말 것**: 좋아요 연타, 대량 팔로우, 복붙 댓글, 홍보 게시물, 프로필 반복 수정, 기기·계정 반복 전환

## DAY 2 — 가입·인지작업

1. 수익화 채널 가입 확인: **토스쇼핑 쉐어링크**(sharelink.toss.im) · **쿠팡파트너스**(partners.coupang.com)
2. 개인 vs 사업자
   - 개인: 사업자 없음 / 관련 업종 사업자 없음 / 초기 테스트
   - 사업자: **광고대행업** 등 관련 업종 사업자가 있을 때
   - 다른 업종 사업자만 있으면 개인으로 시작 → 수익 커지면 업종 추가 검토
3. 노트북에서 인스타 로그인 → 스레드 **"Instagram으로 계속하기"** → **공개 프로필** (비공개면 노출 안 됨)
4. 가입 직후 프로필 건드리지 않기 (팔로우 0도 정상)
5. 인지작업 루프: **검색 → 관찰 → 추천탭 확인 → 부족하면 추가 검색**. TOP 8은 한 번에 다 말고 틈틈이
6. 볼 글: 페르소나와 비슷한 사람의 일상·고민·소비기준 글, 반응 좋은 쿠파스 글
   피할 글: 맞팔·스하리·스팔, 소통 목적 글, 정치·논쟁, 광고 티 강한 글
7. **최소 상호작용: 좋아요 0~3 / 댓글 1** (Meta 공식 아님, 강의 내부 보수 기준)
   - 좋아요는 페르소나 세팅 때 받은 "추천탭에서 우선 읽을 글 유형" 위주 (AI 계정 세팅 대화 목록에서 다시 볼 수 있음)
   - 댓글은 답글이 오가는 글에, 복붙 금지. 답이 오면 이어가면 BEST

## DAY 3 — 인포크·일상글 운영

### 인포크 (link.inpock.co.kr) — 모든 수익화 채널의 중심 링크
1. 디자인 → 프로필 이미지(DAY 1 이미지), 타이틀(예: 효리 PICK), 설명 `⬇️ 제품 번호를 검색해 주세요 ⬇️`
2. 테마·배경·폰트·블록은 자유 (깔끔하면 됨, 가운데 정렬)
3. 한줄 공지(공정위 문구): **"쿠팡 파트너스 활동의 일환으로, 이에 따른 일정액의 수수료를 제공받습니다."** 채널 늘면 앞부분에 추가
4. 비즈니스 제안 기능 ON, **검색 기능 ON** (← 제품 번호 검색용)
5. 인포크 링크 복사

### 채널 등록
- **쿠팡파트너스**: 내 정보 관리 → 웹사이트 목록에 인포크 링크 추가 → 공정위 문구 캡처 업로드 → 체크 → 저장
  (등록 안 한 채널에서 광고 활동하면 문제 소지)
- **토스쉐어링크**: 내 정보 → 활동 정보에 같은 인포크 링크 추가

### 스레드
- 추천탭에 TOP 8 관련 글이 뜨는지 점검, 부족하면 재검색
- **소개글만** 하입덕 추천 문구로. 이름·ID·이미지 유지. **인포크 링크는 아직 스레드에 안 넣음**
- 일상글: 하입덕 일상글 10개 중 하나를 **그대로 복붙** (본인 표현 추가 X)
- **3~4시간 간격**으로 하나씩. 몰아 올리기 금지
- 금지: 스하리·스팔·맞팔, 팔로우·댓글 요청, 링크, 상품홍보, 특가·할인·부업·수익화 언급
- 댓글은 자연스러운 것만 짧게. 전부 답할 필요 없음
- **첫 글 조회수 1~10회** 수준이면 혼자 밀지 말고 강사에게 공유 → 인지작업·활동 패턴 점검

## 하입덕 기능 업데이트 (2026-09-14)

- 스레드 목록(리스트 보기)에서 **원문 1개 → 대본 여러 개** 구조가 정리됨
  - 대본 1개: 원문 줄에 `[대본 1]`만, `[편집]`으로 열기
  - 대본 2개+: `96-1`, `96-2`처럼 번호. 정렬·필터 바꿔도 유지
  - 대본 2개+인 원문은 체크 불가 → 대본 줄을 골라 발행·예약
- **상태 일괄 변경**: 수집 / 분석 / 편집 / 발행대기 / 업로드. 예약 걸린 글은 건너뜀(중복 발행 방지)
- 확장 0.3.67: 느린 PC 즉시발행 멈춤 개선, 발행 직전 로그인 계정 재확인(다른 계정으로 올라가는 것 방지)
- → 하입덕은 **경쟁 글 수집(조회·좋아요·"폭발 N배" 지표) → 대본 생성 → 예약 발행**까지 하는 스레드 운영 툴

## 내 관점 메모 (용팀장 적용)

- 구조가 구매대행 "물갈이·인지" 논리와 같다: **플랫폼이 계정을 뭐로 인식하느냐가 노출을 결정**하고, 그걸 초반에 사람 행동으로 학습시킨다.

- 강의 콘텐츠 관점: "DAY별 금지 목록 + 완료 체크리스트" 포맷은 실전반 사전과제에 그대로 가져다 쓸 만하다.
