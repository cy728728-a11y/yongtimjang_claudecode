# threads-writer — 스레드 글쓰기

말투 설명서대로 쓰고, 첫 줄은 후보 여러 개를 점수로 거른 뒤 고르고, 다 쓰면 검수를 거친다.
원본은 instagram-agent-skill(MIT)의 voice.md·hooks.json·hookscore·ig-repurpose를 스레드 한국어판으로 옮긴 것이다.

## 매번 먼저 읽는다
1. `voice.md` — 말투, 금지, 형식 두 가지, 성과에서 본 것. **이 파일이 기준이다.**
2. `hooks-ko.md` — 첫 줄 공식 14개.

## 글 하나 쓰는 순서
1. **형식 정하기**: 아침·점심 = 짧은 공감 질문형(60~150자) / 저녁 = 정성 글(400~480자). voice.md 표대로.
2. **첫 줄 후보 5개**: hooks-ko.md에서 **서로 다른 공식 5개**를 골라 하나씩 쓴다.
3. **점수 거르기**:
   ```bash
   python3 .claude/skills/threads-writer/scripts/hookscore_ko.py 후보.txt
   ```
   "약함"과 금지 경고(✗)가 뜬 줄은 버린다. 남은 것 중 voice.md "성과에서 본 것"(눈에 그려지는 물건 + 누구나 겪는 장면)에 가장 가까운 줄을 고른다. 점수는 거르는 용도일 뿐이고 조회수를 예측하지 못한다. 1등 점수를 무조건 쓰지 않는다.
4. **본문 쓰기**: 첫 줄이 약속한 걸 앞쪽 절반 안에 준다. 저녁 글은 상황 → 왜 그런지(알아본 것) → 해본 방법 → 주의점 → 가벼운 질문 순서. 생활 팁은 확인된 사실만 쓰고, 경험은 voice.md "쓸 수 있는 실제 이야기"에서만 가져온다.
5. **글자 수 세기**: 공백 포함으로 센다. 저녁 글이 400자 미만이면 해본 방법이나 주의점을 구체적으로 늘린다. 500자를 넘으면 줄인다.
6. **검수**: threads-copy-reviewer 에이전트에 넘긴다. 검수가 줄을 빼서 저녁 글이 400자 밑으로 떨어지면, 뺀 줄 자리에 사실 기반 내용을 다시 채워서 길이를 살린다.

## 묶음으로 쓸 때 (예약 글 여러 개)
- 같은 날 글 3개는 첫 줄 공식이 서로 달라야 한다.
- 주제는 살림 단어가 첫 줄에 분명히 들어가게 한다(관심사에 "살림"을 잡히게 하려고).
- 결과는 `30-knowledge/38-marketing/38.03-daily-posts-*.md` 형식으로 저장한다: `## 날짜 시간 (요일)` + 본문.

## 자료 하나에서 여러 글 뽑기 (녹음·강의·긴 글)
1. 전부 읽고, 요약하지 말고 **따로 설 수 있는 조각**을 뽑아 개수부터 적는다: 주장 / 숫자 / 장면 있는 이야기 / "실제로는 이렇게 돌아가" / 실수 고백 / 그대로 인용할 만한 줄.
2. 조각이 4개 미만이면 자료가 얇다고 말하고 억지로 늘리지 않는다.
3. 조각 하나 = 글 하나. 각 글은 혼자 읽혀야 한다("지난번에 말했듯" 금지). 첫 줄 공식을 글마다 다르게 붙인다.
4. 살림 계정 주제가 아닌 조각(셀러·강의 얘기)은 스레드 일상글 단계에선 쓰지 않고 따로 표시만 해 둔다.

## 결과 형식
```
[저녁 11/12 수] 공식: 몇 년째 실패 · 첫 줄 점수 72.4 강함 · 452자
(본문)
검수: 통과 / 수정 반영
```

## 피드백 반영
용팀장이 글에 피드백을 주면 그 글만 고치지 말고 `voice.md`에 규칙으로 남긴다. 성과(threads.com/insights)를 새로 읽으면 voice.md "성과에서 본 것" 표를 갱신한다.
