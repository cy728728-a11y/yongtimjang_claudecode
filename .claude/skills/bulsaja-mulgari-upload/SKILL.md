# 불사자 물갈이 업로드 (재업로드) — 수동 사이클 · 필터 안내 + 일정 관리

> ⚠️ **핵심 (2026-07-16 확정): 업로드는 용팀장님이 불사자 UI에서 직접 실행한다. Claude는 ① 필터 조건 안내 ② 일정(todo) 관리만 한다.**
> **절대 `market_upload`·`market_group_products` 등 MCP 도구로 업로드를 실행하지 않는다.** 상품 폴링·배치 접수·재시도 자동 절차는 폐기됨(무거워서 수동+일정관리로 전환).

> **물갈이란**: 오래 전시돼 최신성 점수가 떨어진 스마트스토어 상품을 삭제 → 동일 상품·동일 조건 재업로드로 신규 전시처럼 다시 올려 점수 회복. 이 스킬은 **2단계(재업로드)**. 1단계(삭제)는 `bulsaja-mulgari-delete`.

## 트리거 시 답변 (이게 전부)

용팀장님이 "[마켓] 물갈이 업로드 할거야/진행해"라고 하면, **딱 이렇게만 답한다:**

> **"해당 마켓그룹 필터 + 미업로드 필터 걸고 전체 업로드하세요."**

- 마켓그룹명을 자연스럽게 붙여도 됨 (예: "1-3사업자는 `1번_용쌤1-3` 그룹 필터 + 미업로드 필터 → 전체 업로드하세요").
- 상품 목록 조회·개수 브리핑·업로드 실행 **하지 않는다.**

**업로드 필터 = 해당 마켓그룹 + 미업로드** (확정). ※ 삭제 필터(잠금해제+판매중)와 혼동 금지.

## 업로드 완료 후 ("업로드했어")

용팀장님이 "업로드했어"라고 하면:

1. **`active-todos.md`(`40-personal/46-todos/`)의 "{마켓} 물갈이 재업로드" todo 완료 처리.**
2. **+20일 후 날짜로 "{마켓} 물갈이 삭제작업" todo 등록** (물갈이 사이클 반복). 예: 7/18 업로드 → 8/7 삭제 todo.
3. 확인 질문 없이 바로 등록.

todo 예시:
```
- [ ] 1-3 물갈이 삭제작업 (재업로드 +20일 후 사이클 반복)
  - added: <업로드일시>
  - due: <업로드일 +20일>
  - priority: normal
```

## 마켓그룹 지칭 규칙 (삭제 스킬과 동일)

"1-1", "15-2사업자" = 그룹명 `{앞번호}번_용쌤{마켓번호}`의 **용쌤 뒤 번호**. ⚠️ 앞번호는 순환 충돌 — 반드시 `용쌤{번호}`로 매칭. 그룹명 확인이 꼭 필요할 때만 `bulsaja_market_groups` 조회 가능(안내 목적). 업로드 실행은 여전히 금지.

## 참고

- **스마트스토어 고정.** 용팀장님이 말하는 "마켓"은 항상 스마트스토어.
- 업로드는 되돌릴 수 있는 작업(중복은 서버가 자동 차단, 재삭제 가능).
- 셀러에게 표시할 땐 100% 한국어, 내부 ID·코드·필드명 노출 금지.
- 관련 장기기억: mulgari-manual-cycle(현행), mulgari-upload-workflow(폐기·참고용), market-channel-smartstore-only.
