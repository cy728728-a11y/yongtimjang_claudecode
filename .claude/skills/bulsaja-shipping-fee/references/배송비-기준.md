# 배송비 판정 규칙 — 오픈차이나 VIP + 경동비

> **워커 규칙의 정본이다.** SKILL.md 는 요약만 두고 여기를 링크한다(계약 §SKILL.md 분량).
> 출처: 이룸님 `shipping-fee-guide.md`(2026-08-11 이관) + **오픈차이나 결제 내역 실측
> 60건**(2026-08-12). 두 값이 다르면 **실측이 이긴다** — 산식은 `scripts/shipfee_rules.py`.

## 0. 적용 범위

| 항목 | 현재 기준 |
|---|---|
| 배송대행지 | 오픈차이나 |
| 요율 | **실측 60건으로 확정** — `5,500 + 750/0.5kg`(§1-1). 가이드의 VIP 열 값이 아니다 |
| 부대비용 | **요율에 더한다**(§1-2). 실측 87%에 발생, 중앙 +19% |
| 화물택배 | 정기화물이 아니라 **택배 기준**으로 계산 |
| 배송비 ↔ 경동비 | **분리한다.** 합산하지 않고, 기본 마진 수식에 경동비를 넣지 않는다 |

불사자의 `해외배송비`(상품당 1개 값)가 이 문서의 `배송비`다. 국내 한진택배 기본요금이
포함된 통합 요금으로 본다. 불사자 `국내배송비`(마켓 표기용)는 이 스킬이 건드리지 않는다.

**엑셀 다운로드의 `배송비` 열을 요율 근거로 쓰지 마라** — 그건 포장비·할증이 섞인
**합계**다. 순수 요율은 주문내역 화면의 금액을 클릭해야 나오는 결제 내역에만 있다
(2026-08-12 이 혼동으로 한 바퀴 돌았다. `scripts/fetch_oc_actuals.py` 가 거길 긁는다).

## 1. 무게 요율 — 실측으로 교정됨 (2026-08-12)

```text
제안 배송비 = 무게 요율 + 부대비용(§1-2)
```

### 1-1. 무게 요율

- 요금은 **1kg 부터** 시작하고 **0.5kg 단위로 올림**한다(`1.1kg → 1.5kg 요금`).
- 올림은 **오픈차이나가 직접** 한다 — 결제 내역에 `실무게 6.6kg, 측정무게 7.0kg` 으로
  찍히고 **그 `측정무게`가 과금 기준**이다.

```text
청구무게 = max(1.0kg, 예상무게를 0.5kg 단위로 올림)
무게 요율 = 5,500 + ((청구무게 - 1.0) / 0.5 × 750)
```

| 예상무게 | 청구무게 | 요율 |
|---:|---:|---:|
| 0.6kg | 1.0kg | 5,500 |
| 1.1kg | 1.5kg | 6,250 |
| 2.0kg | 2.0kg | 7,000 |
| 3.0kg | 3.0kg | 8,500 |
| 5.0kg | 5.0kg | 11,500 |
| 10.0kg | 10.0kg | 19,000 |
| 38.0kg | 38.0kg | 61,000 |

> **이 값은 이룸님 원본 가이드(`5,600 + 800`)와 다르다.** 오픈차이나 결제 내역 60건을
> 긁어 대조한 결과 `5,500 + 750` 이 26개 무게(1.0~38.0kg) 전부를 **불일치 0건**으로
> 재현했다. 원본 값으로 두면 10kg 에서 1,000원이 과대 계상된다.
> 원본 = [`오픈차이나-실측.json`](오픈차이나-실측.json) · 재수집 = `scripts/fetch_oc_actuals.py`.

### 1-2. 부대비용(포장비·할증) — 요율에 **더한다**

이룸님 지적(2026-08-12): *"포장비가 붙어서 단순 무게 요율표에 더 붙는다.
**파손 위험이 높을수록 포장비가 더 커진다.**"* 실측이 이를 확인했다.

- 60건 중 **52건(87%)** 에 부대비용이 붙었고, 순수 요율 대비 **중앙 +19%**다.
- 항목이 곧 파손 대비다: 외부포장(48건·중앙 3,600) · 한진택배 할증료(27건) ·
  박스교체(6건·중앙 5,000) · 멀티포장 · 모서리 보호대 · 내부포장 · 돼지코.
- **무게 ↔ 부대비용 상관 r = 0.82** — 무게가 1차 예측자이고, 파손위험이 같은 무게
  안에서 갈리는 축이다. 그래서 무게 구간별 **실측 분위수**를 위험도에 매핑한다.

| 청구무게 | n | 낮음(25%) | 중간(중앙) | 높음(75%) |
|---|---:|---:|---:|---:|
| ~2kg | 12 | 0 | **0** | 1,500 |
| 2~5kg | 11 | 2,500 | **3,100** | 3,100 |
| 5~10kg | 13 | 3,600 | **3,700** | 4,000 |
| 10~20kg | 17 | 4,800 | **5,900** | 11,200 |
| 20kg~ | 7 | 11,400 | **13,700** | 13,800 |

2kg 미만이 0원인 건 오타가 아니다 — 가벼운 소품은 절반 이상이 부대비용 0원이었다.
회귀식(`525 + 500×kg`) 대신 분위수를 쓰는 이유: 표본 60건에서 잔차가 ±2,400원이라
구간 안 분포를 그대로 쓰는 편이 정직하다.

**파손위험은 워커가 판정한다** — 판정 기준은 워커 지시서 §2-5.

## 2. 무게를 추정하는 순서 — 워커가 하는 일

### 2-1. 이미지에서 볼 단서

- 제품 전체 크기 · 사람 손/몸/가구와의 비교 크기
- 구성품 개수 · 접힘/분리 가능 여부
- 금속/유리/목재/플라스틱 등 소재
- 박스 포장 시 부피가 커질 가능성
- 옵션별 크기/세트 수량 차이

**텍스트가 이미지보다 강하다.** 옵션 원문·상품명에 `45*39`·`19cm`·`3kg` 같은 표기가 있으면
그걸 1순위 근거로 쓴다. 이미지 추정은 표기가 없을 때의 대체 수단이다.

### 2-2. 표기가 없으면 구간으로 잡는다

| 상품 느낌 | 임시 예상무게 |
|---|---:|
| 작고 가벼운 소품 | 1.0~1.5kg |
| 일반 생활용품/주방용품 | 1.5~3.0kg |
| 여러 개 세트/두꺼운 플라스틱 | 3.0~5.0kg |
| 금속/목재/대형 수납류 | 5.0~10.0kg |
| 대형 가구성/부피 큰 상품 | 10kg 이상 + 경동비 확인 |

구간을 잡았으면 **구간의 상단**을 쓴다. 배송비가 모자라면 마진이 깎이고, 남으면 가격
경쟁력만 조금 손해다 — 두 오차의 값이 다르다.

### 2-2-0. 실측 무게 교정표 (오픈차이나 90건, 2026-08-13)

**위 구간표는 감이고, 아래는 실제로 저울에 오른 값이다.** 추정이 이 표와 크게 어긋나면
추정이 틀린 것이다. 전체 분포: 최소 **1.0kg** · 25% 2.6 · 중앙 **6.8** · 75% 16.0 · 최대 45.0.

| 품목 | 실측 |
|---|---:|
| 의자(Chair) | 15.0 · 17.0kg |
| 워터펌프 · 유압 펀처 | 16.0 · **14.4kg** |
| 기계 스탠드 · 핸드카트 · 돌리 | 11.4~15.6kg |
| 사이드테이블 · 선반 · 테이블 | 4.0~11.8kg |
| 분쇄기 · 베어링 풀러 | 8.0 · 5.0kg |
| 파라솔 · 어닝 · 텐트 | 5.4~7.0kg |
| 행거 · 옷걸이 | 4.0~9.4kg |
| 음료 디스펜서 · 쌀통 · 양념통 | 1.0~3.0kg |
| LED 램프 · 케이블 · 북스탠드 · 허브 · 의류 | **1.0kg** |

**두 가지가 이 표에서만 보인다:**

1. **1.0kg 미만이 90건 중 0건이다.** 최소가 정확히 1.0kg(13건). 소품이라도 포장까지
   재면 1kg 아래로는 안 내려간다 → **1.0kg 미만을 추정하지 마라.** 어차피 청구무게는
   1.0kg 으로 올라가므로 요금은 같지만, 0.5kg 같은 값은 하한 감각이 없다는 신호다.
2. **금속·유압·모터가 든 물건은 무겁다.** 유압 펀처 하나가 14.4kg 다. 공구 세트를
   5~6kg 으로 잡았다면 거의 틀렸다고 보면 된다 — 잭·펌프·모터·주물 베이스가 들어가면
   **10kg 이상**부터 시작한다.

### 2-2-1. 부피무게는 아직 규칙이 없다

결제 내역에 `부피무게 : 0kg ( 0 * 0 * 0 cm)` 자리가 있어 오픈차이나가 부피무게를
**계산할 수는 있다.** 다만 실측 60건 전부 부피가 0으로 찍혀 한 번도 적용되지 않았고,
그래서 **환산 나눗수(÷6000 등)를 정할 근거가 없다.** 부피가 실제로 찍힌 건이 나오면
그때 정한다. 지금은 `측정무게 = max(1.0kg, 실무게 0.5kg 올림)` 이 60건 전건에서 성립한다.

### 2-3. 옵션별로 무게가 다르면 무게군으로 나눈다

불사자 해외배송비는 **상품당 1개 값**이라 옵션마다 다른 요금을 넣을 수 없다.
그래서 워커는 무게가 다른 옵션을 `무게군` 으로 묶어 주고, **적용값은 스크립트가
판매 옵션 중 최대 무게로 정한다**(2026-08-11 기본값). 대표옵션 기준도 같이 계산해
시트에 병기하므로 이룸님이 시트에서 바로 대조할 수 있다.

대부분의 상품은 무게군이 1개다(색상만 다른 경우). 무게군을 억지로 쪼개지 않는다 —
**청구무게가 같은 구간에 들어가면 나눌 이유가 없다**(1.2kg 와 1.4kg 는 둘 다 1.5kg 요금).

## 3. 국내 추가 할증 — 구간 표시만, 금액은 더하지 않는다

> **실측 반영(2026-08-12)**: `한진택배 할증료` 는 결제 내역에서 **부대비용에 이미 들어와
> 있다**(27건·중앙 1,200원). §1-2 의 분위수가 그 금액을 포함하므로 아래 표를 또 더하면
> **이중 계상**이다. 그래서 `apply` 는 `할증안내` 열에 `600원 구간 (포장비에 포함)`
> 처럼 **구간만** 적는다.

기본 배송요금에는 국내 한진택배 **기본요금만** 포함된 것으로 본다. 무게/부피에 따라
추가 할증이 붙는다.

| 기준 | 추가 할증료 |
|---|---:|
| 2~4.5kg / 80~100cm | 600원 |
| 5~9.5kg / 100~120cm | 1,200원 |
| 10~14.5kg / 120~140cm | 2,800원 |
| 15~20kg / 140~160cm | 3,000원 |

- 실제 부과 여부는 배송대행지/택배사 **실측** 기준이다.
- 이 표의 금액은 **참고값**이다 — 실측 10kg 건에는 표의 2,800원이 아니라 2,400원이
  붙었다. 금액이 필요하면 §1-2 의 실측 분위수를 쓴다(그 안에 할증이 이미 있다).

## 4. 경동비 — 대상 판정과 계산

### 4-1. 언제 경동비를 잡나

- 포장 규격 `가로+세로+높이` 합이 **160cm 이상** 가능성
- 옵션/상세 이미지상 대형·중량 상품
- 택배사 일반 택배 규격을 넘을 가능성
- 박스 부피가 커서 국내 화물택배 인계 가능성

경동비가 필요해도 **`배송비` 에는 기본 배송비만** 넣고 `경동비` 열에 따로 적는다.

### 4-2. 계산 — 택배 표만 본다

```text
부피 = 가로 × 세로 × 높이 (㎤)
A운임 = 부피구간 택배 표준운임 × (1 + 지역별 인상율)
B운임 = 무게구간 택배 표준운임 × (1 + 지역별 인상율)
최종 경동비 = max(A운임, B운임)   → 100원 단위 반올림
```

- 표의 **`정기화물` 열은 쓰지 않는다. `택배` 열만** 본다.
- 지역이 안 정해졌으면 보수적으로 **25%** 를 쓰거나 `지역 미정` 으로 메모한다.

예시(수도권 → 경남권, 25%):

```text
A: 40×40×40 = 64,000㎤ → 표준운임 5,500 × 1.25 = 6,875 → 약 6,900원
B: 60kg → 표준운임 15,000 × 1.25 = 18,750 → 약 18,800원
적용: 둘 중 높은 18,800원
```

### 4-3. 표준운임표는 이 문서에 박제하지 않는다

구간이 986개라 md 에 넣을 것이 아니다. [`경동-표준운임.json`](경동-표준운임.json) 에
경동택배 고시표의 **택배 열**(부피 500구간 · 무게 486구간)과 지역 인상율 7×7 이 들어 있다.

```bash
python ../scripts/fetch_kd_table.py            # 고시표 재수집(지역 인상율은 보존)
python ../scripts/fetch_kd_table.py --dry-run  # 파싱만 확인, 파일은 안 건드림
```

출처: `https://kdexp.com/service/charge/package_standard.do`.
구간이 비면 스크립트는 **금액을 만들지 않고** `경동비` 열에 `확인필요` 만 남긴다.

## 5. 이 스킬이 바꾸지 않는 것

- **판매가를 직접 정하지 않는다.** 다만 불사자가 해외배송비를 바꾸면 **옵션 판매가를
  차액만큼 자동으로 조정**한다(100원 단위 반올림). 그래서 변경폭 게이트가 있다.
- **국내배송비·반품비·교환비**(`uploadDelivery`)는 건드리지 않는다.
- **경동비는 불사자에 저장할 자리가 없다** — 시트 전용 값이다.
