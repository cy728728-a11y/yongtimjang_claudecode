# AI 레시피 — 정밀 모드 (헤르메스 06 흡수: 구도·조명까지 짜는 고변형)

> "예쁘게/연출/레시피/다듬어줘"를 지명했을 때만. 기본 모드([`배경생성-기본.md`](배경생성-기본.md))
> 보다 변형이 크므로 검수를 더 엄격하게 본다. 기준 이미지 선택·검수 3축·판정·재생성 상한은
> 기본 모드와 공통(SKILL.md 참조) — 이 문서는 **레시피 작성 전용** 추가 단계만 다룬다.

## 1. 목표 (우선순위)

①1초 안에 제품·용도 이해 ②경쟁 목록에서 눈에 띔 ③실제 판매 제품의 구조·색상·부품·
구성품 오인 없음. **제품 정확성이 클릭 유도력보다 항상 우선한다.**

## 2. 경쟁 썸네일 차별화 분석

핵심 키워드 1~2개 확정 → 카테고리·키워드 조회로 상위 10~20개의 지배 경향 기록
(배경색 계열·흰배경 누끼 비율·구도·연출) → 겹치지 않는 배경 방향을 고른다.
조회 불가하면 카테고리 통념으로 추정하되 **추정임을 기록**한다.

차별화는 배경색·구도·연출 수준까지만 — 과장 연출·기능 암시로 튀는 것은 금지.

## 3. 배경 전략 선택 (4종 중 서로 다른 2개, A/B 안)

용도 전달형 / 제품 집중형 / 감성 생활형 / 계절·상황 강조형.

팔레트는 이룸님 지정이 있으면 그것 우선, 없으면 저채도 파스텔 4색 예시(밀크티 베이지·
파우더 옐로우·샌드 베이지·스위트 피치)를 제안한다. 경쟁 차별화와 팔레트가 충돌하면
차별화를 우선하되 채도·명도는 매장 톤을 유지한다. **HEX 값을 단정하지 않는다.**

## 4. 레시피 작성 (5층 구조)

1. **제품 잠금** — 종류·색상·소재감·실루엣·비율·카메라 각도·부품 개수와 위치(불변 요소)
2. **배경 공간** — 선택한 전략(용도/제품집중/감성/계절)에 맞는 배경 설명
3. **구도** — 점유율·잘림 방지
   - 부품 많은 세트: 75~82%
   - 단품 소형가전·공구: 70~80%
   - 생활 장면 연출: 65~75%
4. **조명·분위기** — 광원 위치·접지 그림자(좌상단 광원 + 우하단 소프트 그림자가 기본형)
5. **금지 조건** — 글자·추가 구성품·사람·손·로고·과장 효과 금지

**'고급스럽게'처럼 추상적으로 쓰지 않는다** — 실제 공간·배경 밝기·광원·점유율·소품 수를
명시한다. A/B 안은 별도 레시피로 작성한다(공유 아님).

## 5. 생성·추적

A안 완료 후 B안을 순차 접수한다(같은 상품에 두 안을 동시에 접수하지 않는다 — 크레딧
이중 소모와 자동반영 충돌을 막는다). **생성 완료분이 대표 순서에 자동 반영될 수 있다**
(실측 확인, SKILL.md §자동반영 방어 참조) — 모든 생성·재생성이 끝난 뒤 원본 전체 순서를
마지막으로 한 번 더 복원·재조회한 뒤에야 판정 단계로 넘어간다.

## 6. A/B 판정 (2026-08-06 — 판정 주체는 Claude, 기본 모드와 공통)

통과안이 2개면 Claude 가 검수 3축 기준으로 **더 나은 1안을 골라** 반영하고, A/B 를
review.html 에 나란히 남긴다(이룸님 사후 검토용 — 바꾸고 싶으면 종합보고 뒤 지목).
둘 다 불합격이면 기본 모드와 같은 자동 처리를 따른다(SKILL.md §검수 불합격 자동 처리 —
글자변조 skip / 재생성 상품당 누적 2회 / 원본 fallback).
