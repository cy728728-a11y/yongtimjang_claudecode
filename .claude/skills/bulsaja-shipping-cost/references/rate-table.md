# 해운 특가 요금표 — 배송비 측정 전용

## 적용 기준

- 제공 자료: `해운_VIP_요금표_100kg이하.xlsx`
- 적용 범위: 예상 청구무게 1.0kg 이상
- 최소 요금: 1.0kg까지 5,600원
- 무게 단위: 0.5kg
- 중간 무게: 다음 0.5kg 구간으로 올림
- 0.5kg 증가할 때마다 800원 증가
- 같은 뜻의 계산식: `배송비(원) = 4,000 + 1,600 × 청구무게(kg)`
  - 단, 청구무게는 최소 1.0kg으로 잡고 0.5kg 단위로 올림한 뒤 계산한다.

원본 표의 1.0kg부터 100.0kg까지 총 199개 구간을 전부 검사한 결과, 모든 행이 위 증가 규칙과 정확히 일치한다.

## 100kg 초과 규칙

원본 표는 100kg에서 끝나지만, 전 구간이 `0.5kg 증가마다 800원 증가`로 일정하므로 100kg을 넘으면 같은 증가 규칙을 연장한다.

- 100.5kg: 164,800원
- 101.0kg: 165,600원
- 105.0kg: 172,000원

100kg 초과 상품도 추천 해외배송비 계산과 입력을 중단하지 않는다. 다만 용팀장님이 선호하지 않는 중량 상품이므로 결과 보고의 첫 부분에 다음 경고를 반드시 붙인다.

```text
⚠️ 예상 청구무게가 100kg을 넘는 중량 상품입니다.
추천 해외배송비는 같은 증가 기준으로 계산해 입력했지만, 용팀장님의 선호 소싱 범위를 벗어나는 상품으로 별도 확인이 필요합니다.
```

## 무게 근거와 부피무게

이 자료는 무게별 요금만 제공하며 부피무게 계산식은 포함하지 않는다.

- 불사자에서 예상 청구무게가 제공되면 그 무게를 위 요금표에 적용한다.
- 포장 실무게만 확인되고 부피무게 계산식이 없으면 실무게 기준 참고액으로 표시하며, 실제 청구액이 달라질 수 있음을 알린다.
- 가로·세로·높이만으로 청구무게를 만들어야 하는 경우에는 사용하는 배대지의 실제 부피무게 계산식을 추가로 확인하기 전까지 임의 계산하지 않는다.

## 검증 규칙

1. 계산 전 무게를 최소 1.0kg, 0.5kg 단위 올림으로 정규화한다.
2. 100kg 이하에서는 원본 표와 계산 결과가 일치해야 한다.
3. 100kg 초과에서는 100kg 요금 164,000원에 초과 0.5kg 구간마다 800원을 더한다.
4. 100kg 초과라도 추천액 입력은 진행하되 중량 상품 경고를 반드시 보고한다.
5. 실제 적용 후 저장된 해외배송비와 판매 중 옵션 가격 변화를 재조회한다.
