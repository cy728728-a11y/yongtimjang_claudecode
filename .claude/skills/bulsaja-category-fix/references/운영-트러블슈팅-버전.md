# 불사자 카테고리 교정 — 동작 원리 · 트러블슈팅 · 버전 이력

> SKILL.md 에서 분리한 안정·참조성 섹션(리팩터 Step6b). 운영 중 필요할 때 연다.
> 관련: [[bulsaja-category-fix-skill]] · [[대표검색어-도출]]

## 동작 원리 (셀하 스크립트)

1. `eroomlib.webdriver.create_driver()`(봇 감지 우회 Chrome)로 크롬 실행
2. `sellha.kr/member/login` 에서 `input[name=email]`·`input[name=password]` 채우고 '로그인' 클릭
3. 카테고리 조회는 **직접 URL 진입**: `sellha.kr/research?keyword=<검색어>&tab=research-result`
4. 렌더된 `document.body.innerText` 에서 `NN% 대분류 > ... > 최종` 패턴을 정규식으로 추출,
   여러 개면 확신도(%) 최고를 선택. 최종차수 = 경로를 `>`로 나눈 마지막 조각.

(셀하 조회 스크립트는 `sellha-category` 스킬로 분리됨 — `skills/sellha-category/scripts/sellha.py`.)

## 트러블슈팅

- **로그인 실패**: 비번 변경 시 `.env` 갱신. 로그인 폼 구조 변경 시 `sellha.py`의 `login()` 셀렉터 갱신.
- **카테고리 파싱실패 다발**: 셀하 페이지 구조/클래스 변경 가능 → `sellha.py`의 `CAT_PAT` 정규식,
  렌더 대기(폴링 22초) 점검. 브랜드 키워드/신조어는 카테고리가 없을 수 있음(정상적인 `조회실패`).
- **불사자 매칭 안 됨**: 최종차수 이름이 애매/동명이면 `부분일치`·`매칭불가`로 뜬다 → **저장 4단계 폴백**
  (leaf+분야한정어 유도 → 썸네일 재검색 → 근접 → 보고)으로 처리. `category_steer.py` 로 배치 유도.
- **동명 카테고리**: 최종차수가 여러 상위경로에 존재 → 자동매칭이 1순위(엉뚱한 상위)를 고른다.
  leaf 앞에 상위 분야 한정어를 붙여 원하는 경로를 1순위로 끌어올린다(폴백 1단계).
- **셀하 경로가 불사자에 없음**: `category_resolve(경로)` 가 실패하면 불사자 체계에 그 경로가 없는 것
  (셀하가 더 세분화). 근접 카테고리로 저장(폴백 3단계, `mode:"near"`) 하거나 이룸님께 보고.
- **짧은 leaf 도달 불가**(`볼`·`솔` 등 1~2글자): 검색 랭킹에서 형제·타 카테고리에 밀린다 → 상위 한정어
  조합(`샐러드볼 식기`)이나 동의어(`믹싱볼`)로 유도. 그래도 안 되면 이룸님 지정 경로로 재시도.
