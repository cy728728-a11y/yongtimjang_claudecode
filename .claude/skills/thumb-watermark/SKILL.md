# 썸네일 워터마크

상품 사진에 글자 워터마크(상호·상표명)를 넣는다. 구독자도 그대로 따라 할 수 있게 **내 컴퓨터 사진만** 다룬다.

## 준비 (처음 한 번)
```bash
pip install pillow
```

## 절차
1. **받을 것 확인** — 사진 파일이나 폴더 경로, 넣을 글자. 글자를 말하지 않으면 기본값 `오네이`. 위치를 말하지 않으면 가운데 대각선.
2. **실행**
   ```bash
   python -X utf8 <이 스킬 폴더>/scripts/watermark.py "<사진 또는 폴더>" --text "오네이" --compare
   ```
   - `--position corner` : 오른쪽 아래 작은 글씨 ("구석에", "작게" 라고 하면)
   - `--opacity 0.3` : 진하기 0~1. 기본은 가운데 0.18(연하게), 구석 0.5. "더 진하게/연하게" 라고 하면 조정
   - `--compare` : 원본|결과를 나란히 붙인 비교 사진을 `워터마크_결과/비교/` 에 저장
3. **눈으로 확인** — `워터마크_결과/비교/` 사진 1~2장을 Read 로 열어 글자가 보이는지, 상품을 너무 가리지 않는지 본다.
4. **보고** — 몇 장 저장했는지, 결과 폴더 위치, 건너뛴 파일(깨진 사진 등)과 이유.

## 지키는 것
- 원본은 절대 덮어쓰지 않는다. 결과는 항상 `<입력 폴더>/워터마크_결과/` 에 같은 이름으로.
- 폴더는 바로 아래 사진(jpg·jpeg·png·webp)만 처리하고, 결과 폴더는 다시 처리하지 않는다.
- 사진 한 장이 깨져 있어도 나머지는 계속 처리한다.
- 투명 배경 PNG 는 흰 배경으로 바꿔 저장한다.
- 글자색은 사진 밝기를 보고 진갈색/아이보리 중 잘 보이는 쪽을 자동으로 고른다.

## 참고
- 네이버는 대표 이미지에 글자가 진하게 들어간 걸 반기지 않는다. 가운데 워터마크는 연하게(기본 18%) 두는 걸 권한다.
- 폰트는 나눔펜스크립트(무료, OFL)를 `assets/` 에 함께 넣어 두어 윈도우·맥 어디서나 같은 모양으로 나온다.
- 점검: `python -X utf8 tests/test_watermark.py` (추가 설치 없음)
