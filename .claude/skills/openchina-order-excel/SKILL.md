# 오픈차이나 주문내역 엑셀 다운로드

## Overview
오픈차이나(openchina.co.kr) 마이페이지의 '주문 엑셀다운로드' 버튼과 동일한 요청을
파이썬 스크립트로 재현한다. 로그인 → 주문내역 엑셀 다운로드 → 워크스페이스에 저장.
브라우저 없이 파이썬 표준 라이브러리만으로 동작한다(추가 설치 불필요).

## 전제
- 로그인 정보는 워크스페이스 루트 `.env`의 `OPENCHINA_ID` / `OPENCHINA_PW`에서 읽는다(git 제외).
- `.env`가 없거나 값이 비어 있으면 스크립트가 안내 메시지를 출력한다.

## Instructions

1. **기간 파악**: 사용자가 기간을 말하면 시작일/종료일(YYYY-MM-DD)로 환산한다.
   - "최근 1개월", "6월 한달", "지난주" 등 → 오늘 날짜 기준으로 계산.
   - 기간을 말하지 않으면 스크립트 기본값(최근 90일)을 그대로 사용 — `--begin`/`--end` 생략.
   - 날짜 추측이 애매하면 사용자에게 한 번 확인한다(추측 판단 금지).

2. **스크립트 실행**: Bash로 실행한다. 경로에 공백이 없어 그대로 호출 가능.
   ```bash
   python "${CLAUDE_SKILL_DIR}/scripts/download_orders.py" --begin 2026-06-01 --end 2026-06-30
   ```
   - 기본 기간(최근 90일)이면 `--begin`/`--end` 없이 실행.
   - 저장 위치를 바꾸려면 `--out-dir "<폴더>"` 추가. 기본은 `50-resources/openchina/`.
   - 주문상태로 거를 필요가 있으면 `--stat-seq <번호>` (기본 0=전체).

3. **결과 보고**: 스크립트가 출력한 저장 경로와 파일 크기를 사용자에게 그대로 전달한다.
   - `.xls` 파일은 엑셀에서 바로 열린다(HTML 테이블 기반 엑셀 형식).
   - 저장 경로를 클릭 가능한 형태(`파일경로`)로 알려준다.
   - 저장 파일명은 **항상 고정**(`오픈차이나_주문내역_최신.xls`) — 매 실행 시 덮어써서 누적 없이 최신 1개만 유지.
     조회 기간이 궁금하면 파일 안 데이터로 확인(파일명에는 기간이 없음).

4. **실패 시**:
   - "로그인 실패" → `.env`의 아이디/비밀번호 확인 요청.
   - "엑셀 응답이 아님" → 해당 기간에 주문이 없거나 세션 문제. 기간을 바꿔 재시도 제안.

## 기술 메모 (검증됨 2026-07-05)
- 로그인: `POST /Front/Join/Login_Ajax.asp` — `sMemId`, `sMemPw` → 성공 시 본문 `1` 반환, 세션 쿠키 유지.
- 다운로드: `POST /Front/Member/Acting_X17.asp` — 마이페이지 `fnPageExl('X17')` 버튼과 동일.
  - 폼 필드: `shBeginDay`, `shEndDay`(기간), `shStatSeq`(상태, 0=전체), `shTabTy`(1), `shGo`(1), 나머지 검색필터는 공란.
  - 응답: `application/vnd.ms-excel`, 파일명 `주문내역다운로드_<날짜>.xls`.
