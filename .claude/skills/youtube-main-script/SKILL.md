# 유튜브 메인 스크립트 초안 (노션 → 초안 → 노션 삽입)

> ⚠️ **핵심 (2026-07-30 확정): 회차 페이지는 시온 PD의 GIGWORKERS 워크스페이스에 있고 용팀장님 계정은 게스트다.**
> **Notion MCP는 절대 시도하지 않는다** — 개인 워크스페이스 연동이라 게스트 페이지는 404 (실측 확인). **크롬 브라우저(로그인 세션)만 사용한다.** 읽기·쓰기 모두 검증됨.

## 페이지 구조 (매 화 동일 템플릿)

`업로드 캘린더` DB (https://www.notion.so/3375fb6a7cd1807a8e86ef6e2ca4a3f2) 하위 회차 페이지:

```
경쟁사 (시온)          ← 토글: 경쟁 영상 썸네일·링크·대본
기획(시온)             ← 토글: 제목·타겟·훅·본론 뼈대·CTA 위치 (회차에 따라 도입부 토글에 합쳐져 있기도 함)
도입부(시온)           ← 토글: 확정 도입부 스크립트 (대담형 또는 독백형)
메인 스크립트(용팀장님) ← 토글: ★ 여기에 초안을 삽입
업로드 본문(하늘)       ← 건드리지 않음
```

## 실행 순서

### 1. 읽기 (크롬)

1. claude-in-chrome 스킬 로드 → `tabs_context_mcp` → 새 탭 or 기존 탭에 노션 링크 `navigate`.
2. 로드 직후 `get_page_text`가 비면 **2~3초 wait 후 재시도** (노션은 비동기 렌더).
3. 토글 펼치기: **반드시 화면 아래쪽 토글부터 위로** 클릭 (위부터 펼치면 아래 토글 좌표가 밀려 클릭이 빗나감). 토글 제목 텍스트가 아니라 **삼각형(▸)** 을 클릭.
4. `get_page_text`로 기획·도입부·경쟁사 전문 확보. 메인 스크립트 토글에 기존 내용이 있는지도 확인.

### 2. 재료 판단 → 인터뷰

- 기획에 본론 뼈대(단계·화면 근거·CTA 위치)가 이미 충분하면 **인터뷰 생략하고 바로 작성**.
- 부족하면: **도입부가 시청자에게 약속한 것들을 목록으로 추출**한 뒤, 약속 기반 질문 3~5개를 한 번에 묻는다 (시연 순서·보여줄 화면·구체 노하우·단톡방 배포 자료). 용팀장님은 대략적인 방향만 답한다.

### 3. 초안 작성

**말투 기준** (우선순위 순):
1. `c:\Users\woori\OneDrive\바탕 화면\최용's 폴더\구매대행\00 구매대행 플랫폼\00 불사자\01 유튜브\용팀장_말투_포터블_최소본.md` (원본, 갱신 반영)
2. 메모리 `yongteamjang-tone-guide` (폴백)
3. 해당 회차나 지난 회차 노션에 용팀장님이 직접 쓴 스크립트 조각이 있으면 리듬 표본으로 참고 (짧은 줄, 줄바꿈 잦음)

**구조**: 도입부 마지막 문장을 이어받는 전환 → 본론(단계별 시연, `[화면: ...]` 지시 포함) → 실제 결과 비교(사회적 증거) → 2차 CTA(본론 중반) → 주의점 → 오늘 할 일 3개 + 구독 유도 마무리.

**분량**: 본편 15분 이상 = **공백 포함 4,500자 이상** (1분 ≈ 300자). 작성 후 반드시 카운트로 확인.

**촬영 시 채울 부분**은 `[촬영 전 확정: ...]` 형태로 명시 (예: 실제 상품명, 차이 단어 짚는 대사).

### 4. 자체 검수 (삽입 전 필수 — 2026-07-30 검증에서 나온 실제 지적 기반)

**말투**:
- 금지표현·유사 패턴: "무조건 됩니다", "따라만 하면", "~만 지키면 확실히", "리스크 없습니다", `글로벌 위탁판매`(→`AI 위탁판매`)
- AI 정확성 절대 보장 금지 ("아예 안 올립니다" 류) — 검수 단계의 존재 이유와 모순됨. AI 한계 + 사람 검수를 함께 말할 것
- 초보자 탓 프레임 금지 ("초보자라면 속습니다" ✗ → 결과물·방식 쪽으로: "그럴듯하게 나와서 그대로 등록하는 경우가 많습니다" ✓)
- 결론 먼저. 숫자·성과엔 조건. 한 문장 한 내용.

**구성**:
- 기획 뼈대의 모든 비트가 지정 순서대로 들어갔는가
- **거짓 콜백 금지**: "아까 말씀드린 ○○"는 확정 도입부에 실제로 있는 것만. 기획 노트에만 있고 도입부에 없는 예고를 콜백하지 말 것
- 숫자 정합성: "다섯 가지 기준"이라 했으면 본문에서 다섯 개 전부 짚기. '기준'(AI 규칙)과 '단계'(작업 순서)처럼 같은 숫자가 두 의미로 쓰이면 본문에서 명시적으로 구분
- 도입부 내용의 재설명 금지 (한 줄 콜백은 허용)

**발화** (소리 내어 읽는 대본):
- 대사에 낭독 불가 기호 금지: 가운뎃점(·) → 풀어쓰기 ("허위·과장입니다" ✗ → "허위광고, 과장광고입니다" ✓)
- 조사 누락 합성어 금지 ("고정댓글 단톡방" ✗ → "고정댓글에 링크 걸어둔 단톡방" ✓)
- 비문·조사 호응·주술 호응 점검 ("순서는 이렇게 하시면 됩니다" ✗ → "순서는 이렇습니다" ✓)
- 이중 헤징 금지 ("가능성을 높일 수 있습니다" ✗ → "가능성이 올라갑니다" ✓)
- 첫째/둘째 열거 반복 최소화, 병렬 구문의 통째 반복 제거

### 5. 노션 삽입 (검증된 절차)

1. PowerShell: `Set-Clipboard -Value (Get-Content <초안파일> -Raw -Encoding UTF8)` — **붙여넣기 직전에 실행**하고, 같은 명령에서 `Get-Clipboard -Raw` 길이로 실렸는지 반드시 검증 (클립보드는 브라우저 조작 사이에 증발할 수 있음 — 2026-07-30 26화에서 실측)
2. 메인 스크립트 토글이 펼쳐진 상태에서 **토글 제목 바로 아래 빈 영역 클릭** → "Press '/' for commands" 플레이스홀더가 잡히면 성공
3. **클릭과 `ctrl+V`를 한 browser_batch에 묶어서** 실행 (사이가 벌어지면 포커스/클립보드 유실) → 3~4초 wait → `get_page_text`로 **전문이 토글 안에, 업로드 본문 앞에** 들어갔는지 확인 (마지막 문장까지)
4. 마크다운 `##`는 노션 헤딩으로 자동 변환됨 (정상)
5. ⚠️ 토글에 **기존 내용이 있으면 덮어쓰지 않는다** — 기존 내용 끝에 덧붙이고 보고

## 트러블슈팅 (2026-07-30 실측)

| 증상 | 원인/해법 |
|------|-----------|
| MCP `object_not_found` 404 | 게스트 워크스페이스. MCP 포기, 크롬으로 |
| 토글 클릭했는데 안 펼쳐짐 | 텍스트를 클릭함 → 삼각형(▸) 좌표를 클릭. 여러 개면 아래→위 순서 |
| 스크린샷 타임아웃 / 렌더러 프리즈 | 토글 대량 펼침 직후 발생. wait 3~5초 후 가벼운 작업(get_page_text)부터 |
| get_page_text "No text content" | 페이지 로드 중. 2~3초 wait 후 재시도 |
| notion.so → app.notion.com 리다이렉트 | 정상. 페이지 ID로 직접 navigate해도 됨 |
| 캘린더에서 회차 클릭 시 모달로 열림 | get_page_text가 뒤 캘린더를 잡음 → 페이지 ID URL로 직접 navigate |
| ctrl+V 했는데 아무것도 안 붙음 | 클립보드가 비어 있음 (로드 후 시간이 지나면 증발 가능) → 재로드 + 길이 검증 + 클릭·붙여넣기 한 배치로 재시도 |
| ctrl+End로 페이지 끝 이동 안 됨 | 문서에 포커스 없음 → 마우스 스크롤 사용 |

## 하지 않는 것

- 도입부·기획·경쟁사·업로드 본문 섹션 수정 (읽기만)
- Notion MCP 시도
- 삽입 전 확인 질문 (바로 삽입이 확정 정책 — 수정은 용팀장님이 노션에서 직접)
