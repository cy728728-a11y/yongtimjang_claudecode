# 쿠팡 판매수수료율 표

> **상태: 미검증 (2026-09-13).** 아래 표는 **비어 있고**, `coupang_rules.FEE_TABLE` 도 비어 있다.
> 즉 현재 모든 카테고리가 `MAX_FEE = 10.8%` 로 계산된다.

## 왜 비워 두었나

불사자 카테고리는 **네이버 체계**다. 쿠팡 카테고리로의 자동 매핑이 없고,
쿠팡 수수료율은 카테고리별로 4~10.8% 범위에서 갈린다.

검증하지 않은 숫자를 표에 적으면 **게이트가 낙관적으로 틀린다** — 실제보다
수수료를 낮게 잡아 적자 상품을 통과시킨다. 반대로 비워 두면 전부 상한(10.8%)으로
계산되므로 **보수적으로만 틀린다**: 통과 후보가 실제보다 줄어들 뿐,
적자 상품이 통과하지는 않는다.

파일럿 규모(70여 건)에서는 사람이 한 번 훑는 쪽이 싸고 정확하다.

## 채우는 법

1. 쿠팡 WING → 판매자 정보 → 판매수수료 안내에서 해당 카테고리 요율을 확인한다.
2. 아래 표에 **네이버 카테고리 경로 접두사 → 요율(%)** 로 적는다.
3. `scripts/coupang_rules.py` 의 `FEE_TABLE` 에 같은 내용을 옮긴다.
4. 이 파일 맨 아래 "갱신 이력" 에 날짜와 출처를 남긴다.

매칭 규칙: **더 긴(구체적인) 접두사가 이긴다.** 미등록 경로는 `MAX_FEE`.
