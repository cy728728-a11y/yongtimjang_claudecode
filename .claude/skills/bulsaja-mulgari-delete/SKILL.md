# 불사자 물갈이 삭제작업 (수동 사이클 — 필터 안내 + 일정 관리)

> ⚠️ **핵심 (2026-07-16 확정): 삭제는 용팀장님이 불사자 UI에서 직접 실행한다. Claude는 ① 필터 조건 안내 ② 일정(todo) 관리만 한다.**
> **절대 `market_delete`·`market_group_products` 등 MCP 도구로 삭제를 실행하지 않는다.** 상품 목록을 폴링하거나 삭제 접수하는 자동 절차는 폐기됨(무거워서 수동+일정관리로 전환).

> **물갈이란**: 오래 전시돼 최신성 점수가 떨어진 스마트스토어 상품을 삭제 → 동일 상품·동일 조건 재업로드로 신규 전시처럼 다시 올려 점수 회복. 상품을 바꾸는 게 아니라 **전시 시점만 리셋**. 이 스킬은 **1단계(삭제)**만.

## 트리거 시 답변 (이게 전부)

용팀장님이 "[마켓] 물갈이 삭제 할거야"라고 하면, **딱 이렇게만 답한다:**

> **"잠금해제 + 판매중 상태 상품만 필터 걸어서 삭제하세요."**

- 마켓그룹명을 자연스럽게 붙여도 됨 (예: "1-3사업자는 `1번_용쌤1-3` 그룹에서 잠금해제 + 판매중 필터 → 전체 삭제하세요").
- 그 외 상품 목록 조회·개수 브리핑·삭제 실행 **하지 않는다.**

**삭제 필터 = 잠금해제 + 판매중** (확정). ※ 미업로드 필터는 삭제가 아니라 **업로드 단계** 전용이니 혼동 금지.

## 삭제 완료 후 ("삭제했어")

용팀장님이 "삭제했어"라고 하면:

1. **삭제 일시(연월일시) 기록.**
2. **`active-todos.md`(`40-personal/46-todos/`) Today에 "{마켓} 물갈이 재업로드" todo 등록.**
   - **재업로드 가능 시각 = 삭제 접수 +3시간** (todo에 명시).
   - 확인 질문 없이 바로 등록.

todo 예시:
```
- [ ] 1-3 물갈이 재업로드 (해당 마켓그룹 필터 + 미업로드 필터 → 전체 업로드)
  - added: <삭제일시>
  - 삭제 접수: <삭제일시>
  - 재업로드 가능: <삭제일시 +3시간>
  - priority: high
```

## 마켓그룹 지칭 규칙 (안내 문구에 그룹명 붙일 때)

용팀장님은 마켓을 "15-2" 또는 "15-2사업자"처럼 부른다. 그룹명 `{앞번호}번_용쌤{마켓번호}`에서 **용쌤 뒤 마켓번호**를 뜻함(15-2 → `15번_용쌤15-2`, 1-3 → `1번_용쌤1-3`).
- ⚠️ 앞번호는 1~20 후 순환해 충돌(`1번_용쌤21-1` 등). **반드시 "용쌤{번호}" 뒤 번호로 매칭**(전체 유일).
- 용쌤 외(엔잡곰·열·송·엽·타임제로 등)는 이 규칙 무관.
- 그룹명 확인이 꼭 필요할 때만 `bulsaja_market_groups` 조회 가능(안내 목적). 삭제 실행은 여전히 금지.

## 참고

- **스마트스토어 고정.** 용팀장님이 말하는 "마켓"은 항상 스마트스토어.
- 불사자 수집본은 삭제해도 보존됨(재업로드 소스) → 물갈이는 되돌릴 수 있는 작업.
- 셀러에게 표시할 땐 100% 한국어, 내부 ID·코드·필드명 노출 금지.
- 재업로드(2단계)는 `bulsaja-mulgari-upload`, 완료 후 +20일 삭제 todo로 사이클 반복.
- 관련 장기기억: mulgari-manual-cycle(현행), mulgari-delete-workflow(폐기·참고용), market-channel-smartstore-only.
