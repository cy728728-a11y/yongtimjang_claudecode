# payroll-tax-filing (원천세 신고)

직원 급여에 대한 매월 3.3% 원천세 신고를 반자동으로 진행하는 스킬.
**할 수 있는 것**: 엑셀 파싱·검산, 화면별 입력값 산출, 근거자료 생성, 단계별 가이드.
**할 수 없는 것**: 홈택스/위택스 로그인·최종 제출·납부·PDF 다운로드 클릭 → 이건 용팀장님이 직접(인증서·보안 때문). 스킬은 값 채워서 화면마다 안내하고, 용팀장님이 클릭·엔터하면 다음 단계로 진행.

## 고정 정보 (매번 묻지 않는다)

| 항목 | 값 |
|------|-----|
| 신고 사업자번호 | **692-51-00285** (와이제이 컴퍼니 / YJ COMPANY) |
| 홈택스 로그인 | 최용 — 공동/금융인증서 (용팀장님이 직접) |
| 대상 직원 | 최소영(740828-2018817), 조미미(860112-2187112) |
| 소득 구분 | 사업소득 3.3% |

※ 홈택스 로그인 계정에 사업자가 2개(185-95-00379 / 692-51-00285) 뜬다.
   **원천세 신고는 692-51-00285 로 한다.** (2026-08-09 용팀장님 확인)

## 절대 규칙

- 스킬은 **제출·납부 버튼을 대신 누르지 않는다.** 값 제시 + 안내만.
- 검산 경고(flags)가 있으면 **멈추고** 용팀장님께 알린 뒤 진행 여부 확인.
- 화면 안내는 노션 고정 순서 기준. "화면이 다르다"고 하면 그 지점에서 맞춰 조정.

## 진행 순서

### 1. 엑셀 경로 확보
- 사용자 메시지에 `.xlsx` 경로/첨부가 있으면 그걸 쓴다.
- **없으면 묻지 않는다.** 인자 없이 실행하면 기본 폴더의 최신 `.xlsx`를 자동 선택한다.
- 기본 위치: `…\구매대행\소영님미미님근로사업소득원천세신고\원천세신고관련\소득신고자료엑셀\`
  (파일명 관례: `YYYYMMDD신고.xlsx` — 날짜는 **신고기한**, 즉 지급 다음달 10일)
- 엑셀이 열려 있어 잠겨 있어도 엔진이 임시 복사본으로 우회하므로 "엑셀 닫으세요" 라고 하지 않는다.

### 2. 엔진 실행 (파싱·검산·근거생성)
```bash
cd "C:/Users/workspace/.claude/skills/payroll-tax-filing"
python generate_filing.py            # 최신 파일 자동 선택
python generate_filing.py "<엑셀 절대경로>"   # 특정 파일 지정
```
- stdout JSON을 파싱. `flags`, `people`, 합계, `deadline`, `out_dir` 확인.
- 이 실행만으로 근거자료 2종이 `out_dir`(=`지급명세서\N월지급분\`)에 저장됨:
  - `신고진행시트_YYYY-MM.md`
  - `근거_원천세신고_YYYY-MM.html` (인쇄용 → 용팀장님이 PDF로 출력)

### 3. 요약 보고
JSON을 근거로 이렇게 보고:
- **읽은 파일명**(`excel`) — 자동선택이 엉뚱한 달을 잡았는지 용팀장님이 바로 알아채도록 항상 표기
- 귀속/지급연월, **신고기한**, 대상 인원
- **① 홈택스**: 인원 / 총지급액 / 소득세(=`total_income_tax`)
- **② 위택스**: 지방소득세(=`total_local_tax`)
- **③ 간이지급명세서**: 인별 표 (이름/주민번호/귀속연월/지급연월/지급총액)
- `flags`가 있으면 ⚠️로 먼저 알리고 **여기서 멈춤**. 없으면 "검산 통과".

### 4. 가이드 진행 여부 확인
"지금 신고 시작할까요? (홈택스 띄우고 단계별로 진행)" 라고 물어본다.
- "시작" / "진행" / "응" 이면 5단계로. 아니면 여기서 종료(시트·근거는 이미 저장됨).

중간 메뉴 클릭·필드 입력·팝업 확인은 전부 자동으로 처리한다. (2026-08-09 확립)

#### 팝업 처리 규칙 (여기서 많이 막혔다)

- 확인 버튼은 `value='확인'` 이 아닐 수 있다. **`id` 에 `btn_confirm` 이 들어간 input 을 누른다** (`예`/`확인` 공용). 취소는 `btn_cancel`.
- **`value='확인'` 을 무차별로 누르지 말 것.** 사업자번호 조회 버튼(`btn_txprNo`)도 value 가 `확인` 이라, 빈 값으로 눌러 "사업자(주민)등록번호가 올바르지 않습니다" 오류를 부른다.
- 누르기 전에 팝업 **본문을 먼저 읽어** 보고한다(`class` 에 `w2window` 포함 레이어).
- Claude 는 화면을 상시 감시하지 않는다 — 스크립트를 돌리는 순간에만 본다. 용팀장님이 "팝업 떴다" 하면 그때 처리한다.
- 공용 헬퍼(attach/accept/popup_text/screen)를 매번 새로 짜지 말고 `scripts/htlib.py` 를 쓴다.

   3) 제출구분 = `정기신고`, `attrYr`/`pymnMm` = 귀속연도 / **지급월**
2. **[상세내역 작성하기]** `btnDpclWrt` → `지급명세서작성방법선택` 팝업.
   ⚠️ **`신규작성` 을 고른다.** `미리채움(전월자료 불러오기)` 은 전월 2건이 `미확인` 상태로 목록에
   남아, 새로 입력한 행과 합쳐져 **총 4건**이 되고 제출이 막힌다.
   (이미 미리채움을 골랐다면: 미확인 행 체크 → **`btnDelete`(선택자료 목록제외)** 로 제거.
    이 버튼은 헤더에 가리므로 `scrollIntoView({block:'center'})` 후 네이티브 클릭.)
3. **인별 입력** (id 접두사 `mf_txppWframe_wfDetailBrkd_`):
   | 항목 | 요소 |
   |---|---|
   | 주민번호 | `edtIeNo1` → `btnIeNoChk`(확인) |
   | 성명 | `edtIeNm` |
   | 업종 | `btnBsicTfbCd`(검색) → 레이어에서 **940600 자문/고문** 행의 [선택] |
   | 귀속연월 | `attrYr_A0162` / `cmbAttrMm` ← **엑셀의 귀속월**(지급월−1) |
   | 지급액·세율 | `edtTotaPymnAmt` / `edtTxrte`(3 고정) |
   | 소득세·지방세 | `edtIncTxamt` / `edtLinTxamt` → `edtTotTxamt`(계) 자동계산 |
   - 한 명 끝나면 **`btnAddRow`(등록하기)**. 폼이 초기화되므로 **업종도 다시 선택**해야 한다.
4. 전원 등록 후 목록이 **정확히 {count}건 / 총 {total_gross}원** 인지 확인 → `btnGoSbms`(제출하러 가기).
5. 제출 화면에서 **`label[for=mf_txppWframe_chkConfirm_input_0]`**("위 내용을 확인하고 제출합니다")
   체크 → **`btnSbms`(제출하기)**. 체크 없이 누르면 alert 로 막힌다.
6. **[제출내역 조회]** 탭 → 제출연월 이번달 → 조회 → 행의 **[접수증]** 및 팝업의
   **[정상(제출)자료조회]** 를 각각 캡처해 `{out_dir}` 에 저장:
   `간이지급명세서_접수증_{paid_ym}.png` / `간이지급명세서_상세내역_{paid_ym}.png`
