# payroll-tax-filing (원천세 신고)

직원 급여에 대한 매월 3.3% 원천세 신고를 반자동으로 진행하는 스킬.
**할 수 있는 것**: 엑셀 파싱·검산, 화면별 입력값 산출, 근거자료 생성, 단계별 가이드.
**할 수 없는 것**: 홈택스/위택스 로그인·최종 제출·납부·PDF 다운로드 클릭 → 이건 용팀장님이 직접(인증서·보안 때문). 스킬은 값 채워서 화면마다 안내하고, 용팀장님이 클릭·엔터하면 다음 단계로 진행.

## 절대 규칙

- 스킬은 **제출·납부 버튼을 대신 누르지 않는다.** 값 제시 + 안내만.
- 검산 경고(flags)가 있으면 **멈추고** 용팀장님께 알린 뒤 진행 여부 확인.
- 화면 안내는 노션 고정 순서 기준. "화면이 다르다"고 하면 그 지점에서 맞춰 조정.

## 진행 순서

### 1. 엑셀 경로 확보
- 사용자 메시지에 `.xlsx` 경로가 있으면 사용. 없으면 경로를 물어본다.
- 기본 위치: `…\구매대행\근로사업소득원천세신고\원천세신고관련\소득신고자료엑셀\`

### 2. 엔진 실행 (파싱·검산·근거생성)
```bash
cd "C:/Users/workspace/.claude/skills/payroll-tax-filing"
python generate_filing.py "<엑셀 절대경로>"
```
- stdout JSON을 파싱. `flags`, `people`, 합계, `deadline`, `out_dir` 확인.
- 이 실행만으로 근거자료 2종이 `out_dir`(=`지급명세서\N월지급분\`)에 저장됨:
  - `신고진행시트_YYYY-MM.md`
  - `근거_원천세신고_YYYY-MM.html` (인쇄용 → 용팀장님이 PDF로 출력)

### 3. 요약 보고
JSON을 근거로 이렇게 보고:
- 귀속/지급연월, **신고기한**, 대상 인원
- **① 홈택스**: 인원 / 총지급액 / 소득세(=`total_income_tax`)
- **② 위택스**: 지방소득세(=`total_local_tax`)
- **③ 간이지급명세서**: 인별 표 (이름/주민번호/귀속연월/지급연월/지급총액)
- `flags`가 있으면 ⚠️로 먼저 알리고 **여기서 멈춤**. 없으면 "검산 통과".

### 4. 가이드 진행 여부 확인
"지금 신고 시작할까요? (홈택스 띄우고 단계별로 진행)" 라고 물어본다.
- "시작" / "진행" / "응" 이면 5단계로. 아니면 여기서 종료(시트·근거는 이미 저장됨).

### 5. 가이드 진행 모드 (막히면 멈추고 대기)

각 단계에서 **넣을 값을 제시 → 용팀장님이 입력·클릭 → "다음"/"엔터" 하면 다음 단계.**
막히면 그 단계에서 멈추고 도와준다.

**[A] 홈택스 — 사업소득 원천세 신고**
1. 홈택스 열기:
   ```bash
   powershell -Command "Start-Process 'https://www.hometax.go.kr'"
   ```
   → "로그인(공동/금융인증서) 하고 **엔터** 치세요."
2. 세금신고 → 원천세 신고 → 정기신고 이동 안내.
3. 사업자번호 옆 **확인** 클릭 → 사업자정보 자동입력 확인. (연말정산 포함이면 `여` 체크)
4. 원천징수 내역 입력:
   - 인원: **{count}명**
   - 총지급액: **{total_gross}원**
   - 소득세: **{total_income_tax}원**  ← 소득세만 입력, 지방세는 여기서 X
   - 환급 관련 미기입 → **저장 후 다음이동**
5. 신고서 제출 → **소득세 납부**.
6. 지급명세서 **PDF 다운로드** → `지급명세서\{N}월지급분\` 폴더에 저장 안내.
7. "소득세 3% 완료. 지방세 팝업 뜨면 확인/닫기 하고 **엔터**."

**[B] 위택스 — 지방소득세 신고·납부**
- 홈택스에서 "납부할 세액이 있는 경우" 팝업 → 이미 소득세 냈으므로 무시하고 **확인** → 위택스 자동 이동.
  (자동 이동이 안 되면: `powershell -Command "Start-Process 'https://www.wetax.go.kr'"`)
- 사업자번호 입력 → 확인 → 휴대폰번호 입력 → 다음·다음·다음 → **제출**
- 지방소득세 **{total_local_tax}원** 납부.
- 납부 → 납부결과 → 지방세 납부내역 → 전자납부번호 클릭 → **영수증 출력**(즉시), 납부확인서는 20분 후.
- 영수증 PDF도 `지급명세서\{N}월지급분\`에 저장 안내.

**[C] 간이지급명세서(사업소득) — 월말까지**
- 홈택스 → 간이지급명세서(사업소득) 제출.
- 귀속연월 **{accrual_ym}**(일한 달) / 지급연월 **{paid_ym}**(지급한 달).
- 상세내역 작성하기 → 인별로 입력 후 등록 (인적사항: 사업소득):
  {people 표: 이름 / 주민번호 / 지급총액}
- 전원 입력 후 **제출** → 접수증 PDF를 같은 폴더에 저장 안내.

### 6. 마무리 보고
- 완료 단계 체크리스트로 보고.
- 근거자료 폴더(`out_dir`) 경로 안내: 신고진행시트·근거HTML + 용팀장님이 받은 PDF들.

## 참고
- 소득세·지방세 모두 **10원 미만 절사**. 엔진이 엑셀값을 검산해 불일치 시 flag.
- 근거자료 루트는 엔진의 `DEFAULT_BASE` 상수. 위치 바뀌면 `--base`로 넘김.
