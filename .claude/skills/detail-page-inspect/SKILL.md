# 상세페이지 검수 (읽기 전용)

상세페이지 이미지 폴더 하나를 받아 **모든 이미지를 한 장씩 직접 보고** 8가지 항목을
점검한 뒤 표로 정리한다.

## 절대 규칙

- **고치지 않는다.** 이미지 수정·삭제·이름 변경·불사자 반영 모두 금지. 검수 폴더에는
  결과 문서(`검수결과_YYYYMMDD.md`) 하나만 새로 쓴다.
- **의심만 표시한다.** 확정 판단(위법이다/불가하다)은 하지 않는다. "의심"과 이유만 적는다.
- **전부 본다.** 장수가 많아도 건너뛰지 않는다. 긴 이미지는 조각을 전부 읽는다.
  일부만 봤으면 표에 "미확인"으로 남긴다 — 안 본 걸 "이상 없음"으로 적지 않는다.

## 입력

1. **검수할 상세 폴더 경로** (필수). 폴더 바로 아래 이미지만 대상
   (`originals/`, `_apply/` 같은 하위 폴더는 보지 않음).
2. **상품명·옵션** (7번 항목용, 선택). 찾는 순서:
   1. 사용자가 말해 준 상품명·옵션
   2. 폴더 안 `product.json` / `meta.json` / `info.json` / `상품정보.txt`
   3. 사용자가 판매자상품코드를 줬으면 불사자에서 **조회만** (`bulsaja_product_find_by_code`
      → `bulsaja_product_detail`) — 쓰기 도구는 쓰지 않는다
   4. 그래도 없으면 묻지 않고 진행하고, 7번 칸은 "대조 불가(상품명·옵션 없음)"로 적는다.
      단, 상세 안에서 서로 다른 장끼리 모순(1장은 3단, 5장은 2단 등)은 그대로 점검한다.

## 절차

### 1단계 — 준비 (스크립트)

```bash
python -X utf8 "<워크스페이스>/.claude/skills/detail-page-inspect/scripts/prep.py" "<검수 폴더>"
```

- 이미지를 파일명 숫자 순서로 정렬하고, 세로로 긴 이미지는 가로 860 기준 1400px씩
  (120px 겹치게) 잘라 **임시 폴더**에 저장한다. 검수 폴더는 건드리지 않는다.
- 출력 JSON의 `pages[].read` 목록이 실제로 읽을 파일들이다. `info_files`가 있으면 먼저 읽는다.
- `error`가 있는 장은 표에 "열기 실패"로 적는다.

### 2단계 — 한 장씩 보기 (Claude가 직접 Read)

`pages` 순서대로 `read`의 파일을 **전부** Read 도구로 연다. 장마다 보이는 글자를
최대한 그대로 옮겨 적고(작은 글씨·워터마크·모서리 로고 포함), 아래 8개 항목을 점검한다.
20장 넘으면 10장 단위로 끊어 중간 메모를 남기며 진행한다(앞 장 내용을 잊지 않게).

### 3단계 — 8개 항목 기준

| # | 항목 | 의심으로 표시하는 경우 | 예시 |
|---|------|----------------------|------|
| 1 | 중국어·외국어 잔존 | 한자(간체·번체), 일본어, 번역 안 된 영어 문장이 이미지 안에 남음. 제품 본체에 인쇄된 각인·로고는 "제품 인쇄"로 따로 구분해 적음 | 加厚, 包邮, 产品参数, 尺寸 |
| 2 | 과장 문구 | 최상급·단정 표현, 근거 없는 1위·판매량·만족도 수치 | 최고, 최초, 1위, 유일, 완벽, 100% 만족, 누적 10만개, 평생 사용 |
| 3 | 효능 문구 | 일반 공산품이 질병 예방·치료·인체 효능을 말함 (의약품·건강기능식품 오인) | 항균 99.9%, 살균, 혈액순환, 통증 완화, 피로회복, 면역, 다이어트, 숙면, 피부 재생, 탈모 |
| 4 | 중국 쇼핑몰 흔적 | 타오바오·티몰·1688·징동 로고·매장명·워터마크, 중국 쇼핑몰 화면 캡처, 위안(¥/元) 가격, 중국식 배송·AS 안내, QR코드, 중국 전화번호·위챗 | 淘宝, 天猫, 店铺, 旗舰店, 客服, 7天无理由 |
| 5 | 남의 브랜드·캐릭터 | 타사 브랜드명·로고, 유명 제품명 비교·언급, 디즈니·산리오·포켓몬 등 캐릭터, 연예인·유명인 사진 | "다이슨 스타일", 곰돌이 푸 프린트 |
| 6 | 근거 없는 인증마크 | KC·CE·FDA·ISO·SGS·특허·KS·친환경·식품용 마크 등을 인증번호·근거 없이 표시 | 인증번호 없는 KC 마크, "FDA 승인" |
| 7 | 상품명·옵션과 다른 내용 | 상세 속 제품이 상품명과 다른 물건, 옵션에 없는 색상·사이즈·구성, 구성품 수량 불일치, 장끼리 서로 모순 | 옵션은 3색인데 상세엔 5색, 상품명 "2단"인데 상세 "3단" |
| 8 | 사이즈·소재 표기 | 사이즈 또는 소재 표기가 **아예 없음**, 단위 누락(숫자만), 장끼리 숫자가 다름, 중국어로만 표기 | 사이즈표가 중국어, 1장 30cm / 6장 35cm |

판정 기호: `✅` 이상 없음 · `⚠️` 의심 · `—` 해당 없음(그 장에 글자 없음 등) · `?` 미확인/열기 실패
8번은 **상세 전체 기준**으로도 따로 판정한다(어느 장에도 사이즈/소재가 없으면 전체 ⚠️).

### 4단계 — 결과 정리

검수 폴더에 `검수결과_YYYYMMDD.md`로 저장하고, 같은 내용을 대화에도 보여준다.

```markdown
# 상세페이지 검수 결과
- 폴더: <경로> · 이미지 N장 · 검수일 YYYY-MM-DD
- 상품명·옵션 대조: <사용한 출처 또는 "대조 불가">
- 요약: 의심 N건 (항목별 개수)

## 1. 장별 점검표
| 장 | 파일 | ①외국어 | ②과장 | ③효능 | ④중국몰 | ⑤타브랜드 | ⑥인증 | ⑦상품불일치 | ⑧사이즈·소재 |
|----|------|--------|-------|-------|--------|----------|------|-----------|-----------|
| 1 | 01.jpg | ✅ | ⚠️ | ✅ | ✅ | ✅ | ✅ | ✅ | — |

## 2. 의심 상세
| 장 | 항목 | 위치 | 문구·내용 (보이는 그대로) | 왜 의심인지 |
|----|------|------|----------------------|-----------|
| 1 | ②과장 | 상단 제목 | "국내 판매 1위" | 근거 없는 순위 표현 |

## 3. 사이즈·소재 (상세 전체)
- 사이즈: <찾은 표기 / 없음> (몇 장)
- 소재: <찾은 표기 / 없음> (몇 장)
- 판정: ✅ / ⚠️ 이유

## 4. 미확인
- (열기 실패·글씨가 너무 작아 못 읽은 부분 등. 없으면 "없음")
```

대화에서는 결론 먼저: "의심 N건 — 가장 큰 건 OO" 한 줄 → 표. 고칠 방법은 묻지 않으면 제안하지 않는다.

## 주의

- 글씨가 흐려 확신이 없으면 추측해서 ✅ 주지 말고 `?`와 함께 "4. 미확인"에 적는다.
- 같은 문구가 여러 장에 반복되면 처음 나온 장에 적고 "(3·7장에도 반복)"을 붙인다.
- 검수 결과 문서 외에는 아무 파일도 만들거나 바꾸지 않는다(임시 조각은 시스템 임시 폴더).
