# 전자세금계산서 발급 (폰 손택스 자동조작)

공동인증서 없이, 폰 손택스의 지문 로그인·지문 발급을 이용한다. 노트북이 USB로 폰 화면을 찍어 보고(캡처) 눌러서(탭) 진행한다.
첫 성공: 2026-11-16 와이제이 컴퍼니 → 주식회사 아이팩 1,020,000원.

## 0단계 — 시작하자마자 필요한 정보 안내 (생략 금지)

**가장 먼저 `거래처.md`(거래처별 카드)와 `발급이력.md`(건별 기록)를 읽는다.** 사용자가 부르는 이름은 `거래처.md` 맨 위 '빠른 찾기'에서 찾는다.
- 카드가 있는 거래처면: 품목명·금액 방식(부가세 포함 여부)·결제정보·수신메일을 카드대로 채우고 **묻지 않는다.** 이번에 새로 받은 것(수량·금액·날짜)만 확인한다.
- 복사발급 조회기간은 `발급이력.md`의 그 거래처 마지막 발급일을 포함하는 2개월로 바로 잡는다(헤매지 않기).

사용자가 "세금계산서 끊어줘"라고 하면, **작업 전에 아래 체크리스트를 보여 주고** 이미 받은 정보는 ✅, 빠진 것만 묻는다.
`거래처.md`에 있는 거래처면 카드 값으로 미리 채워서 보여 준다. 카톡·문자에서 찾을 수 있는 건 직접 찾는다(kakao-read 스킬, 폰 문자 조회).

```
세금계산서 발급에 필요한 정보
[필수]
 1. 거래처(받는 곳)      예) 주식회사 아이팩  ← 처음 거래면 사업자번호도
 2. 품목·규격·수량·단가  예) 에어보조탱크 1L × 16개 × 40,000원
 3. 단가에 부가세 포함?   포함 / 별도   (기본: 포함)
 4. 작성일자             기본: 오늘
[기본값 있음 — 다르면 말해 줘]
 5. 우리 사업자          기본: 와이제이 컴퍼니(692-51-00285)
 6. 결제 구분            기본: 대장 관례 (없으면 현금·청구)
[네가 해 줄 것]
 7. 폰 USB 연결 + 손택스 로그인(생년월일·지문)
```

- 정보가 다 모이면 **금액 계산표**(품목별 공급가액·세액·합계)를 보여 주고 바로 진행한다. 발급 승인은 사용자가 이미 "끊어줘"라고 했으면 따로 묻지 않는다.
- 처음 거래하는 곳(복사할 지난 내역 없음)은 한글 입력이 안 되므로 **거래처 상호·품목명 한글은 사용자가 폰에서 직접 입력**해야 한다고 미리 알린다.

### 금액 계산 규칙
- 부가세 포함 단가면: 품목 합계(수량×단가) ÷ 1.1 → 공급가액(반올림), 세액 = 품목 합계 − 공급가액.
- 단가 칸에는 받은 단가(부가세 포함 단가)를 그대로 두고, 공급가액·세액은 직접 입력한다(2025-09 아이팩 발급 때부터 이 방식). **'계산하기' 버튼은 누르지 않는다** — 누르면 단가×수량을 공급가액으로 다시 잡아 부가세가 이중으로 붙는다.
- 마지막에 합계가 수량×단가 총액과 정확히 같은지 확인.
- **단가 칸을 바꾸면 앱이 공급가액=단가, 세액=10%로 자동으로 다시 채운다**(11/20 긱워커스). 그래서 순서는 단가 → 공급가액 → 세액, 마지막에 '합계구분' 값을 캡처로 확인.

## 1단계 — 연결 확인

```bash
P=".claude/skills/tax-invoice-issue/scripts/phone.sh"
bash $P check          # "device" 로 떠야 함
```
- 목록이 비면 아래 **USB 디버깅 켜기 절차**를 그대로 안내한다(용팀장은 비개발자 — 메뉴 이름 그대로, 한 줄씩).
- `unauthorized`: 폰 화면의 "USB 디버깅 허용"에서 '항상 허용' 체크 후 허용 안내.
- 안내 후 사용자가 "됐어" 하면 `check` 를 다시 돌려 `device` 확인 후 진행.

### USB 디버깅 켜기 절차 (갤럭시 기준, 사용자 안내용)

```
[1] 개발자 옵션 켜기 (처음 한 번만)
  설정 → 휴대전화 정보 → 소프트웨어 정보 → '빌드번호'를 7번 연속 톡톡
  → 잠금 비밀번호 입력 → "개발자 모드를 켰습니다" 뜨면 완료

[2] USB 디버깅 켜기
  설정 맨 아래 '개발자 옵션' → 맨 위 스위치 켜짐 확인
  → 조금 내려서 'USB 디버깅' 켜기 → 확인

[3] 선 연결
  데이터 되는 선으로 노트북에 꽂기 (충전 전용 선은 안 잡힘)
  → 폰 알림창 내려서 USB 항목이 '충전만'이면 '파일 전송'으로 변경

[4] 허용
  폰에 "USB 디버깅을 허용하시겠습니까?" 창 → '이 컴퓨터에서 항상 허용' 체크 → 허용
  창이 안 뜨면: 개발자 옵션 → 'USB 디버깅 권한 승인 취소' 누르고 선 다시 꽂기
```

- 그래도 안 잡히면: 다른 USB 구멍에 꽂기 → 폰 재부팅 → `check` 다시.
- 개발자 옵션이 다시 꺼져 있는 경우가 있다(업데이트·재부팅 후). [1]부터 다시 안내.
- adb가 없으면: scrcpy 압축본(github Genymobile/scrcpy 릴리스 win64 zip)을 `~/tools/`에 풀기. winget 설치는 권한 오류로 실패했었다.

## 2단계 — 조작 원칙 (사고 방지)

- **누르기 전에 반드시 캡처해서 지금 화면을 확인한다.** 사용자가 폰을 쓰는 중이면 다른 앱이 앞에 있다(11/16 캘린더 설정 화면을 잘못 누른 사고).
- 캡처 이미지는 923×2000으로 줄여 보이므로, 탭 좌표 = 보이는 좌표 × 1.17 (원본 1080×2340).
- 사용자가 "멈춰"라고 하면 즉시 멈추고 현재 화면 상태만 보고한다.
- 숫자 입력: 칸 탭 → `clear` → `text 숫자` → `back`(키보드 닫기). 그다음 캡처로 값 확인.
- 한글 입력 불가. 한글은 복사발급으로 가져오거나 사용자에게 부탁.

## 3단계 — 손택스 발급 절차

1. `bash $P app hometax` → 캡처.
2. **로그인**: 로그인 화면이면 사용자에게 "생년월일 넣고 지문 찍어 줘" 요청 후 대기(개인정보라 Claude가 넣지 않음).
3. **사업자 전환**: 전체메뉴(우상단 ≡, 약 984,164) → 상단 '사업자전환' → 목록에서 해당 사업자 '전환하기' → 확인.
   - 상단 인사말이 "와이제이 컴퍼니(YJ COMPANY)님"으로 바뀌었는지 확인. 개인 상태면 발급 메뉴가 "사업자 전환 이용 후 가능합니다"로 막힌다.
4. **복사발급**: 전체메뉴 → 전자(세금)계산서·현금영수증·신용카드 → 전자(세금)계산서 발급 펼치기 → **전자(세금)계산서 복사발급**.
   - 조회기간은 **최대 2개월**. `거래처.md`의 '지난 발급일'을 포함하는 2개월로 시작일·종료일을 달력에서 지정(◀/▶로 월 이동) → 조회.
   - 목록에서 해당 거래처 행의 동그라미 선택 → 맨 아래 '세금계산서작성'.
5. **품목(3단계 화면)**: '합계정보 수정' 또는 '품목명 수정'으로 진입.
   - 맨 위 작성일자: 달력 아이콘으로 날짜 선택.
   - 품목마다: 작성일자 '일' 칸, 수량, (필요하면 단가), 공급가액, 세액 입력. 규격은 영문·숫자라 입력 가능(예: 1L, 20L).
   - 품목이 지난번보다 많으면 '품목추가'(최대 4개), 적으면 '삭제'.
   - 아래 '합계구분'에서 공급가액·세액·합계금액이 계산표와 같은지 확인 → '저장' → "발급정보로 이동" 확인.
6. **결제정보**: 결제정보 '수정' → 청구/영수 선택, 현금 등 칸에 금액 → 저장 → 확인.
7. **미리보기**: 맨 아래 '발급 미리보기' → 끝까지 내려서 공급자·공급받는자·수신메일·품목·금액·청구/영수 전부 확인.
8. **발급**: '발급하기' → 확인 팝업(작성일자·공급가액·세액) → 확인 → '발급인증유형 선택'에서 **지문인증** 탭 → 사용자 지문.
9. 성공 팝업의 **승인번호**를 캡처로 남기고 확인.

## 4단계 — 마무리

- 사용자에게 보고: 승인번호, 거래처, 품목 표, 합계, 결제 구분, 수신메일.
- **기록은 생략 금지 — 승인번호를 받았으면 보고하기 전에 두 파일을 먼저 쓴다.**
  1. `발급이력.md` 맨 아래에 한 줄 추가: 작성일자·거래처·품목(규격×수량×단가)·공급가액·세액·합계·결제·승인번호·근거(무엇을 보고 끊었는지).
  2. `거래처.md`: '빠른 찾기' 표의 마지막 발급일 갱신. 카드 내용(품목명·금액 방식·결제·메일·담당자)이 이번에 달라졌으면 카드 수정.
     새 거래처면 '빠른 찾기'에 줄 추가 + 카드 새로 만들기(사용자가 부르는 이름, 무엇에 대한 계산서인지, 금액 방식까지).
  3. 복사발급 조회 중에 대장에 없던 과거 발급 건을 봤으면 `발급이력.md`에도 채워 넣는다("홈택스 조회로 확인").
- 원하면 거래처 카톡방에 "세금계산서 발행했습니다" 안내 문구 초안 제시(전송은 사용자가).
