# 한국식품산업협회 온라인 위생교육 신청 (연 1회, 본인+사모님)

## Overview

한국식품산업협회가 매년 우편으로 "기존영업자 온라인교육 안내"를 보낸다. **매년 회원가입을
새로 해야 하는 구조**이므로(전년도 계정 재사용 불가), 매년: ① 회원가입 → ② 로그인 →
③ 온라인 교육신청(업소코드·사업자등록번호 확인) → ④ 결제 → ⑤ 수강 → ⑥ 수료증 출력
순서를 **용팀장님 계정, 사모님 계정 각각** 반복한다.

사이트: https://www.kfia21.or.kr
문의: 1577-3869 (교육 일반) / 02-3460-8507 (기술문의, 평일 9~18시)

## 요청 문구별 실행 범위 (2026-08-11 확정)

용팀장님이 아래 두 문구를 구분해서 쓴다. **말 그대로 그 범위까지만** 하고 멈춘다.

- **"교육신청한다"** (신청/등록 의도) → 아래 "Claude의 역할과 한계"에 나온 전체 절차
  (로그인 → 업소코드번호 검색 → 사업자등록번호 확인 → "교육신청" 버튼 클릭까지) 수행.
- **"교육 들어야 된다"** (수강/시청 의도) → **로그인까지만** 하고 멈춘다. "나의 학습방"
  이동, 강의 재생 등은 하지 않고 "로그인해놨으니 들어가서 수강하시면 됩니다"라고 안내한다.
  (수강 자체는 동영상 재생·진도 체크 등 용팀장님이 직접 화면 보면서 해야 하는 일이라
  Claude가 대신 진행하지 않음.)

## Claude의 역할과 한계 (중요, 2026-08-11 용팀장님 확정)

**Claude가 하는 부분**: 로그인 → 기존 영업자 온라인 교육신청 페이지 이동 → 업소코드번호
검색 → 사업자등록번호 입력 → "확인"(국세청 조회) → 통과하면 버튼이 "교육신청"으로 바뀜 →
**"교육신청" 버튼 클릭까지.**

**여기서부터는 반드시 용팀장님이 직접**:
- "교육신청" 클릭 시 뜨는 **브라우저 네이티브 confirm() 팝업**("총 N건 수강신청합니다" /
  확인·취소) — 이건 페이지 요소가 아니라 브라우저 자체 팝업이라 Claude가 클릭하면 탭이
  멈춰버림(스크린샷·조작 전부 타임아웃). **반드시 용팀장님이 직접 확인 클릭.**
- 이후 뜨는 **결제 페이지**에서 결제수단 선택 + 결제 확정 — 금전 거래라 Claude가 대신 안 함
- 신규 계정 만들 때는 추가로: **본인확인(휴대폰인증)** SMS 인증번호 입력, **"회원가입 완료"
  버튼 클릭**도 용팀장님 몫

그 외 텍스트 필드 입력(아이디/비밀번호/이메일/업소코드번호/사업자등록번호 등)은
용팀장님이 값을 불러주면 Claude가 폼에 채워 넣는다.

로그인 세션은 다음날/다른 세션에서 유지 안 됨(로그아웃 상태로 재접속됨) — 매번 재로그인 필요.

## 진행 절차

### 1. 회원가입 (매년 새로 필요)
1. `https://www.kfia21.or.kr/Member.cmd?cmd=newMemberJoin` 접속
2. 이용약관 + 개인정보 수집 "전체동의" 체크 → 동의
3. "가입 시 주의사항" 모달 확인 (회원정보는 **실제 교육받을 사람 본인** 정보로, 가입 후 수정 불가)
4. 본인확인(휴대폰인증) — **용팀장님이 직접 진행** (SMS 인증번호 입력)
5. 인증 완료 후 자동 채워지는 이름/생년월일/성별 확인, 나머지 필드(아이디/비밀번호/직책/업체전화번호/이메일) 입력
   - 직책(자격): 대표자 or 식품위생관리책임자 — 실제 이수증 인정 대상에 맞게 확인 후 선택
6. "회원가입 완료" 버튼 — **용팀장님이 직접 클릭**

### 2. 로그인 → 온라인 교육신청
1. 로그인 (방금 만든 계정)
2. 상단 메뉴 "기존 영업자" → "기존 영업자 온라인 교육신청" (`OnlineEdu.cmd?cmd=onlineMain&Menu=1`)
3. 업소코드번호 입력 → 검색 (교육 통지서에 명시된 번호)
   - ⚠️ "업소코드번호를 모르시는 경우 → 업소 코드번호 검색" 버튼은 Claude가 제어하는 탭
     밖에서 별도 팝업창을 여는 방식이라 Claude가 결과를 볼 수 없음(2026-08-11 확인,
     `ComTypeCodeSearch()` → `showPopupBox()`가 새 창을 띄움). 업소코드번호는 **용팀장님이
     교육통지서를 보고 직접 불러주는 방식**을 기본으로 한다.
4. 조회된 업체명/대표자명/영업의 종류/업체주소 확인
5. 교육과정 체크박스 자동 선택됨 확인
6. **사업자등록번호** 입력(3-2-5자리) → "확인" 클릭
   - ⚠️ 국세청 사업자상태 조회(odcloud.kr) 연동인데, **새벽 시간대 등에 `API 서버 오류가
     발생하였습니다`(code -5) 오류가 반복될 수 있음**(2026-08-11 새벽 확인, 같은 날 낮에는
     정상). 콘솔에 같은 오류가 계속 뜨면 재시도보다 **평일 업무시간대(오전 9시 이후)** 재시도
     권장.
   - 확인 성공 시 버튼 문구가 "확인" → **"교육신청"**으로 바뀜 (통과 신호)
7. Claude가 "교육신청" 버튼 클릭 → **브라우저 네이티브 confirm() 팝업**("총 N건
   수강신청합니다") 뜸 → **용팀장님이 직접 확인 클릭** (Claude가 누르면 탭이 멈춤)
8. 결제 페이지 도착 → 결제수단(무통장입금/신용카드/실시간계좌이체/휴대폰결제) 선택 →
   **용팀장님이 직접 결제 확정**

### 3. 수강 → 수료증
- "나의 학습방"에서 수강, 완료 후 "수료증 출력"에서 출력
