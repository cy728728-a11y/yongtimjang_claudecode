# 정인호 고객 구매정산시트 채우기

정인호 고객이 시트를 보고 필요한 상품을 골라 산다. **오래된 상품엔 관심 없는 고객이라 최근 한 달(30일) 안에 올린 상품만** 넣는다.

- 시트: https://docs.google.com/spreadsheets/d/11bk9FvZWtKk8gD-IR7fxZt5IGWryYKBtuy1Cz1RLakQ/edit?gid=1802319683 (`구매정산` 탭)
- 채우는 칸: A 마켓명 · B 상품등록일(`2026-10-13 11:57` 형식) · C 판매자상품코드 · D 상품명. 나머지 칸(검색키워드·구매일자·금액·정산 등)은 고객 몫이라 건드리지 않는다.
- 5행부터 상품이 들어간다(1행 제목, 2~3행 요약).

## 실행 (워크스페이스 루트에서)

```bash
S=.claude/skills/jeonginho-sheet/scripts/jeonginho_sheet.py
.venv/bin/python3 $S add 4-1 5-2        # 기본: 맨 아래에 이어 붙이기 (이미 있는 코드는 건너뜀)
.venv/bin/python3 $S remove 2-3         # 그 마켓 행 통째로 삭제
.venv/bin/python3 $S reset 1-3 2-2      # 5행부터 비우고 새로 쓰기
.venv/bin/python3 $S count 1-1 4-1      # 시트 안 건드리고 최근 한 달 건수만
# 옵션: --days 30  --dry-run
```

## 말 → 명령

| 용팀장 말 | 명령 |
|---|---|
| "4-1 5-2" / "4-1 추가해줘" | `add` |
| "N-N은 빼(삭제)하고 M-M 추가" | `remove N-N` 후 `add M-M` |
| "처음부터 다시 / 덮어서" | `reset` |
| "어느 마켓이 상품 많아?" | `count` (운영 마켓 범위만) |

묻지 말고 바로 실행하고, 끝나면 **마켓별 개수 표 + 들어간 행 범위**로 보고한다. 한 달 등록이 10개 미만인 마켓은 "상품이 적다"고 한 줄 덧붙인다.

## 알아둘 것

- 마켓 번호 → 스토어명은 `~/.eroom/naver-commerce-stores.json` 의 name (= "마켓별 등록수량 현황" 시트와 같은 이름).
- 판매자상품코드는 스스의 판매자관리코드 = 불사자 판매자상품코드.
- 판매금지(PROHIBITION) 상품은 뺀다.
- `remove` 는 행을 지우므로 고객이 그 행에 적어 둔 구매 기록도 같이 사라진다. 고객이 이미 구매·정산을 적기 시작한 뒤라면 지우기 전에 E~N 칸에 내용이 있는지 보고 용팀장에게 알린다.
- 운영 마켓은 `용쌤N-M` 범위만(타임제로·쿠팡 제외).

## 기록

- 2026-11-12 첫 작성: 1-3(950) · 2-2(659) · 3-2(5) = 1,614개, 5~1618행. 2-3은 5개뿐이라 빼고 3-2로 교체.
