# cs-response

고객 CS 상황을 받아 구매대행 특화 답변 문구를 작성하고, 구글시트에 CS 로그를 누적한다.

## 수행 순서

### 1. CS 유형 분류
구매대행 특화 유형 중 해당하는 것으로 분류(복수 가능):
배송지연(해외/현지) · 통관·관부가세 · 오배송·상품상이 · 파손·불량 · 환불·취소 · 교환 · 품절·재고 · 단순문의(사용법/스펙/사이즈) · 기타

### 2. 정보 부족 시 확인
답변에 필요한 핵심 정보(주문번호, 현재 진행상황, 배송사/송장번호, 예상 소요일, 환불 사유 등)가 상황 설명에 없으면 먼저 되묻는다. 이미 충분하면 3번으로 바로 진행.

### 3. 답변 문구 작성
- **정중한 존댓말**(CS 응대 톤). 용팀장님과의 반말 대화 규칙은 Claude와의 대화에만 적용되고, 고객에게 보낼 문구에는 적용하지 않는다.
- 문장 구조: **결론(처리방향) → 이유/근거 → 다음 행동**(고객이 할 일 또는 우리가 할 일).
- 근거 없는 확답·과장 금지 — "무조건", "바로 됩니다" 대신 조건과 변수(통관 심사, 해외 배송사 상황 등)를 명시.
- 구매대행 특성상 해외 배송 리드타임·통관 변수가 있다는 점을 필요할 때 자연스럽게 설명.

### 4. 구글시트 로그 append
- 마스터 시트가 아직 없으면(최초 실행) 생성:
  ```bash
  gws sheets spreadsheets create --json '{"properties":{"title":"CS응대로그"},"sheets":[{"properties":{"title":"로그"}}]}' 2>/dev/null
  ```
  생성된 `spreadsheetId`를 이 파일 하단 "저장 위치"에 즉시 기록해 고정한다(다음 실행부터 재사용, 다시 생성하지 않음).
- 헤더(6열): `작업일 / CS유형 / 상황요약 / 고객원문 / 답변문구 / 비고`
- append:
  ```bash
  gws sheets +append --spreadsheet <CS응대로그 시트ID> \
    --json-values '[["2026-08-18","배송지연","...","...","...",""]]'
  ```

### 5. 보고
완성된 답변 문구를 그대로 붙여넣기 쉬운 형태로 제시하고, 시트 링크를 안내한다.

## 저장 위치 (최초 실행 시 채움)
- **이름**: CS응대로그
- **spreadsheetId**: _(미생성 — 최초 실행 시 자동 생성 후 여기 기록)_
- **URL**: _(자동 생성 후 기록)_
- **탭**: 로그
- **헤더(6열)**: 작업일 / CS유형 / 상황요약 / 고객원문 / 답변문구 / 비고

## gws 사용 주의
- 요청 본문은 `--json`, append는 `--json-values`.
- stderr에 `Using keyring backend: keyring` 경고가 섞여 나오므로 JSON 파싱 시 `2>/dev/null` 권장.
