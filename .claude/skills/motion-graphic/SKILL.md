# 모션그래픽 (Remotion)

AI뚝딱 "GPT 모션그래픽 복붙 프롬프트"(코덱스용)를 클로드코드로 옮긴 스킬. 코덱스와 같은 Remotion을 쓰고, 프롬프트 원칙도 그대로 따른다.

## 작업실

- 폴더: `~/Documents/motion-graphics/` (워크스페이스 밖 — 영상 파일이 깃에 안 올라가게)
- 영상 하나 = `src/videos/<영상id>/index.tsx` 폴더 하나. 넣기만 하면 자동 등록된다.
  - 영상id는 영어 소문자·숫자·하이픈 + 버전: `newyear-v1`, `birthday-mom-v1`, `meetup-v2`
  - 파일 맨 위에 `export const meta = { id, seconds, fps, width, height }` 필수, `export default` 가 화면.
- 공용 부품 `src/lib/`:
  - `fonts.ts` — `SANS`(Pretendard, 현대·광고형), `SERIF`(나눔명조, 전통·품격). 글자는 **항상 이 둘 중 하나**(한글 깨짐 방지).
  - `BeatText.tsx` — 글자/단어/줄 단위로 박자에 맞춰 올라오며 살짝 커졌다 정착, **다 나오면 멈춤**. `shine`(금빛 한 번), `exitFrame`(퇴장).
  - `beat.ts` — `beatFrames(bpm,fps)`, `onBeat(n,bpm,fps)`, `sec(s,fps)`.
  - `Hanji.tsx` — 그림 파일 없이 만든 한지 질감 배경.
- 재료: `public/images/`(사진·그림), `public/audio/`(음악), `public/fonts/`. 코드에선 `staticFile("images/x.png")`.
- 도구 `scripts/`:
  - `new-version.sh <영상id>` → 다음 버전 폴더 복사 후 새 id 출력
  - `check.sh <영상id> <초...>` → 해당 초 장면 PNG (`out/stills/<id>/`)
  - `export.sh <영상id>` → `out/<id>.mp4` (H.264+AAC, 이미 있으면 덮어쓰지 않고 멈춤)
  - `make_bgm.py --style 전통|밝은|세련 --bpm N --seconds S --out public/audio/x.wav` → 간단 배경음 합성(유명곡 흉내 없음, 끝 0.5초 페이드)
  - `uv run -q --with librosa python scripts/bpm.py <음악파일>` → BPM·박자 위치(초)
- 시험 영상 `test-newyear-v1`(무음)·`test-newyear-v2`(배경음)이 참고 예제다. 새 영상은 이 구조를 본떠 쓴다.

## 흐름

### 1. 요청 해석 → 명세 확정
- 프리셋 요청("새해 인사 그거", "생일 축하", "모임 초대")이면 `references/presets.md`를 명세로 쓴다. [대괄호]는 사용자 값, 안 주면 문서 기본값.
- 한 줄 요청이면 내가 명세를 채운다: 크기(기본 1920×1080, 세로 숏폼이면 1080×1920), fps(전통·따뜻 30 / 세련·광고 60), 길이(기본 15초 안팎), 장면별 초 구간·문구·그림·움직임, BPM(전통 150 / 광고 128).
- 장면 구간은 **박자 단위로 끊는다**(예: 128BPM 4박 = 1.875초, 150BPM 6박 = 2.4초).
- 묻지 말고 만든다. 꼭 필요한 재료(가게 사진, 음악 파일)가 없을 때만 알린다.

### 2. 그림 전략 (코덱스와 다른 점)
코덱스는 GPT 이미지 생성으로 그림을 만든다. 클로드코드는 그림(사진풍 이미지)을 직접 생성하지 못하므로:
1. **기본: 그림을 SVG(코드 그림)로 직접 그린다.** 부위별로 나눠서 그려야 움직일 수 있다(까치 = 몸통·날개 따로 → 날갯짓). 수묵·플랫·그림책·인포그래픽풍에 잘 맞는다. 번짐은 `feTurbulence`+`feDisplacementMap`, 먹 농담은 opacity 겹치기.
2. **사용자가 사진·그림을 주면** `public/images/`에 넣고 쓴다(가게 사진, 가족 사진, ChatGPT로 따로 뽑은 그림 등). 움직임은 확대·이동·가리개 열기·조각내기로.
3. 사진풍·정교한 인물 일러스트가 꼭 필요하면 "필요한 그림 목록"(파일명·내용·배경 투명 여부·포즈별)을 적어 주고, 사용자가 ChatGPT 등에서 뽑아 폴더에 넣으면 이어서 만든다. **없는 그림을 있다고 가정하지 않는다.**
- 외부 영상 생성 서비스는 쓰지 않는다.

### 3. 만들기 규칙 (문서의 시행착오 = 기본값)
- **글씨는 그림에 그려 넣지 않고 텍스트로.** 그림보다 글씨가 먼저 보이게 크게(큰 문구 120~180px, 보조 40~56px), 굵게, 진한 색.
- **움직이는 장면은 진짜 움직이게.** 정지 그림만 붙여 놓고 끝내지 않는다(날갯짓·튀어오름·문 열림·절하고 일어서기 등 동작을 키프레임으로).
- **글자는 등장할 때만 화려하게, 다 나오면 멈춘다.** 읽는 동안 흔들림·반복 확대 금지. 마지막 문구는 최소 2초 유지.
- 첫 장면 그림체를 끝까지 유지. 같은 인물은 같은 얼굴·옷(같은 SVG 컴포넌트 재사용).
- 카드·그림이 화면 밖으로 잘리거나 문구를 가리지 않게. 사용자가 금지한 모양(예: 도넛·꽃·S자 리본)은 넣지 않는다.
- 랜덤은 `random(seed)`(remotion)로만 — `Math.random()` 쓰면 프레임마다 달라져 깜빡인다.

### 4. 음악
- 사용자가 파일을 주면: `public/audio/`에 두고 `bpm.py`로 BPM·박자 위치를 잰다. **BPM이 반/두 배로 잡히는 일이 흔하다**(150곡이 75로) — 체감 템포와 다르면 2배·½배로 보정. 어울리는 구간을 `<Audio startFrom>`으로 고르고, 장면 전환·글자 등장을 박자 위치에 맞춘다. 영상 길이는 유지, 끝 0.5초 `volume` 페이드.
- 파일 이름이 틀리거나 없으면 **먼저 알리고 다른 음악으로 대체하지 않는다.**
- 파일이 없고 배경음을 원하면 `make_bgm.py`로 간단히 합성(전통=북+종, 밝은=피아노·기타풍, 세련=킥·하이햇·베이스). 품질이 단순하다고 솔직히 말하고, 무료 음원을 원하면 웹에서 찾아 사용 조건·출처 표기를 함께 알린다. 출처는 `out/<id>-음악출처.txt`로.
- 사용자가 "음악은 나중에"면 무음으로 만든다.

### 5. 직접 확인 (사람에게 넘기기 전에)
- `scripts/check.sh <id>` 로 **각 장면 시작+0.5초, 장면 중간, 마지막 프레임** PNG를 뽑아 Read로 직접 본다.
- 확인 항목: 한글 깨짐 / 글자 잘림 / 그림이 글자를 가림 / 화면 밖 잘림 / 빈 화면 / 그림체 일관성 / 마지막 문구가 끝까지 보이는지.
- 문제가 있으면 고치고 다시 찍는다. 깔끔해질 때까지 반복(보통 1~3회).

### 6. 미리보기 → 수정 → 저장
- 미리보기: `scripts/export.sh <id>` 로 MP4를 만들고 경로와 함께 **장면 사진 2~3장**을 보여 준다. 사용자가 "보여줘/틀어줘"라고 하면 `open out/<id>.mp4`. 직접 만지며 보고 싶다 하면 `npx remotion studio`(백그라운드, 완료 감시 포함) 후 주소 안내.
- **수정은 항상 새 버전**: `scripts/new-version.sh <현재id>` → 새 폴더에서 고친다. 이전 버전 파일·MP4는 절대 덮어쓰지 않는다.
- 수정 요청이 "좀 더 예쁘게"처럼 막연하면, 장면 사진을 근거로 내가 고칠 곳 2~3개를 정해 바로 고치고 무엇을 바꿨는지 "몇 초에·무엇을·어떻게"로 보고한다(되묻지 않는다).
- 최종 저장 후 ffprobe 결과(해상도·fps·길이·영상/소리 코덱)를 확인하고, 음악이 들어갔어야 하는데 소리 트랙이 없으면 저장 전에 알린다.

### 7. 스타일 저장 (선택)
"이 스타일 저장해 줘"면 `~/Documents/motion-graphics/styles/<스타일이름>.md`에 기록: 색(HEX), 글씨체·크기·굵기, 장면 구성과 초 구간, 움직임 방식, BPM과 박자 맞춤법, 원본 영상id·재사용 그림 컴포넌트 위치. 다음엔 "<스타일이름>으로 [친구 생일] 만들어 줘" 한 줄이면 그 파일을 명세로 쓴다.

## 참고 자료 활용
- 사용자가 영어 애니메이션 프롬프트(예: aicssanimations.com 의 "The prompt")를 붙여 넣으면 그 스타일 설명을 Remotion으로 옮긴다. CSS 애니메이션 코드는 그대로 쓰지 말고 `interpolate`/`spring`으로 바꾼다(Remotion은 프레임 기준이라 CSS 애니메이션이 렌더에 안 잡힌다).
- 참고 영상을 주면 `ffmpeg`로 몇 장면을 뽑아 보고 색감·글씨 움직임·전환만 가져온다. 그대로 베끼지 않는다.

## 함정 (실측)
- **렌더용 브라우저**: Remotion이 내려받는 크롬은 이 맥에서 깨져서 멈춘다(`icudtl.dat not found`). `remotion.config.ts`에 설치된 Google Chrome을 지정해 해결했다. 렌더가 "Getting composition"에서 멈추면 이것부터 의심.
- 첫 렌더는 묶기(번들)에 몇 초 걸린다. 장면 사진 여러 장은 `check.sh`로 한 번에.
- 영상id에 한글·밑줄 불가(Remotion 규칙). 한글 제목은 파일 안 주석에.
- 코드로 만든 SVG 그림은 사진풍 품질이 안 나온다 — 사용자가 고퀄 일러스트를 원하면 2번의 3안(그림 목록 전달)을 먼저 제안.

## 비용
Remotion은 개인·소규모 사용 무료. 이미지 생성 크레딧이나 외부 서비스 비용 없음.
