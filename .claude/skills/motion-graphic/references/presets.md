## ⑩ 새해 인사 (14.4초)
```
가족과 지인들에게 보낼 설날 인사 모션그래픽을 만들어 줘.
따뜻한 한지 바탕에 먹선과 전통 채색을 살려서,
성인들이 보기에도 품격 있고 정겨운 느낌이면 좋겠어.


가로 1920×1080, 30fps, 14.4초로 만들어 줘.
첫 장면에서 정한 그림체를 뒤 장면까지 일관되게 유지해 줘.


0~2.4초에는 소나무와 붉은 해, 산수 배경에 까치가 날아오게 해 줘.
큰 문구는 '새해 복이 / 날아옵니다'로 해 줘.
작은 보조 문구는 '[2027] 새해를 맞이하며'로 넣어 줘.


2.4~6.4초에는 붉은 복주머니에서 금빛 엽전과 장식 지폐가
솟아올랐다가 떨어지게 해 줘.
문구는 '복은 가득, / 살림은 넉넉하게'야.
이 장면에서는 소나무를 반복하지 말고 한지 여백을 살려 줘.


6.4~14.4초에는 기와집의 한지 창호문이 양쪽으로 열리고,
한복 입은 남녀가 함께 새해 인사 절을 올린 뒤 몸을 일으키게 해 줘.
문구는 '새해 복 많이 받으세요'로 해 줘.
기와집과 인물은 문구가 잘 보이도록 화면 아래쪽에 작게 배치해 줘.


글씨는 크고 굵게, 먹색이나 진한 적갈색으로 또렷하게 보여 줘.
150 BPM의 빠른 박자에 맞춰 글자가 차례로 올라오고,
살짝 커졌다가 제자리에 정착하게 해 줘.
등장한 뒤에는 계속 흔들지 말고, 마지막 문구는 최소 2초 동안 유지해 줘.


가능하면 경쾌한 타악기와 은은한 종소리 느낌의 간단한 배경음을 만들어 줘.
유명한 곡의 멜로디는 따라 하지 마.
음악 제작이 어렵다면 무음 미리보기를 먼저 보여 줘.
그림은 필요한 부분과 동작 포즈를 따로 준비해서 움직여 줘.
```

## ⑪ 생일 축하 (14.4초)
```
[50~60대 부모님]께 보내는 생일 축하 모션그래픽을 만들어 줘.
따뜻한 한지 질감과 먹선, 부드러운 전통 채색을 사용해 줘.
설날 영상의 원본이나 참고 그림이 있으면 그 그림체를 활용하고,
없으면 이 설명을 기준으로 일관된 가족 그림을 새로 만들어 줘.


가로 1920×1080, 30fps, 14.4초로 만들어 줘.
[부모님과 성인 자녀 둘, 어린 손자 한 명]이 나와.
장면이 바뀌어도 같은 얼굴과 옷차림을 유지해 줘.


0~3.2초: 가족들이 집 안 식탁에 둘러앉아 웃는 모습.
식탁에는 음식과 생일 케이크가 있어.
문구는 '오늘은, / 당신의 생일'.


3.2~6.4초: 부모님이 케이크의 촛불을 부는 모습.
문구는 처음에 '소원은 크게!', 중간에 '행복은 가득!'으로 바뀌게 해 줘.
그림은 오른쪽, 큰 문구는 왼쪽에 배치해 줘.


6.4~9.6초: 부모님이 나란히 서서 다정하게 웃는 모습.
문구는 '함께라서 / 더 행복한 날'.


9.6~14.4초: 가족들이 부모님을 가운데 두고 축하하는 모습.
문구는 '생일을 진심으로 / 축하드립니다'.
아래에는 '[우리 가족의 사랑을 담아]'를 넣어 줘.
마지막 가족 그림은 한 위치에 고정해 줘.


그림보다 글씨가 먼저 눈에 들어오게 크게 배치해 줘.
글자는 빠르게 펼쳐지며 살짝 커졌다가 정착하고,
강조 문구에 금빛 효과가 짧게 한 번 지나가게 해 줘.
읽는 동안에는 글자나 가족 그림이 반복해서 흔들리지 않게 해 줘.


움직임은 150 BPM 기준으로 경쾌하게 해 줘.
가능하면 피아노와 기타 중심의 따뜻하고 밝은 간단한 배경음을 만들어 줘.
드럼은 세게 치지 말고 부드럽게 해 줘. 음악 제작이 어렵다면 알려 줘.
설날 영상은 그대로 보관하고 별도 영상으로 만들어 줘.
```
변형: 문구를 '[어머니, 생신을 축하드립니다]', '[아버지, 늘 건강하세요]'로.

## ⑫ 모임 초대 (15초)
```
친구들에게 보낼 15초짜리 모임 초대 모션그래픽을 만들어 줘.
가로 1920×1080, 60fps로 해 줘.
검정, 크림색, 선명한 파랑, 오렌지를 사용해 줘.
큰 한글과 초대장 카드가 중심인 세련된 광고 느낌이면 좋겠어.
이 영상은 사진이나 새 삽화 없이 글자와 도형을 코드로 만들어 줘.


0~1.875초: 왼쪽에 '평범함은 / 여기까지.'
오른쪽에는 초대장 카드 세 장이 펼쳐지게 해 줘.
글자와 카드의 크기를 맞추고 충분한 간격을 둬.


1.875~3.75초: 컬러 카드 세 장에 '오늘 / 우리 / 만나요'.
3.75~5.625초: 파란 배경에 '취향이 / 만나는 순간'.
5.625~7.5초: '이야기 / 웃음 / 설렘 / 함께!'를 박자마다 한 단어씩 크게.
7.5~9.375초: 겹친 초대장 카드에 '당신을 / 초대합니다.'
9.375~11.25초: 사각 프레임 전환과 함께 '함께라서 / 더 특별한'.
11.25~15초: 크림색 배경 중앙에 '좋은 사람들과, / 특별한 하루'.
마지막 아래 문구는 '함께할 순간을 기대해요'로 해 줘.


128 BPM 기준으로 글자와 장면 전환의 박자를 맞춰 줘.
큰 글자는 빠르게 나타난 뒤 읽을 시간 동안 안정적으로 유지해 줘.
도넛, 꽃 모양, S자 리본은 넣지 마.
카드가 화면 밖으로 잘리거나 문구를 가리지 않게 해 줘.
마지막 문구는 중앙에 크게 보여 줘.


음악은 다음 요청에서 지정할 테니 지금은 무음 미리보기를 만들어 줘.
다른 영상들은 유지하고 별도 원본으로 보관해 줘.
```
변형: 동창회·독서 모임·회사 송년회 — 문구만 바꿔서.

## 한 줄 요청 예시

- [우리 가게] 사진을 넣어서 15초짜리 가게 홍보 모션그래픽
