# Quick 260925-2d8: 배너 검수 👁·↩ 표식 장 필터 Summary

배너 검수 화면에 서버의 `출처표식`에서만 나오는 `data-mark` 속성과, 그걸 보고 표식 장·표식 줄만 남기는 화면 전용 토글(기본 OFF, `?only=marks`로 상태 유지)을 붙였다.

## 한 일

- **`_banner_strip.html`**: `{%- if 장.출처표식 %} data-mark="{{ 장.출처 }}"{% endif %}`. 판단은 서버 값으로만 하고, 템플릿은 출처 문자열을 비교하지 않는다. 라벨 POST 조각도 같은 파일을 쓰므로 교체 뒤에도 속성이 남는다.
- **`banner_review.html`**: `#mark-filter` 체크박스(checked 없음)와 `#mark-filter-count` 개수 글귀를 추가했다. `body.ct-only-marks` 숨김 규칙 2개를 넣었고(strip 장 / 표식 없는 `.ct-row`), 기준 확인 섹션(sample)은 대상에서 뺐다. `/static/banner_review.js`도 링크했다.
- **`banner_review.js`**(신규): DOM 속성으로 표식 장 수 · 상품 수 · ✋ 없는 장 수를 센다. 개수 글귀는 "화면 표식(👁·↩) 기준이고 04-GATE 128장과 다르다"고 밝힌다. 표식이 0장이면 그 사유를 보여 준다. `replaceState`로 `only=marks`를 넣고 빼며 `run_dir`은 그대로 둔다. `htmx:afterSettle`에서 개수를 다시 세고, 실패하면 try/catch로 필터만 끄고 `console.warn`을 남긴다.
- **테스트**: pytest 3개를 새로 넣었다(표식 장에만 data-mark / 라벨 조각에도 유지 / 기본 OFF, JS 200, S-1 가드). CDP 검사 V-BANNER-05a~05d도 추가했다.
