# Quick 260929-t1: ② 체크박스로 썸네일 견적 버튼이 안 켜지는 버그

## 원인
thumb.js 는 document click/keyup 버블링으로만 `#thumb-estimate-btn` 을 갱신한다.
Tabulator rowSelection 체크박스 클릭은 document 까지 안 올라와 버튼이 disabled 로 남는다(07-uat P1).

## 작업
1. thumb.js 에서 `Tabulator.findTable("#board")` 로 board.js 의 같은 인스턴스를 찾아
   `rowSelectionChanged` 에 `버튼갱신` 을 붙인다. board.js 는 안 고친다(D-19). click/keyup 은 보조로 유지.
2. coupang.js 확인 — 버튼을 선택과 무관하게 켜므로 같은 패턴 아님(수정 없음).
