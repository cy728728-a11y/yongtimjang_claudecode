# Quick 260929-g1: 게이트 '정상' 직후 반영 실행 버튼이 새로고침 없이 뜨게

## 문제 (P2 — 06-market-update/deferred-items.md · evidence/06-04-uat.md)
게이트 버튼은 `closest .market-gate-panel` 만 outerHTML 로 갈아끼운다. 결과 표 아래
`#market-commit-next`(반영 실행 버튼)는 응답에 없어서 새로고침 전까지 안 뜬다.

## Task 1 — oob 로 버튼 자리 같이 갱신
- `_market_commit_next.html` 조각 신설: `<div id="market-commit-next">` 를 **항상** 그린다(빈 자리 포함 —
  oob 대상이 DOM 에 있어야 한다). 버튼은 정상 · preview_job_id · 남은반영가능>0 일 때만.
  `oob` 참이면 `hx-swap-oob="true"`.
- `_market_result_table.html` 은 그 조각을 include (oob 없음).
- `_market_gate_response.html` 신설: 게이트 패널 + 조각(oob=true). `POST /market/gate` 가 이걸 돌려준다.
- 상한·대상은 여전히 `_게이트패널ctx` → `_마켓반영상한()` (서버 결정). 이상이면 버튼 없는 빈 자리.
- 테스트: 정상 응답에 oob 조각 + 버튼 + 최대 N건, 이상 응답에 oob 빈 자리·버튼 없음.
