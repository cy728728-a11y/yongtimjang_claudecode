`requests` 를 새로 깔지 마라 — Range 헤더·타임아웃·재시도만 필요하다.

**URL 화이트리스트(SSRF · ASVS V5)를 다운로드 직전 한 관문에서 건다.** 순수 함수
`허용URL인가(url) -> tuple[bool, str]` 로 떼어내 단위테스트 가능하게 만든다(`stitch.py` 가 순수
로직을 떼어 둔 것과 같은 구조). 규칙: 스킴은 `https` 만(실측 상대경로·`data:` 0건이지만 미래 방어) ·
호스트가 IP 리터럴이면 거부 · 호스트가 `localhost` 이거나 `127.` `10.` `192.168.` `169.254.` `172.16~31.`
대역으로 해석되면 거부 · 빈 문자열이면 거부(`src` 없는 `<img>` 자리). 거부는 예외가 아니라
`판정: "미판정"` + 사유 `"허용되지 않는 URL"` 이다 — **URL 출처가 외부 서비스(불사자)라 신뢰할 수 없다.**

**재시도:** 지수 백오프 3회(0.3s / 0.6s / 0.9s). **404 는 즉시 포기**(재시도 무의미 — 실측 25장이
3회 재시도 후에도 영구 404). 실패한 장은 `판정: "미판정"` + 사유 `f"HTTP {코드} (3회 재시도)"`.
`try/except: pass` 를 한 줄도 쓰지 마라 — Phase 3 CR-01~03 과 정확히 같은 계열의 병이다.

**캐시:** `<cache>/<run_dir>/<상품순번>_<장순번>.bin` 에 저장하고, 이미 있으면 재다운로드하지 않는다.
받기 전에 `<cache>` 아래 회차 디렉터리를 mtime 내림차순으로 훑어 `--keep-runs` 개를 넘는 오래된
회차를 지운다(디스크 고갈 방어). 지운 회차 이름을 로그로 말한다.

**로그:** `[2/5] 다운로드 {n}장 (실패 {m})` + 실패 호스트별 집계 한 줄(실측: `img.alicdn.com` 20 ·
