## Critical Anti-Patterns

| anti-pattern | severity | 왜 |
|---|---|---|
| 게이트 기준을 완화해 통과시키기 | blocking | 이 페이즈의 존재 이유가 사라진다. Phase 5 가 크레딧을 태운다 |
| in-sample 재측정을 "미탐 0% 달성" 으로 보고 | blocking | 지시문 v3 는 그 표본을 보고 골랐다. 과적합이다 |
| 지시문에 배너 낱말 목록 넣기 | blocking | 실측 — 비전이 낱말매처로 퇴화해 83.3%→56.7% (§11-1) |
| 사람 라벨을 기계가 수정 | blocking | 정본이다. 용팀장만 뒤집는다 |
| `webapp/` 에 네트워크·PIL 추가 | blocking | D-19 트리순회 가드가 집행. 비전 호출은 `.venv` CLI 안에만 |
| API 실패를 `제품` 으로 흘려보내기 | blocking | 그게 곧 미탐이다. 실패는 `미판정`+사유 |
