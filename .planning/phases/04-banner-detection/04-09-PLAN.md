**(1) 지시문 상수 `지침_v3`**
`evidence/vision_pilot_v3.py` 의 `지침` 문자열을 **한 글자도 바꾸지 말고** 그대로 옮긴다.
옆 주석에 이유를 적어라: v2 실험(배너 낱말 목록 추가)이 같은 30장에서 26/30 → 17/30 으로
**26p 떨어뜨렸다**(04-GATE §11-1). 지시문에 낱말을 넣으면 비전이 낱말 매처로 퇴화한다.
"개선"은 금지다.
그 아래에 `지침_sha256 = "5ff5d8cc3a7fc55cc9666ffaae67c340cf3bc3f2e194d53c4b0e7b626ec3ea2e"` 를
상수로 박고, 모듈 로드 시가 아니라 **테스트가** 이 값을 검증한다(Task 3).
`지침판 = "v3"` 상수도 같이 둔다.

**(2) 예외 `비전2차불가(RuntimeError)`**
키 파일 없음 · 키 값 없음 · 호출 상한 초과처럼 **회차 전체의 전제가 깨진** 경우에만 올린다.
`Vision미설치` 와 같은 급이다. 장 하나의 실패에는 쓰지 마라.

**(3) `비전키읽기(키파일경로) -> str`**
`vision_pilot_v3.py::키읽기` 와 같은 방식 — 파일을 읽고 `^GEMINI_API_KEY=(.*)$` 를
`re.M` 으로 찾아 따옴표를 벗긴다. `eroomlib` 을 import 하지 마라(이 스크립트는 stdlib +
`webapp.banner`/`webapp.state` 만 쓴다는 규율이 모듈 docstring 에 박혀 있다). `import re` 를
파일 상단 import 블록에 더한다.
파일이 없거나 키가 비면 `비전2차불가` 를 올리고 **사유에 파일 경로는 적되 키 값은 절대 적지 않는다.**

**(4) `비전이미지준비(원본경로, 최대=1024) -> bytes`**

목 테스트가 이 모듈 속성 하나만 갈아끼우면 네트워크가 끊긴다. 다른 용도로 쓰지 마라
