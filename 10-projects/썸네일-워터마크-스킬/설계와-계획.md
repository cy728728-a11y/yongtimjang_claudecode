# 썸네일 워터마크 스킬 — 설계와 계획

작성: 2026-11-18 · 승인: 용팀장 "좋아, 진행해"

## 왜
유튜브·인스타 구독자에게 "클로드 코드 스킬 만드는 기본 방법"을 보여 주는 시연 예제. 그래서 누구나 자기 PC에서 그대로 따라 할 수 있어야 한다.

## 목표 / 하지 않을 것
- 목표: 폴더(또는 한 장)의 상품 사진에 글자 워터마크를 넣어 별도 폴더에 저장. 키워드로 자동 실행.
- 하지 않음: 불사자 연동, 로고 이미지, 네이버 업로드 (2편 소재로 남김).
- 실패 기준: 원본을 덮어쓰거나, 구독자 PC에서 추가 설치가 많아 못 따라 하면 실패.

## 방식 (검토한 세 가지)
1. 로컬 폴더 + 글자 워터마크 — **채택**. 파이썬+Pillow 하나, 코드가 짧아 설명하기 좋음.
2. 1 + 로고 이미지 — 설명량 두 배, 첫 예제로 무거움.
3. 불사자 썸네일 직접 교체 — 구독자가 못 따라 함, detail-page-opus 가 이미 함.

## 정한 값
- 글자: `--text` (기본 "오네이")
- 위치: `center`(기본, 18도 대각선, 폭의 최대 15% 글자 크기) / `corner`(오른쪽 아래 작은 글씨)
- 투명도: 18% 기본(`--opacity`로 조정), 글자색은 아래 밝기에 따라 진갈/아이보리 자동, 반대색 옅은 테두리
  (detail-page-opus/thumb_wm.py 기준값 차용 — 원본 스킬은 수정하지 않음)
- 대상: 파일 하나 또는 폴더(jpg·jpeg·png·webp), 하위 폴더는 안 봄
- 결과: `<입력폴더>/워터마크_결과/` 에 같은 이름으로 저장. 원본 절대 안 건드림. `--compare` 면 원본|결과 비교 이미지도 저장
- 폰트: 나눔펜스크립트(OFL)를 스킬 assets 에 동봉 → 윈도우·맥 동일

## 계획 (직접 실행)
1. `.claude/skills/thumb-watermark/scripts/watermark.py` — `add_watermark(im, text, position, opacity) -> Image`, `process(path, text, position, opacity, compare) -> list[Path]`, CLI. 한국어 주석, 파일마다 try-except(한 장 실패해도 나머지 진행).
2. `tests/test_watermark.py` — ① 결과 크기 = 원본 크기 ② 원본 파일 바이트 불변 ③ 깨진 이미지 섞여도 나머지 처리 ④ 투명 PNG(RGBA)도 처리 ⑤ 결과 폴더는 다시 처리 대상에 안 들어감.
3. `SKILL.md` — 트리거 문구, 사용법, 구독자용 설치 한 줄.
4. 샘플 사진 몇 장으로 실행 → 비교 이미지 눈으로 확인.

## 검토 포인트 (테스트가 막아야 할 것)
- 투명 PNG → JPG 저장 시 검은 배경 (흰 배경으로 합성)
- 아주 작은 사진(100px)·아주 긴 글자
- 결과 폴더 안 사진을 또 처리해 워터마크 이중으로
- 깨진 파일 하나 때문에 전체 중단
