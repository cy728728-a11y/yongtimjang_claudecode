쿠팡 광고 자동화 — 브레인스토밍 중간 정리

2026-11-10 · 용팀장 × Claude · 아직 설계 확정 전 (정할 것 남음)
한 줄 요약
스마트스토어에서 팔리는 상품을 쿠팡에 올리고(용팀장 직접), 광고는 구리삽 방식 = 수동성과형 + 매일 17시 영점을 시스템이 대신 돌린다. 쿠팡은 광고를 만질 공식 통로가 없어서, 시스템이 브라우저로 광고센터를 직접 눌러 조절하는 방식이 된다.

2. 조사 결과 — 쿠팡 광고를 기계가 만질 수 있나

  1. 공식 통로 없음. 쿠팡이 개발자에게 열어 준 기능은 상품·주문·배송·반품·쿠폰까지. 광고 입찰가를 바꾸는 기능은 공식 문서에 없다.
  2. 남은 길 = 브라우저 대신 조작. 쿠팡 약관은 "자동화 프로그램(매크로)으로 비정상적 활동"을 금지 사례로 들고, 제재는 광고 노출 하향~계정 정지까지 있다. 광고 조절에 그대로 적용되는지는 명시돼 있지 않다.
  3. 쿠팡 공식 자동 조절(매출최적화)은 있다 — 목표 수익률만 정하면 24시간 알아서 조절. 하지만 강의 방식이 아니라서 채택 안 함.
  4. 수동 광고 입찰을 대신 돌려주는 외부 서비스는 못 찾았다.

5. 부록 — 구리삽 광고 규칙 핵심 (시스템이 따를 규칙)

강의(2025-03~04)와 전자책(2024-12)이 다르면 강의 기준. 전체 정리: 30-knowledge/38-marketing/쿠팡-광고-운영-정리.md

지표

  • END ROAS = 1 ÷ 마진율 (마진 30% → 333%, 40% → 250%, 20% → 500%) — 본전 광고수익률
  • ROAS = 광고전환매출 ÷ 광고비 (클릭 후 14일 내 구매) / ROI(트래픽) = 자연매출 ÷ 트래픽비용
  • 판정은 무조건 8일. ROAS·ROI를 합치지 말고 각각 END ROAS와 비교.
  • 계정 전체 광고비 ≤ 매출 5% 목표, 광고매출 : 자연매출 = 1:1이 이상적 (전자책)

세팅

항목값
캠페인 이름대표키워드 + END ROAS (예: 소파베드 333%)
상품수동상품설정 → 모든 옵션 선택 / 운영방식 직접입력
일예산 / 스마트타겟팅12,000원 / OFF
키워드15~50개. 쿠팡 연관검색어를 대표키워드 앞뒤에 붙여 변형(띄어쓰기 없이). 대표키워드 변형(소파베드·쇼파베드·소파침대)은 반드시.
입찰200원 일괄 → 제안가 >200 그대로 / 없음 100원 / <200 제안가로. 비검색 영역도 같은 규칙.

매일 17시 영점

  • 기준 = 예산/2 ± 1,000 → 1.2만이면 6,000 ± 1,000. 5천↓ CPC↑ / 7천↑ CPC↓, 100원 단위(100~600원).
  • CPC를 올릴 땐 전날 기준 +100원 일괄 후 제안가 비교 다시.
  • 100원까지 내렸는데도 17시 소진이 빠르면 → 키워드를 제안가 없는 것·낮은 것·높은 것 순으로 세워 낮은 쪽 절반 삭제 (25→13→7→4).
  • 광고 옵션은 절반씩 OFF: 전환판매 1순위, 전환 없으면 클릭률 높은 것 살림. 10개 이상이면 10개로, 미만이면 한 번만.

안 될 때 (이벤트 관리)

  • 소진이 안 됨 → 입찰 600원까지 → 그래도 안 되면 스마트타겟팅 ON(600원) + 매출최적화(제외) 추가 + 썸네일 개선 → 5일 관찰
  • 소진은 되는데 5일째 ROAS < END ROAS → 마진 20%로 가격 인하 2일 → 매출최적화(제외)로 변경 2일
  • 그래도 안 되면 광고 OFF, 상품은 지우지 않음. 광고 없이 2개쯤 팔리면 다시 켬.

잘 될 때 (일예산 증액)

CPC 최저(100원)·목표수익률 5000%↑인데도 예산 다 씀 → END~1.2배 3만 / 700%+ 6만 / 1100%+ 12만 / 1500%+ 24만

수동성과형 → 매출최적화로 넘기기

수동에서 효율 나오면 매최(1000% 시작)로. 제외키워드는 셀러라이프 "키워드추천" 전체 복사를 3번 이상, 최소 200개. 목적: 상품별로 수동이 잘 도는지 매최가 잘 도는지 확인.
