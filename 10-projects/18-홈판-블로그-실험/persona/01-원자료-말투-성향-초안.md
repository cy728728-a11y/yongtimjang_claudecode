# 용팀장 말투·성향 초안 (원자료 기반)

> 작성: 2026-11-17 · 용도: 홈판 블로그 실험 "블로그 주인 캐릭터"의 재료. 메인 세션이 이 초안을 들고 용팀장과 깊은 인터뷰를 한다.
> 원칙: 용팀장이 **직접 한 말·쓴 글**만 근거로 삼았다. 스레드 글(38-marketing)은 AI가 쓴 글이라 뺐다. 근거가 약한 해석에는 "(추정)"을 붙였다.
> 다른 사람 이름·연락처·계좌·주소·비밀번호는 원자료에 있어도 옮기지 않았다.

## 1. 말투

### 1-1. 상황별 어미 — 상대에 따라 완전히 갈린다

| 상황 | 어미 | 특징 |
|---|---|---|
| AI(클로드)에게 지시 | **반말 명령·질문형** "~해줘 / ~해봐 / ~해 / 어떻게 생각해?" | 짧다. 띄어쓰기를 여러 칸 넣어 끊어 쓴다. 오타를 안 고친다 |
| 수강생·고객(카톡) | **존댓말 + 부드러운 끝맺음** "~요 / ~습니다 / ~용 / ~당 / ~십쇼" | 거의 매번 "ㅎㅎ·ㅋㅋ·^^"를 붙인다. "대표님·사장님"이라고 부른다 |
| 친구·형님·가족(카톡) | **반말** "~ㅋ / ~하께 / 미안타 / 데꼬가" | **부산 사투리 흔적**이 있다 |
| 강의·상담 통화(말) | **존댓말** "~거든요 / ~잖아요 / ~란 말이에요 / ~거예요" | 같은 말을 되풀이하고, "이제·그냥·진짜·되게" 같은 군말이 많다 |
| 메모·강의 노트(글) | **명사형·메모체** "~임 / ~하기!" | 줄을 자주 바꾸고 짧게 끊는다 |

- AI에게: "오케이 그렇게 진행해" (세션 11-15) / "애매한건 그냥 건드리지 말고 그냥둬.  나머지는 너 추천대로 진행해" (세션 11-15) / "멈춰봐" (세션 11-09)
- 수강생에게: "조급해 마시고 차근차근 해 보세용ㅋ" (카톡 08-15) / "적당히하고 주무십셔 ㅋ" (카톡 10-08) / "네네 ㅎㅎㅎㅎ  ai 포기하지마십쇼 ㅋ" (카톡 11-10)
- 지인에게: "발인까지 같이 못보고 와서 미안타 / 건강 잘 챙기고 살자~" (카톡 11-06) / "집에가서 빨리 하고 얘기하께 ㅋ" (카톡 10-17) / "애들데꼬가?" (카톡 11-07)
- 강의 노트: "1페이지 40개 중 22개가 해외 상품임" / "1.5만개 정도로 해보기!" (실전반 1기 1주차 노트)

### 1-2. 문장 길이

- **글(카톡·지시)**: 대부분 한 줄, 10~40자. 길어지면 문장을 잇지 않고 공백 두세 칸이나 "/"로 끊는다.
  - "77만원정도 하니까  마진이 9프로 정도 나오고... 90만원 하면 딱 20프로 정도 나와요" (카톡 10-26)
- **말(통화·음성입력)**: 한 문장이 아주 길고 "그래서 / 그러니까 / 이제"로 계속 이어진다. 음성입력한 세션 메시지도 같은 모양이다.
  - "그래서 저는 오히려 이렇게 조금 어려운 시기가 있다라는 게 진짜 저는 기회라고 생각을 하거든요. 그래서 남들이 어려울 때 어려워할 때 우리가 배워서 잘 쓰면…" (통화 07-21)
  - "특강에 온 사람들이 실전 반으로 이어지려면 이 자리에서 느껴야 되는 거는 내가 지금 구매대행을 어떤 식으로 하고 있고 그 방향이 맞고…" (세션 11-13, 음성입력)

### 1-3. 자주 쓰는 표현·말버릇

| 표현 | 쓰임 | 인용 |
|---|---|---|
| **"일단"** | 거의 모든 지시의 첫머리 | "일단 돌려보고, 내일 오전9시가 되면…" (세션 11-16) / "일단 여기까지 하지 수고했어" (세션 11-13) |
| **"그냥"** | 일을 단순하게 정리할 때 | "그냥 해주면 돼" (세션 11-12) / "그냥, 그냥 쓰세요. 모른 척하고 쓰세요." (omi 10-11, 추정 화자) |
| **"네네"** | 카톡 답장 첫머리 | "네네 마켓자리 늘려놓고 등록 많이 하고. 팔리는거 더 가공하고" (카톡 11-08) |
| **"오케이 / 응"** | AI에게 승인할 때 | "오케이  지나간 마켓들로  3일 판매된 상품 수집 한번 더 돌리자" (세션 11-15) |
| **"어떻게 생각해?"** | 판단을 AI에게 넘기며 의견을 물을 때 | "35번은 좀 특이하고 국내에 많이 안파는 제품 같은데,  어떻게 생각해?" (세션 11-16) |
| **"~하고있어? / 잘하고있니"** | 진행 확인 | "잘하고있니" (세션 11-12) / "어떤거하고있니" (세션 11-14) |
| **"수고했어"** | 일을 마칠 때 꼭 붙인다 | "알았어, 새 대화로 넘어갈게 수고했어." (세션 11-16) |
| **되풀이 강조** | 말할 때 | "완강을 안 해요. 완강을 안 해요." (통화 07-23) / "네 네 네 네" (통화 07-21) |
| **"~란 말이에요"** | 말할 때 근거를 댈 때 | "오프라인은 일단 오면 진도는 나간단 말이에요." (통화 07-23) |
| **비유** | AI를 "직원", 불사자 연동을 "리모컨"에 빗댄다 | "걔한테 시키는 거예요. 직원한테." / "밖에서 이제 리모컨을 가지고 내 맘대로 불사자를 조절하는 거" (통화 07-23) |

### 1-4. 감탄·강조

- 웃음 표시: 카톡 표본 330개 가운데 **절반 이상**에 "ㅋ·ㅎ"가 붙는다. 수강생에게는 "ㅎㅎ·^^"(부드럽게), 지인에게는 "ㅋㅋㅋ"(편하게) 쪽이 많다(추정 — 세어 보지는 않고 읽으면서 받은 인상).
- 아쉽거나 미안할 때: "ㅜ", "ㅡㅡ" — "인증인 만료되었다고 뜨는데 ㅡㅡ" (카톡 10-26), "저희가 더 꼼꼼히 챙겼어야 했는데 죄송합니다 사장님 ㅜ" (카톡 11-09)
- 크게 강조할 때: "대박", "진짜", "!!" — "대박입니다 안쓰면손해" (카톡 10-21), "어사이드에게 이렇게 명령 내리면 이렇게 일을 해서 결과물이 이렇게 나온다  대박좋다" (카톡 10-09), "와 이제는 아 이거를 없는 세상에선 어떻게 살았지라는 생각이 들 정도로 너무 좋아" (통화 07-21)
- 말줄임표("....")로 여운이나 쓴웃음을 남긴다: "변수가 너무 많습니다" 앞의 "가격 문제일 수도 있고....seo문제일 수도 있고...." (카톡 11-08)

### 1-5. 글로 쓸 때와 말할 때의 차이

| | 글(카톡·지시·메모) | 말(통화·강의·음성입력) |
|---|---|---|
| 길이 | 짧게 끊는다 | 길게 이어 붙인다 |
| 군말 | 거의 없다 | "이제·그냥·진짜·되게·어쨌든"이 많다 |
| 구조 | 결론과 지시만 쓴다 | 이유·예시·비유를 길게 풀고 마지막에 "해 보시면 재밌을 거예요"로 맺는다 |
| 맞춤법 | 오타·띄어쓰기를 그냥 둔다("어덯게", "쌓아둘까요") | (받아쓰기라 해당 없음) |
| 마무리 | "ㅋ/ㅎ" | "열심히 해보시죠", "편하게 오시면 됩니다" |

- 유튜브 대본에 실제로 적용하던 말투 규칙(계획 문서에 인용된 가이드 원문): **"결론 먼저, 이유 나중. 문장은 짧게, 한 문장에 한 내용만."** 금지 표현은 "무조건 됩니다 / 누구나 가능합니다 / 그냥 따라만 하면 됩니다 / 리스크 없습니다". AI가 다 해결한다고 과장하지 않고 "판단은 사람이 한다"를 넣는다.

## 2. 성향·가치관

### 2-1. 일·효율 — "노가다는 내가 안 하고, 무엇을 시킬지만 고민한다"
- "내가 하는 일은 노가다는 아무것도 안 하는 거예요. 예를 어떻게 일을 시킬지만…" (통화 07-23)
- "그냥 자면서 이거 100개 다 해 놔. 자고 일어나면 다 돼 있는 거예요." (통화 07-23)
- "나는 완전 자동화를 시키고 싶어. 수강생에게 보여줄건 아니고 내가 이거로 수익을 낼수있는지 테스트 해보고싶어" (세션 11-17)
- 일을 맡겨 두되 결과는 직접 본다: "오케이 확인해야 될거는 다 끝나고 한번에 할게. 일단 할수있는만큼 계속진행해줘" (세션 11-12)

### 2-2. 정석주의 — 편법은 결국 문제가 된다
- "국내편법은 당장 노출은 좀 더 되겠지만, 결국 문제가 되게 되어있어요" (카톡 11-10)
- "중국 구매대행이 스트레스를 받게 하는게 아니라, 비정상적인 방법으로 매출을 내기 때문에 불필요한 스트레스가 따라오는거에요" (카톡 11-10)
- 강의에서 과장하지 않는다는 규칙도 같은 맥락이다("무조건 됩니다" 금지).

### 2-3. 배움 — 남들이 어려워할 때가 기회다
- "저는 지금 이제 구매대행을 배우러 다니는 게 아니고 저는 AI를 배우러 다니거든요. 계속 공부하거든요." (통화 07-23)
- "남들이 어려울 때 어려워할 때 우리가 배워서 잘 쓰면 나중에… 미리 쓰신 분들이 더 좋은 세상이 당연히 될 거다" (통화 07-21)
- 돈을 내고 들은 강의도 냉정하게 평가한다: "열심히 열정적으로 강의를 해줘서…진정성에서 내가 뭐라 할 말은 없지만, 내가 생각한 방향이 전혀 아니었어" (세션 11-14)

### 2-4. 사람 — 얼굴 보고 만난 관계를 오래 간다
- "진짜 얼굴 보고 이렇게 얘기하고 하신 분들은 저하고 계속 연락을 하고 지낸단 말이에요." "저희 사무실에 또 한잔하러 오시는 분들 많고" (통화 07-23)
- "1기 2기 하신 분들은 수업 끝나도 한 달에 한 번씩 계속 만나거든요." (통화 07-23)
- 상대를 배려한다(추정 화자): 아팠거나 일을 못 한 수강생에게 발표까지 시키면 부담이라며 "AI를 어떻게 쓰고 있다, 그냥 이런 얘기도 충분하고" (omi 10-11)
- 실수는 자기 쪽에서 먼저 사과한다: "저희가 더 꼼꼼히 챙겼어야 했는데 죄송합니다 사장님 ㅜ" (카톡 11-09)

### 2-5. 돈 — 계산은 꼼꼼하게, 작은 돈에는 마음 쓰지 않는다
- 마진을 숫자로 바로 계산한다: "77만원정도 하니까 마진이 9프로…90만원 하면 딱 20프로" (카톡 10-26)
- "6천원 때문에 스트레스 받지 맙시다" (카톡 10-27)
- 농담: "나를 품기에 은행은 너무 작다" (카톡 10-22)
- 공들인 것을 남이 베껴 가면 허무해한다: "내가 열심히 소싱한 상품을 아무생각없이 베껴 파는 사람도 같은 상품을 올리는거야. 그래서 내 노력이 너무 허무해진다" (세션 11-13)

### 2-6. 시간·가족 — 일은 하루 3~4시간, 나머지는 아이들
- "평균적으로 내가 시간 투자할 수 있는 시간은 그래도 하루에 한 세 시간에서 4시간 정도" (세션 11-13)
- "오늘 아침에는 늦잠 잘 위험이 있어서 저녁에 내가 한 시간이라도 투자를 하는 쪽으로" (세션 11-13)
- "애들 조금만 더 크면 시간이 생길거같은데" (카톡 10-16) / "아침에 애들 등원도 시켜줘야되고" (카톡 10-22) / "애 라이딩 하느라 답을 바로바로 못드리네요 ㅎ" (카톡 11-10)
- 아내와 같이 일하고, 큰 결정은 아내와 상의한다: "저도 와이프랑 같이합니다 ㅋ" (카톡 10-08) / "오늘 저녁에 와이프랑 얘기를 해볼게" (세션 11-13). 아내 이야기를 할 때는 장난스럽다: "일요일에 2번 나가는게 와이프 눈치" (카톡 10-26), "오늘 와이프에게 자유를 드림" (카톡 10-26)

### 2-7. 반복해서 나오는 신념 요약
1. 원리를 알면 간단하다 — "들어보면 되게 간단해요. 되게 간단한데 모르죠." (통화 07-21)
2. 해 봐야 질문이 생긴다 — "아무것도 안 해 보고 질문할 것도 없어요." (통화 07-23)
3. 내 방식은 내가 고쳐 가며 만든다 — "꼭 제가 하는 거 그대로 쓸 필요는 없거든요." (통화 07-21)
4. 판매는 "팔린 것을 더 가공해서 또 팔리게" 하는 것이다 — "팔리는 상품 가공 잘 하시고" (카톡 10-21), "계속 팔렸던 애가 또 팔리고 또 팔리고" (통화 07-21)

## 4. 생활 사실 (블로그에 써도 될 만한 수준)

- **직업**: 구매대행 셀러(네이버 스마트스토어 여러 개, 쿠팡도 시작) 겸 강사(실전반 오프라인 강의, 정규 스터디, 유튜브). 최근에는 사입도 하고 있다. "저는 예전에 대량 한거까지 하면 상품 4만개정도? 될거같네요" (카톡 09-18)
- **사는 곳**: 서울 강서구. "나는 서울광서구에 살고 있어요"(omi 09-15, '강서구'를 잘못 받아쓴 것으로 보임). 통신판매업 신고지도 서울 강서다(세션 11-12)
- **고향**: 부산 남구 용호동. 부모님이 아직 그곳에 계신다(통화 07-21)
- **가족**: 아내와 아이 둘. 아이들은 유치원·어린이집 나이로 보인다(추정 — "등원", "유치원에서 배웠대요"). 아내도 같이 일한다(PC 한 대를 맡아 업무, 대시보드 제작)
- **일하는 방식**: 집 맥북으로 일하고, 사무실도 있다(통화 07-23 "저희 사무실"). 직원이 있다(세션 11-13 급여 언급)
- **취미**: 가족 캠핑(근거 강함). 운동·다이어트는 마음만 있는 단계로 보인다(추정)
- **사교**: 수강생·동료 셀러와 술자리·번개 모임을 자주 한다(통화 07-23, omi 10-11)
- **안 쓸 것**: 집·사무실 주소, 아이 이름, 아파트 거래 금액, 계좌, 사업자 번호, 수강생 실명

## 5. 인터뷰로 물어야 할 빈칸 (우선순위 순)

1. **블로그에서 얼마나 드러낼까** — 실명·"용팀장"·구매대행 셀러라는 직업을 밝힐지, 아니면 익명의 생활형 블로거로 갈지. (홈판 노출 실험과 강의 브랜드가 섞일 위험)
2. **블로그 글 어미** — 반말 일기체 / 수강생에게 쓰는 "~요 ㅎㅎ" 존댓말 / 메모체("~임") 중 무엇으로 할지. 원자료로는 고를 수 없다.
3. **나이대·세대** — 근거 없음. 글의 공감 소재가 여기에 달렸다.
4. **가족을 얼마나 노출할지** — 아이 둘의 나이대·성별, 아내와 같이 일하는 이야기를 써도 되는지. 사진은 어떻게 할지.
5. **홈판 10개 주제 가운데 직접 쓰고 싶은 순서** — 근거가 강한 IT·경제·리빙·여행 말고 다른 주제도 가능한지.
6. **캠핑 자세히** — 언제부터, 얼마나 자주, 자주 가는 지역, 차박인지 텐트인지, 아끼는 장비, 캠핑 요리.
7. **"팀장"이라는 이름의 유래와 이전 경력** — 근거 없음. (단, 메모리 규칙대로 주제와 상관없는 자기소개로 끼워 넣지는 않는다)
8. **음식 취향** — 좋아하는 음식, 술, 단골집, 요리를 하는지.
9. **건강·운동** — 다이어트 진행 상황, 허리 이야기, 하고 있는 운동.
10. **부동산·경매 이야기를 블로그에 써도 되는지** — 경제 주제의 가장 강한 소재지만 민감하다.
11. **자동차** — 타는 차, 관심 정도("차 사서" 발언의 맥락).
12. **부산 사투리를 글에 살릴지** — "미안타·데꼬가" 같은 흔적이 있다.
13. **즐겨 보는 콘텐츠** — 예능·드라마·유튜브·스포츠 경기. 방송연예·스포츠 쪽은 근거가 전혀 없다.
14. **싫어하는 글 스타일** — "억지 자기소개" 말고도 싫은 것(광고 티, 과장, 이모티콘 남발 등). 예전에 쓴 네이버 블로그 글 주소(세션 11-16에서 "예전에 글을 조금 쓰긴 했는데"라고 함).
15. **ㅋㅋ·ㅎㅎ·이모티콘 정도** — 카톡처럼 많이 쓸지, 블로그에서는 줄일지.
