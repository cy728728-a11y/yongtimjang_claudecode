# 1. 1:1 상담 신청 폼

## 설계 원칙

이 폼의 목적은 **결제가 아니라 통화**다.
전화 클로징 전환율이 100%이므로, **전화까지 가는 문턱을 최대한 낮추는 것**이 전부.

---

## 폼 제목

```
용팀장 구매대행 실전반 — 1:1 상담 신청
```

## 폼 설명문 (제목 아래)

```
결제 신청이 아닙니다. 편하게 통화하는 자리입니다.

"나도 될까?" 싶은 마음으로 강의를 알아보다가
결국 아무것도 못 하고 넘어가는 분들을 많이 봤습니다.

10분 통화로 지금 상황에서 무엇부터 해야 하는지,
실전반이 본인한테 맞는지 아닌지 솔직하게 말씀드립니다.

맞지 않으면 맞지 않는다고 말씀드립니다.
그게 서로한테 이득이니까요.

※ 사업자등록증, 스마트스토어 계정 없어도 괜찮습니다.
※ 지금 매출이 0원이어도 괜찮습니다.
```

**이 문단이 하는 일 3개**
1. "결제 아님" → 문턱 제거
2. "맞지 않으면 맞지 않다고 한다" → 영업당할 공포 제거
3. 마지막 두 줄 → 초보 진입 허가 (기존 신청서 이탈 원인 해소)

---

## 문항 (필수 3 + 선택 2 + 동의)

**1. 성함** — `단답형` *필수*

**2. 연락처** — `단답형` *필수*
> 안내 문구: 통화 가능한 번호로 적어주세요.

**3. 현재 상황을 골라주세요** — `객관식 단일선택` *필수*
```
□ 아직 시작 전입니다 — 뭐부터 해야 할지 모르겠어요
□ 스토어는 만들었는데 매출이 거의 없습니다
□ 월 100만원 미만
□ 월 100~500만원
□ 월 500만원 이상
```
> 앞 두 칸이 "초보도 자리 있다"는 신호. 기존 신청서의 **월매출 서술형**이 초보를 걸러내던 문제를 여기서 해결.

**4. 통화 가능한 시간대** — `객관식 복수선택` *(선택)*
```
□ 평일 오전 (9~12시)
□ 평일 오후 (13~18시)
□ 평일 저녁 (18~21시)
□ 주말
□ 아무때나 괜찮습니다
```
> 내 편의용이 아니라 **신청자 안심용**. "아무때나 전화 오는 거 아니구나" → 제출률·통화 성사율 동시 상승.

**5. 미리 묻고 싶은 게 있다면** — `장문형` *(선택)*
> 안내 문구: 없으면 비워두셔도 됩니다. 통화에서 편하게 물어보셔도 돼요.
>
> 서술형은 이탈 유발 1순위. **빈칸 허용을 명시**해야 안 무서워짐.

**6. 개인정보 수집 동의** — `체크박스` *필수*
```
□ 상담 진행을 위한 연락처 수집에 동의합니다
```

```
상담 신청하기
```

## 제출 완료 화면

```
신청 감사합니다.

용팀장이 직접 전화드립니다.
보통 1~2일 안에 연락드리며, 늦어도 3일은 넘기지 않습니다.

모르는 번호로 전화가 올 수 있으니 놓치지 말아주세요.
```
> **"직접"**과 **"1~2일"**이 핵심. 언제 올지 모르는 연락은 불안하고, 불안하면 신청을 후회함.
> 동시에 나 자신에게 거는 강제성.

```

그 상태로 6개월 지나면 그냥 6개월이 지나는 겁니다.

10분만 통화하시죠.
지금 상황에서 뭐부터 해야 하는지 말씀드리고,
실전반이 안 맞으면 안 맞는다고 말씀드립니다.

사업자등록증 없어도, 매출 0원이어도 괜찮습니다.
그런 분들 전화가 오히려 더 많습니다.

▶ 신청: [링크]
소요시간 30초 (이름·연락처·현재상황)
```

> **"소요시간 30초"** 필수. 폼 링크 안 누르는 이유 1위가 "얼마나 걸릴지 몰라서".

# 2. 라이브 사전신청 폼

## 설계 원칙

상담 폼과 목적이 정반대다.
상담 폼 = **통화로 데려가는 폼** / 사전신청 폼 = **명단만 따는 폼**.

무료 라이브는 이미 무료라 설득이 필요 없다. 뭔가 더 물어보면 딱 그만큼 명단이 준다.
**목표는 단 하나 — 861명 중 최대한 많은 연락처.**

---

## 폼 제목

```
[무료] 구매대행 라이브 강의 — 사전신청
```

## 폼 설명문

```
0월 0일 (요일) 밤 0시, 유튜브 라이브로 진행합니다.

신청하시면 시작 전에 알림 보내드립니다.
못 오셔도 다시보기 링크 보내드리니 일단 신청해두세요.

무료입니다. 결제 없습니다.
```

**세 줄이 각각 일을 한다**
1줄 = 언제인지 / 2줄 = **알림 + 다시보기 = 신청할 이유 두 개** / 3줄 = 무료 못박기

특히 **"못 오셔도 다시보기 보내드리니 일단 신청해두세요"** 가 핵심.
라이브 시간에 못 오는 사람이 신청을 안 하는 게 최대 누수인데 이 한 줄이 막는다.
덤으로 다시보기 링크를 보낼 명분까지 생긴다.

---

## 문항 (딱 2개 + 동의)

**1. 성함** — `단답형` *필수*

**2. 연락처** — `단답형` *필수*
> 안내 문구: 라이브 시작 전 알림과 다시보기 링크를 보내드립니다.

**3. 동의** — `체크박스` *필수*
```
□ 라이브 안내를 위한 연락처 수집에 동의합니다
```

### ⚠️ 더 넣지 말 것

"현재 상황도 물어볼까?" "궁금한 점도 받을까?" 하는 유혹이 온다.
**한 칸 늘릴 때마다 명단이 준다.**
현재 상황은 상담 폼에서 물으면 되고, 이 폼의 유일한 일은 그 사람을 상담 폼까지 데려오는 것.

---

## 제출 버튼

```
신청하고 링크 받기
```

## 제출 완료 화면

```
신청 완료됐습니다.

라이브 링크는 시작 1시간 전에 문자로 보내드립니다.
당일 알림도 한 번 더 갑니다.

0월 0일 (요일) 밤 0시에 뵙겠습니다.
```

```
무료입니다.

```

## 리마인드 시퀀스 — 사전신청의 진짜 가치

명단을 따는 이유가 이것. **문자 5번 보낼 권리**를 사는 것.

| 시점 | 내용 |
|---|---|
| 신청 직후 | `[용팀장] 사전신청 완료됐습니다. 0/0(요일) 밤 0시 라이브, 시작 1시간 전 링크 보내드릴게요.` |
| 전날 저녁 | `[용팀장] 내일 밤 0시 라이브입니다. 링크는 내일 보내드립니다.` |
| 당일 1시간 전 | `[용팀장] 오늘 밤 0시 시작합니다. ▶ [링크]` |
| 시작 5분 전 | `[용팀장] 곧 시작합니다. ▶ [링크]` |
| **다음 날** | `[용팀장] 어제 라이브 다시보기입니다 ▶ [링크] / 1:1 상담 신청 ▶ [링크]` |

**마지막 줄이 제일 중요하다.** 다시보기 링크에 상담 신청을 붙여 보내는 것 —
현재는 이게 없어서 라이브 본 사람들이 그냥 증발하고 있다.

라이브 못 본 사람에게도 이 문자가 간다. 사전신청 해놓고 못 들어온 사람이
오히려 미안함 반 관심 반이라 다시보기를 잘 본다.

---

## 예상 효과

| 항목 | 현재 | 사전신청 도입 후 |
|---|---|---|
| 명단 확보 | **0명** | 사전신청자 전원 |
| 라이브 실참여 | 동접 150 | 알림 3회 → 상승 |
| 라이브 후 접촉 | 단톡방 공지뿐 | **개별 문자 가능** |
| 못 본 사람 회수 | 불가 | 다시보기 발송으로 회수 |

---

## ⚠️ 문자 발송 주의

광고성 정보 표시 의무가 있다. 사전신청 동의를 받았으니 안내 문자는 괜찮지만,
**마지막 날 상담 신청 링크를 보낼 때는 `(광고)` 표기 + 수신거부 번호**를 넣는 게 안전하다.
문자 대행사(문자나라, 뿌리오 등)를 쓰면 자동 처리된다.

# 3. D-8 체크리스트 (자기선별 콘텐츠)

## 설계 원칙

목적이 두 개인데 방향이 반대다.

- 안 맞는 사람을 **진짜로 밀어낸다** → 신뢰 생성
- 맞는 사람은 **"이거 완전 내 얘긴데"** → 강한 당김

**핵심은 ❌ 리스트를 진짜로 아프게 쓰는 것.**
여기서 봐주면 전체가 광고가 되고, 광고가 되면 아무도 안 움직인다.

---

## 단톡방 카피 (전문)

```
[실전반, 이런 분은 오지 마세요]

다음 주 무료 라이브 앞두고 솔직하게 적습니다.
매 기수 상담하다 보면, 안 맞는데 오시는 분들이 계세요.
서로 시간 아끼자는 뜻으로 먼저 적습니다.


❌ 이런 분은 오지 마세요

· 한 달 안에 월 500만원 만들고 싶은 분
  → 안 됩니다. 그렇게 말하는 사람이 있으면 그쪽이 거짓말입니다.

· 자동으로 굴러가는 걸 원하는 분
  → 자동화는 손으로 100번 해본 다음 얘기입니다. 순서가 있습니다.

· 하루 1시간도 못 내는 분
  → 강의만 듣고 상품 안 올리면 아무 일도 안 일어납니다.

· 아이템만 찍어주면 하겠다는 분
  → 아이템 찍어주는 강의 아닙니다. 찾는 법을 알려드립니다.

· 이미 월 1,000만원 넘게 하시는 분
  → 제가 드릴 게 별로 없습니다. 다른 데 가시는 게 맞습니다.


✅ 이런 분은 오세요

· 사업자등록증도 스마트스토어도 없는 분
  → 그 상태로 오신 분들이 제일 빨리 갑니다. 지울 습관이 없어서요.

· 스토어는 만들어놨는데 몇 달째 방치 중인 분
  → 뭘 올려야 할지 몰라서 멈춘 겁니다. 그 지점만 뚫으면 됩니다.

· 상품은 올리는데 매출이 안 나오는 분
  → 대부분 상품 문제가 아니라 상품명·카테고리 문제입니다.

· 유튜브 보고 따라 해봤는데 중간에 막힌 분
  → 영상으로 못 알려주는 게 있습니다. 그거 하려고 오프라인 합니다.

· 혼자 하다가 물어볼 사람이 없어서 지친 분
  → 이게 제일 큽니다. 실전반 절반은 사실 이것 때문에 옵니다.


읽어보시고 ✅ 쪽에 두 개 이상 걸리면
다음 주 무료 라이브 꼭 들어오세요.

❌ 쪽이 더 많으면 안 오셔도 됩니다. 진심입니다.

▶ 라이브 사전신청: [링크]
```

## 작동 원리

| 장치 | 효과 |
|---|---|
| **❌를 먼저** 배치 | 광고가 아니라 조언으로 읽힘 → 끝까지 읽음 |
| "월 1,000만원 이상은 오지 마세요" | **돈을 거절함** → 신뢰 폭발. 이 한 줄이 제일 셈 |
| "그쪽이 거짓말입니다" | 다른 강의와 선 긋기 |
| ✅ 첫 줄에 **초보** 배치 | 이탈하던 초보에게 정면 입장 허가 |
| "지울 습관이 없어서요" | 초보의 약점을 **강점으로 재해석** |
| "혼자라서 지친 분" | 기능이 아닌 **감정** — 반응 최다 예상 |
| "두 개 이상 걸리면" | 스스로 판정 = 자기설득 |
| "안 오셔도 됩니다. 진심입니다" | 압박 제거 → 역설적으로 신청 증가 |

## 운영 팁

**1. ❌ 항목은 실제 사례로 계속 갈아끼운다**
상담 전화 중 "이 사람은 진짜 안 맞는데" 싶은 순간을 메모 → 다음 기수 ❌ 리스트에 반영.
기수를 거듭할수록 카피가 날카로워지고 신뢰도 올라간다.

**2. ✅ 항목 중 반응 좋은 걸 추적한다**
댓글·DM이 붙는 항목 = **실제 핵심 고객**. 다음 유튜브 영상 주제로 바로 전용.
