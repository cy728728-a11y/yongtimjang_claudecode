## 1. 왜 지금 자료로는 부족한가

| | 지금 배포 자료 6종 | 오션 배포 자료 |
|---|---|---|
| 성격 | 도구(프롬프트·가이드) | 읽을거리(책) + 바로 쓸 리스트 |
| 받은 뒤 행동 | 써 보려면 세팅이 필요 → 대부분 안 연다 | 5분이면 한 챕터, 엑셀은 바로 열어 본다 |
| 강의로 이어지는 장치 | 없음 | 챕터마다 "여기서 더 들어가면 → 정규 강의" 상자 |
| 신뢰 장치 | 라이브 화면 | 실제 숫자 해부(원가·배송·수수료·마진), 직접 판 상품 목록 |

→ 도구는 "이미 결심한 사람"에게만 쓸모가 있다. 결심 전인 사람에게 필요한 건 **읽히는 이야기 + 내 사업에 바로 대 볼 숫자**다.

## 2. 무엇을 만드나 — 얇은 책 3권 + 부록 2개

권당 15~20분, PDF(우측 하단 쪽번호), 불특정다수 배포 기준으로 넉넉하게.

### 0권 · 먼저 읽어 주세요 (5쪽)
- 이 자료가 뭐고, 왜 순서대로 읽는지, 챕터마다 행동 하나

### 1권 · 구매대행이 노가다가 되는 이유, 그리고 AI 직원의 하루
- 퇴근 후 2시간 하던 시절 → 지금 하루 (1109 라이브 13~33장을 글로 옮김: 00:01 판매상품 잠금, 07:30 자동 점검, 효자상품, 상세페이지, 휴대폰으로 지시)
- **비교표 한 장**: "프로그램 여러 개 갈아타기" vs "AI 직원 하나가 직접 일하기" — 월 비용, 맡길 수 있는 범위, 사람이 남는 일 (경쟁 강사 이름은 안 씀)
- 여기서 더 들어가면 → 실전반 1주차

### 2권 · 효자상품이 계속 팔리는 구조
- 이게 용팀장의 핵심 원칙(한 번 대박 X, 팔리는 상품이 계속 팔리게)
- 상세페이지만 바꾼 전후 사례(1109 24장), 썸네일, 옵션명 정리, 카테고리 함정(35장)
- 숫자 해부 1건: 판매가 − 원가 − 배송 − 수수료 = 마진 (실제 판매 상품 하나)
- 여기서 더 들어가면 → 실전반 상세·썸네일 주차

### 3권 · 많이 올려도 안 터지는 법 — AI 검수
- 대량 소싱의 진짜 위험은 금지품: 콘크리트 타정기 사고, KC 민원 삭제 사례
- AI가 하루 수천 개를 거르는 구조(그림 1장), 판매금지 품목 표
- 여기서 더 들어가면 → 실전반 소싱·검수 주차

### 부록 A · 시즌 키워드 리스트 (엑셀)
- 오션 부록2와 같은 형식이되 **검색량을 붙여서**. 오션 겨울 리스트는 확인해 보니 상위 9개 중 8개가 검색량 상위 40만 키워드 밖(거의 안 찾는 말)이었다 → "검색량 확인된 리스트"가 그대로 차별점.
- 재료: 불사자 시즌 키워드 데이터(달별 성수기). 단, 원자료엔 브랜드·영화관·금시세 같은 잡음이 대부분이라 **구매대행으로 팔 수 있는 것만 거르는 단계**(우리 검수 금지 규칙 재사용)가 필요.

### 부록 B · 내가 실제로 판 상품 N선
- 재료: 판매상품 잠금 기록(10/13 이후 약 2,270개).
- ⚠ 결정 필요: 효자상품 목록을 1,000명에게 공개하면 그대로 따라 올리는 사람이 생긴다. 안: ① 시즌 지난 상품만 ② 상품명 대신 "품목 유형" 수준 ③ 부록 B 빼기.

## 3. 배포 위치 (퍼널 안에서)
- 라이브 끝 자료 묶음에 추가(기존 6종은 실전반 맛보기로 유지)
- 단톡방 "용팀장 - AI로 셀링하는 사람들" 배포 → 각 권 마지막 쪽에 상담·신청 링크
- 다음 라이브 사전신청 미끼로도 사용(명단 확보)
