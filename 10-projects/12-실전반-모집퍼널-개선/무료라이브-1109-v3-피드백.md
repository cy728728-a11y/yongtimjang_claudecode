## 0. 결론 먼저 (우선순위 순)

1. **카톡 공지에서 약속한 것 3개가 덱에 없다** → 9/28에 공지·라이브가 어긋났던 실수가 그대로 반복될 판이다. (자료 암호 3번 공개 / 3교시 "내 반복 업무 받아서 그 자리에서 맡겨 보기" / 1:1 자동화 진단 15분). 아직 안 나간 공지(D-4·D-3·D-2)를 고치든, 덱에 넣든 하나로 맞춰야 한다. **추천: 덱에 넣는다** (셋 다 시청 유지·참여에 좋은 장치라서).
2. **본 판매(5기 소개)가 너무 늦다.** 덱 메모 기준으로도 42장이 약 1:50, 실제로는 지난 두 번처럼 시연이 늘어지면 2시간 넘어서 나온다. 9/28은 2:30, 10/6은 1:47(동시 시청 30명)에 처음 나왔다. → **잘라낼 장 6~8개**(§3)를 빼서 공지 시간표대로 20:45 안에 "🔥 중요 공지"를 시작한다.
3. **월요일 광고 보고서 시연(17·18장)은 지금 상태론 못 보여 준다.** 10/27부터 맥북 광고 작업이 꺼져 있다. 맥미니 쪽 광고 결과 시트로 보여줄지 결정하고, 11/9 아침에 결과가 나왔는지 확인해야 한다. 15장 아침 카톡의 "물갈이 정상" 줄도 같은 이유로 실제 화면과 다를 수 있다.
4. **"오늘 드린 것 vs 실전반에서 채울 것"을 한 장으로 보여 주는 슬라이드가 없다.** 두 라이브 모두 이 '빈칸'이 약했다(9/28은 5점 만점에 2.5점, 10/6은 "거의 없음"). 시연마다 붙인 "5기는 받아서 씁니다" 한 줄은 좋다. 그런데 이걸 모아서 보여 주는 장이 없으니 판매 구간이 "구성·일정 설명"에 그친다. → 새 슬라이드 2장(§4).
5. **입에서 나오면 안 되는 말 목록**을 모니터 옆에 붙인다(§6). 지난 두 번 모두 "다 알려 드려요", "시간 많이 남았어요", "빨리 넘어갈게요", 가구매 발언이 나왔다. 덱이 아무리 좋아도 이 말 하나가 판매를 꺼 버린다.

**잘된 점부터 인정할 것**: v3는 지난번 문제를 이미 많이 고쳤다. 30초 소개, 시작부터 판매 예고("마지막에 5분 얘기할게요"), 상담 링크 채팅 고정, 가격을 입으로 말하는 대본(50장), 오늘 자정 가격 잠금, LIVE 05 직후 중간 안내(28장), FAQ 12개까지 다 들어가 있다. **문제는 덱 내용이 아니라 순서·길이·공지와의 일치**다.

## 2. 공지 ↔ 덱 불일치 (가장 먼저 해결)

| 카톡 공지에서 약속한 것 | v3 덱 | 처리 |
|---|---|---|
| D-4: 자료 암호 **시작·중간·끝 3번** 공개 | 끝에 한 번(54장, 1109) | **덱을 3단으로**: 1차 = 기존 자료 5종(오프닝) / 2차 = 쉬는 시간(룰렛 때) / 3차 = NEW 상세 프롬프트(마지막). 54장은 3차 공개 장으로 |
| D-4: 1:1 **"내 스토어 자동화 진단" 15분** 3명 | "마켓 점검" 3분 (2·36·54장) | 덱 문구를 "자동화 진단 15분"으로. 10/6엔 마켓 점검 지원자가 3명뿐이었다. 상담과 이어지는 "진단 통화"로 바꾸는 게 맞다 |
| D-3 시간표: 1교시 디지털 노가다 → 2교시 어젯밤 AI → **20:15 쉬는 시간** → **3교시 내 업무 어디까지** → **20:50 중요 공지** → 21:10 Q&A | 시간표 장 없음. 디지털 노가다는 41장(끝), 3교시 해당 구간 없음 | §3 새 순서로 덱을 시간표에 맞춘다. 화면 오른쪽에 시간표 띄워 두기(기획 §2) |
| D-2: 준비물 "매일 반복하는 일 3개" → **3교시에 채팅으로 받아서 분류 + 하나는 실제로 AI한테 시켜 봄** | 39장 마지막 칸에 "채팅 남겨 주세요" 한 줄 | **3교시를 새로 만든다**(§4-③). 참여형이고 "혼자 하면 막히는 지점"을 보여 줄 수 있어 판매 직전 구간으로 제일 좋다 |
| D-6 이후 공지: "광고 꺼진 거 정리" 등 | 17·18장 광고 시연 | §0-3 결정에 따름 |

> 9/28 교훈: 공지에선 "상품명 맨 앞 두 단어가 제일 세다"고 해 놓고 라이브에선 "위치 상관없다"고 했다. 공지를 본 사람이 제일 열성 시청자다.

## 4. 새로 넣을 슬라이드 4장

### ① "오늘 보신 것 / 5기에서 채우는 것" (38장 다음, 42장 앞)

```
              오늘 보신 것            5기에서 채우는 것
자는 동안     잠긴 결과 화면          내 스토어 기준으로 그 루틴 켜기 (4강)
효자상품      결과 상품명             효자상품 매뉴얼 파일 + 순위 기록 시트
상세페이지    전후 비교 + 프롬프트     검수·반영 매뉴얼 (지어낸 말 잡는 것까지)
옵션·카테고리  불사자가 바뀌는 장면     내 계정에 출입카드 연결 (1강)
휴대폰         보는 장면               내 폰 연결까지 끝내고 귀가 (1강)
판단 기준      "기준이 있어야 한다"    그 기준을 내 스토어에 세우기 (2·3강)

         오늘은 '결과'를 보셨고, 5기는 '만드는 법과 파일'을 가져가십니다
```

**대사**
> 오늘 보신 거 한 장으로 정리해 볼게요. 왼쪽이 오늘 보신 거예요. 전부 결과예요. 잠긴 화면, 바뀐 상품명, 바뀐 상세.
> 오른쪽이 5기에서 가져가시는 거예요. 그 결과를 만드는 매뉴얼 파일이랑, 그걸 여러분 컴퓨터에 까는 거요.
> 오늘 일부러 안 보여 드린 게 있어요. 효자상품 매뉴얼 안쪽, 상세 검수 기준 같은 거요. 그건 녹화로도 밖에 안 나가고, 강의장에서만 열어요.

### ③ 3교시 진입: "여러분 일, 어디까지 맡길 수 있을까" (공지 D-2 약속)

```
   채팅에 남겨 주세요: "내가 매일 반복하는 일" 하나
   
   ✅ 지금 맡길 수 있다     ⚙️ 세팅하면 맡긴다     🙋 아직은 사람 몫
```

**진행**: 채팅 5~6개를 읽고 세 칸으로 나눈다. 그중 **하나는 그 자리에서 클로드 코드에 시킨다.** 결과가 30초 안에 나오는 걸로 고른다. 예: 시트 정리, 문구 만들기, 상품 3개 옵션명 정리.
**미리 준비**: 많이 나올 답 5개를 예상하고 각각의 답변을 정해 둔다. 예: CS 답변(⚙️ 만드는 중), 주문 확인(⚙️), 상품명(✅), 소싱 판단(🙋), 배송 조회(⚙️ 만드는 중).

**대사**
> 준비물 기억하시죠? 매일 반복하는 일 3개. 지금 채팅에 하나만 남겨 주세요.
> (읽으면서) 아, "옵션명 정리". 이건 지금 바로 맡겨요. 오늘 보셨죠. … "CS 답변". 이건 저도 지금 만들고 있어요. 거의 다 됐어요. … "뭐 팔지 고르기". 이건 아직 사람 몫이에요. 이건 제가 판단해요.
> 그럼 하나는 지금 바로 시켜 볼게요.

### ④ "혼자 하시면 여기서 막힙니다" (37장 다음, 공지 직전)
10/6 마지막에 지나가듯 한 말("혼자 하기엔 좀 어렵긴 해요")을 앞으로 당겨 구체적으로 만든 장이다.

3  매일 돌리기         예약 실행·점검 카톡까지 가야 '직원'이 됩니다

**대사**
> 아까 직접 해 보셔도 된다고 했죠. 진짜예요. 그런데 해 보시면 딱 세 군데서 막혀요.
> 첫째, 설치하고 연결하는 데서 대부분 멈춰요. 둘째, 처음 시키면 엉뚱하게 해요. 제가 기준을 안 줬으니까요. 셋째, 매일 혼자 돌아가게 만드는 거. 여기까지 가야 직원이에요. 아니면 그냥 똑똑한 도구고요.

(9/28·10/6처럼 "1분만 기다렸다가"는 하지 않는다. 늦게 온 분용 인사는 2교시 시작 때 한 번만.)
