## 1. 현재 퍼널 (감으로 추정한 숫자)

```
유튜브 (영상당 조회수 300 이하)
        ↓
단톡방 861명
        ↓  ← 라이브 링크만 뿌림, 명단 확보 0
무료 라이브 (동시접속 150명 미만)
        ↓  ← 실제 고유 시청자는 300~450명 추정 (미확인)
        ↓  ★ 유일한 병목 (전환율 2~7%)
유료 신청서 10명
        ↓  100% ← 자발결제 5 + 전화 클로징 5
등록 10명 / 목표 20명
```

**핵심 발견: 신청서를 쓴 사람은 100% 등록한다.**
→ 신청서 작성 수만 20명으로 올리면 목표 달성. 유입 확대는 지금 불필요.

---

## 2. 진단 — 병목을 만든 원인 6가지

| # | 문제 | 근거 |
|---|---|---|
| 1 | 무료라이브에 **사전신청이 없어 명단 0** | 링크만 뿌림 → 시청자 리타겟 불가 |
| 2 | 라이브 → 유료신청 사이 **중간 사다리 없음** | 전환율 100%인 전화 무기를 이미 결심한 소수한테만 사용 |
| 3 | 신청서 **월매출 서술형**이 초보를 걸러냄 | 신청자 대부분이 기존 셀러. 유입 주력인 초보가 자격미달로 자진 이탈 |
| 4 | 마감을 세게 못 검 | **통제 불가능한 정원**에 희소성을 걸어서 (겁이 아니라 무기 선택 오류) |
| 5 | 861명 알림권을 **5번밖에** 안 씀 | 10일간 홍보 총 5회 |
| 6 | 실제 숫자를 모름 | 동시접속자만 봄. 고유 시청자·전환율 기준선 없음 |

### 짚고 갈 것
- **정원 20명은 정원이 아니라 목표였음.** 물리적 상한이 아니라 "차면 만족스러운 숫자".
  → 10명은 미달이 아니라 그냥 10명. 미달이라 부르니 쪽팔림이 생기고, 쪽팔림이 마감을 막았음.
- 자기충족 루프: `신청 저조 → 자신감 하락 → 마감 약함 → 긴장감 없음 → 신청 저조`
- **매일 아침 명언 올리기는 위 6개 중 아무것도 못 고침.** 단, "매일 아침 861명 알림권" 슬롯 자체는 최고 자산 → 카운트다운에 쓸 것.

## 3. 고객이 실제로 한 질문 (설득은 이미 끝난 상태)

> 오프라인 하루 못 오는데 녹화본 되나요 / 추후 강의일정 따로 주시나요 /
> 사업자등록증도 없고 스마트스토어도 없는 초보도 되나요 /
> **모집 언제인가요 / 정원 다 찼나요 / 다음 기수 인상 가격 얼마인가요** /
> 상담받고 싶은데 통화 가능할까요

**"이거 하면 돈 벌리나요"를 물은 사람이 0명.** 유튜브가 설득을 끝내놨음.
→ 단톡방의 역할은 설득이 아니라 **대기열 관리**.
→ 고객이 먼저 희소성(정원·인상)을 물어봄 = 그 무기가 통한다는 증거.
→ "상담받고 싶다"는 사람이 스스로 창구를 뚫음 = 중간 사다리 수요의 증거.

## 4. 실행 항목

### 즉시 (다음 기수 전)

- [ ] **유튜브 스튜디오에서 지난 무료라이브 실측** — 고유 시청자 수 / 조회수 / 평균 시청 지속 시간
- [ ] **무료라이브 사전신청 신설** — 이름 + 연락처 **2칸만**. 링크는 신청자에게 발송
- [ ] **1:1 상담 신청 창구 신설** — 이름·연락처·현재상황 3칸. 유료신청서와 별개
- [ ] **유료 신청서 월매출 → 선택지 전환**

```
현재 상황 (택 1)
□ 아직 시작 전 — 뭐부터 할지 모르겠다
□ 스토어는 만들었는데 매출이 없다
□ 월 100만원 미만
□ 월 100~500만원
□ 월 500만원 이상
```
※ 앞 두 칸이 "초보도 자리 있다"는 신호

- [ ] **서술형 축소** — `답답한점` + `묻고싶은것` → 1칸 통합 (나머지는 어차피 전화에서 물음)

### 목표 퍼널 (수정 후)

```
라이브 사전신청(2칸) → 라이브 → 상담신청(3칸) → 전화 → 유료신청 → 등록
```
전환율 100%짜리 전화 무기를 **훨씬 많은 사람**에게 쓰는 구조.

## 5. 희소성 무기 교체

| 무기 | 통제 | 쓸까 |
|---|---|---|
| 정원 "20명 마감!" | ❌ 불가 — 남이 신청해줘야 사실이 됨 | 쓰지 않음 |
| **날짜** "8월 25일 자정 마감" | ✅ 100% | 사용 |
| **가격** "다음 기수부터 N만원 인상" | ✅ 100% | 사용 |
| **특전** "이번 기수만 녹화본 평생 제공" | ✅ 100% | 사용 |

날짜·가격·특전은 **3명이 오든 30명이 오든 무조건 진짜**. 쪽팔릴 구석 0.
→ **한 번 지킨 마감은 다음 기수의 신뢰가 된다.**

## 6. 10일 카운트다운 캘린더 (홍보 5회 → 10회)

| 날 | 아침에 올릴 것 | 목적 |
|---|---|---|
| D-10 | 라이브 예고 + **사전신청 링크** | 명단 확보 |
| D-9 | 수강생 결과 캡처 1장 (초보 출신으로) | 증거 |
| D-8 | "이런 분께 맞습니다 / 안 맞습니다" 체크리스트 | 자기선별 |
| D-7 | 라이브에서 다룰 것 3줄 예고 | 기대 |
| D-6 | 자주 받는 질문 1개 답 (사업자 없어도 되나요) | 초보 안심 |
| **D-5** | 🔴 **무료 라이브** + 방송 중 링크 3회 | 유입 |
| D-4 | 다시보기 + **상담신청 안내 ①** | 회수 |
| D-3 | 초보 출신 후기 + **가격 인상 예고** | 긴급성 |
| D-2 | "이 질문 많았습니다" Q&A + **안내 ②** | 이탈 회수 |
| D-1 | **내일 자정 마감** 못박기 + **안내 ③** | 마감 |
| D-day | 오전 / 오후 / 자정 3회 마감 리마인드 | 라스트콜 |

**원칙 3개**
1. 매일 링크를 건다. 링크 없는 날 = 버린 날
2. **라이브 안 본 700명이 진짜 시장.** D-4 이후 콘텐츠는 라이브 안 본 사람도 이해되게
3. 자정 마감은 반드시 지킨다
