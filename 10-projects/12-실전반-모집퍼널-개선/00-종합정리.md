# 한 줄 요약

> **문제는 유입이 아니다. 신청서 작성 수 하나다.**
> 신청서를 쓴 사람은 100% 등록했다. 신청서만 10명 → 20명이면 정원이 찬다.

# 1부. 오늘 확인한 사실들

## 현재 자산

| 항목 | 숫자 |
|---|---|
| 단톡방 인원 | **861명** |
| 하루 질문 | 10개 이하 (참여율 약 1%) |
| 유튜브 조회수 | 편당 300 이하 |
| 무료 라이브 | 동시접속 150명 미만 |
| 유료 신청서 | **10명** |
| 등록 | **10명** (목표 20명) |

## 현재 퍼널

```
유튜브 (조회수 300 이하)
        ↓
단톡방 861명
        ↓  ← 라이브 링크만 뿌림. 명단 확보 0
무료 라이브 (동시접속 150명 미만)
        ↓  ← 실제 고유 시청자는 300~450명 추정 (미확인)
        ↓  ★★★ 병목은 여기 하나뿐
유료 신청서 10명
        ↓  100% ← 자발결제 5 + 전화 클로징 5
등록 10명
```

## 🔑 가장 중요한 발견

**신청서를 쓴 사람은 100% 등록했다.**

자발 결제 5명 + 내가 전화해서 5명 = 10명. 신청서 작성자 전원이 등록했다.
→ 내 전화 클로징이 그만큼 강하다는 뜻이고,
→ **퍼널에서 안 새는 유일한 구간이 거기**라는 뜻이다.

그러니까 **신청서 작성 수만 20명으로 올리면 끝난다.**
- 유튜브 조회수 300 → 안 건드려도 됨
- 라이브 참여자 150 → 안 늘려도 됨
- 필요한 건 **150명 중 전환율을 6.7% → 13%로**

# 2부. 병목을 만든 원인 6가지

## ① 무료라이브에 사전신청이 없어 명단이 0이다

링크만 뿌리고 끝났다. **라이브를 본 사람이 누군지 모른다.**
→ 라이브 후 개별 연락 불가 / 못 본 사람 회수 불가 / 실제 몇 명이 봤는지도 모름

## ② 라이브와 유료신청 사이에 중간 사다리가 없다

```
라이브 시청 →  [ 없음 ]  → 유료 신청서 → 전화 → 등록
   150명                      10명       100%   10명
```

**순서가 거꾸로 됐다.**
전환율 100%짜리 무기가 전화인데, 그 무기를 쓰려면 상대가 **먼저 유료 신청서를 써야** 한다.
즉 사람들은 **결제 결심을 다 끝낸 뒤에야** 나와 통화하게 된다.
아직 망설이는 140명은 나와 얘기할 방법이 아예 없다.

> 실제로 이렇게 물어본 사람이 있었다 — **"상담을 받아보고 싶어서 그러는데 통화 가능하실까요?"**
> 이 사람이 정답을 알려준 것. 공식 창구가 없으니 그렇게 용기 낸 사람 말고는 조용히 사라졌다.

## ③ 신청서의 월매출 서술형이 초보를 걸러낸다

현재 신청서 항목 10개, 서술형 3개. 그중 **월매출**이 문제다.

라이브 보고 마음이 뜨거워진 초보가 폼을 열었는데 "월매출" 칸이 나온다.
아직 시작도 안 한 사람은 뭐라고 쓰나? 0원?
→ 그 순간 **"아 나는 아직 자격이 안 되나 보다"** 하고 창을 닫는다.

**실제로 신청자 대부분이 기존 셀러였다.** 초보가 적었다.
그런데 유튜브로 들어오는 사람 대부분은 초보다.
→ **유입의 주력을 신청서가 문 앞에서 돌려보내고 있다.**

> 실제 질문: "사업자등록증도 없고 스마트스토어 아이디도 없는 처음 시작하는 사람도 할 수 있나요?"
> 이 사람이 신청서에서 월매출 칸을 봤다고 상상해보면 답이 나온다.

## ④ 마감을 세게 못 걸었다 — 겁이 아니라 무기 선택 오류

내 말: *"사실 자신이 없어서 마감공지를 세게 못하는편"*
→ 이유는 **A. 세게 질렀다가 10명이면 쪽팔려서.**

### 여기 숨어있던 잘못된 가정

> **"사람들이 몇 명 신청했는지 안다"** 는 가정.
>
> **아무도 모른다.** 861명 중 내 정원이 몇 명 찼는지 아는 사람은 0명이다.
> 내가 말 안 하면 모른다. 유일하게 아는 사람은 나뿐이고, 나 혼자 쪽팔려했다.

### 진짜 원인 — 통제 못 하는 것에 희소성을 걸었다

| 무기 | 통제 | 무서운가 |
|---|---|---|
| **정원** "20명 마감!" | ❌ 남이 신청해줘야 사실이 됨 | 무섭다 |
| **날짜** "8/25 자정 마감" | ✅ 내가 마감하면 사실 | 안 무섭다 |
| **가격** "다음 기수부터 인상" | ✅ 내가 정함 | 안 무섭다 |
| **특전** "이번 기수만 녹화본" | ✅ 내가 정함 | 안 무섭다 |

날짜·가격·특전은 **3명이 오든 30명이 오든 무조건 진짜**다. 쪽팔릴 구석이 0이다.

**나는 겁이 많았던 게 아니라 무기를 잘못 골랐다.**

### 게다가 정원 20명은 정원이 아니었다

- **정원** = 넘으면 강의 질이 망가지는 **상한선**
- **목표** = 차면 내가 기분 좋은 숫자

20명은 후자였다. "그냥 20명이면 만족할 것 같아서" 정한 숫자.
목표를 정원이라 불렀기 때문에 10명이 **"미달"**이 됐고,
미달이니 쪽팔렸고, 쪽팔리니 마감을 못 걸었고, 마감을 못 거니 또 10명이 왔다.

```
신청 저조 → 자신감 하락 → 마감 약함 → 긴장감 없음 → 신청 저조
```
**완벽한 자기충족 루프. 시작점은 시장이 아니라 내 마음이었다.**

사실은 그냥 **10명이 온 것**이다. 미달이 아니라.

## ⑤ 861명 알림권을 5번밖에 안 썼다

10일 동안 홍보 총 5회. 신청서 안내는 라이브 다음날 2번이 전부.
**861명에게 매일 알림 울릴 권리**를 거의 안 쓰고 있다.

## ⑥ 실제 숫자를 모른다

동시접속자만 봤다. 동시접속은 **순간 스냅샷**이라
실제 고유 시청자는 보통 **최대 동접의 2~3배 = 300~450명**이다.

즉 전환율이 6.7%가 아니라 **2~3%**였을 수 있다.
→ 병목이 생각보다 더 심각하다. 동시에 **가능성도 더 크다.**

**마감을 못 건 것도 결국 숫자를 몰라서 자신이 없었던 것이다.**

# 3부. 원래 질문에 대한 답 — 매일 아침 명언?

## 결론: 하지 마라

명언은 위 6가지 원인 중 **아무것도 못 고친다.**

## 왜인가

고객들이 실제로 나에게 물어본 질문 전부:

> 오프라인 하루 못 오는데 녹화본 되나요 / 추후 강의일정 따로 주시나요 /
> 사업자등록증도 없고 스마트스토어도 없는 초보도 되나요 /
> **모집 언제인가요 / 정원 다 찼나요 / 다음 기수 인상 가격 얼마인가요** /
> 상담받고 싶은데 통화 가능할까요

**"이거 하면 돈 벌리나요"를 물은 사람이 단 한 명도 없다.**

→ 이 사람들은 **이미 설득이 끝난 상태**다. 유튜브가 설득을 다 해놨다.
→ 단톡방에 들어온 순간 이미 "하고 싶다"는 마음이다.
→ 그러니 **단톡방의 역할은 설득이 아니라 대기열 관리**다.

명언은 **"용팀장은 좋은 사람이다"**를 증명한다.
그런데 이 사람들에겐 그 증명이 필요 없다. 필요한 건 **언제·얼마·나도 되나·놓치면 어떻게 되나**다.

> 참고: 고객이 먼저 **"다음 기수 인상되는 가격이 얼마인가요?"**를 물었다.
> 희소성 무기가 통한다는 걸 시장이 이미 증명했다. 나만 안 쓰고 있었다.

## 단, 슬롯 자체는 금덩어리다

**"매일 아침"이라는 슬롯은 내 최고 자산이다.** 861명에게 알림 울릴 권리다.

- 명언에 태우면 → **소각**
- 카운트다운에 태우면 → **정원이 찬다**

# 4부. 실행 계획

## STEP 0. 오늘/내일 바로 — 숫자 확인

유튜브 스튜디오 → 지난 무료라이브 영상 → 분석 → 개요

- [ ] **고유 시청자 수 (Unique viewers)** ← 제일 중요
- [ ] 조회수
- [ ] 평균 시청 지속 시간

이게 있어야 **기준선**이 생긴다. 지금은 감으로 만든 숫자로 판단하고 있다.
기준선이 생기면 다음 기수부터 감이 아니라 **계산**으로 움직인다.

## STEP 1. 폼 3개 정비

| 폼 | 목적 | 문항 수 | 상태 |
|---|---|---|---|
| **라이브 사전신청** (신설) | 명단 확보 | **2개** | 만들어야 함 |
| **1:1 상담 신청** (신설) | 전화로 데려가기 | **3개** | 만들어야 함 |
| **유료 신청서** (수정) | 결제 전환 | 기존 유지 | 월매출만 손보기 |

### 유료 신청서 수정 사항

**월매출 서술형 → 선택지로 교체**
```
현재 상황 (택 1)
□ 아직 시작 전 — 뭐부터 할지 모르겠다
□ 스토어는 만들었는데 매출이 없다
□ 월 100만원 미만
□ 월 100~500만원
□ 월 500만원 이상
```
※ 앞 두 칸이 **"초보도 여기 자리 있다"는 신호**다. 지금은 그 신호가 없어서 초보가 창을 닫는다.

**서술형 3개 → 1개로**
`답답한점` + `용팀장에게 묻고싶은것` → 한 칸으로 통합. 나머지는 어차피 전화에서 묻는다.

## STEP 2. 목표 퍼널로 재설계

```
라이브 사전신청(2칸) → 라이브 → 상담신청(3칸) → 전화 → 유료신청 → 등록
        ↓                            ↓            ↓
    명단 확보                   중간 사다리    100% 무기를
                                              더 많이 사용
```

## STEP 3. 희소성 무기 교체

앞으로 마감은 **내가 100% 지킬 수 있는 것**에만 건다.

- ✅ **날짜** — "8월 25일 자정 마감"
- ✅ **가격** — "다음 기수부터 N만원 인상"
- ✅ **특전** — "이번 기수만 녹화본 평생 제공"
- ❌ **정원** — 쓰지 않는다

**한 번 지킨 마감은 다음 기수의 신뢰가 된다.**

## STEP 4. 10일 카운트다운 (홍보 5회 → 10회)

| 날 | 아침에 올릴 것 | 목적 |
|---|---|---|
| **D-10** | 라이브 예고 + **사전신청 링크** | 명단 확보 |
| D-9 | 수강생 결과 캡처 1장 (초보 출신으로) | 증거 |
| **D-8** | "이런 분께 맞습니다 / 안 맞습니다" 체크리스트 | 자기선별 |
| D-7 | 라이브에서 다룰 것 3줄 예고 | 기대 |
| D-6 | 자주 받는 질문 1개 답 (사업자 없어도 되나요) | 초보 안심 |
| **D-5** | 🔴 **무료 라이브** + 방송 중 링크 3회 | 유입 |
| D-4 | 다시보기 + **상담신청 안내 ①** | 회수 |
| D-3 | 초보 출신 후기 + **가격 인상 예고** | 긴급성 |
| D-2 | "이 질문 많았습니다" Q&A + **안내 ②** | 이탈 회수 |
| D-1 | **내일 자정 마감** 못박기 + **안내 ③** | 마감 |
| **D-day** | 오전 / 오후 / 자정 3회 마감 리마인드 | 라스트콜 |

### 원칙 3개
1. **매일 링크를 건다.** 링크 없는 날 = 버린 날
2. **라이브 안 본 700명이 진짜 시장이다.** D-4 이후 콘텐츠는 라이브 안 본 사람도 이해되게 쓴다
3. **자정 마감은 반드시 지킨다**

## STEP 5. 라이브 리마인드 문자 시퀀스

사전신청으로 명단을 따는 이유 = **문자 5번 보낼 권리**

| 시점 | 내용 |
|---|---|
| 신청 직후 | 신청 완료 + 일정 안내 |
| 전날 저녁 | 내일입니다 |
| 당일 1시간 전 | 링크 발송 |
| 시작 5분 전 | 곧 시작합니다 + 링크 |
| **다음 날** | **다시보기 링크 + 상담신청 링크** |

**마지막 줄이 제일 중요하다.** 현재는 이게 없어서 라이브 본 사람들이 그냥 증발한다.

# 5부. 목표 숫자

## 필요한 것

```
라이브 참여      150명 유지 (지금 수준, 안 늘려도 됨)
신청서 전환      6.7% → 13%
신청서 작성      10명 → 20명
등록             10명 → 20명 (전환율 100%이므로 자동)
```

초보 이탈 차단 + 중간 사다리 신설 + 안내 2회 → 10회.

# 6부. 내일 아침 할 일 (우선순위)

1. **유튜브 스튜디오 고유 시청자 수 확인** ← 이거부터. 5분이면 된다
2. **라이브 사전신청 폼 만들기** (구글폼, 2칸, 10분)
3. **1:1 상담 신청 폼 만들기** (구글폼, 3칸, 15분)

# 부록. 오늘 대화에서 나온 핵심 문장들

> **"신청서를 쓴 사람은 100% 등록했다."**
> — 퍼널에서 안 새는 유일한 구간. 여기를 넓히는 게 전부다.

> **"사실 자신이 없어서 마감공지를 세게 못하는편"**
> — 오늘 대화 통틀어 제일 큰 발견. 브레이크는 시장이 아니라 내 마음이었다.

> **"겁이 많았던 게 아니라 무기를 잘못 골랐다."**
> — 통제 못 하는 정원에 희소성을 걸었으니 무서운 게 당연했다.

> **"그냥 20명이면 내가 만족할 것 같아서 그렇게 했어"**
> — 20명은 정원이 아니라 목표였다. 그러니 10명은 미달이 아니라 그냥 10명이다.

> **"이거 하면 돈 벌리나요"를 물은 사람이 0명.**
> — 유튜브가 설득을 끝냈다. 단톡방의 일은 설득이 아니라 대기열 관리다.

> **"상담을 받아보고 싶어서 그러는데 통화 가능하실까요?"**
> — 고객이 먼저 중간 사다리를 요구했다. 창구가 없어서 나머지는 사라졌다.
