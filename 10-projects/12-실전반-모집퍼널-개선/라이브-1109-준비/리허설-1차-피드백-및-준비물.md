## 1. 한눈에

- **말투는 좋다.** 리허설 말투가 PPT 대본보다 자연스럽다. "바퀴 없는 제품에 바퀴가 생긴다", "AI 알바 20명", "앞 AI의 결과가 다음 AI의 일감" 같은 건 대본에 없던 좋은 말이다. v4 대본에 다 넣었다.
- **문제는 시간이다.** 23장까지 42분 걸렸다. 그런데 시연은 하나도 안 했다(14·18장 캡처로 대체, 룰렛 생략, 효자상품·상세 시연 미룸). 시연을 넣으면 23장 끝이 약 1시간 5분이다. 같은 속도면 5기 소개(42장)는 **1시간 50분~2시간**에 나온다. 지난 두 라이브와 같은 패턴이다.
- **줄일 곳은 정해져 있다.** 5장 하루 예고 3분, 10장 상품명 기준 설명 1분, 17장 광고 이론 2분, 20장 텀 설명 1분. 이 4곳만 대본대로 줄여도 약 6분이 빠진다. 지난번 피드백의 장 삭제(33·34~36·39·40장)까지 하면 20분 넘게 줄어든다.

## 5. 블랙 노트북 시연 준비 (리허설 끝에 말한 것)

시연은 **용팀장 불사자 계정**으로, **블랙 노트북의 오르카**에서 한다.

### 순서
1. **블랙 노트북 클로드 코드 로그인 확인**: 클로드 메인 계정(cy17281728)인지.
2. **불사자 연결을 용팀장 계정으로 바꾸기**
   - 불사자 사이트에서 **용팀장 계정**으로 로그인 → 연동 토큰 발급.
   - 블랙 노트북 터미널에서 아래 두 줄 실행. 토큰은 채팅에 붙여 넣지 말고 터미널에 직접 넣는다.
     ```
     claude mcp remove --scope user bulsaja
     claude mcp add --transport http --scope user bulsaja 'https://api.bulsaja.com/mcp' --header 'Authorization: Bearer <용팀장 토큰>'
     ```
   - **클로드 코드를 껐다 켠다.** 안 그러면 예전 계정을 계속 쓴다.
   - "불사자 내 프로필 보여 줘" → **'용팀장'이 나오는지** 확인. '부킹'이 나오면 아직 용쌤 계정이다.
3. **⚠ 그 노트북에서 밤 자동작업(00:01 잠금 등)이 도는지 확인.** 돈다면 계정을 바꾸는 순간 그 작업도 용팀장 계정으로 돈다. 라이브가 끝나면 원래 계정으로 되돌릴지 정해 둔다.
4. **시연할 상품은 용팀장 계정 상품으로 미리 고른다.** 옵션명이 지저분한 상품 3~5개(27장), 효자상품 1개(21장), 상세 바꿀 상품 1개(23장).
5. **크롬 준비**
   - 시연용 크롬 프로필 하나만 쓴다(개인 북마크·자동완성이 화면에 안 뜨게).
   - **팟쿤 확장** 설치 + 주소창 옆에 고정.
   - **GPT 로그인** — 이미지 만들기가 되는 요금제인지 확인.
   - **불사자 로그인(용팀장 계정)**.
   - 스마트스토어 판매자센터 로그인(전후 확인용).
6. **화면 공유 정리**
   - 카톡·메일 **알림 끄기**(방해 금지 모드). 팝업에 개인정보가 뜬다.
   - 클로드 코드 화면 **글씨 크게**(지난 두 번 다 "화면 작나요?" 나왔다).
   - 다른 셀러 스토어명·주문자 정보가 나오는 창은 미리 닫기.
7. **전원선 꽂기, 절전 끄기, 덮개 닫지 않기.**
8. **그 노트북으로 22~23장·27장 시연을 한 번씩 미리 돌려 보기.** 첫 연결 때 "허락하시겠어요?" 같은 확인 창이 뜨는데, 그건 라이브 전에 다 눌러 두기.

- "다 알려 드려요", "유튜브 찾아보세요", "빨리 넘어갈게요", "시간 많이 남았어요"가 나오는지.
- 마지막 1분이 "요약 3줄 → 오늘 자정 → 상담 링크 → 내일 전화"로 끝나는지.
