## Claude에게: 목표

Claude Code 세션 하나를 **직원 한 명**으로, 사용자의 업무 분야를 **팀(사무실 구역)**으로 보여 주는 가상 사무실 웹 화면을 만든다.
일하는 세션은 책상에서 타자를 치고, 쉬는 세션은 라운지로 가고, 팀마다 어느 자리가 바쁜지 한눈에 보이게 한다.

참고작(MIT 라이선스): https://github.com/d-onworks/claude-3d-frog-office
똑같이 만들지 않는다. 화면 엔진(그림 위에 캐릭터가 걷고 앉는 JS)은 가져다 쓰고, 데이터 쪽은 아래 "원본과 다른 점"대로 새로 짠다.

## 사용자는 개발자가 아니다

- 쉬운 말로 설명하고, 결론부터 말한다. 기술 용어가 나오면 한 줄로 풀어 준다.
- 묻는 건 **아래 "질문 3개"뿐**이다. 나머지는 이 문서의 기본값으로 정하고 진행한다.
- 선택지를 낼 때는 추천을 맨 앞에 두고, 사용자가 대답하지 않으면 추천대로 간다.

## 원본과 다른 점 (꼭 지킬 것)

| 항목 | 원본 | 이번에 만들 것 |
|---|---|---|
| 직원 단위 | 폴더 1개 = 1명 | **세션 1개 = 1명.** 사용자 대부분은 한 폴더에서 세션을 여러 개 연다. 원본 방식대로 하면 직원이 한 명만 나온다 |
| 직원 이름 | 폴더 이름 | 세션 이름. 대화 파일(`~/.claude/projects/*/*.jsonl`) 안에서 `"type":"custom-title"` 줄의 `customTitle`(사용자가 /rename 한 이름)을 먼저 쓰고, 없으면 마지막 `"type":"ai-title"` 줄의 `aiTitle`(자동 제목)을 쓰고, 그것도 없으면 세션 id 앞 8자를 쓴다 |
| 자리 | 빈 책상 아무 데나 | **자기 팀 구역의 책상.** 팀 배정은 설정 파일 하나로 한다 |
| 서버 | Node.js | **Python 표준 라이브러리만** 쓴다(설치할 것 없음). 화면 파일(web/)은 원본을 복사해 고친다 |

## 질문 3개 (이것만 묻는다)

**질문 1. 팀 구성.**
먼저 최근 7일 세션 이름 목록을 직접 뽑는다. 그걸 보고 팀 4~8개와 팀별 키워드 규칙을 **초안으로 만들어서** 보여 주고, "이름만 고칠 거 있으면 말해 줘"라고 묻는다.
- 예시(구매대행 셀러): 비서실(업무관리·메일) / 상품운영팀(옵션·썸네일·상품명) / 상품기획팀(상세페이지·효자상품) / 소싱팀 / CS팀 / 콘텐츠팀(유튜브·강의) / IT개발팀(스킬 만들기)
- 지금 쉬고 있는 업무가 있으면 그 팀은 `closed: true`(휴업)로 둔다.

**질문 2. 디자인.**
세 가지 시안을 **HTML 한 장에 탭으로** 만들어 보여 준다. 사용자의 실제 세션 이름과 팀으로 그린다.
- A. 층별 빌딩: 팀 하나 = 층 하나. 제일 쉽고 폰에 잘 맞는다
- B. 아이소메트릭: 원본처럼 비스듬히 내려다본 한 층 오픈플랜, 팀은 파티션 구역. 제일 예쁘지만 사무실 그림을 새로 그려야 한다
- C. 픽셀아트: 위에서 본 게임풍 방 여러 개

**질문 3. 폰으로도 볼 건지.**
볼 거면 Tailscale(내 기기끼리만 잇는 무료 사설망)로 연다. 안 볼 거면 이 컴퓨터에서만 연다(추천: 일단 이 컴퓨터만).

## 만드는 순서

폴더 `claude-office/`를 만들고 그 안에서 작업한다.

```
claude-office/
  server/   server.py · sessions.py · activity.py · teams.py · snapshot.py
  web/      원본 web/ 복사본(고친 것)
  config/   office.json(포트 등) · office-map.json(팀 매핑)
  tests/    pytest — 가짜 대화 파일로 시험
  NOTICE    원본 MIT 라이선스 전문
  README.md 켜는 법·끄는 법·팀 고치는 법(쉬운 말)
```

원본 저장소는 `git clone --depth 1`로 별도 임시 폴더에 받는다. 받은 코드는 **읽고 복사만** 하고, 그 안의 스크립트(setup.mjs 등)는 실행하지 않는다. 원본의 설치 스크립트는 `settings.json`에 훅을 추가하는데, 이번 1~3단계에는 필요 없다.

### 1단계 — 데이터 서버 (그림은 원본 그대로)
- `GET /api/office`를 원본 `docs/CONTRACT.md` 형식 그대로 응답한다. 사람(Person)마다 `team`, `teamName`, `teamColor`를 붙인다
- 보여 줄 세션: 최근 6시간 안에 바뀐 대화 파일만
- 상태 판정:
  - 일하는 중: 파일이 90초 안에 바뀌었거나, 마지막 도구 호출의 결과가 아직 없음
  - 쉬는 중: 그 밖의 경우
- 대화 파일은 **끝 64KB만** 읽어서 지금 하는 일을 뽑는다. 이름 줄은 파일 앞쪽에 있을 수 있으니 이름 찾기는 따로 훑는다
- 서브에이전트 수: 대화 파일 옆 `<세션id>/subagents/agent-*.jsonl`을 센다
- 팀 배정 순서: ① `sessions`에 직접 지정한 것 → ② `rules` 키워드(대소문자 무시) → ③ 둘 다 아니면 `lobby`(로비·미배정)
- 서버는 `127.0.0.1`에만 연다. Host 헤더를 검사하고, 정적 파일은 web/ 밖으로 못 나가게 막는다
- **완료 확인**: 브라우저로 직접 열어서 오늘 연 세션들이 이름별로 따로 뜨는지, 상태가 실제와 맞는지 본다

### 2단계 — 고른 디자인 적용
- **A·C를 골랐을 때**: 원본 화면 대신 직접 그린다(CSS 또는 canvas). 데이터는 1단계 API를 그대로 쓴다
- **B를 골랐을 때**: 원본 `web/office-world.js`의 좌표(통로·책상·벽)는 원본 그림 `floor.webp` 한 장에 손으로 맞춘 값이다
  - 팀 구역이 있는 새 사무실 그림을 만든다. AI 이미지 생성을 쓰면 **비용이 드니 생성 전에 사용자에게 먼저 묻는다**
  - 새 그림에 맞춰 좌표를 다시 잰다. 주소 뒤에 `?debug`를 붙이면 점과 선이 보인다
  - 자리 배정 로직을 "자기 팀 구역의 빈 책상 → 꽉 차면 보조석"으로 고친다
- 캐릭터 모자·옷 색은 팀 색으로 칠한다(원본의 `-key` 마스크 방식). 휴업 팀 구역은 빗금으로 칠한다

### 3단계 — 편하게 켜기 (+ 폰)
- 맥: launchd(로그인하면 자동 실행), 윈도우: 작업 스케줄러. 켜기·끄기 명령을 README에 적는다
- 폰도 보기로 했으면: 서버를 `127.0.0.1`과 Tailscale 주소(100.x.x.x)에만 연다. 다른 네트워크에는 열지 않는다

### 4단계 (선택) — 승인 대기 표시
- 원본처럼 훅을 깔면 "승인 기다리는 세션이 폴짝 뛰는" 표시가 생긴다
- `settings.json`을 고치는 일이라 **반드시 먼저 백업하고**, 사용자에게 물어본 뒤에 한다

## 안전 규칙
- `~/.claude/` 안의 파일은 **읽기만** 한다. 쓰기·삭제·이동하지 않는다
- 화면에 파일 이름·명령 설명이 보인다. 강의 화면 공유나 인터넷 공개는 하지 말라고 README에 적는다
- 코드는 Python 표준 라이브러리만 쓰고, 한국어 주석, 예외 처리(try-except)를 넣는다
- 단계가 끝날 때마다 사용자에게 "지금 이렇게 보여요"를 한 줄로 알리고, 주소를 알려 줘서 직접 열어 보게 한다

## 나중에 고치는 법 (README에 그대로 넣을 것)
- **팀 이름·색·추가**: `config/office-map.json`의 `teams`
- **세션을 다른 팀으로 옮기기**: `sessions`에 `"세션이름": {"team": "팀키"}` 한 줄 추가
- **자동 분류 규칙**: `rules`의 `match`(키워드를 `|`로 이어 쓴다)
- 저장하고 브라우저를 새로고침하면 바로 반영된다
