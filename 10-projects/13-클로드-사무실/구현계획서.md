# 클로드 사무실 — 구현계획서

> 작성: 2026-10-28 · 디자인: **B안 아이소메트릭**(시안 https://claude.ai/artifact/Krc6WiJvhe5wTpfE6LyWzK)
> 참고: https://github.com/d-onworks/claude-3d-frog-office (MIT)

## 1. 목표

Claude Code 세션 하나를 직원 한 명으로 보여 주고, 직원을 팀 구역에 앉혀 **어느 팀이 일하고, 누가 멈춰 있는지**를 한 화면에서 보게 한다.
맥북에서 돌리고, 밖에서는 Tailscale로 폰에서 본다. v1은 **보기 전용**이다(세션 조작 없음).

## 2. 원본과 다른 점 (설계의 핵심)

| 항목 | 원본 개구리 사무실 | 우리 사무실 |
|---|---|---|
| 직원 단위 | 폴더(git 저장소) 1개 = 1명 | **세션 1개 = 1명**. 우리 세션은 거의 다 같은 워크스페이스 폴더라, 원본 방식이면 한 명으로 뭉친다 |
| 이름 | 폴더 이름 | 세션 이름: `customTitle`(/rename) → 없으면 `aiTitle`(자동 제목) |
| 자리 | 빈 책상 아무 데나 | **팀 구역 안의 책상**(매핑 파일로 배정) |
| 사무실 그림 | 오픈플랜 1장(책상 11개) | 팀 파티션 8구역 + 라운지 + 서버실(로봇)을 새로 그린 1장 |
| 서버 | Node.js | **Python 표준 라이브러리**(설치 의존성 0). 화면(JS)은 원본을 가져와 고친다 |
| 상태 감지 | 훅 카드 + 대화 기록 | v1은 대화 기록만 쓴다. 승인 대기 감지(훅)는 4단계 선택 |
| 로봇 직원 | 없음 | Aside 루틴·launchd 작업을 로그 시각으로 표시 |

## 3. 구조

```
~/.claude/projects/*/*.jsonl ──(읽기 전용)──▶ server.py ──GET /api/office(3초 폴링)──▶ 브라우저(web/)
office-map.yaml(팀 매핑) ──────────────────▶     │
robots.yaml(로봇 직원: 로그 경로) ──────────▶     └─ 127.0.0.1 + Tailscale IP 에만 바인딩
```

폴더: `10-projects/13-클로드-사무실/`
```
server/   server.py · sessions.py(세션 찾기·이름·상태) · teams.py(매핑) · robots.py
web/      원본 web/ 을 복사해 고침(office-world.js 좌표, 자리 배정 로직, 한국어 문구)
config/   office-map.yaml · robots.yaml
art/      사무실 배경·캐릭터 원본 그림
tests/    pytest — 세션 파싱·상태 판정·매핑
NOTICE    원본 MIT 라이선스 고지
```

## 4. 판정 규칙 (v1 기본값, 설정으로 조정)

**보여 줄 세션**: 최근 6시간 안에 바뀐 대화 파일만 보여 준다. 그보다 오래된 건 퇴근으로 보고 숨긴다.

**상태**

| 상태 | 조건 | 화면 |
|---|---|---|
| 일하는 중 | 파일이 최근 90초 안에 바뀜, 또는 마지막 기록이 도구 호출인데 결과가 아직 없음 | 책상에서 타자 + 말풍선("📖 xx 읽는 중") |
| 쉬는 중 | 90초 넘게 조용함 | 라운지·탕비실로 이동 |
| 승인 대기 | (4단계 훅 설치 후에만) | 자리에서 폴짝 + 빨간 글씨 |
| 휴업 | 팀 설정 `closed: true` | 구역에 빗금, 직원 회색 |

**팀 배정**(`office-map.yaml`)
1. `sessions:` — 세션 id나 이름으로 직접 지정하는 게 최우선
2. `rules:` — 이름 키워드 → 팀 (예: `상세페이지|오푸스|효자` → 상품기획팀)
3. 둘 다 안 맞으면 **로비(미배정)** 구역에 앉힌다. 패널에서 미배정이 보이면 내가 매핑에 한 줄 추가

```yaml
teams:
  - {key: sec,  name: 비서실,        color: "#8a6bb8"}
  - {key: it,   name: IT개발팀,      color: "#3f7fb5"}
  - {key: plan, name: 상품기획팀,    color: "#c2793a"}
  - {key: ops,  name: 상품운영팀,    color: "#2f8f6a"}
  - {key: src,  name: 소싱팀,        color: "#a0913a"}
  - {key: cs,   name: CS·권리팀,     color: "#b5566a"}
  - {key: edu,  name: 콘텐츠·강의팀, color: "#d0628f"}
  - {key: ads,  name: 광고팀,        color: "#7b8a83", closed: true}
sessions:
  "to-do-list": {team: sec, role: 업무관리}
rules:
  - {match: "업무|todo|메일|카톡|주소지|잔금", team: sec}
  - {match: "스킬|uat|세션관리|오피스|MCP|자동화 패키징", team: it}
  - {match: "상세페이지|오푸스|효자|가로러너|쿠팡|스쿠도제", team: plan}
  - {match: "옵션|썸네일|상품명|카테고리|태그|잠금|배송비", team: ops}
  - {match: "소싱|검수|키워드|벤치마크", team: src}
  - {match: "CS|권리|소명", team: cs}
  - {match: "숏폼|유튜브|하입덕|스레드|강의|라이브|실전반", team: edu}
  - {match: "광고|입찰", team: ads}
```

**로봇 직원**(`robots.yaml`): 이름, 팀, 정해진 실행 시각, 확인할 로그 파일. 로그가 최근에 바뀌었으면 "일하는 중", 예정 시각을 지나도 로그가 안 바뀌었으면 "결근"(노란 경고)으로 표시한다.
시작 목록은 물갈이(Aside), 판매상품 잠금, auto-watch 07:30, 고퀄 상세 밤 배치, 권리침해 소명이다. 로그 경로는 1단계에서 실제 위치를 찾아 채운다.

## 5. 단계

### 1단계 — 데이터 서버 (그림 없이 동작 확인)
- `server.py`: 원본 `/api/office` 응답 형식(docs/CONTRACT.md)을 그대로 따르고, 각 사람에 `team` 필드를 붙인다
- 세션 이름·상태·지금 하는 일(대화 기록 끝 64KB만 읽음)·서브에이전트 수를 채운다
- 이 단계에선 원본 화면과 개구리 그림을 그대로 띄운다. 직원이 세션별로 따로 나오는지만 확인한다
- **완료 기준**: 오늘 연 세션이 이름별로 따로 뜨고 상태가 실제와 맞는다(uat-verifier 판정)

### 2단계 — 팀 구역 사무실 그림 + 자리 배정
- 사무실 배경 1장(1536×1024 아이소메트릭): 팀 파티션 8구역에 구역당 책상 3~4개, 로비, 라운지, 탕비실, 서버실(로봇)
  - 그리는 방법: AI 이미지 생성(힉스필드). **크레딧을 쓰니까 생성 전에 견적을 보고한다.** 시안 2~3장 중 내가 고른다
- `office-world.js` 좌표(통로·책상·벽)를 새 그림에 맞춰 다시 잰다(원본 `?debug` 모드 사용)
- 자리 배정 로직: 아무 빈 책상 → **자기 팀 구역의 빈 책상**, 꽉 차면 그 구역 보조석
- 구역 위에 팀 이름 팻말, 휴업 구역은 빗금 처리
- 캐릭터: 원본 개구리·카피바라 그림을 쓰고, 모자·가디건 색을 팀 색으로 칠한다. 로봇은 서버실에 배치
- **완료 기준**: 직원이 매핑대로 자기 팀 책상에 앉는다. 미배정은 로비에 앉는다

### 3단계 — 폰 접속 + 상시 기동
- 서버를 `127.0.0.1`과 Tailscale IP(100.x)에만 바인딩한다. Host 헤더를 검사하고, 그 밖에서는 열지 않는다
- launchd LaunchAgent로 로그인하면 자동으로 켜지게 한다(`caffeinate` 불필요: 읽기만 하니까)
- 폰 화면: 사무실 그림은 가로 스크롤, 패널은 아래로 쌓는다
- **완료 기준**: 폰에서 Tailscale 주소로 열린다. 맥북을 재부팅해도 다시 뜬다

### 4단계 (선택) — 승인 대기 감지 · 우리만의 캐릭터
- 원본 훅(`office-hook.mjs`)을 Python으로 옮겨 `settings.json`에 추가한다(**설치 전 백업**, 남의 훅은 건드리지 않음). 승인 대기 폴짝이 여기서 생긴다
  - bypass 모드로 주로 일하니까 체감 효과가 작으면 생략한다
- 개구리 대신 우리 캐릭터 그림(시트 규격은 원본 docs/SPRITES.md)
- 업무판 연동: 직원을 누르면 업무판에서 그 세션의 할 일을 보여 준다

## 6. 안전·제약
- 세션 파일은 **읽기만** 한다. 쓰기·삭제 없음
- 화면에 파일 이름·명령 설명이 보이므로 폰 외의 공유는 하지 않는다(Tailscale 망 안에서만)
- 공유 작업트리라 브랜치를 바꾸지 않는다. 커밋은 이 폴더 안에서만
- Python, 한국어 주석, try-except. 원본 MIT 고지는 `NOTICE`에 남긴다
- 기능 검증은 uat-verifier, 사람은 그림(심미)만 본다
- 크레딧이 드는 일은 2단계 그림 생성뿐이고, 생성 전에 견적을 보고한다

## 7. 진행 방법
단계마다 `/gsd-quick`으로 실행한다. 단계가 끝날 때마다 uat-verifier로 판정하고, 그림 확인만 내가 한다.
