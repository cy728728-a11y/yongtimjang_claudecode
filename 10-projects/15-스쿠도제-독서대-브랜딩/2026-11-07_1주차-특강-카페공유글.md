■ 1. 특허는 4종류, 뭐가 가장 값진가

① 상표 ② 디자인 ③ 실용신안(기능 개선) ④ 발명특허(진짜 특허)

- 판매자에게 가장 값진 건 "상표"
  → 디자인·실용신안·발명특허는 최장 20년이면 끝. 특허의 본래 취지가 "기술을 공개하는 대가로 20년 보호"라서 20년 뒤엔 누구나 쓸 수 있음.
  → 상표만 기간 제한 없이 갱신 가능.
  → 쿠팡 '위너' 때문에 판매자들이 상표의 중요성을 (안 묶이려고) 알게 됐다는 얘기도 있었죠.

- 정부 지원금·대출 받을 때는 "기술특허(실용신안·발명특허)"가 으뜸
  → 신용보증기금: 보통 2~3천만 원이 기본
  → 기술보증기금: 기술이 있다는 전제면 1~2억이 기본
  → 40대 미만은 받을 확률이 특히 높고, 40대 이상도 지원 자금은 차고 넘친다. 안 찾아가서 그렇지.

- 기술특허는 빨라야 6개월, 보통 1년 반 걸림.
- 남의 특허를 사도 똑같은 권리. 단 15년 된 건 의미 없고 1~2년 내 최신 특허여야.
- 변리사 비용 참고: 상표·디자인 10~20만(비싸면 30~40만), 발명특허 150~200만. 이것만 직접 할 수 있어도 돈 꽤 절약.

■ 2. 특허 읽는 법 (치약 특허 실습)

- 리뷰 12만 9천 개짜리 치약이 상세페이지에 "특허"를 크게 걸어 놨는데, KIPRIS에서 전문을 열어 보니 성분 배합표(중량 몇 g) 특허였음. 기술이 아니라 성분표로도 특허가 나옵니다.
- 특허 심사는 제목이 아니라 내용을 보지만, 소비자는 제목만 봅니다. 그래서 특허 낼 때 "제목"이 굉장히 중요. (제목 장사)

★ 가장 중요한 개념: 청구항이 길면 권리가 넓은 게 아니라 "좁아진다"
- 청구항 = 내 권리 범위
- 청구항의 조건들은 OR가 아니라 AND(교집합). 조건 하나만 빼면 우회가 되고 침해가 아님.
- 교수님 비유: "제 집이 마곡동이에요" → 마곡동 전체. "마곡동 ○○빌딩 5층 세미나실" → 점점 좁아짐. 한 줄로 깔끔하게 쓴 특허가 가장 넓습니다.
- 그 치약 특허도 청구항 1항만 살고 3항 이후는 전부 삭제돼 있었음.

■ 3. 상품 분석 실습 — 캐리어 바퀴 커버 (교수님이 수업 30분 전에 즉석으로 고른 상품)

(1) 찾는 법: 네이버 쇼핑 → 카테고리 → 대·중·소로 내려가기. 이번엔 패션잡화 > 여행가방 > 캐리어 소품. 리뷰 400개 정도면 초보도 들어갈 수 있는 수준.

(2) 하루 판매량 추정: 리뷰를 최신순으로 놓고 "최근 3일 리뷰 합 = 하루 판매량"
  → 네이버는 10명 사면 3명이 리뷰 씀(페이 혜택). 쿠팡은 10명 중 1명도 잘 안 씀.
  → 오늘 기준 11/6·5·4 리뷰 11개 → 하루 10개로 잡음.

(3) 1688 원가: 0.1위안(8개 세트). 원가 계산은 위안 × 환율 210 × 약 1.4
  → 1.4는 부가세 10% + 관세 8~10% + 배송 10% + 수수료 10%를 러프하게 묶은 것
  → 관세는 원산지표시 증명 있으면 0~3%, 없으면 8~13%. 공산품은 8~10%로 잡으면 됨.
  → 원가 약 24원 → 계산 편하게 30원

(4) 마진: 판매가 7,800 − 수수료 10%(800) − 원가 30 = 약 6,970원
  → 하루 10개 × 30일 ≈ 월 200만 원 (쿠팡 가면 가격경쟁으로 30~50% 빠진다고 보기)
  → 물건 사입비는 30원 × 300개 = 9천 원. 색상 10개 전부 가져와도 10만 원.

(5) 진짜 돈은 1페이지 올리는 비용 (리뷰·트래픽)
  → 롤모델은 1~3년 먼저 했는데 그걸 15~20일에 따라잡으려니 돈이 든다.
  → 리뷰 건수 = 롤모델 하루 판매 × 30일 = 300건
  → 리뷰 1건 비용: 택배 3,000 + 품값 2,500 + 수수료 800 ≈ 1만 원 (스마트스토어만 하면 약 6천 원)
  → 300건 × 1만 = 300만 원은 "휘발"되는 돈
  → 거기에 물건값 7,800 × 300 = 약 234만 원, 쿠팡까지 하면 ×2 = 약 470만 원. 이건 돌아오지만 당장 현금 필요.
  → 합계 약 800만 원 필요. 그걸로 롤모델 매출의 1/2~1/3을 뺏어온다고 보면 됨(보수적으로 월 130~140만).
  → 리뷰용 상품 보낼 때 다른 상품을 하나 더 실으면 택배비 이중 지출을 아낄 수 있음.

(6) 조회수·경쟁 체크
  → "캐리어 바퀴 커버" 월간 조회수 약 1,000. 교수님 기준: 월 1,000 넘으면 초보에게 리스크.
  → 블로그를 최신순·연관으로 돌려 봤을 때 경쟁 업체가 외부 유입을 세게 밀고 있지는 않음 → 해볼 만함.
  → 스마트스토어 프리미엄 등급 기준이 월 1억 → 5천만 원으로 바뀜. 이 판매자는 원가 비중이 낮아 월 5천이면 순이익 4천 가능성.

★ 원가 비율이 너무 낮은 상품은 "특허가 걸려 있나"를 먼저 의심하고, 다른 사람들도 열심히 팔고 있는지 확인.

■ 4. 상표 — 지정상품 보는 법 (경쁜 업체 '꾸민공간' 실습)

- 종류별로 볼 곳이 다릅니다: 특허·실용신안 = 청구항 / 상표 = 지정상품 / 디자인 = 그림
- 꾸민공간은 35류(도소매)만 등록돼 있고, 지정상품에 가방 손잡이·가방 끈은 있는데 "바퀴"가 없었음. 변리사를 통했는데도 빠진 것 → 변리사 문제가 아니라 말 전달 문제.
- KIPRIS 지정상품 검색에 "바퀴"를 직접 치면 "여행용 가방 바퀴 커버"(18류)가 나옵니다. 기존 업체가 안 넣었다고 없는 게 아니에요. 찾으면 나옵니다.
- 35류에도 "여행용 가방 바퀴 커버 소매업/도매업"처럼 품목별 도소매가 따로 있음.

★ 상표 등록 전략
① 1~4등 업체 상표를 KIPRIS에서 검색
② A·B·C업체의 35류·18류 지정상품을 전부 정리
③ "합집합"으로 내 상표에 다 넣는다
④ 제품류(예: 18류) + 유통류(35류) 두 개는 꼭 나란히

- 상표 권리는 등록되면 출원일부터 시작.
- 등록 후 3년 안에 사용 안 하면 다른 사람이 취소심판 걸 수 있음. 아기용 바퀴 스티커에 상표 붙여 올려 두는 것만으로도 사용 증빙 가능.
- 상호가 출원 가능한지, 유사 상표가 많은지는 개인 면담 때 봐 주신다고 하셨어요.

■ 5. 디자인권 — 검색, 과실 책임, 2만 9천 원 전략

- KIPRIS 디자인에서 "캐리어 바퀴 커버" 41건 중 해당 없음 → 들어갈 수 있음.
- 등록자가 이름을 그냥 "커버"라고 애매하게 해 놔서 내 검색에 안 잡혔다면? 과실은 "판매자"에게 있습니다. (KIPRIS 만들어 놨으니 찾으면 되지 않았냐는 게 법의 입장) 억울하지만 그렇습니다.
- 실제로 애매하게 등록 → 중국에서 제조해 1688에 올려 둠 → 2~4년 키워서 4~5천 개 팔았을 때 형사+민사로 싹 거두는 사람들이 있다고.

★ 쉬운 방법: 찾아봐도 없는데 찜찜한 1%가 남으면, 그 물건을 그대로 디자인 출원(약 2만 6천~9천 원)
  → 심사관이 몇 달 안에 선행 디자인을 다 찾아서 결과를 보내 줌. 내가 몇 달 검색할 필요 없음.
  → 꼭 "출원인"과 "창작자"를 다르게 (내가 창작한 게 아니니까)
  → 만약 등록되면 등록하는 게 맞다. 총 약 38만 원. 남을 막는 권리 행사는 못 하지만 "특허 등록 제품" 표기는 가능하고 사기도 아님.
  → 캔톤페어에서 신제품 보고 바로 등록해 버리는 사람들이 있으니 주의.

■ 7. 스쿠도제 사이트
- 회원가입은 "사업자"로, 사업자등록증 업로드. (개인은 직구용)
- 엑셀 주문서는 끝. 사이트에서 주문서 등록 → 주문관리 → 결제관리. 중국 직원이 입금을 직접 확인하니 사이트 안에서 바로 소통.
- 주문서는 빨간 별표 필수 항목만. 옵션별로 추가, 사진은 색상별 한 번씩. 1688에서 옵션 이미지 다운로드해 두면 계속 재사용.
- "한 박스 수량"은 본주문 때 박스 × 개수로 전체 수량 파악용. 1688에 없으면 알리왕왕(판매자 채팅, 물방울 아이콘)에 물어보기. 한글로 쳐도 대화됨.
- 샘플은 1~2개씩 넣으면 2~3주면 도착.

■ 8. 샘플 받았을 때 검수 요령
- 같은 공장 주문은 합포장, 다른 업체는 개별 포장으로 옴.
- 송장을 뜯어서 제품과 함께 지퍼백에 보관(구매일·판매자 연락처가 있어 나중에 다시 찾기 쉬움). 테이프 붙은 부분 인쇄는 금방 지워지니 필요한 건 따로 적어 두기.
- 롤모델이 가진 옵션은 전부 주문해서, 개수·색상·구성품(어댑터 같은 부속)이 다 왔는지 하나하나 확인.
- 색상이 같은 게 왔거나 수량이 틀리면 사이트 주문 밑 문의란에 사진+글 → 중국 직원이 확인하고 답글.
- 발송 전 중국에서 옵션 검수해 주는 것도 가능(질문 있었어요).
- 정상 통관 샘플은 나중에 필요 없으면 팔아도 되지만, 개인통관으로 들어온 건 판매 금지.
- 업체 정하고 나면 "칼선"(박스 전개도)을 달라고 하면 줍니다. 그 위에 디자인을 입히면 됨.

■ 9. 1688 가격 네고
- 레벨6 5% 할인 말고도 방법이 많음. 돈 내고 깎는 건 의미 없음.
- 채팅으로 "한 달 판매량 200~300개"만 말해도 95%는 네고됨. 5~20% 할인.
- 교수님 순서: ① 관심 상품 올려놓고 ② 가격은 먼저 묻지 않고 "한 박스 수량" ③ CBM(부피, 운송료 계산용) ④ 그다음 필요 수량을 박스가 딱 떨어지게
- 예: 250개 필요, 박스당 100개 → 3박스. 잘 나가는 검정·회색은 한 박스씩, 나머지 색은 20개씩 섞어 달라고 요청.
- 포장 인쇄부터 바코드까지 중국에서 다 찍어 옵니다.

■ 10. 88 바코드 vs 쿠팡 바코드
- 쿠팡 바코드: 무료지만 쿠팡 물류센터 전용. 올리브영·CJ몰·오늘의집·아이디어스·무신사 같은 입점몰 물류센터에선 안 통해서 나중에 코드 작업을 다시 해야 함.
- 88 바코드: 전국 단일 표준. 소상공인 26만 원 / 일반 36만 원에 바코드 1,000개(판매 수량이 아니라 바코드 개수).
- 바코드는 옵션(색상)별 1개. 4색이면 4개. 그걸로 1만 개를 팔든 10만 개를 팔든 상관없음.
- 교수님 추천: 비용이 들어도 88 바코드. 처음엔 1,000개까지 필요 없으니 나눠 써도 되고(다른 기수는 1개당 1만 원씩), 많이 할 거면 직접 36만 원 내고 받는 게 낫다.
