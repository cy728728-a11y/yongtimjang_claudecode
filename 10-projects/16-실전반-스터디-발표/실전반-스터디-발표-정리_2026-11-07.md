## 1. 구매대행에 적합한 키워드 뽑는 방법

**한 문장**: "누가 2주 기다려서 이걸 사겠어?" 에 "그렇다"고 답할 수 있는 상품에서, 내 카테고리로 노출되고, 경쟁이 적은 키워드를 작은 것부터 잡는다.

### 1-1. 먼저 상품이 구매대행에 맞아야 한다

판단 질문은 하나 — **"누가 2주 기다려서 해외구매대행으로 사겠어?"**

| 빼는 것 | 이유 |
|---------|------|
| 집집마다 하나씩 있는 생활가전·범용품 (드라이기·전기포트·믹서기·에어프라이어·청소기…) | 쿠팡에서 내일 받는데 2주 기다릴 이유가 없다 |
| 국내 어디서나 파는 흔한 생활용품 (박스·수납함·기본 생필품) | 같은 이유 |
| 전기·모터로 작동하는 기계인데 판매가 10만 원 초과 | 구매대행은 수리를 못 한다. 고장 = 환불. 10만 원까지만 감당 |
| 주문마다 치수·견적 상담이 필요한 맞춤 제작 | 직원이 감당 못 한다 |
| 액체류 전부, 배터리 단품, 설치 필요한 야외 구조물, 데우기만 하는 업소용 보온 기계 | 통관·CS·불량 반품 |

| 남기는 것 | 예 |
|-----------|-----|
| 특정 취미·요리를 하는 사람이 찾아서 사는 틈새 가전 | 수비드 조리기, 제면기, 전동 야채 탈수기, 붕어빵 기계 |
| 국내에 없거나 디자인·기능이 독특한 것 | — |
| 충전·무선 공구류 | 무선 고압세척기, 충전 송풍기·분무기 |
| 가구·수동 기구(고장 환불 부담 없음) | 코너 책장, 틈새 행거, 모니터 받침대 |

### 1-2. 카테고리를 먼저 확정한다

- 네이버에서 그 키워드를 검색했을 때 **가격비교가 어느 카테고리로 노출하는지** 본다. 예: "고추 건조기" → 식품 건조기. 그냥 "건조기"는 식기 건조기·세탁 건조기로 퍼진다.
- 스마트스토어 등록 카테고리는 **반드시 그 카테고리와 같아야** 노출된다.
- 상품명에 넣을 서브 키워드도 **전부 같은 카테고리로 노출되는 것만** 고른다. 원칙: "어떤 키워드로 검색해도 내가 등록한 카테고리로 노출돼야 한다."
- 불사자 "최적화 상품명 짓기" 기능이 같은 카테고리 키워드만 보여 준다(수강생용).

### 1-3. 경쟁이 적은 키워드만 남긴다

| 기준 | 수치 |
|------|------|
| 상품수 | **1만 개 이하** 기본. 추천이 6개 미만이면 2만까지 넓힌다 |
| 정보성 키워드 | 뺀다 (쇼핑성만) |
| 브랜드·제조사 키워드 | 뺀다 (다이소·한샘·락앤락 같은 것) |
| 개수 | 억지로 채우지 않는다. 최대 10개 |

### 1-4. 작은 키워드부터 잡는다

- 신규 상품으로 큰 키워드(월 6,000회)는 800위 밖 — 순위가 안 나온다.
- **소형(월 80회)으로 먼저 노출 → 판매 → 인기도 상승 → 중형 → 대형으로 상품명 교체.**
- 대형 키워드에서 상위 노출되면 그때부터는 안 건드려도 자연 노출로 매출이 난다.

### 1-5. 상품명 규칙 (키워드를 쓸 때)

- 키워드는 **붙어 있고, 순서가 맞고, 사이에 다른 단어가 없어야** 한다. 위치(맨 앞·가운데·맨 뒤)는 상관없다.
- "고추 벼 건조기"처럼 사이에 단어가 끼면 꼴등. "건조기 고추"처럼 순서가 뒤집히면 적합하지 않음.
- 텀즈(상품명을 가장 잘게 쪼갠 단어 수)가 넘치면 페널티. 긴 상품명이 아니라 **텀즈 초과**가 문제.
- 순위 확인은 아이템스카우트 → 랭킹 추적 → 실시간(무료)에 키워드 + 스토어명. "내 상품 1등"이 아니라 "어떤 키워드로 몇 위"가 맞는 말.

### 1-6. 도구

| 도구 | 쓰는 것 |
|------|---------|
| 아이템스카우트 | 키워드별 검색수·상품수, 순위 추적 |
| 셀러라이프 | 카테고리 소싱 전체 받기. **네이버 해외배송 비율·쿠팡 해외배송 비율·신규진입 키워드** 열이 있다 — "구매대행에 적합한지"를 숫자로 보여 주는 지표 |
| 불사자 최적화 상품명 짓기 | 같은 카테고리 키워드만 추려 보기 |

> 발표 전 확인: 셀러라이프 해외배송 비율 열의 실제 화면 캡처 1장이 있으면 좋다.

## 3. 타오바오 88VIP 가입 방법 (2026년 11월 보완판)

**한 문장**: 타오바오 점수 1,000점을 채우고 88위안에 **쇼핑카**로 가입하면, 5% 할인과 반품 보조로 연회비는 한 달이면 뽑는다.

기준 자료는 맴쌤 블로그(2025-04) 「타오바오 88VIP 가입 방법 혜택 총정리」. 그 뒤 바뀐 두 가지(카드 3종·반품 한도)를 보완했다.

### 3-1. 88VIP가 뭔가

- 타오바오·티몰 공통 연회비 멤버십. 2026년 6월 말 기준 회원 약 6,400만 명.
- 셀러에게 의미: **상품 5% 할인**(티몰 슈퍼마켓·티몰 글로벌·지정 브랜드), **반품 운송비 보조**, **매일 2위안 홍바오**, 전용 고객센터 → 사입 원가와 반품 손실이 줄어든다.

### 3-2. 가입 조건

| 조건 | 내용 |
|------|------|
| 타오바오 점수(淘气值) | **1,000점 이상 → 88위안/년**(올인원카 168위안) · **1,000점 미만 → 888위안/년** |
| 점수 갱신 | 매월 8일 |
| 점수 산정 | 최근 12개월의 타오바오·티몰·飞猪·淘票票 이용 실적 |
| 알리페이 | 실명(여권) 인증 + 카드 등록 |
| 결제 | 연회비는 알리페이로. 유효기간 가입일부터 365일, 본인 계정만 |

**숫자 콜아웃**: 1,000점 전후로 **10배**(약 18만 원 vs 1.8만 원). 999점이면 기다린다.

### 3-3. 점수 올리는 법

- 가입만 해도 기본 400점. 실명 인증·알리페이 연결·휴대폰 연결 등 계정 정보를 다 채우면 기본 점수 만점.
- 나머지 600점은 구매 실적. 구매대행 셀러는 주문이 곧 점수.
- 사진 후기·구매 질문 답변 → 가산. 상품과 무관한 내용은 감점.
- 가족 계정 연결: 첫 연결 +20점, 이후 1명당 +10점(최대 3명).
- 88VIP 도전 과제: 마이페이지 88VIP 표시를 누르면 과제가 뜨고, 아주 싼 상품 결제로 달성.
- 대형 행사 때 문턱이 내려간 적 있음(2024 광군제 800점). 살짝 모자라면 618·광군제를 노린다.

### 3-4. 가입 절차 (앱, 4단계)

**준비**: ① 타오바오 가입 → ② 알리페이 가입 + 여권 인증 → ③ 알리페이 카드 등록 → ④ 알리페이–타오바오 연동

1. 타오바오 앱 → 마이페이지(我的淘宝) → 상단 **88VIP**
2. 내 점수 확인. 1,000점 미만이면 "○○점 부족" 안내 → 가입하지 말고 점수를 채운다
3. **카드 종류 선택**(아래 3-5) → 「立即开通」(즉시 개통)
4. 알리페이로 결제 → 바로 적용

**결제 수단 주의**: 블로그(2025-04)에서는 알리페이에 **등록한 카드로는 안 되고 충전 잔액으로만** 결제됐다. 잔액이 없으면 중국 판매자에게 "카드로 결제할 테니 알리페이로 넣어 달라"고 부탁하는 요령. 2026년 해외 자료는 연결 카드도 결제 수단으로 들고 있어 자료마다 다르다 → 발표 전 직접 확인.

### 3-5. 바뀐 것 ① — 카드가 세 종류

| 카드 | 연회비(1,000점 이상) | 들어 있는 것 | 누구용 |
|------|---------------------|--------------|--------|
| 생활카(生活卡) | 88위안 | 优酷·芒果TV·网易云·饿了么 등 중국 생활 서비스 회원권 | 중국 거주자 |
| **쇼핑카(购物卡)** | **88위안** | **매일 2위안 홍바오, 반품 운송비 보조, 사후 보장** | **구매대행 셀러** |
| 올인원카(全能卡) | 168위안 | 둘 다 | 둘 다 쓰는 사람 |

→ 같은 88위안이면 **쇼핑카**. 생활카의 영상·배달 혜택은 한국에서 쓸 일이 없다.

### 3-6. 바뀐 것 ② — 무료 반품은 "무제한"이 아니다

| 시점 | 규칙 |
|------|------|
| 2024-04 ~ 2025-02 | 반품 운송비 **무제한** 보조(블로그가 쓰인 시기) |
| **2025-02-18 이후 가입·갱신** | **건당 최대 25위안, 월 누계 50위안, 1년 누계 288위안.** 월 한도는 31일 단위 |
| 2026 | 사용자 실측으로 "월 50위안 + 연간 총액" 이중 한도 유지 확인 |

- 체감: 한 달 반품 2~4건, 1년 10여 건이 무료. 반품 많은 셀러는 "무제한"으로 알고 있으면 안 된다.
- 한도가 화면 앞에 안 보여 반품하고 나서야 차감을 아는 경우가 많다 → 권익 페이지에서 남은 한도 확인 습관.
- 판매자의 반품 보험(退货宝)을 써도 88VIP 한도가 깎인다는 제보. 한도·무게 초과분은 본인 부담.

### 3-7. 혜택 정리 (셀러가 쓰는 것)

| 혜택 | 내용 |
|------|------|
| 상품 5% 할인 | 티몰 슈퍼마켓·티몰 글로벌·지정 브랜드 자동 적용. "88VIP" 표시가 뜨면 대상 |
| 매일 2위안 홍바오 | 하루 1장, 금액 조건 없음, 모바일 결제만. 다른 쿠폰과 중복 가능 |
| 반품 운송비 보조 | 월 50·연 288위안 한도 |
| 전용 고객센터 | 분쟁·환불 처리 빠름 |
| 대형 행사 쿠폰 | 618·광군제 때 "3,000위안 이상 240위안 할인" 같은 대형 쿠폰 선점 |

### 3-8. 주의

- 연회비 환불 안 됨. 자동 갱신이 기본으로 켜진 경우가 많다 → 알리페이 자동 결제 메뉴에서 해지. 해지해도 남은 기간 혜택 유지.
- 제3자 "88VIP 싸게 대신 개통"은 사기 사례 있음. 본인 앱에서만.
- 계정이 여러 개면 **사입 주력 계정 하나에만**.

> 발표 전 확인: ① 한국 카드로 연회비 결제가 되는지 ② 내 계정의 현재 가격·점수 화면 캡처(2026년 기준 근거).

## 4. 셀프 상표권 출원

**한 문장**: 대행사가 한 일은 "제출 버튼"이었다. 머리 쓰는 일(지정상품 10개)은 어차피 내가 한다 — 그러니 셀프.

### 4-1. 경험담 — 대행사가 한 일이 뭐였나

- 마크인포로 출원할 때 담당자가 전화해서 **"보통 35류로 하는데, 지정상품 10개를 고르세요"**.
- 10개를 **내가 직접 골랐다.** 서류 제출은 그쪽이 했지만 머리 쓰는 일은 내가 했다.
- 결론: 대행사가 해 준 건 "제출 버튼". 그건 내가 눌러도 된다.

### 4-2. 절차는 쉽다

| 항목 | 내용 |
|------|------|
| 방법 | 특허청 전자출원 가입 → 출원서 작성 → 수수료 결제. 블로그·유튜브 매뉴얼대로 **5~10분** |
| 비용(셀프) | 출원 약 5만 원 + 등록 약 25~30만 원 ≈ **28만 원** |
| 지정상품 | 기본 10개, 11개째부터 개당 2천 원 |
| 심사 기간 | 일반 1년~1년 반 / 우선심사 3~4개월(비용 약 2배, 50~60만 원) |
| 요령 | 급한 10개만 1건으로 우선심사, 나머지는 다른 1건에 몰아 일반심사 |
| 주의 | 등록 뒤 지정상품 **추가 불가**(새로 출원) → 처음 10개를 꼼꼼히 |

### 4-3. 어려운 건 지정상품 10개

- 상표는 이름만 등록하는 게 아니라 **"이 이름을 어떤 상품·서비스에 쓰겠다"(지정상품)**를 같이 적는다. 류(類)는 그 상품의 분류 번호.
- 구매대행 셀러는 **35류(도소매·통신판매·광고)**를 기본으로 깔고, 실제 파는 상품의 류를 더한다.
- 지정상품 이름이 수천 개라, 뭘 골라야 내 사업 범위가 빠짐없이 덮이는지 처음엔 감이 안 온다.

### 4-4. 팁 — 가격비교 상단 브랜드를 베낀다 (6단계)

1. **내가 주로 파는 상품 하나**를 정한다.
2. 네이버 **가격비교에서 그 상품명을 검색**하고 상단 **브랜드 5~8개**를 적는다.
3. **키프리스(kipris.or.kr)** 에서 브랜드명으로 상표 검색. 안 나오면 **대표자 이름**으로.
4. 출원 건마다 **지정상품을 전부 펼쳐 본다**("더보기"·"+" 꼭 누르기). 류·상품명을 표로.
5. 브랜드 5~8개의 표를 겹치면 **공통으로 들어간 류·상품명**이 보인다 = 그 시장의 표준 답안.
6. 거기서 **내 사업 범위에 맞는 10개**. 아직 안 파는 품목도 **다음에 팔 계획이 있으면 미리 넣는다** — 잘하는 브랜드들은 다 그렇게 한다.

> 상담 때 들은 말: "벤치마크 브랜드 지정상품을 정리해 내 사업 범위에 맞게 고르면 빠지는 게 거의 없다. 절차는 유튜브로 5~10분, 시간 걸리는 건 지정상품 고르기뿐."

### 4-5. 같이 알아 두면 좋은 것

- **이름 확인 순서**: ① 키프리스 검색 ② 네이버 검색광고 조회수(10 이하면 사실상 없는 이름) ③ 네이버 검색(우리만 모르는 유명 브랜드인지).
- **좋은 이름**: 짧고, 발음 쉽고, 어디에도 없는 이름. 특정 상품에 갇히지 않는 이름.
- **한글 vs 영문**: 국내는 발음 기준이라 효과 같음. 해외까지 보면 **영문 출원**(국내에선 한글로 써도 됨). 상표는 나라별 권리라 한국 먼저, 진출할 때 국제출원.
- **디자인권**: 셀프 약 30만 원, 3~6개월. 이미 중국에서 팔던 디자인이면 무효될 수 있지만 무효시키려면 소송(250만 원~)이라 **"진입을 막는 벽"으로는 30만 원 값어치**.

### 4-6. 마무리 멘트

- "나도 아직 셀프 출원은 안 해 봤다. **다음 달 되기 전에 직접 출원하고**, 막힌 데·걸린 시간·비용을 다음 스터디에서 공유하겠다."
- 그동안 각자: 주력 상품 하나 정해서 가격비교 상단 브랜드 키프리스 조회 → 지정상품 표 만들어 오기.

> 슬라이드 메모: 특정 상품 예시는 보여 주지 않는다. 키프리스에서 상표 하나 열어 지정상품 펼친 화면 1장(브랜드명 가려도 됨)이 있으면 좋다.

## 5. 클로드·코덱스 계정 2개로 한도 최대한 쓰는 법

**한 문장**: 주간 한도가 바닥나면, 다음 달 결제를 다른 계정으로 넘겨서 그 주 안에 0%에서 다시 시작한다. 구독료는 하나 그대로.

출처: 카이안, 디하클(디노 하이클래스) 네이버 카페 글 「클로드 코드·코덱스 무료로 더 쓰는 꼼수 2가지」. 코쿠쿠님이 2026-10-29 공유.

### 5-1. 원리 — 결제일과 주간 한도 초기화는 따로 돈다

- 주간 한도는 결제일에 풀리는 게 **아니다**. 계정마다 정해진 **요일·시각에 매주** 0%로 돌아간다(글쓴이 계정은 화요일).
- 그래서 이번 주 84%를 쓴 계정에 다음 달 결제를 해도, 결제한 날 남은 건 **16%**. 새 달이 돼도 이번 주 사용량은 그대로.

### 5-2. 방법 (4단계)

1. 계정을 두 개 만들어 둔다(A, B).
2. A로 그 주 한도를 끝까지 쓴다.
3. 다음 달 결제할 때 A가 아니라 **B로 결제를 넘긴다**.
4. B는 그 주에 쓴 게 없으니 **바로 0%에서 시작**.

→ 결제를 두 번 하는 게 아니다. **결제하는 계정만 번갈아** 바꾼다.
→ **클로드든 코덱스든 같은 원리.** 코덱스에 따로 방법이 있는 게 아니다(용팀장 확정).

### 5-3. 글쓴이의 실제 기록

| 날짜 | 내용 |
|------|------|
| 10/22 | A 계정 96% 사용. A 초기화는 10/27 00시 |
| 10/23 09:07 | B로 바꾸자마자 **주간 사용 0%**. B 초기화는 10/27 08시 |
| 10/23~10/27 | 6일 동안 B로 100%까지 사용 |
| 10/27 08시 | B 다시 0%로 초기화 |

근거: 화면 아래 상태줄에 10분마다 찍힌 사용량 기록 242건.

### 5-4. 주의

- **이득 보는 경우**: 결제일 즈음 주간 한도가 바닥나 며칠씩 손 놓고 있을 때. **그 주에만 한 번** 효과. 매주 한도를 늘려 주는 방법은 아니다.
- **먼저 볼 것**: 내 계정 주간 초기화가 무슨 요일 몇 시인지(상태줄 또는 사용량 메뉴).
- **계정 공유(한 계정을 여럿이) 금지** — 글쓴이도 강조.
- 글은 "공식 기능 안에서 하는 방법"이라지만 이용 규칙에 걸리는지는 확인 안 됨 → **출처를 밝히고 "이런 방법이 있다" 수준으로** 소개.

> 발표 전 확인: 이용 규칙 한 번 보기. 가능하면 내 계정 상태줄 캡처(초기화 요일 보이는 것).

## 6. 피클 AI 소개 + 용팀장 사용법

**한 문장**: 클로드 코드가 컴퓨터 앞 직원이라면, 피클은 휴대폰 속 비서다.

### 6-1. 피클이 뭔가 (짧게)

- 한국 팀(YC 출신)이 만든 **휴대폰용 AI 비서 앱**. 답만 하는 게 아니라 **주문·예약·민원·전화를 대신 한다.**
- 다른 에이전트와 다른 점:

| 구분 | 다른 에이전트 | 피클 |
|------|--------------|------|
| 위치 | 컴퓨터 앞 | 휴대폰 안 |
| 역할 | 일을 돕는 동료 | 일을 돕는 비서 |
| 맡기는 일 | 회사 업무 | 쇼핑·예약·민원 같은 일상 |
| 기본 연결 | 해외 서비스 | 네이버·쿠팡·코레일·정부24 등 한국 서비스 |
| 쓰는 법 | 설정 필요 | 말 한마디 |

- **가격**: 한국에서는 무료. 하루 사용량 제한, 새벽 4시 초기화. 초기화 티켓은 구매 또는 친구 초대로.
- **가입**: 아이폰·안드로이드. 아직 베타라 **초대 링크 필요** — 스레드에서 "피클" 검색하면 링크 공유하는 사람이 많다.
- 할 수 있는 일: 쿠팡·무신사·다이소몰 주문(결제 전 **승인 카드** 확인), 캐치테이블·네이버 예약, 코레일 잔여석 조회·예매, CGV 예매, 정부24 민원 서류(캡챠는 사람에게 넘김), **전화 걸기**(모닝콜·요금제 변경·환불 요청), 정해 둔 시간에 알아서 실행, 아침 브리핑, 피클끼리 일정 조율.

### 6-2. 용팀장은 이렇게 쓴다 (발표의 알맹이)

| 쓰임 | 어떻게 | 왜 피클인가 |
|------|--------|-------------|
| **메일 보고** | 여러 이메일을 메인 지메일 하나로 전달(포워딩)해 모으고, 그 지메일 하나만 피클이 읽고 보고 | 메일함 여러 개를 일일이 안 열어도 됨 |
| **아침 7시 30분 모닝콜** | 피클이 **전화**를 걸어 그날 **날씨 + 타임트리 일정**을 말해 줌 | 다른 AI는 보통 구글 캘린더만 붙는데 피클은 **타임트리와 연동**. 구글 캘린더로 갈아타는 큰 일을 안 해도 됨 |
| **기차표** | 코레일 예매를 대신 | 말 한마디로 조회·예매 |

→ 스터디원에게 가장 와닿을 포인트: **"쓰던 앱(타임트리)을 안 바꿔도 된다."**

### 6-3. 보여 주면 좋은 장면

- 모닝콜 통화 기록 화면(또는 녹음) 1장 — 설명이 필요 없어진다.
- 메일 보고 화면 1장.
- 코레일 잔여석 조회 화면 1장.

### 6-4. 주의

- 피클도 실수한다. 확인 없이 호텔에 전화를 건 사례, 조사 내용이 그럴듯하게 틀린 사례가 있다.
- 처음엔 작은 일부터. **결제·예약은 승인 카드에서 직접 확인.**
- 내 계정(쿠팡·코레일·메일)을 연결하는 구조라 **어디까지 맡길지 선을 정하는 것**이 중요.
