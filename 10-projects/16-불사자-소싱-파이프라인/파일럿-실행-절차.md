# 재수확 파일럿 실행 절차 (용팀장이 하는 것 / Claude가 하는 것)

작성 2026-11-10 · 설계서 `docs/superpowers/specs/2026-11-08-sourcing-pipeline-design.md` 7절

## 왜 하나

기존 마켓을 매주 "3일베스트"로 다시 돌리면 마켓 하나에서 새 상품이 몇 개 나오는지(재수확 수율)를 모른다. 이 숫자가 없으면 월 14만 통과 공급이 가능한지 계산이 안 된다. 그래서 마켓 2,000개로 한 번 재서 숫자를 뽑는다.

## 용팀장이 하는 것 (한 번, 10분)

1. 불사자 엔잡곰소싱기에서 **새 캠페인**을 만든다.
   - 이름: `R-YYMMDD-파일럿3일` (YYMMDD는 오늘 날짜, 예 `R-261110-파일럿3일`)
   - 방식: **마켓 모드** → **3일베스트**
   - 가격: **3만 원 ~ 50만 원**
   - 마켓당 최대: **100개**
   - 나머지 조건(비브랜드·해외배송 등)은 28765 캠페인과 같게
2. 마켓 칸에 **`pilot_markets_261110.txt`**(이 폴더에 있음, 2,000줄) 내용을 그대로 붙여넣는다.
3. 실행한다.
4. 캠페인을 열었을 때 **주소창에 보이는 캠페인 ID**(영문·숫자 15자 정도)를 Claude에게 알려 준다. 크롬 확장이 연결돼 있으면 Claude가 직접 읽어 가도 된다.

이게 끝이다. 나머지는 Claude 몫.

## Claude가 하는 것

1. 수집이 끝나기를 자동으로 기다린다(상품 수가 30분 동안 안 늘면 끝으로 본다).
2. 이미 본 상품(네이버 번호 장부)을 걸러 휴지통으로 보낸다.
3. 1차(금지 카테고리·금지어) → 이미지 매칭 → 이미 본 타오바오 물건 걸러내기 → 2차 AI 검수.
4. 통과 상품을 '신규소싱상품'으로 상품수집한다. **이번 회차는 '소싱테스트_통과'로 옮기지 않는다**(옮기기 자동화는 2단계). 숫자만 보고한다.
5. 장부에 기록하고 보고서를 이 폴더에 남긴다.

## 보고서 읽는 법

- **첫 줄**이 결론이다: "월 공급 예측 B = N건 / 목표 140,000 / 차이 ±M".
  - 차이가 +면 재수확만으로 충분. −면 그만큼을 새 마켓 전체 이력·3만~5만 원 전체 이력·회차 추가로 채워야 한다.
- **묶음별 표**: 상위 1,000(상품 많이 낸 마켓)과 무작위 1,000의 마켓당 통과를 비교한다. 상위가 2배 이상 많이 내면 앞으로 재수확 대상을 상위 마켓으로 좁혀 소싱기 시간을 아낄 수 있다.
- 중복 제거 수가 크면 정상이다. 3일베스트는 전에 팔린 상품을 또 담기 때문이고, 그걸 공짜로 걸러낸 게 장부의 역할이다.

## 막혔을 때

- Claude가 "웹 토큰 만료"라고 하면: 맥북 크롬(Claude 확장 붙은 프로필)에서 불사자에 cy17281728 구글 계정으로 다시 로그인만 해 주면 된다. 비밀번호는 Claude에게 주지 않는다.
- 수집이 48시간 넘게 안 끝나면 Claude가 멈추고 알린다. 그 PC의 인터넷·소싱기 상태를 봐 달라는 뜻이다.
