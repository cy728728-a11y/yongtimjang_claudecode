### 3. 물갈이 후 광고 재투입 (자동화 막힘)

물갈이 재업로드 뒤 **광고에 소재를 새로 넣는 일**은 여전히 수작업이다
(네이버 광고 UI 에서 미투입 상품 전체 선택).

**2026-08-30 실측: 광고 API 에 "광고 미투입 상품 목록" 엔드포인트가 없다.**
`/ncc/product-group` · `/ncc/shopping-products` · `/tool/shopping-products` ·
`/ncc/channel-products` 전부 404. 비즈채널(`/ncc/channels`) 아래에도 상품 목록이 없다.

소재 등록(`POST /ncc/ads`) 자체는 `nccAdgroupId` + `referenceKey`(네이버쇼핑 상품ID) + `type`
만 있으면 될 것으로 보이나, **재업로드된 새 상품의 `referenceKey` 를 얻을 방법이 없다.**
커머스 API 로 우회 가능성이 있으나 현재 앱 권한에 상품 조회 스코프가 없다(403).

## 반드시 알아야 할 함정 5가지

1. **`/stats` 의 `convAmt`·`ccnt` 는 장바구니 포함 총전환이다.** 구매완료는 `AD_CONVERSION` 리포트의
   `purchase` 유형만. 실측 차이 **14배**(총전환 ROAS 3,844% vs 구매완료 275%).
2. **`salesAmt` 는 매출이 아니라 광고비다.**
3. **그룹입찰 상품의 인상 출발점은 그룹 기본가다.** 소재의 `bidAmt` 는 잠자는 값이다
   (실측: 잠자던 값 50 / 그룹 기본가 150 — 헷갈리면 올리려다 90원 내린다).
4. **노출 0 소재는 `/stats` 응답에서 행 자체가 빠진다.** 그래서 규칙 ① 은 역산이다.
5. **리포트는 D-2 부터 쓸 수 있다.** D-1 은 `20007 지표 준비중`.

## 미해결

**`AD_ABNORMAL_INTERLOCK` 은 고장이 아니다 — 물갈이 20일 사이클의 부산물이다** (2026-08-30 확인).
물갈이 삭제로 스마트스토어 상품이 사라지면 광고 소재가 연동을 잃고 자동 정지된다.
