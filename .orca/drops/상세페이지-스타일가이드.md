## 왜 AI 티가 나는가

예시 없이 만들면 AI는 아래를 기본값으로 깐다. 레퍼런스 3개 중 **어디에도 없는 것들**이다.

- 그라데이션 배경, 보라·초록 계열 색
- 이모지, 체크(✓) 아이콘 목록, 아이콘과 3열 카드 묶음
- 그림자 진 둥근 카드를 섹션마다 반복
- 모든 섹션이 똑같이 "가운데 제목 + 가운데 본문"
- 굵기 한 종류, 큰 글씨 남발
- "혁신적인", "프리미엄", "완벽한" 같은 형용사

→ 프롬프트에 **금지 목록 + 실측 숫자 + 레퍼런스 이미지**를 같이 넣어야 안 나온다.

## 스타일 3종 (실측)

### A. 갤러리형 — 엔알세라믹스 힌
> 사진이 주인공이다. 글은 거의 없다. 그릇·인테리어 소품·패브릭처럼 생김새로 파는 상품

| 항목 | 값 |
|---|---|
| 배경 | 글 섹션은 흰색 `#FFFFFF`, 사진 배경은 따뜻한 회백 `#D8D8D0`~`#E0E0D8` |
| 영문 제목 | **얇은 세리프** (Cormorant Garamond 계열), 약 44~50px, `#111111` |
| 한글 본문 | 본고딕(Noto Sans KR) Regular, 약 28px, 줄간격 44px(1.6배), `#1E1E1E` |
| 정렬 | 브랜드 소개는 가운데, 상품 정보는 왼쪽(여백 44px) |
| 스펙 표기 | `Size  W23.5 x D21 x H3.5 (cm)`처럼 영문 라벨 + 값, 선·표 없이 줄만 맞춤 |
| 사진 | 가로 꽉 차게, 사진 위에 글자 없음. 사진 사이에 흰 줄 6px |
| 색상 옵션 | 같은 각도로 찍은 컷 3장을 나란히 + 아래 영문 색이름 |
| 비율 | 사진 약 85% : 글 15% |

### B. 정보형 — 알엠에스 세라믹 플레이트
> 차분한데 설명이 충분하다. 기능·소재·안전성을 말해야 하는 생활용품 대부분에 맞음. **구매대행 기본값으로 추천**

| 항목 | 값 |
|---|---|
| 배경 | 글 섹션은 흰색 `#FFFFFF`, 사진 배경은 연회색 `#F0F0F0` |
| 소제목 | Pretendard SemiBold, 약 42~44px, `#303030`. 영문 한마디("About 700g", "Ceramic Plate") 또는 한글 짧은 구 |
| 본문 | Pretendard Regular, 약 27px, 줄간격 43px(1.55배), `#4A4A4A` |
| 각주·출처 | 약 19px, `#9E9E9E` |
| 정렬 | **전부 왼쪽 정렬**, 왼쪽 여백 48px |
| 간격 | 소제목→본문 약 50px, 문단 사이는 빈 줄 하나(86px), 섹션 위아래 여백 약 80px |
| 문장 | 섹션당 2~3줄 × 1~3문단. "~했습니다" 체. 한 줄에 한 생각 |
| 라인업 | 번호 동그라미(01·02) + 제품컷 + 오른쪽에 이름·설명 3줄, 사이에 얇은 회색 선 |
| 신뢰 요소 | 시험성적서를 흰 바탕에 작게 + 설명 3줄. 배지 없음 |
| 사진 순서 | 제품 단독 → 사용 장면(음식·손) → 디테일 클로즈업 → 자연·공정 사진 |

### C. 세일즈형 — 매직캔 히포2
> 판매 장치(옵션 비교·기능 포인트)가 많은데 정신없지 않다. 공산품·기능 비교가 필요한 상품

| 항목 | 값 |
|---|---|
| 배경 | 아이보리·베이지 한 톤 `#F8F8F6` → `#E8E4DC`. 공간 사진도 같은 톤 |
| 강조색 | **진갈색 하나만**: `#514733` (제목·띠 배경 모두 이 색) |
| 큰 제목 | 굵은 고딕(G마켓산스 Bold 계열), 약 56~64px, 가운데 정렬, `#514733` |
| 강조법 | 한 줄 안에서 굵기만 바꿈: "커터로 **자르면** 자동으로 **묶이는**". 색을 바꾸지 않음 |
| 본문 | 약 36~40px, 줄간격 60px, `#4F4838`. 화면에서 보면 B보다 큼 |
| 영문 장식 | 디돈 세리프(Playfair Display 계열) 80~100px: "OPTION", "Select Point" + 아래 한글 부제 |
| 비교 띠 | 진갈색 띠 + 흰 글씨 2줄 ("히포1 … 기본형 / 히포2 … 고급형") |
| 포인트 표 | 사진 ↔ 글 지그재그 2열, 작은 둥근 라벨(`#8A7F70` 배경, 흰 글씨) |
| 주의 | 상단 이벤트 배너·민트 봉투처럼 **제품 색이 튀면 톤이 깨진다** → 구매대행에선 이벤트 섹션 빼기 |

## 공통 규칙 (3개 모두 해당)

1. 배경 한 톤 + 강조색 0~1개. 글자색은 순검정 대신 진회색(`#1E1E1E`~`#4A4A4A`)
2. 글자 굵기는 2단계만 (제목 SemiBold·Bold / 본문 Regular)
3. 사진 위에 글자를 얹지 않는다 (C의 히어로 로고 1곳만 예외)
4. 영문 한마디 소제목 + 한글 2~3줄 설명
5. 스펙·소재·주의사항은 맨 끝, 선 없는 작은 표

## 아스트라 프롬프트용 스타일 블록

상품에 맞는 블록 하나만 골라 붙이고, 같은 이름의 레퍼런스 보드 이미지를 함께 첨부한다.

### B 정보형 (기본)
```
[스타일 — 레퍼런스 이미지와 같은 톤으로]
- 가로 860px. 글 섹션 배경 #FFFFFF, 제품사진 배경 #F0F0F0
- 소제목: Pretendard SemiBold 42px #303030, 영문 한마디 또는 한글 짧은 구
- 본문: Pretendard Regular 27px, 줄간격 43px, #4A4A4A, 왼쪽 정렬, 왼쪽 여백 48px
- 섹션당 본문 2~3줄 × 최대 3문단. 문단 사이는 빈 줄 하나. 섹션 위아래 여백 80px
- 각주는 19px #9E9E9E
- 사진 순서: 제품 단독 → 사용 장면 → 디테일 → 스펙
```

### A 갤러리형
```
[스타일]
- 가로 860px. 글 배경 #FFFFFF, 사진 배경 #DCDCD4(따뜻한 회백)
- 영문 제목: Cormorant Garamond 46px #111111 / 한글 본문: Noto Sans KR Regular 28px, 줄간격 44px, #1E1E1E
- 글은 전체의 15% 이하. 사진은 가로 꽉 차게, 사진 사이 흰 줄 6px
- 스펙은 'Size  W00 x D00 x H00 (cm)'처럼 영문 라벨 + 값, 표·선 없이
```

### C 세일즈형
```
[스타일]
- 가로 860px. 배경 아이보리 #F8F8F6~#E8E4DC 한 톤. 강조색은 진갈색 #514733 하나만
- 큰 제목: G마켓산스 Bold 60px #514733 가운데 정렬. 강조는 같은 줄에서 굵기만 바꿔서
- 본문 38px, 줄간격 60px, #4F4838
- 섹션 라벨은 Playfair Display 90px 영문 한 단어 + 아래 한글 부제
- 기능 포인트는 사진↔글 지그재그 2열, 라벨은 #8A7F70 둥근 알약 모양에 흰 글씨
```

### 금지 목록 (모든 블록에 같이 붙임)
```
[금지]
그라데이션, 보라·초록·파랑 계열, 이모지, 체크·아이콘 목록, 그림자 카드 반복,
아이콘+3열 카드 묶음, 모든 섹션 가운데 정렬, 사진 위 글자,
"혁신적인·프리미엄·완벽한·최고의" 같은 형용사, 번역투("~하는 것이 가능합니다", "~를 통해")
```

## 남은 것

- 오늘의집 2개(하우스레시피·layer 수건)는 차단으로 실측 못 함. 필요하면 브라우저로 따로 캡처
- 폰트 이름은 눈으로 본 추정이다(측정값 아님). 크기·색·간격은 실측
- 레퍼런스 이미지는 **스타일 참고용**. 사진·문구를 그대로 쓰면 안 되고, 영상에 띄울 땐 출처 표기
